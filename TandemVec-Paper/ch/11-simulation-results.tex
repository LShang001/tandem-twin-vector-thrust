\section{数值仿真实验与验证}
\label{sec:simulation_results}
\label{sec:simulation}

本章将可复验的配平、模态和积分结果，与历史高保真控制器脚本输出分层报告。
自动测试通过只说明既定软件行为未回归，脚本运行成功只说明给定模型与初值产生了输出；
二者都不能替代参数标定或固件闭环试验。当前控制器脚本尚未逐式对齐固件，
故其表格保留作方法审计和后续复现实验基线，不作为控制器性能排名。

\label{fig:rk4_euler}

恒定角速率$\omega=(0,0,1)^T$\,rad/s、$dt=0.004$\,s、$T=60$\,s条件下，
四元数状态误差分别为$\lVert q_{\mathrm{Euler}}-q_{\mathrm{theo}}\rVert_2=3.99999\times10^{-5}$

该结果只验证这一对照问题中的离散精度。

\subsection{历史INDI脚本结果的实现审计}

历史脚本曾报告俯仰与滚转累积误差改善，但当前审计发现其算法与固件并不同构：
脚本采用相反方向的四元数误差、$\bm u_k=\bm u_{k-1}+\Delta\bm u_k$增量累加、
固定工作点和$\pm25^\circ$限幅；固件采用绝对分配、电机模型观测器、增益调度、
惯量前馈和$\pm15^\circ$限幅。因此本节保留的百分数只描述历史脚本输出，
不再表述为当前INDI或固件闭环的性能验证。

\subsection{轴间耦合抑制历史对比的审计}
\label{sec:coupling_rejection}

第\ref{sec:allocation}节的反扭矩投影说明全矩阵分配具有主动补偿交叉项的潜力。
下述实验可用于展示这一机理，但不能代表当前固件：Web默认SAS、脚本INDI和固件BTRUE
分别采用不同状态、误差方向与分配方式。

\textbf{历史实验设置}：\texttt{sas\_vs\_indi\_coupling.py}实际使用24\,m/s、单位四元数和
固定$0.441\omega_{\max}$工作点，并非28\,m/s四方程配平。脚本在前摆施加$10^\circ$阶跃，
用俯仰角峰值作为耦合指标；表中“5次Monte Carlo均值”缺少当前代码可追溯的种子与逐次输出。

在该历史脚本内部，结果呈现如下趋势：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{SAS的耦合峰值（$1.63^\circ$）与噪声无关}——这是对角分配的\textbf{结构性}局限。由于分配矩阵不含交叉项，前摆产生的俯仰耦合$-\tau_f\sin\delta_f$完全未被前馈补偿，只能依赖俯仰角速率阻尼和姿态反馈被动衰减，其峰值由耦合量级与闭环带宽决定，与传感器噪声无关。这是几何解耦近似的固有代价（第\ref{sec:allocation}节）。
    \item \textbf{历史理想脚本中的主动解耦趋势}：全矩阵逆把交叉项纳入分配，表中峰值较小；
          这说明方法机理值得复验，但不能单独验证INDI或固件性能；
    \item \textbf{角加速度估计敏感性}：历史表中加入噪声后峰值增大，符合差分噪声经矩阵逆
          进入增量指令的机理；由于试验条件不统一，不再据数值倍数宣称优于SAS。
\end{enumerate}

\textbf{证据边界}：表中差异同时包含控制算法、工作点、误差方向、执行器动态和限幅差异，
不能归因于INDI本身，也不能支持“数量级改善”或控制器优劣排序。正式比较必须共享同一植物、
初值、约束、随机种子和数据导出管线。

\subsection{角加速度估计器历史对比的审计}
\label{sec:estimator_study}

第\ref{sec:INDI}节§\ref{sec:accel_estimation}讨论了角加速度获取方法。
历史正文把\texttt{compare\_estimators.py}描述为“每条件6次Monte Carlo”，但当前代码每个条件
只以默认seed 0调用一次，无法生成表中的均值与标准差。因此以下表格保留为历史数据审计对象，
而不是当前可复现统计结果。

\textbf{估计器实现}（统一接口，接入INDI替换差分项）：
\begin{itemize}
    \item \textbf{后向差分}：只使用当前与上一采样点，但不是“零延迟”；微分会放大高频噪声；
    \item \textbf{Savitzky-Golay滤波}：半窗$M=3$、二阶多项式，中心窗群延迟为
          $M\Delta t=12$\,ms，而不是4\,ms；
    \item \textbf{Kalman滤波实现}：类名含“FixedLagSmoother”，但当前历史缓存未用于回溯平滑，
          实际代码是普通Kalman滤波，不能按$N=2$报告固定滞后平滑性能；
    \item \textbf{自适应互补滤波}：模型前向预测（含刚体转动、陀螺、Coriolis项）与数值差分融合，截止频率随角加速度残差自适应（$20$--$150$\,rad/s）。
\end{itemize}

历史表格提示延迟--噪声权衡，但具体排序还不能复验：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{零噪声历史趋势}：表中差分项较小，但S--G的实际中心窗延迟为12\,ms，
          所谓固定滞后实现也未执行回溯平滑；因此原先把$2.8$--$3.2^\circ$完全归因于
          “4--8\,ms同步效应”的解释需要重做。
    \item \textbf{历史表中的中高噪声趋势}：自适应互补项在表中较低，但其均值、标准差和
          截止频率实现尚未由同一代码链重建，不能称为“首次在本构型定量验证”或最优结论；
    \item \textbf{自适应互补的优势依赖模型通道准确性}：进一步的完整闭环实验发现，当模型预测通道所用的控制输入先验与实际电机响应存在偏差（电机一阶滞后导致增量指令与实际推力不一致）时，自适应互补的估计方差反而增大（$\pm 0.95$）。因此其工程应用前提是模型通道与实际执行器动态的一致性标定。
\end{enumerate}

\textbf{工程含义}：选择估计器前应先重建可重复的噪声、延迟与执行器同步试验，
报告采样率、滤波相位、随机种子和原始时序。当前证据不足以推荐某一方案用于HIL或实机。

\subsection{模型参数敏感性}

上述数值结果对气动导数不确定性敏感。若仅把$C_{m\alpha}$按$\pm30\%$缩放并用
$\sqrt{1\pm0.3}$估计频率变化，只能得到启发式量级，不能同时推断阻尼比；
正式敏感性分析应对完整模型重新配平、重新线性化，并报告极点与参与因子的变化。

\subsection{实机初步验证（2026-08）}
本文写作时（v0.2.0 参数集，MODEL-DEFAULT 未标定）仿真结论仍属概念级；
2026-08起项目记录进入实机首飞阶段，以下条目用于说明部署状态与待归档证据：
\begin{itemize}
    \item \textbf{轴语义}：手动直通确认\texttt{roll\_raw}$\to$上摆、
          \texttt{pitch\_raw}$\to$下摆（第\ref{sec:axis_semantics}节）；
    \item \textbf{$k_Q/k_T$}：三轮调参记录收敛到约0.027，但不是独立推力--扭矩台架标定；
    \item \textbf{差速工作点}：接入$\tau_m$开环模型估计后，项目记录中的抖油门振铃减弱；
          仍需原始阶跃日志和重复试验量化；
    \item \textbf{滤波边界}：物理减震下记录$4.2^\circ$@1\,Hz稳定、$6.9^\circ$振铃，
          但尚未形成当前闭环的相位裕度证据；
    \item \textbf{在线辨识}：方波激励记录$b=0.35/0.36/0.90$、
          $d_{\text{yaw}}=-7.36$；单位、参数快照和重复次数尚未归档，且这些集总读数
          不能直接换算为电机不对称百分比。
\end{itemize}
这些非标定记录只支持控制链部署和轴方向语义；在补齐原始日志、时间戳、参数快照、
单位和重复次数前，不能定量验证滤波、辨识、抗扰或飞行品质。
