## 系统架构

```
USB-C (5V) ──→ D1(ESD) ──→ U30(CH343P USB-UART) ──→ U1(STM32H743)
                               │
5V ──→ U26(AMS1117-3.3V) ──→ 3.3V Rail (全域供电)
                               │
                    ┌──────────┼──────────┐
                    │          │          │
              U27(DPS310)  R12(ICM42688)  U4(W25N01GV Flash)
              气压计        6轴IMU        1Gbit NAND
                    │          │
              I2C2(PB11/PB10) SPI1(PA4-PA7)
              +PE15(ADDR)       │
                    │          │
              U28(MCP2515) + U29(TJA1050) ──→ CAN Bus
```

## 12. 未使用硬件资源（扩展预留）

> 🔬 EDA实测：以下硬件已完整焊接并连接到 MCU，固件中尚未驱动，可供未来功能扩展直接使用。

### 12.1 CAN 总线 — 飞控组网/发动机通信

| 位号 | 型号 | 接口 | MCU 引脚 | 说明 |
|------|------|------|---------|------|
| U28 | MCP2515-I/SO | SPI2 | — | SPI→CAN 控制器，SOIC-18 |
| U29 | TJA1050T/CM,118 | CAN PHY | — | CAN 收发器，SOIC-8 |

**MCU 连接：**

| MCU 引脚 | 网络 | 功能 |
|---------|------|------|
| 51 (PB12) | CAN1_CS | SPI 片选 |
| 52 (PB13) | SPI2_SCK | SPI 时钟 |
| 53 (PB14) | SPI2_MISO | SPI 主入从出 |
| 54 (PB15) | SPI2_MOSI | SPI 主出从入 |
| 57 (PD10) | CAN1_INT | 中断信号 |

> **开发指引**：库 `lib/arduino-CAN/` 已集成且已扩展 `CAN.setSPI(SPIClass&)`。当前实现使用独立 `SPIClass CAN_SPI(PB15, PB14, PB13)` + `CAN.setSPI(CAN_SPI)`，并在 `handleCANBus()` 主循环任务中轮询 `CAN.parsePacket()`；不要使用 `CAN.onReceive()`，避免在中断上下文中操作 SPI2。
> 典型用例：多飞控 CAN 组网、CAN 发动机控制器直连、CAN GPS/空速计。
