## 一、总调度（200 Hz，runGNCExecutive L5282）

八步，顺序固定：

1. `process_control_inputs`（L4143）— 遥控解码、模式开关、摇杆值、解锁状态
2. `determine_control_mode` — MANUAL / AUTO_ALTITUDE / AUTO_POSITION / GUIDED，GUIDED 超时保护
3. `manage_pid_integrals`（L4344）— 按模式使能各环积分
4. `compute_thrust_control`（L4380）— 高度/速度环 → 油门百分比
5. `generate_attitude_target`（L4945）— 生成目标四元数 q_target
6. `execute_attitude_controller`（L5099）— 滚转/俯仰姿态环 + 速率环 → 舵角
7. `execute_yaw_controller`（L5199）— 偏航速率环 → 差速 µs
8. `mix_and_output_commands`（L5227）— 舵角/油门/差速 → PWM

## 二、传感器到控制量

### 2.1 陀螺链路

```
ICM42688 采样（2 kHz）
  → imuCalibrator.update/apply（零偏，静止自动校准）
  → gyroXFilter/gyroYFilter/gyroZFilter 一阶低通 alpha=0.15
  → 轴映射：gxBody=-gzFiltered, gyBody=gxFiltered, gzBody=-gyFiltered
  → icm_gyro_x/y/z = gxBody/gyBody/gzBody * DEG_TO_RAD     (L1729)
```

控制侧（L5102-5106）：

```
current_omega_rps_body = {icm_gyro_x, icm_gyro_y, icm_gyro_z}
current_omega_dps_body_filtered = rollSpeedFilter.filter(omega*RAD_TO_DEG)   // 0.3，仅一级
```

**要点：没有 EKF 零偏补偿，没有二级滤波。** 从采样到控制使用，反馈延迟 ≈ 0.5 ms（2 kHz 采样）+ 1.8 ms（0.15 低通）+ 15 ms（0.3 @200 Hz）= 约 17 ms。

### 2.2 姿态链路

```
EKF15State（bfs::Ekf15State nav_ekf）
  → nav_ekf.quat() → AHRS_Packet.Qw/Qx/Qy/Qz     (L2945)
  → nav_ekf.roll_rad() → AHRS_Packet.Roll/Pitch/Heading
```

`backup_ahrs`（Madgwick）只做后台对照/失效回退，正常飞行不参与姿态输出。

**结论：原版姿态源就是 EKF，与 TandemVec 一致。** 早期代码注释里“姿态解算：Madgwick”已过时。

## 三、控制律（execute_attitude_controller L5099）

### 3.1 激活条件

```
is_attitude_control_active = is_unlocked && !is_manual_tvc
```

不含油门门控（油门只门控积分）。

### 3.2 ATTITUDE_MODE 外环

```
q_error = conj(q_current) * q_target
sign_qw = sign(q_error.w)
error_roll_deg  = 2.0 * sign_qw * q_error.x * RAD_TO_DEG   // 小角度近似
error_pitch_deg = 2.0 * sign_qw * q_error.y * RAD_TO_DEG

rollRateTarget  = rollAnglePID.computeWithExternalDerivative(error_roll, 0, -omega.x)
pitchRateTarget = pitchAnglePID.computeWithExternalDerivative(error_pitch, 0, -omega.y)
rollRateTarget  = constrain(±MAX_TARGET_RATE=80)
pitchRateTarget = constrain(±80)
```

外环增益 `4.25`，`computeWithExternalDerivative` 的第三参数传 `-omega`，内部再取反得到“误差导数 = ω”，即**微分项用陀螺直接给，不经过差分**。

### 3.3 RATE_MODE

```
rollRateTarget  = mapFloat(roll_raw, 988, 2012, -MAX_MANUAL_rollRATE, +MAX_MANUAL_rollRATE)   // ±80 线性
pitchRateTarget = mapFloat(pitch_raw, 988, 2012, +80, -80)                                    // 推杆=低头
rollAnglePID.reset(); pitchAnglePID.reset();   // 每拍都 reset（纯 P 外环，无影响）
```

### 3.4 两级滤波与内环

```
rollRateTarget = rollAngleOutputFilter.filter(rollRateTarget)      // alpha 0.85
roll_correction_deg = rollRatePID.computeDerivativeOnMeasurement(rollRateTarget, omega.x)
roll_correction_deg = constrain(±MAX_CORRECTION=10)
roll_correction_deg = rollOutputFilter.filter(roll_correction_deg) // alpha 0.25
```

### 3.5 偏航（execute_yaw_controller L5199）

```
yawRateTarget = mapFloat(yaw_raw-1500, ±512, -80, +80)              // ±80 dps 线性
if (is_unlocked && throttle_raw > 1050)
    yaw_diff = yawRatePID.computeDerivativeOnMeasurement(yawRateTarget, omega.z)
else
    yawRatePID.reset(); yaw_diff = 0
yaw_output = constrain(1500 + yaw_diff, 1000, 2000)
```

偏航没有航向锁、没有死区、没有模式区分，纯角速率指令。

### 3.6 未激活分支（手动 TVC / 未解锁）

```
roll_correction_deg  = mapFloat(rollTarget,  ±MAX_ANGLE_COMMAND=30, ±MAX_CORRECTION=10)
pitch_correction_deg = mapFloat(pitchTarget, ±30, ±10)
→ rollOutputFilter.filter(constrain(±10))
```

即未解锁/手动时舵机跟随摇杆映射的“目标角 30°→10° 舵角”。

## 四、混控（mix_and_output_commands L5227）

```
roll_servo_percent  = mapFloat(-roll_correction_deg,  -15, 15, 66.67, 33.33)   // 反向
pitch_servo_percent = mapFloat( pitch_correction_deg, -15, 15, 66.67, 33.33)   // 不反向

base_motor_us = mapFloat(throttle_percent, 0, 100, 1000, 2000)   // 未解锁强制 1000
motor1_us = constrain(base - yaw_diff_us, 1000, 2000)
```

注意：**舵角映射基准是 ±15°（机械半行程），不是 ±10°**。±10° 只是修正量限幅。

## 七、与 TandemVec 统一后共轴的逐项差异

> 本表在 2026-11-11 按最终实飞参数复核更新（原表写于 11-10 排查中段，限幅/滤波/摇杆量程均已变化）。
>
> | 环节 | 原版 | 新固件 | 影响 |
|---|---|---|---|
| 姿态源 | EKF15State | EKF15State | **相同** |
| 陀螺低通 | 0.15 | 0.15 | 相同 |
| 速率反馈滤波 | 一级 0.3 | 一级 0.8 + 二级 0.99 | 新多一级，反馈更快 |
| EKF 零偏补偿 | 无 | 有（`nav_ekf.gyro_bias_radps`） | 已 A/B 排除为抖动源 |
| 姿态误差 | `2·sign·q.x·RAD2DEG` | 分段精确式（`q_vec_norm>0.25` 用 atan2） | 小误差等价 |
| 内环输出 | 直接舵角 deg | α[deg/s²] → `asin(I·α/(l·T))` | 新增一层换算 |
| 内环限幅 | ±10 deg | ±1151 deg/s²（I=0.015、l=0.21 下对应 10° 舵角） | 等效 |
| 内环输出滤波 | 0.25 | 0.5 | 新略快 |
| **RATE 摇杆映射** | 线性 ±80 dps | rcRateCurve，`rc_rate`=0.12 → **满杆 80 dps** | **已对齐原版量程** |
| RATE_MODE 角度 PID reset | 每拍 reset | 仅进入时 reset | 新更正确 |
| 偏航 | 纯速率，油门>1050 才输出 | `att_yaw.kp`=0，纯速率内环 | 已对齐原版（无航向外环） |
| 手动 TVC | 摇杆→±30°→±10° 舵角 | 摇杆→±10° 舵角直通 | 映射基准不同 |

## 八、最关键的差异：RATE 模式满杆量程

原版：`mapFloat(roll_raw, 988, 2012, -80, +80)`，满杆 **80 dps**。

新固件：`rcRateCurve(rcNormFromUs(roll_raw), rc_rate, expo=0.25, super=0.7, 600)`，
满杆 = rc_rate × 200/(1-super)。共轴分支已单独取 `rc_rate = 0.12`：
0.12 × 200/0.3 = **80 dps**，与原版量程一致（纵列/单涵道仍为 0.5 → 333 dps，不受影响）。

当时（rc_rate=0.5）同样打满杆，目标角速率是原版的 4.16 倍，速率环看到 4 倍误差、按同一 kp 输出 4 倍舵角。这是排查中段得出的首要嫌疑。**2026-11-11 已把共轴 `rc_rate` 改为 0.12 使满杆回到 80 dps，该项差异已消除。**

按原版量程反推，若要保持 80 dps 满杆，`rc_rate` 应为 `80×0.3/200 = 0.12`；或保持 rc_rate 0.5，把 `rc_super` 提到 0.85（0.5×200/0.15=667，不现实），所以只能调 rc_rate。

## 九、复现/验证建议

1. 在线把 `rc_rate` 调到 0.12，使满杆回到 80 dps，再测角速率模式抖动是否消失。
2. 若消失，说明是量程问题，增益可维持 50；若不消失，再查 EKF 零偏补偿那一步。
3. 需要核对 `att_yaw`（航向锁）在 RATE 模式的行为，原版没有这层。
