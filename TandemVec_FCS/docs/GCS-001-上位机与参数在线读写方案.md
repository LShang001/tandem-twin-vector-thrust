# GCS-001-上位机与参数在线读写方案

> 状态：✅ 已实施（2026-08-08）
> 范围：固件参数在线读写（AnoCom 0xE0/0xE1 完整实现）+ 配套上位机 TandemVec_FCS/GCS/

## 背景

实机调参依赖串口重刷固件：改 `FlightCtrlParams.h` → 编译 → 刷机，一轮数十分钟。C 路径（参数集中）落地后，`kFlightCtrlParams` 成为唯一事实源，但仍是 `static constexpr`（编译期只读）。本方案补齐**运行时在线读写**，并交付配套上位机（仪表/曲线/黑匣子/参数一体化）。

## 固件侧改动

### 1. kFlightCtrlParams 可变化（默认行为零变化）

- `include/FlightCtrlParams.h`：
  - `kFlightCtrlParamsDefaults`（static constexpr）= 原值逐字搬移，**出厂默认值唯一源**
  - 固件编译（`-DTANDEMVEC_FIRMWARE`，platformio.ini build_flags）：`extern FlightCtrlParams kFlightCtrlParams;`
  - 宿主机测试（test_host，单文件编译）：`static constexpr kFlightCtrlParams = kFlightCtrlParamsDefaults`（只读副本，测试参数永不漂移）
- `src/state_data.cpp`：定义可变唯一实例 + `applyFlightCtrlParams()`（12 个 PositionPID setter + 9 个 ComplementaryFilter `setAlpha`，无扰同步保留积分/滤波状态）

### 2. AnoCom 参数读写完整实现

- `lib/AnoComProtocol`：`setRxCallback` 签名扩展，`parseData` 把源帧 SC/AC 传给回调（占位注释预留的扩展点）——0x00 校验帧回传真实校验值
- 新增 `src/ano_params.cpp/h`：117 参数注册表（12 PID 环 × kp/ki/kd/out_min/out_max/int_limit/threshold/filter_alpha/enabled + 9 滤波 alpha）：
  - `0xE0`：CMD 0x00 设备信息（0xE3，沿用）、0x01 参数个数、0x02 读值（回 0xE1）、0x03 读信息（回 0xE2，ID+TYPE+NAME 20B）、0x10 系列（0xAA 恢复默认 / 0xAB 保存——无持久化仅确认）
  - `0xE1` 写入：长度/类型严格校验 → 更新 kFlightCtrlParams → `applyFlightCtrlParams()`
- 参数 ID = 注册表顺序（0..116）；名称/类型自描述（E2 帧），上位机无需硬编码参数表

### 3. 黑匣子 P 帧增量数修正（bug 修复，格式不变）

`buildPFrame` 循环写 22 个增量会把末 2B 写到 CRC 槽（被覆盖）→ 实际恒为 21 增量，但 flash_export.py 按 22 解析致 p2 通道被 CRC 字节污染。修正：循环显式收敛 21（`(PFRAME_SIZE-9)/2`），帧长/布局不变；`tools/flash_export.py` 与 GCS `blackbox.py` 同步按 21 增量解析（末通道保持参考值）。

## 上位机（TandemVec_FCS/GCS/）

Python 后端（FastAPI + WebSocket + pyserial）+ Web 前端（玻璃拟态深色主题，three-r170 vendored），串口协议 = AnoCom（与官方 Ano 上位机生态兼容，可换用）。

- 页面：仪表盘（人工地平线/HUD/状态灯/RC/控制量/GNSS）、3D 姿态、实时曲线（8 组预设）、黑匣子（findseg 段列表→export→表格/分组绘图/CSV）、参数（分组读写+校验帧确认+恢复默认）、控制台（DBG 终端+记录/回放）
- 模式：遥测（AnoCom 4 组轮发）/ DBG（flash 命令，互斥，自动切换）
- 测试：`GCS/tests/` 26 项 pytest 全绿（无硬件，FakeSerialLink 注入）

## 行为红线核对

- 默认参数数值逐字搬移（kFlightCtrlParamsDefaults = 原值）→ 控制行为零变化
- AnoCom 帧格式按官方协议手册既有定义实现（非新协议）；遥测轮发未动
- P 帧修正：字节布局不变（51B/CRC 有效），仅解析语义修正（p2 由"CRC 垃圾"→"参考值"）
