# 2026-08-08 ELRS 遥测扩展与电池电压采样

> 主题：ELRS 回传从"液体火箭氧压占位"升级为电动 VTOL 真实数据；电池电压分压电路确认。
> 关联：`src/communication.cpp`（7 个 ELRS 回传任务）、`lib/CrsfSerial/crsf_protocol.h`（枚举补全）、`docs/电路拓扑参考.md` §11.1（分压电路）、`docs/reference/elrs-official/`（官方源码沉淀）、`docs/elrs-telemetry-research.md`（调研文档）。

## 要点

### 1. ELRS 遥测机制（官方源码实证）
- ELRS RX 对 FC 遥测帧**透明转发**：`SerialCRSF::processBytes` 只标记 BATTERY/BARO 检测，不挑帧类型，FC 发标准 CRSF 帧即回传。
- 4 种封装路径：直接 CRSF（本项目路径）/ MSP over CRSF（`CRSF2MSP`）/ MAVLink（`MSP_ELRS_MAVLINK_TLM`=0xFD）/ MSP DisplayPort。
- 官方源码已沉淀到 `docs/reference/elrs-official/`（commit 5909f77，2026-07-31）。

### 2. CRSF 协议头 "mv×100" 注释是错的（重要）
- `crsf_protocol.h` 里 BATTERY_SENSOR.voltage 注释 "mv * 100" 为**过时错误**。
- 权威接收端 EdgeTX（`crossfire.cpp:59`）：`CS(BATTERY_ID, 0, ..., UNIT_VOLTS, 1)` → precision=1，**实际按 0.1V 解释**（12.6V 发送 126）。
- ELRS 官方 `getHoTTvoltage()` 返回 0.1V 单位（166=16.6V）直接填入，佐证。
- **发送端换算：`voltage = mV / 100`**（0.1V 单位），不是 ×100。若按注释写 ×100 会溢出且显示错误 100 倍。

### 3. 电池电压分压电路（双模型视觉确认）
- U40 电池检测口：`VBAT ──[10kΩ]──┬── ADC_BATT (PC5, pin33) ──→ ADC1_INP8`，下臂 `[1kΩ]→GND`。
- **分压比 = 11.0**（(10k+1k)/1k），terra + mimo 双模型独立交叉验证一致。
- 量程：3S→1.145V / 4S→1.527V / 6S→2.29V，全在 ADC 0-3.3V 内。
- 固件：`BATTERY_DIVIDER_RATIO=11.0`（`state_data.h`）、`updateBatteryMonitor()` 10Hz 采样 → `bat_voltage_mv` → ELRS 回传。

### 4. ELRS 回传任务全景（7 个）
| 任务 | 频率 | 帧 | 数据源 |
|---|---|---|---|
| sendElrsBatteryData | 25Hz | BATTERY_SENSOR | ADC_BATT PC5（**已去氧压**） |
| sendElrsAttitudeData | 25Hz | ATTITUDE | AHRS_Packet |
| sendElrsBaroAltitudeData | 25Hz | BARO_ALTITUDE | baro_altitude + estimated_velocity |
| sendElrsVarioData | 25Hz | VARIO | estimated_velocity |
| sendElrsGpsData | 10Hz | GPS | ubx.lat_deg/lon_deg + NED 速度合成 |
| sendElrsTempData | 10Hz | TEMP | DPS310 temperature |
| sendElrsFlightModeData | 10Hz | FLIGHT_MODE | getControlMode |

- 氧压 `receivedP1/P2` 是液体火箭项目遗留，**电动 VTOL 不适用**，已从电池回传移除（AnoCom 的 `sendVoltCurr` 仍传氧压，待后续清理）。

### 5. CrsfSerial 库状态
- 本机自魔改版 > BobbyIndustries 原版（2022 停更，无升级价值）。
- 已补全 9 个 ELRS 官方帧类型枚举（GPS_TIME/VARIO/BARO_ALTITUDE/HEARTBEAT/ELRS_STATUS/HANDSET/KISS_REQ/KISS_RESP/ARDUPILOT_RESP）。
- ELRS 官方架构（CRSFRouter/CRSF2MSP）是 ESP32 专属，不能直接替换本机库。

### 6. CAN 总线电路拓扑（同日原理图视觉双模型验证）
- U28 MCP2515（SPI2：CS=PB12/SCK=PB13/MISO=PB14/MOSI=PB15/INT=PD10）+ U29 TJA1050 收发器。
- **CAN1_TX/CAN1_RX 只连 MCP2515↔TJA1050，不直连 MCU**——MCU 只经 SPI2 与 MCP2515 通信。
- RESET# 10kΩ 上拉 3.3V + C41 100nF；X3 16MHz 晶振（C44/C45 10pF）；R24 120Ω 总线终端（板上含终端）；R23 4.7kΩ 拉低 S 脚=正常高速；C46/C47 30pF 共模滤波。
- **VREF (U29 脚5) 接 3.3V——用户实测确认**。TJA1050 标准用法是 2.5V 参考输出接去耦电容，此处被外部 3.3V 驱动属非标准电平适配设计，已按实际设计记录（勿"修正"）。
- 已沉淀至 `docs/电路拓扑参考.md` §12.1。
