# 2026-08-08 W25N01GV NAND Flash 黑匣子存储实现

> 主题：板载 W25N01GV (1Gbit NAND, SPI3) 驱动从零实现 + 黑匣子日志层。
> 关联：`lib/W25N01GV/`（命令层+日志层）、调试命令 `flash` 组、`docs/电路拓扑参考.md` §12.2。

## 要点

### 1. 芯片关键事实（datasheet）
- 1Gbit SLC NAND：页=2048B+64B spare，块=64页，共 1024 块，坏块≤20（BBM LUT 可重映射）
- **ECC 上电默认使能**（SR2 配置寄存器 ECC_E=1），写页自动算 ECC 存 spare 区
- **上电块写保护**（SR1 BP 位默认保护！必须先清，否则页编程 P-FAIL）
- SR3 状态寄存器：BUSY(bit0)/WEL(bit1)/LUT-F(bit2)/ECC-1:0(bit4-5)/P-FAIL(bit6)/E-FAIL(bit7)
- 命令：读ID 0x9F / 块擦 0xD8 / 页编程=装载0x02+执行0x10 / 页读=0x13+读0x03 / BBM 0xA1 / 状态寄存器 SR1=0xA0写 SR2=0xB0写 SR3=0xC0读
- 时序：页编程~0.7ms、块擦~2ms（BUSY 轮询）

### 2. ★ SPI 硬件 NSS 与手动 CS 冲突（本次最隐蔽的坑）
- `SPIClass(mosi, miso, sclk, ssel)` 传 ssel 引脚 → spi_com.c L255-256 设 `SPI_NSS_HARD_OUTPUT` + L339 `pinmap_pinout` 把 ssel 配成 AF
- 结果：读 JEDEC ID 全 0x6E（MISO 无响应，SPI 时序被硬件 CS 干扰）
- **修复：SSEL 传 NC（默认 PNUM_NOT_DEFINED）→ `SPI_NSS_SOFT`，CS 完全由驱动 `digitalWrite` 手动控制**（命令层本就手动拉 CS）
- 排查过程：0x6E 连续重复 = MISO 读到发送数据自身 → 引脚/时序问题 → 读 variant SPI3 映射（PB2=AF7/PC11=AF6/PC10=AF6/PA15=AF6 都在）→ 定位 NSS 冲突

### 3. 架构（3 层）
- **命令层** `W25N01GV`：读ID/擦块/页写/页读/状态，全部阻塞 BUSY 轮询 + noInterrupts 保护事务，SPIClass 注入（仿 CAN_SPI 模式）
- **日志层** `W25N01GVLog`：RAM 环形缓冲(32帧) + `logPush()`(µs级非阻塞) + `logService()`(每tick≤2帧预算) + 顺序游标 + 游标持久化(super page=倒数第8页) + 坏块跳过(整块)
- **帧格式**：magic(0xAA55) + seq(4) + t_ms(4) + payload(84) + CRC8（复用 lib/crc8 的 Crc8 类，注意 len 是 uint8_t<255）

### 4. 验证结果（全部通过）
- `flash id` → 0xEF/0xAA/0x21（芯片点亮）✅
- `flash test` → 5 帧写入+读回，magic=0xAA55, seq 正确, CRC 通过 ✅
- 掉电恢复：复位后 cursorPage 正确恢复 ✅
- 续写：从上次游标继续，无覆盖 ✅

### 5. 调试命令（DBG 模式）
- `flash id | erase | stat | dump <page> | test`
- 后台写任务：`handleFlashService` 100Hz 注册（main.cpp），每 tick ≤2 帧
