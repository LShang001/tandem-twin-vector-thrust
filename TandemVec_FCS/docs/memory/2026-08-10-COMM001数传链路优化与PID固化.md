# 2026-08-10 — COMM-001 数传链路优化 + PID 固化调参记录

## 1. 背景

2M 波特率在 DAP-Link VCP 上实测丢帧 ~15%（2026-08-09 任务调度统计坐实），遥测全量 50Hz 均等轮发对调参分辨率不足。经 grilling 逐项决策（COMM-001）实施三层优化并烧录实机验证。

## 2. 实施内容（全部已烧录 Verified OK）

### A 打包层（`lib/AnoComProtocol/`）
- **A1 长度保护**：`buildFrame` 超 `ANO_MAX_DATA_LEN=256` 截断——修复 `sendData` 无上限检查的栈溢出隐患
- **A2 校验合并**：sum/add 双循环 + memcpy 三遍遍历 → 单循环边拷边算（host 测试独立参考实现验证逐字节一致）
- **A3 组模式**：`beginGroup()/endGroup()` + 内部 256B 组缓冲——同 tick 多帧合并单次 write（快环 5 帧 → 1 次写），组缓冲满自动 flush 防御

### B 节奏层（`communication.cpp` handleAnoCom，双环替代 4 组轮发）
| 档位 | 频率 | tick 判定 | 帧 |
|------|------|-----------|-----|
| 快环 | 100Hz | t%2==1 | 0x01 IMU / 0x03 欧拉 / 0x0A 目标姿态 / 0x21 控制量 / 0xF1 执行器 |
| 位置 | 50Hz | t%4==2 | 0x08 |
| RC | 25Hz | t%8==4 | 0x40 |
| 显示帧 | 25Hz | t%8==6 | 0x05 高度 / 0x06 模式 / 0x07 速度 / 0x20 PWM / 0x0B 目标速度 |
| GPS/氧压 | 10Hz | t%20==10 | 0x30 GPS / 0x0D 电压+氧压 |

- 快变字段每 tick 采集（陈旧度 20ms→5ms）；慢变字段各自档位采集
- 决策记录：位置保持 50Hz（快速飞行分析）、快环 100Hz（200Hz 与前端 20-50Hz 推送无差异）

### C 链路层
- **波特率 2M→921600**：`src/state_data.h SERIAL6_BAUDRATE`（唯一权威源）+ GCS 四处（cli.py DEFAULT_BAUD / main.py / bb_tool / _id_probe）
- `serial_link.py` read_size 1024→256（攒批延迟 68ms→17ms）
- `main.py` TELEMETRY_PERIOD 0.05→0.02（推送 20Hz→50Hz 跟上快环）

### 随附修复
- `ano_vars.cpp`：`tx[1+2+16]=19B` 越界（memset 写 16B 到 &tx[4] 需 20B）→ `tx[1+2+1+16]=20B`，-Warray-bounds 警告消除

## 3. PID 固化（实机在线调参后写入 FlightCtrlParams.h）

| 参数 | 旧默认 | 新固化 | 说明 |
|------|--------|--------|------|
| att_roll.kp | 2.6 | **2.8** | 实机稳定 |
| att_pitch.kp | 2.6 | **2.8** | 实机稳定 |
| att_yaw.kp | 1.0 | **5.0** | ★ 有效增益 5.0×0.20=1.0（2026-08-09 末态 0.22×0.45≈0.10 的 10 倍）——τm 观测器+增益调度修复后限带边界大幅放宽，kp>1 极限环红线不再适用（2026-08-10 实机验证） |
| rate_yaw.kp | 0.22 | **0.20** | 配合 att_yaw 5.0 压低速率环增益 |
| rate_roll/pitch.kp | 0.28 | 0.28 | 不变 |

**经验**：差速通道（yaw）调参从"角度环+速率环乘积=有效回路增益"看——调大角度环 kp 后必须同步审视速率环 kp，避免有效增益越过 τm 限带。

## 5. 踩坑

- **DAP-Link 烧录失败模式**：`cannot read IDR`（握手失败）→ 重试多次可自愈（本次 6 次失败后第 7 次成功，期间错误逐步演进 IDR→CMD_INFO→写内存→成功）；物理拔插不是唯一解，耐心重试 + 检查目标板遥测（COM10 有数据 = 板子活着，问题只在 SWD 链路）
- **遥测双环验证**：改频率后不要只看"有没有数据"，用 `cli.py sniff all` 统计功能码分布核对各档频率
