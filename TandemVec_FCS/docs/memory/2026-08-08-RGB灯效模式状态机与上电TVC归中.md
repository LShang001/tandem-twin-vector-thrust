# 2026-08-08 RGB 灯效模式状态机扩展 + 上电无信号 TVC 满偏修复

> 主题：`Ws2812AppStatus` 从四态升级为 13 态 `FcsLedState` 模式状态机（含飞行模式色相编码）、
> ELRS LQ 弱信号接入、上电无信号安全修复（顺带发现并修复舵机满偏 bug）。
> 关联：`include/Ws2812AppStatus.h`、`src/communication.cpp`（handleStatusLedTask）、
> `src/flight_control.cpp:68`、`src/main.cpp`、`test_host/test_led_status.cpp`。

## 要点

### 1. 上电无信号 → TVC 舵机满偏 bug（重要安全发现）
- 根因：`raw_rc_values` 初始化全 0 → `is_manual_tvc = (raw_rc_values[7] < 1200)` 恒为 true →
  GNC 走"手动 TVC 旁路"分支（flight_control.cpp:1133），摇杆映射 `mapFloat(0, 988, 2012, ...)`
  把摆角钳到**满偏 ±15°**（机械 1.333 传动后舵机 PWM 72%/28%，即 ±20° 舵机角），
  直到首帧通道数据到达。电机侧因 `is_unlocked` 的 isLinkUp 门控而安全停转，但舵机危险。
- 修复：`inputs.is_manual_tvc = isLinkUp && (raw_rc_values[7] < 1200);` —— 无链时强制自动分支，
  落入全锁定分支（舵机 1500us 中位 + 电机 500us）。**链路正常时手动 TVC 标定功能不受影响**。
- 教训：**接收机通道数据未就绪（全 0）时，任何 `raw_rc_values[x] < 阈值` 的开关判定都会误触发**
  低档分支——无链时所有开关判定都应以 `isLinkUp` 门控兜底。

### 2. 灯效状态机设计（FcsLedState，优先级高→低）
`FAULT(红快闪10Hz) > FAILSAFE(红SOS双闪) > CALIBRATING(黄快闪) > NO_RECEIVER(红慢闪1Hz) >
LINK_DOWN(品红慢闪) > LOW_LQ(橙慢闪) > LOW_VOLTAGE(红慢呼吸) > ARMED_*(模式呼吸) > STANDBY(蓝呼吸)`

- **解锁后按飞行模式编码色相**（呼吸 2s）：MANUAL 绿 / AUTO_ALT 青 / AUTO_POS 白 / GUIDED 紫。
  判定与 `getControlMode` 同款分档（raw_rc_values[6] 三档 + trajectoryPlanningStarted→GUIDED）。
- **BOOT 上电自检**：白→蓝→绿 三段各 400ms 呼吸，非阻塞（100Hz 帧内推进），首次 update 自动播放。
- `update(FcsLedState, now_ms)` 传时间戳：单测可注入时间、防任务抖动漂移。
- 解锁判定改用 `g_is_unlocked`（GNC 真实状态，与电机行为一致），不再用裸 `raw_rc_values[4]`。
- `ever_linked`（communication.cpp 静态）：区分"上电无信号"(NO_RECEIVER) 与"地面断链"(LINK_DOWN)。
- 故障 `setFault` 保留（wsfault 调试命令），在 Ws2812AppStatus 内部覆盖组装的状态。

### 3. ELRS LQ 弱信号预警（早于 300ms 断链判定）
- 注册库现成回调 `crsf.onPacketLinkStatistics` → `s_elrs_lq`（uplink LQ 0-100）。
- LQ < 40% → 橙色慢闪（渐进预警）；300ms 无帧才触发 `linkDownCallback`（既有失控逻辑不变）。

### 4. 测试基建：WS2812Driver mock
- `test_host/stub/WS2812Driver.h`：与 Arduino.h 同模式的最简 mock（记录 setPixelColor/show），
  使 `Ws2812AppStatus.h` 可在宿主机 g++ 编译测试。stub/Arduino.h 补充了 `PI` 宏。
- `test_host/test_led_status.cpp` 37 断言：BOOT 三段时序、13 态颜色/节奏（呼吸/慢闪/快闪/SOS 时基）、
  setFault 覆盖、亮度上限。**单测时间点要避开呼吸 sin<0 暗区（蓝呼吸 t%2500∈(1250,2500) 亮度≈0）**。
- 已挂入 `test_host/run_all.sh`（led 项）。

## 验证
- `test_host/run_all.sh` 全绿（含新增 led 37 断言）；`pio run` 2 环境编译 SUCCESS。
