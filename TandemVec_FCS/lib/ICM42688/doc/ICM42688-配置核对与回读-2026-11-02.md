# ICM-42688-P 配置核对与上电回读（2026-11-02）

> 目的：把“驱动到底把芯片配成了什么”从**靠飞行数据反推**变成**上电可验证的确定状态**。
> 背景：2026-11-01 曾发现 LPF 被写进 ODR 字段而静默失效（手册核对后修复）；这类错误
> 不会报错、只会让滤波/带宽与设计不符。本次补充回读校验与编码层测试。

## 1. 本机默认配置（ImuConfig 默认：2 kHz / ±2000 dps / ±8 g / 陀螺 200 Hz / 加计 100 Hz）

| 寄存器 | 地址 | 写入值 | 含义 | 解码 |
| --- | --- | --- | --- | --- |
| PWR_MGMT0 | 0x4E | `0x0F` | accel+gyro 进 LN 模式 | 低 4 位 = 0xF |
| GYRO_CONFIG0 | 0x4F | `0x05` | ±2000 dps / 2 kHz | FS=0<<5, ODR=0x05 |
| ACCEL_CONFIG0 | 0x50 | `0x25` | ±8 g / 2 kHz | FS=1<<5, ODR=0x05 |
| GYRO_ACCEL_CONFIG0 | 0x52 | `0x64` | 陀螺 UI 低通 200 Hz、加计 100 Hz | accel=6<<4, gyro=4 |

`selectLpfCode(2000, 200)=4`（2000/10=200 Hz 精确）、`selectLpfCode(2000,100)=6`
（2000/20=100 Hz 精确）；ODR<400 Hz 时手册以 400 Hz 为基（`lpfCutoffHz`）。

## 2. AAF / notch 的复位默认状态（驱动不改，属于芯片出厂配置）

| 滤波器 | 复位状态 | 依据 | 处理 |
| --- | --- | --- | --- |
| AAF（陀螺/加计） | **使能**，DELT=13/DELTSQR=170/BITSHIFT=8 → 3 dB 带宽 **585 Hz** | DS-000347 §5.3 表、STATIC 寄存器复位值 | 保持；AAF 在 UI 低通之前，保留抗混叠 |
| Notch（陀螺三轴） | **使能**，COSWZ 为**出厂逐片 trim**（0xXX） | §5.1、STATIC6–9 复位值 0xXX | 保持；用于压陀螺谐振峰，禁用反而损失性能 |

> 结论：驱动只写 UI 低通（0x52），**不动 AAF/notch** 是符合芯片设计意图的；
> 上板要做的是“确认它们处于默认使能状态”，而不是盲目关闭。

## 3. 上电回读校验（新增）

`ICM42688::readConfigSnapshot()` 读回 bank0 四个配置寄存器；
`ICM42688_ImuDevice::begin()` 末尾与期望值逐位比对，结果存
`configCheckMask()` 位图：

| bit | 寄存器 | 期望（本机默认） |
| --- | --- | --- |
| 0 | PWR_MGMT0 | 0x0F |
| 1 | GYRO_CONFIG0 | 0x05 |
| 2 | ACCEL_CONFIG0 | 0x25 |
| 3 | GYRO_ACCEL_CONFIG0 | 0x64 |

- 不一致：`sensor_imu` 上电日志打印 `[Warn] IMU cfg readback mismatch mask=0x..`
  并附四个回读值（`pwr/gyro/accel/lpf`），不阻断启动（配置可能仍可用，交人工判读）。
- 读寄存器失败：`begin()` 返回 `-7`（写成功而读不回 = 总线异常，按初始化失败处理）。

## 4. 编码层测试（宿主）

`test_host/test_imu_filter_math.cpp` 新增：

- `lpfCutoffHz`：ODR 2000 码 0..7 → 1000/500/400/250/200/125/100/50 Hz，
  ODR<400 以 400 为基；保留码 8 返回 0。
- `selectLpfCode`：2000/200→4、2000/100→6、2000/400→2、100/100→1、100/50→0。
- `aafRegisters` 打包：213 Hz→DELT=5/DELTSQR_L=25/STATIC5=0xA0；
  3979 Hz→63/0x80/0x3F（与手册 §5.3 位域一致）。

驱动侧改为调用同一份 `imu_filter_math.h` 实现（消除驱动/测试两套映射的漂移风险）。
