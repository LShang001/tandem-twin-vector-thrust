# 三机型快速参数化 MC（反演模型 + 超大规模扫描）

> 目标：用**可飞行配置**反演三型飞行器的等效系统模型，用向量化降阶 6DOF 内核做
> 数十万级参数/噪声/误差/故障扫描，回答“哪些参数组合会把闭环推出包线”。
> **这不是固件 SIL，也不是实机验证**；固件 SIL 在 `TandemVec_FCS/test_host/fw_sil`。

## 1 反演模型

模型表见 [models.py](models.py)，原始来源与置信度：

| 机型 | 直接来自实飞配置 | 反演/假设 | 不可辨识 |
|---|---|---|---|
| TandemVec | m=0.70 kg、Ix=0.0021、Iy=Iz=0.022、kT/kQ/wMax、a=b=0.315、τm=0.28、15° | 无（参数为实飞配置/组件估算） | 气动阻尼、Jp、部分惯量为组件估算 |
| 共轴 VTVL | m=0.84 kg、Tmax=14 N、PID 4.25/0.25/0.08、yaw 3.8/30、滤波/限幅 | I=0.05/0.05/0.08、lever=0.15、yaw 力矩系数=0.0005；用 assumed 0.12 s rate-loop 时间尺度使 `Kp_rate·lever·T/I≈10.5 s⁻¹` | 惯量/力臂/差速力矩/TVC 机械方向没有实飞辨识 |
| 液体火箭 | M0=16.5 kg、Tmax=200、Tmin=80、Isp=200 s、T-rate=1800 N/s、delay=0.1 s | I=0.35/3.0/3.0、lever=0.45、姿态增益 3.0/8.0 | 惯量/力臂/气动阻尼/RCS；CCAEGT `M_DRY=12.5` 与固件 `DRY_MASS=13.5` 不一致 |

**反演的核心假设**：共轴/液体的惯量与力臂无法从“能飞”唯一反解；本表用控制权限
（增益、限幅、质量、推力）与假设的闭环时间尺度构造一个**低置信等效模型**。
因此这里的结果只能用于敏感度/包线研究，不能写成“实机模型”或“飞行通过”。

## 2 快速 MC 内核

[fast_mc.py](fast_mc.py)：

- 状态：高度/垂速、roll/pitch/yaw 角度与角速率；
- 控制：姿态外环 P → 速率内环 P（角度域）+ 高度 PD；
- 执行器：电机/舵机一阶滞后、推力曲线（TandemVec `T=Tmax·u²`，共轴/液体线性）、
  限幅、舵机卡死、推力损失；
- 扰动：质量/惯量/推力/增益/力臂偏差、角度/角速率噪声与偏置、传感器延迟、
  垂直风、力矩噪声；
- 每个 case 独立参数，按 chunk 向量化；输出 max 角度、最终高度、失败标记。

**边界**：无 EKF/导航融合、无气动/桨叶动态、无真实振动谱；这是“快速包线工具”，
不是固件复刻。

## 3 运行

```bash
cd simulations/three_vehicle_mc
py -3.12 run_mega.py --cases 2000 --nominal          # 名义参数快速自检
py -3.12 run_mega.py --cases 100000 --duration 20    # 宽范围 100k/机型
py -3.12 run_mega.py --cases 100000 --variant osc    # 振荡自适应 A/B
py -3.12 analyze_mega.py --dir sim-data/<campaign> \
  --compare-dir sim-data/<reference>                 # 分桶/1% 样本/最坏案例
py -3.12 compare_casewise.py --baseline <dirA> --candidate <dirB>  # 同种子逐 case A/B
py -3.12 run_boundary_grid.py --out sim-data/boundary-grid-2026-10-24  # TandemVec 边界网格
```

结果写入 `--out` 指定目录（默认 `sim-data/three-vehicle-mc-2026-10-24`），
包含 `summary.json` + `samples.csv`；`analyze_mega.py` 追加
`analysis.json`、`samples_1pct.csv`、`worst_cases.csv`、`compare.json`；
`compare_casewise.py` 要求两套 campaign 的逐 case 参数完全一致。

## 4 当前结果（2026-10-24，L1 降阶 MC）

- **名义范围 50k/机型（无故障，150k 总）：三机型 100% 通过**，
  max_ang P95 0.62–1.17°，final_h P05/P95 9.47–10.19 m。
- **宽范围 100k/机型（含 2% 推力损失、1% 舵机卡死，300k 总；早期批次）**：

> ⚠ 该表为 `thrust_loss` 修正前结果：TandemVec 的“全部/含故障”列与
> `thrust_loss` 敏感度受油门平方律放大影响，已作废；无故障列仍有效。
> 修正后权威结果见下文。

| 机型 | 全部通过/失败 | 无故障通过/失败 | 含故障通过/失败 | max_ang P95 |
|---|---|---|---|---|
| TandemVec | 78.49% / 3.16% | 80.37% / 1.09% | 18.40% / 69.31% | 11.60° |
| 共轴 VTVL | 84.71% / 3.91% | 86.63% / 2.35% | 21.92% / 54.91% | 11.26° |
| 液体火箭 | 60.52% / 23.48% | 61.90% / 21.89% | 15.38% / 75.74% | 35.53° |

- 敏感度：TandemVec `thrust_loss=-0.802`、`delay=+0.179`；共轴
  `thrust_loss=-0.530`、`wind/mass/thrust≈±0.18`；液体
  `mass=+0.410`、`thrust=-0.381`、`wind=-0.372`，低 T/W 主导失效。
- 宽范围采样：质量 ±18%、惯量 ±35%、推力 ±15%、τm 0.4–2.5×、增益 ±25%、
  力臂 ±35%、角度噪声 0–~6°、角速率噪声 0–~15°/s、偏置 ±6°/±6°/s、风 ±4.5 m/s²、
  力矩噪声、0–150 ms 延迟、2% 推力损失、1% 舵机卡死。
- 鲁棒化 A/B（20k/机型）：振荡自适应让 TandemVec 失败 3.01%→2.33%、
  max_ang P95 11.49°→10.47°；权限归一化反而使 P95 到 25°，不采用；
  液体低 T/W 是物理边界，调增益无效。候选只做仿真，不改固件默认参数。
- **影响修正**：早期 `thrust_loss` 乘在油门、再过二次曲线，TandemVec 的 0.5
  被平方成 0.25 推力；已改为乘在推力上。无故障 case 逐位不变，共轴/液体
  线性油门不受影响；TandemVec 故障桶必须用修正后数据。
- **修正后 300k 同代码同种子 A/B**（100k/机型；逐 case 参数一致校验通过）：

| 机型 | 通过 fixed / 默认 / tuned | 失败 fixed / 默认 / tuned | 无故障失败 fixed / 默认 / tuned | max_ang P95 fixed / 默认 / tuned |
|---|---|---|---|---|
| TandemVec | 78.63% / **79.76% / 79.95%** | 1.90% / **1.17% / 1.02%** | 1.05% / **0.32% / 0.17%** | 11.67° / **10.39° / 10.28°** |
| 共轴 VTVL | 84.86% / 84.91% / 84.93% | 3.85% / 3.84% / 3.84% | 2.31% / 2.30% / 2.31% | 11.27° / **10.52° / 10.43°** |
| 液体火箭 | 60.52% / 60.50% / 60.50% | 23.92% / 23.95% / 23.97% | 22.32% / 22.35% / 22.38% | 35.13° / 35.13° / 35.13° |

- 逐 case（TandemVec）：默认 osc 救回 726/新增 3（均为边缘→失败，无通过→失败）；
  **tuned 救回 877/新增 4（无通过→失败）**；默认→tuned 再救回 152/新增 2。
  tuned 相对 fixed 新增通过 1433、107 例通过→边缘；净严格通过 +1326。
- 延迟分层（TandemVec 无故障）：tuned 把 90–120/120–150/>150 ms 失败率
  从 fixed 的 6.72/37.37/60.96% 降到 **0.92/5.98/12.35%**；<90 ms 仍为 0。
  默认 osc 对应 1.81/11.21/24.30%。
- **50% 推力损失语义（修正后）**：TandemVec T/W=4→2，仍可产生升力，但降阶
  高度 PD 无积分，工作点被推到近地面（final_h 中位 0.03 m、P05 −5.38 m），
  失败主要是高度丢失/触地；osc 只减少高延迟下的姿态发散，**不能恢复高度**。
  共轴/液体 50% 损失后 T/W<1，仍以坠落为主。**osc 不是故障容错。**
- **确定性边界网格**（延迟 0–210 ms × 增益 0.8–1.4 × 故障，TandemVec）：
  无故障失败 fixed 35.4% → 默认 7.6% → **tuned 1.0%**；tuned 救回 285/
  新增 0。latch（recovery=1.0）可达 0.8%，但降增益后永不恢复，只作上限参考，
  不作为飞行候选。
- **1M 独立种子（seed 20261025）**：fixed 78.65%/1.95%、tuned
  **79.91%/1.07%**；无故障失败 1.06%→0.18%，P95 11.63°→10.30°。
  逐 case 救回 **8,826**、新增 **31**（全部边缘→失败，无通过→失败）。
  尾部失败 19,488→10,693，`max_ang>120°` 1620→321、`>180°` 410→94，
  `final_h<−1000 m` 1225→389。
  **但最坏单例不变**（165.1° / −4197.7 m，delay 0.159 s、增益 1.245/1.390）：
  tuned 降低概率和尾部质量，不提供最坏情况保证。
- **60 s 时窗（5k，seed 20261026）**：fixed 77.68%/2.26% → tuned
  79.36%/1.24%，无故障失败 1.22%→0.23%；逐 case 救回 51、新增 0、
  无通过→失败。样本小，只作时窗外推。
- **机型适用性**：tuned 在 TandemVec 一致正收益；共轴中性；液体救回 7/
  新增 59（边缘→失败），净负。**低 T/W 机型不得无条件启用降增益**。
- **检测轴边界**：快速 MC 只用滚转速率误差触发阻尼；俯仰/偏航轴的
  触发频率与收益未验证。模块可每轴独立实例，但不能共用状态。
