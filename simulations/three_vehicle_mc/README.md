# 三机型快速参数化 MC（反演模型 + 超大规模扫描）

> 目标：用**可飞行配置**反演三型飞行器的等效系统模型，用向量化降阶 6DOF 内核做
> 数十万级参数/噪声/误差/故障扫描，回答“哪些参数组合会把闭环推出包线”。
> **这不是固件 SIL，也不是实机验证**；固件 SIL 在 `TandemVec_FCS/test_host/fw_sil`。

## 1 反演模型

模型表见 [models.py](models.py)，原始来源与置信度：

| 机型 | 直接来自实飞配置 | 反演/假设 | 不可辨识 |
|---|---|---|---|
| TandemVec | m=0.70 kg、Ix=0.0021、Iy=Iz=0.022、kT/kQ/wMax、a=b=0.315、τm=0.28、15° | 无（参数为实飞配置/组件估算） | 气动阻尼、Jp、部分惯量为组件估算 |
| 共轴 VTVL | m=0.84 kg、Tmax=14 N、PID 4.25/0.25/0.08、yaw 3.8/30、滤波/限幅 | I=0.05/0.05/0.08、lever=0.15、yaw 力矩系数=0.0005；用 assumed 0.12 s rate-loop 时间尺度使 `Kp_rate·lever·T/I≈10.5 s⁻¹` | 惯量/力臂/差速力矩/TVC 机械方向没有实飞辨识 |
| 液体火箭 | M0=16.5 kg、Tmax=200、Tmin=80、Isp=200 s、T-rate=1800 N/s、delay=0.1 s | I=0.35/3.0/3.0、lever=0.45、姿态增益 3.0/8.0 | 惯量/力臂/气动阻尼/RCS；CCAEGT `M_DRY=12.5` 与固件 `DRY_MASS=13.5` 不一致 |

**反演的核心假设**：共轴/液体的惯量与力臂无法从“能飞”唯一反解；本表用控制权限
（增益、限幅、质量、推力）与假设的闭环时间尺度构造一个**低置信等效模型**。
因此这里的结果只能用于敏感度/包线研究，不能写成“实机模型”或“飞行通过”。

## 2 快速 MC 内核

[fast_mc.py](fast_mc.py)：

- 状态：高度/垂速、roll/pitch/yaw 角度与角速率；
- 控制：姿态外环 P → 速率内环 P（角度域）+ 高度 PD；
- 执行器：电机/舵机一阶滞后、推力曲线（TandemVec `T=Tmax·u²`，共轴/液体线性）、
  限幅、舵机卡死、推力损失；
- 扰动：质量/惯量/推力/增益/力臂偏差、角度/角速率噪声与偏置、传感器延迟、
  垂直风、力矩噪声；
- 每个 case 独立参数，按 chunk 向量化；输出 max 角度、最终高度、失败标记。

**边界**：无 EKF/导航融合、无气动/桨叶动态、无真实振动谱；这是“快速包线工具”，
不是固件复刻。

## 3 运行

```bash
cd simulations/three_vehicle_mc
py -3.12 run_mega.py --cases 2000 --nominal          # 名义参数快速自检
py -3.12 run_mega.py --cases 100000 --duration 20    # 宽范围 100k/机型
```

结果写入 `sim-data/mega-300k-2026-10-24/summary.json` + `samples.csv`。

## 4 当前结果（2026-10-24，L1 降阶 MC）

- **名义范围 50k/机型（无故障，150k 总）：三机型 100% 通过**，
  max_ang P95 0.62–1.17°，final_h P05/P95 9.47–10.19 m。
- **宽范围 100k/机型（含 2% 推力损失、1% 舵机卡死，300k 总）**：

| 机型 | 全部通过/失败 | 无故障通过/失败 | 含故障通过/失败 | max_ang P95 |
|---|---|---|---|---|
| TandemVec | 78.49% / 3.16% | 80.37% / 1.09% | 18.40% / 69.31% | 11.60° |
| 共轴 VTVL | 84.71% / 3.91% | 86.63% / 2.35% | 21.92% / 54.91% | 11.26° |
| 液体火箭 | 60.52% / 23.48% | 61.90% / 21.89% | 15.38% / 75.74% | 35.53° |

- 敏感度：TandemVec `thrust_loss=-0.802`、`delay=+0.179`；共轴
  `thrust_loss=-0.530`、`wind/mass/thrust≈±0.18`；液体
  `mass=+0.410`、`thrust=-0.381`、`wind=-0.372`，低 T/W 主导失效。
- 宽范围采样：质量 ±18%、惯量 ±35%、推力 ±15%、τm 0.4–2.5×、增益 ±25%、
  力臂 ±35%、角度噪声 0–~6°、角速率噪声 0–~15°/s、偏置 ±6°/±6°/s、风 ±4.5 m/s²、
  力矩噪声、0–150 ms 延迟、2% 推力损失、1% 舵机卡死。
- 数据：`sim-data/mega-300k-2026-10-24/`（summary/analysis/1% 样本/最坏案例）
  与 `sim-data/mega-nominal-150k-2026-10-24/`；完整 110 MB CSV 未入库，可由脚本复现。
