2 核对矩阵

断言强度定义：

  • 强：与解析解、理论值或不变量对比，容差有量级依据；实现写错会失败。
  • 中：只验证方向、单调性、收敛、门控或边界行为，无绝对参考值。
  • 弱：无断言（只打印/基准/产出数据），失败需人读表或由外部脚本判定。

3 覆盖边界（仿真口径 vs 实机）

  1. 全部为宿主/离线口径：没有任何测试接触真实 IMU/GNSS/气压计/舵机/电机， 传感器输入均为合成或注入；fw_sil/ 是真实固件源码 + 理想 plant，仍不是 pio run 二进制、不是 QEMU/Renode、不是实机。
  2. 执行器与气动：plant 侧只有一阶电机滞后与推力/反扭，无桨叶气动、无风扰模型 （fw_sil_env_main 的侧风以等效 NED 力注入）；舵机在 SIL 中另加 300°/s 速率限幅与 0.1% PWM 量化，但与真实舵机的死区/回差/温度漂移不同。
  3. 传感器误差模型：ICM-42688/UBX PVT 用型号标称量级，不是实机标定值； 无振动谱形状、无磁干扰、无 GNSS 多径、无杆臂安装误差（杆臂只在仿真里显式参数化）。
  4. 轴序：test_flight_control_axis.cpp 是直连轴序，与实机 mix 层的 存档系→模型系置换不同构；该差异已在 README 与文件头显式声明，专项核对前不引入置换。
  5. 时标：GNSS 延时用编译常量或合成延时，真实链路延迟需 PPS 标定； ins_gnss_pps_latency.h 的硬件捕获尚未接入。
  6. 通信：只验证打包/校验/组模式与变量注册表；handleAnoCom 的双环频率分档 （COMM-001）、MAVLink 互斥切换、0xF2/0xF3 实机时序均无宿主回归。
  7. 参数来源：控制增益读 kFlightCtrlParams（唯一事实源），但测试内仍有 局部常数（惯量、kT/kQ 取自 TandemVec_Config.h）；models/aircraft-model.json 的仿真参数不在本区域验证。
