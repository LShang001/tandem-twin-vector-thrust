2.4 等价变换推导（单列）

E-1 φ 与 δβ 的关系：秦书 Ĉ^n_b=(I−[φ]×)C^n_b（Ĉ 为计算值）；固件 C_true=C_est·Exp(δβ)（右乘）。一阶展开 C_est=C_true(I−[δβ]×)，与 (I−[φ]×)C_true=C_true(I−[C^b_nφ]×) 比较得 δβ=C^b_nφ，即 φ=C^n_b·δβ。 E-2 δ 方向取反：秦书速度误差 δV=计算−真值，固件 δv=真值−估计，故 δv=−δV；姿态误差 φ 由 E-1 与 δβ 同向。 速度通道：δV̇=−φ×f^n+… ⇒ δv̇=+φ×f^n=−C^n_b[f^b]×δβ，对应 F(V,β)=−C^n_b[f^b]×（代码实现）。 E-3 F(V,β) 的坐标旋转：−[f^n]×=−[C^n_b f^b]×=−C^n_b[f^b]×C^b_n，左乘/右乘 φ 与 δβ 的转换后与代码一致。 E-4 F(β,V) 的符号与矩阵：φ̇⊃δω_in^n，其中 δω_en^n=∂ω_en/∂v·δV，NED 下 ∂ω_en/∂v=[[0,1/(Rn+h),0],[−1/(Rm+h),0,0],[0,−tanφ/(Rn+h),0]]（代码 transport_jacobian）。 由 δβ̇=C^b_nφ̇+Ċ^b_nφ 得 δβ̇⊃C^b_n·∂ω_en/∂v·δV；再用 E-2 的 δv=−δV 取反，得 F(β,V)=−C^b_n·M，其中 M=∂ω_en/∂v——与代码 fs_.block<3,3>(6,3) = -t_b2ned_mid.transpose() * transport_jacobian 一致。 E-5 划摇两式恒等：(2/3)[ΔV₁×Δθ₂−ΔV₂×Δθ₁] = (2/3)(Δθ₁×ΔV₂+ΔV₁×Δθ₂)（叉积反交换）。 E-6 位置误差→LLA 比例尺：δL=δp_N/(Rm+h)、δλ=δp_E/((Rn+h)cosL)、δh=−δp_D，代码 InjectErrorState() 用更新前纬度/高度统一比例尺。
