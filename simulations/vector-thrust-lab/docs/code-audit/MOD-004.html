4 分主题核对结论

4.1 姿态、旋转与欧拉角

  • math.mjs / QuaternionMath.h / Quat4f.h：四元数乘法、共轭、归一化、三明治积 q⊗v⊗q* 与 t=2(q×v) 展开一致；数值复算误差 3.11e-15（sim）、1e-15 量级（fw-nav）。
  • theta = -asin(R13) 与代码 sin_pitch = 2(wy−xz) 是恒等变换（R13=2(xz+wy)），且被列为红线；fw-nav 已加“不可改符号”警示。
  • eulerFromQuat 实际是 ZYX(Rᵀ) 分解（三个角都是逆旋转角），MOD-002 只解释了 theta 的负号——sim 已登记 P2，建议文档补全语义。
  • 姿态更新右乘 q_{k+1}=q_k⊗Exp(ωΔt) + 每步保范，与 REF-120 §9.2 (9.2.14) p.268、MOD-002 §3 一致。

4.2 捷联惯导与 15 状态 ESKF（固件，本轮无 P0）

  • 比力方程 V̇ⁿ=Cⁿ_b f^b−(2ω_ie+ω_en)×Vⁿ+gⁿ（REF-120 §7.4 (7.4.6) p.189）、速度更新 (9.6.9) p.298、旋转效应 (9.6.17)、划摇 (9.6.25) p.301：与 ekf_15_state.h 实现逐项一致；P0-0 修复后 T7 残差 0.000125005（期望 0.000124999）。
  • 误差定义：固件为体轴右乘 q_true=q_est⊗Exp(δβ)，与秦书导航系失准角 φ 的关系 φ=Cⁿ_b·δβ；δ=计算值−真值 vs 固件 δ=真值−估计 的方向取反已单列推导（FW-EKF §2.4 E-1…E-6），F 矩阵与 (9.8.3)/(9.8.13) 换算后逐块一致——属于等价变换，不是符号错误。
