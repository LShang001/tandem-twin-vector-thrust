CTL-006 控制-机型解耦契约与分配器

目标：把"控制律"与"机型动力学/执行机构"之间的接口写成显式契约——姿态/角速度环只输出三轴角加速度指令，制导只输出三轴加速度指令，由机型分配器结合惯量、力臂、推力权限与硬件行程求逆到执行器。控制层不再出现"摆角/差速/舵机 µs"。 关系：分层与红线见 CTL-003；控制律见 CTL-001；共轴原始固件对照见 VER-004。本文记录 2026-10-31 落地的契约、共轴 α 分配器与验证证据，并列出尚未接线的部分。

1 契约分层

层 输入 输出 坐标系/单位 谁负责饱和
制导/位置环 位置/速度误差、杆量 GuidanceCommand.a_cmd_mps2_ned NED，m/s² 制导层做加速度圆限幅
姿态/角速度环 姿态误差或杆量、角速度 AlphaCommand.alpha_body_radps2 机体系 FRD，rad/s² 不饱和；只做增益与滤波
机型分配器 α、油门、角速度、惯量/力臂/行程 舵机角、差速、电机 µs + AllocatorStatus 执行器物理量 分配器钳位并回报 sat_mask/残差
输出映射 规范化通道值 PWM/µs/百分比 硬件槽 映射层做量程保护

结构体定义在 TandemVec_FCS/include/ControlContracts.h（bfs::control 命名空间）：

  • GuidanceCommand{a_cmd_mps2_ned[3], yaw_cmd_rad, yaw_valid, valid}
  • AttitudeSetpoint{q_w,q_x,q_y,q_z, thrust_n, valid}
  • AlphaCommand{alpha_body_radps2[3], valid}
  • AllocatorStatus{torque_cmd_nm[3], torque_achieved_nm[3], torque_residual_nm, sat_mask, valid}
  • ActuatorCommand{channel[8], count, valid}

饱和位（sat_mask）：kSatAlphaRoll/Pitch/Yaw（α 请求超物理权限）、kSatTvcRoll/Pitch（摆角撞行程）、kSatYawDiff（差速撞行程；偏航 α 权限即差速权限，故与 kSatAlphaYaw 并列置位）、kSatLowThrust（推力不足以支撑 TVC）、kSatMotorClamp（电机撞上下限）、kSatInvalid（非法输入/参数）、kSatRateCoupling（陀螺耦合补偿启用）。

1.1 为什么传 α 而不是力矩

力矩 τ=I·α+ω×Iω 需要惯量，而惯量是机型属性；传 α 让控制层完全不知道 I，由分配器统一做动力学逆解。代价是控制增益的物理正确性依赖惯量估计——当前 coax.inertia_* 是 MODEL-DEFAULT（0.05/0.05/0.08 kg·m²），文档与遥测必须保留这一前提。

2 共轴分配器（α + 油门 → TVC/差速）

实现：TandemVec_FCS/include/CoaxialAllocator.h::allocateCoaxial()；固件接线：src/flight_control.cpp 共轴分支，开关 coax.alloc_mode（0=legacy 修正角路径，1=α+分配器，默认 0）。

2.1 正向模型

机体系 FRD，l 为 TVC 力臂、k 为差速力矩系数（N·m/µs）：

Mx =  l·T·sin(δ_roll)      （滚转，两个摆座同向）
My =  l·T·sin(δ_pitch)     （俯仰）
Mz = -k·diff_us            （偏航，差速反向）

2.2 逆解与权限

  1. T = thrust_estimate（缺省 throttle%·max_total_thrust_n）；
  2. α 物理权限：α_max_roll/pitch = l·T·sin(δ_max)/I_roll/pitch，α_max_yaw = k·diff_max/I_z；
  3. 钳位 α → τ=I·α（可选 +ω×Iω，默认关，保证与 legacy 手感一致）；
  4. 摆角：δ=asin(τ/(l·T))，T<min_thrust_for_tvc_n/l 时归中并置 kSatLowThrust；
  5. 差速：diff=τ_z/k，夹在 ±max_yaw_diff_us；
  6. 电机：base=min+throttle%·span，m1=base-diff、m2=base+diff，逐电机钳位；
  7. 回报：torque_requested_nm（未钳位请求）、torque_cmd_nm（钳位后）、torque_achieved_nm（由实际摆角/差速反算）、torque_residual_nm = max|requested-achieved|。

参数（FlightCtrlParams.h::CoaxialCtrlParams，注册表 coax.*，ID 158–163）：

参数 默认 说明
coax.alloc_mode 0 0=legacy，1=α+分配器
coax.lever_m 0.15 TVC 力臂 m
coax.yaw_nm_per_us 1.0e-6 差速力矩系数，MODEL-DEFAULT（由 SIL 差分推力/力臂推导；任务书原稿 0.0005 大 500 倍，已修正）
coax.inertia_roll/pitch 0.05 kg·m²
coax.inertia_yaw 0.08 kg·m²

2.3 identity 约束（legacy 等价）

alloc_mode=1 时固件把 legacy 控制器输出的修正角/差速按同一组参数折回 α：

α_roll  = (l·T_est/I_x)·sin(δ_legacy_roll)
α_pitch = (l·T_est/I_y)·sin(δ_legacy_pitch)
α_yaw   =  k·diff_legacy/I_z

再走分配器逆解。只要参数一致，名义点严格往返，因此"换实现不改手感"可被逐点验证，而不是靠肉眼。

3 纵列分配器现状

纵列路径已是 α 输入：execute_attitude_controller() 写 alpha_roll/pitch_radps2，execute_yaw_controller() 写 alpha_yaw_radps2，TandemVecAllocator 内做 Mx=-Ix·α_yaw、My=Iy·α_pitch、Mz=-Iz·α_roll 后进入 BTRUE 开方、摆角几何与差速。该路径未改动，见 CTL-001 §分配器。

共轴与纵列的差异只在"分配器 + 输出映射"两段；输入解析、模式、积分、定高、目标姿态生成完全共用（flight_control.cpp 步 1–5）。

4 制导 → 动力分配

现状：handlePositionControl() 输出目标加速度（NED），generate_attitude_target() 内部用

f_up = g + a_up
T_cmd/norm = sqrt(a_n² + a_e² + f_up²)
comp_N = a_n/norm, comp_E = a_e/norm

构造倾斜四元数，compute_thrust_control() 给出 specific_force_up_mps2 与 cos_tilt。这套计算与 GUIDED 路径重复，且"加速度→推力/姿态"的饱和责任散落在三个函数与全局量里。

契约化目标（尚未接线）：GuidanceCommand → AttitudeSetpoint 由纯函数一次完成——f_cmd=a_cmd-g_ned、T=m|f|、倾角按 max_tilt 限幅、推力按 max_total_thrust_n 限幅、饱和位回报；q_target 由推力方向与航向构造。接线前必须先证明与现有实现逐位一致（同一输入网格），否则不改飞行路径。

5 通用性路线（AirframeSpec）

  1. 数据化：AirframeSpec 作为唯一真值（机型 id、后端枚举、引脚/输出通道、参数组掩码、安全策略、构建宏）；先做零行为变化的表 + 宿主一致性测试。
  2. 输出合一：applyAirframeOutputs(spec, cmd) 统一 4 槽写引脚；mapTandemVecOutputs/mapCoaxialVtvOutputs 降为测试适配器。
  3. 后端接口：IControlBackend + 编译期模板特化，单二进制只编一条链；共享只到归一化指令/执行器命令/生命周期。
  4. 参数与遥测 schema：params.def 生成 C++ 注册表与 GCS expected_names；遥测公共头 + 机型扩展块；ID 只许尾部追加并用前缀哈希锁死。
  5. 第三机型试点：四旋翼 VTVL 接表 + tools/airframe_matrix.py 一键矩阵。

边界：控制律/增益/故障阈值/模式状态机不共享；不做运行期热切换（一机型一二进制，可审计）；CTL-003 §4 红线（BTRUE 开方、dMax/dwMax、航向门控）不迁移。

6.1 已知行为与风险

  • 低推力差速不门控：T<0.35 N（含 throttle=0）时 TVC 归中并置 kSatLowThrust，但偏航指令仍驱动差速（实测 m1=1000 µs、m2=1180 µs）。该行为与 legacy mapCoaxialVtvOutputs 完全一致，属有意保留；风险已在 VER-004 登记，是否改为"TVC 不可用即零差速"需实机安全评审，不在本次改动内。
  • 饱和语义：torque_cmd_nm 是钳位后力矩，torque_requested_nm 是未钳位请求，残差按后者算；消费方不得用 cmd-achieved 反推残差。
  • 惯量/推力为 MODEL-DEFAULT：α 权限与逆解精度依赖 coax.inertia_*、coax.lever_m、coax.yaw_nm_per_us，未台架标定前只作设计值。
  • 遥测 ABI：GncTelemetry 尾部新增 coax_alloc_sat、coax_torque_residual_nm；AnoVars 尚未暴露分配器饱和位。
  • 制导→动力分配契约尚未接线：当前仍是内联公式；提取纯函数并用网格证明逐位一致后才会替换。
