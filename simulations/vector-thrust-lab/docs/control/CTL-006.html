CTL-006 控制-机型解耦契约与分配器

目标：把"控制律"与"机型动力学/执行机构"之间的接口写成显式契约——姿态/角速度环只输出三轴角加速度指令，制导只输出三轴加速度指令，由机型分配器结合惯量、力臂、推力权限与硬件行程求逆到执行器。控制层不再出现"摆角/差速/舵机 µs"。 关系：分层与红线见 CTL-003；控制律见 CTL-001；共轴原始固件对照见 VER-004。本文记录 2026-10-31 落地的契约、共轴 α 分配器与验证证据，并列出尚未接线的部分。

1 契约分层

层 输入 输出 坐标系/单位 谁负责饱和
制导/位置环 位置/速度误差、杆量 GuidanceCommand.a_cmd_mps2_ned NED，m/s² 制导层做加速度圆限幅
姿态/角速度环 姿态误差或杆量、角速度 AlphaCommand.alpha_body_radps2 机体系 FRD，rad/s² 不饱和；只做增益与滤波
机型分配器 α、油门、角速度、惯量/力臂/行程 舵机角、差速、电机 µs + AllocatorStatus 执行器物理量 分配器钳位并回报 sat_mask/残差
输出映射 规范化通道值 PWM/µs/百分比 硬件槽 映射层做量程保护

结构体定义在 TandemVec_FCS/include/ControlContracts.h（bfs::control 命名空间）：

  • GuidanceCommand{a_cmd_mps2_ned[3], yaw_cmd_rad, yaw_valid, valid}
  • AttitudeSetpoint{q_w,q_x,q_y,q_z, thrust_n, valid}
  • AlphaCommand{alpha_body_radps2[3], valid}
  • AllocatorStatus{torque_cmd_nm[3], torque_achieved_nm[3], torque_residual_nm, sat_mask, valid}
  • ActuatorCommand{channel[8], count, valid}

饱和位（sat_mask）：kSatAlphaRoll/Pitch/Yaw（α 请求超物理权限）、kSatTvcRoll/Pitch（摆角撞行程）、kSatYawDiff（差速撞行程；偏航 α 权限即差速权限，故与 kSatAlphaYaw 并列置位）、kSatLowThrust（推力不足以支撑 TVC）、kSatMotorClamp（电机撞上下限）、kSatInvalid（非法输入/参数）、kSatRateCoupling（陀螺耦合补偿启用）。

1.1 为什么传 α 而不是力矩

力矩 τ=I·α+ω×Iω 需要惯量，而惯量是机型属性；传 α 让控制层完全不知道 I，由分配器统一做动力学逆解。代价是控制增益的物理正确性依赖惯量估计——当前 coax.inertia_* 是 MODEL-DEFAULT（0.05/0.05/0.08 kg·m²），文档与遥测必须保留这一前提。

2 共轴分配器（α + 油门 → TVC/差速）

实现：TandemVec_FCS/include/CoaxialAllocator.h::allocateCoaxial()；固件接线：src/flight_control.cpp 共轴分支。2026-10-31 应用户要求，旧 δ 控制路径（CoaxialVtvControl::update 旧实现）与 coaxialLegacyToAlpha 适配器已从固件删除，α-native 是唯一控制路径；coax.alloc_mode 参数仅保留 ID 兼容旧 GCS，固件不再读取。

2.1 正向模型

机体系 FRD，l 为 TVC 力臂、k 为差速力矩系数（N·m/µs）：

Mx =  l·T·sin(δ_roll)      （滚转，两个摆座同向）
My =  l·T·sin(δ_pitch)     （俯仰）
Mz = -k·diff_us            （偏航，差速反向）

2.2 逆解与权限

  1. T = thrust_estimate（缺省 throttle%·max_total_thrust_n）；
  2. α 物理权限：α_max_roll/pitch = l·T·sin(δ_max)/I_roll/pitch，α_max_yaw = k·diff_max/I_z；
  3. 钳位 α → τ=I·α（可选 +ω×Iω，默认关）；
  4. 摆角：δ=asin(τ/(l·T))，T<min_thrust_for_tvc_n 时归中并置 kSatLowThrust；
  5. 差速：diff=τ_z/k，先夹到电机实际余量 [motor_min−base, motor_max−base]∩±max_yaw_diff_us；
  6. 电机：base=min+throttle%·span，m1=base-diff、m2=base+diff，逐电机钳位；
  7. 回报：torque_requested_nm（未钳位请求）、torque_cmd_nm（钳位后）、torque_achieved_nm（由实际摆角/差速反算）、torque_residual_nm = max|requested-achieved|。

参数（FlightCtrlParams.h::CoaxialCtrlParams，注册表 coax.*，ID 158–163）：

参数 默认 说明
coax.alloc_mode 0 已废弃：固件忽略；α-native 唯一路径
coax.lever_m 0.15 TVC 力臂 m
coax.yaw_nm_per_us 1.0e-6 差速力矩系数，MODEL-DEFAULT（由 SIL 差分推力/力臂推导；任务书原稿 0.0005 大 500 倍，已修正）
coax.inertia_roll/pitch 0.05 kg·m²
coax.inertia_yaw 0.08 kg·m²

2.3 α-native 内环（唯一路径，2026-10-31）

速率环 PI 的输入仍是角速率误差，输出量纲改为 rad/s²：

  • kp_α = g_deg·kp_old、ki_α = g_deg·ki_old，g_deg = (l·T_est/I)·π/180；
  • 积分状态上限保持 int_limit/ki_old，积分输出上限 g·int_limit，输出限幅 α_max=(l·T_est/I)·sin(δ_max)；
  • 偏航：g_yaw = k_yaw/I_z，α_max_yaw = g_yaw·max_yaw_diff_us；
  • T_est = max(0.01·throttle·T_max, 0.35 N)，与分配器同源；α 经原 α0.25 输出滤波后交 CoaxialAllocator 逆解 δ=asin(α·I/(l·T))；
  • ATTITUDE 外环、积分门控、RATE 只复位外环、手动 TVC 路径均不变；手动/未激活仍输出 δ， alpha_valid=false，分配器不接管；
  • 线性化边界：α=g_deg·δ 对 sin 做线性近似，逆解得 δ'=asin(δ_rad)；δ=10° 时 +0.5%，δ=1° 时 +0.005%。

2.4 惯量/增益关系（为什么必须台架标定）

旧 identity 路径已删除，不再有"正逆相消"。当前 g ∝ T_est/I_assumed：

  • 惯量/推力估错会直接改变内环增益，不是只改变中间量；
  • 名义点 A/B 与验收只能证明"在假设参数下响应与旧架构一致"，不能外推到实机；
  • 0.05/0.08 kg·m²、0.15 m、1e-6 N·m/µs 均为 MODEL-DEFAULT，启用前需台架辨识惯量与推力， 并做系留/限高测试；偏航同样依赖 k_yaw/I_z。

2.5 两层输出限幅（2026-10-31 用户要求）

  • 控制器层：α_max=(l·T_est/I)·sin(δ_max)，保证 α 指令在可达包线内；
  • 出口层：最终下发前按执行机构量纲硬夹——舵机 ±max_correction_deg（10°）、 差速 ±max_yaw_diff_us（180 µs），电机 1000–2000 µs 由映射层钳位；
  • 越界写 coax_alloc_sat（kSatTvcRoll/Pitch/YawDiff/MotorClamp），遥测 coax_roll_corr_deg/coax_pitch_corr_deg/coax_yaw_diff_us 即最终下发值；
  • 出口夹层不依赖 T_est/惯量假设，与分配器内部约束构成双保险。

3 纵列分配器现状

纵列路径已是 α 输入：execute_attitude_controller() 写 alpha_roll/pitch_radps2，execute_yaw_controller() 写 alpha_yaw_radps2，TandemVecAllocator 内做 Mx=-Ix·α_yaw、My=Iy·α_pitch、Mz=-Iz·α_roll 后进入 BTRUE 开方、摆角几何与差速。该路径未改动，见 CTL-001 §分配器。

共轴与纵列的差异只在"分配器 + 输出映射"两段；输入解析、模式、积分、定高、目标姿态生成完全共用（flight_control.cpp 步 1–5）。

3.1 液体火箭分配器试点（2026-10-31）

新增 TandemVec_FCS/include/LiquidRocketAllocator.h：同一份 α 输入，按火箭的 L1 假设分配成

通道 逆解 说明
喷管 y（pitch） δy = asin(My/(L·T))，钳 ±8° My = L·T·sinδy
喷管 x（yaw） δx = asin(Mz/(L·T))，钳 ±8° Mz = L·T·sinδx
差动 RCS（roll） u = Mx/k_rcs，钳 ±1；u>0 左喷、u<0 右喷 Mx = k_rcs·u
主阀 油门直通 点火/推力动态仍由 LiquidRocketModel 负责

默认参数取 LiquidRocketModel 的量级（干重 13.5 kg、Tmax 200 N、Isp 200 s、摆心力臂 0.5 m、摆角 8°、RCS 2 N·m、I=[0.6,0.6,0.25]），全部为 MODEL-DEFAULT。α 权限里滚转只由 RCS 决定，pitch/yaw 由 L·T·sin8° 决定；推力低于 min_thrust_for_gimbal_n 时摆座归中并置 kSatLowThrust，滚转仍由 RCS 承担。

边界：这是分配器级试点，未接固件主循环（火箭的制导/点火/阀门时序不在本次范围），也未接 GenericControlAllocation 的冗余通道分配；符号约定按 r×F 的 pilot 假设（+δy→+My、+δx→+Mz），实机需按喷管安装/舵机极性核对。不改变任何现有机型路径。

4 制导 → 动力分配

现状：handlePositionControl() 输出目标加速度（NED），generate_attitude_target() 内部用

f_up = g + a_up
T_cmd/norm = sqrt(a_n² + a_e² + f_up²)
comp_N = a_n/norm, comp_E = a_e/norm

构造倾斜四元数，compute_thrust_control() 给出 specific_force_up_mps2 与 cos_tilt。这套计算与 GUIDED 路径重复，且"加速度→推力/姿态"的饱和责任散落在三个函数与全局量里。

2026-10-31 已提取为纯函数层 include/PowerAllocation.h（无硬件依赖、可单测）：

函数 语义
clampAccelCircle(an, ae, max_accel, sat) 水平加速度矢量圆形限幅，置 kSatAccelLimit
thrustComponentsFromAccel(an, ae, az_up, g, min_norm, comp_n, comp_e, force, sat) f_up=g+az、T=sqrt(an²+ae²+f_up²)、水平分量按 min_norm 下限保护，置 kSatDegenerate
clampTiltComponents(comp_n, comp_e, sin(max_tilt)) 水平分量 ≤ sin(max_tilt)，等比缩放，置 kSatTiltLimit
allocatePowerFromAccel(...) 组合入口（GUIDED 路径使用：圆形限幅 + 推力分量 + 倾角限幅），返回 PowerAllocationOutput

handlePositionControl 的 AUTO_POSITION 路径已改为调用前两个函数（保持原滤波顺序与 min_force=0.5 语义），GUIDED 路径改用 allocatePowerFromAccel(min_force_norm=0, 无滤波)。等价性由 test_power_allocation.cpp 用"拆分前内联代码逐字参考实现"对 9×9×5×3 网格逐位比较（299 882 断言 0 失败），并覆盖饱和位、退化、NaN 与滤波顺序。

q_target 仍由 generate_attitude_target() 构造；GuidanceCommand → AttitudeSetpoint 的显式结构体接线留待下一步（当前先保证纯函数与飞行路径逐位一致）。

5 通用性路线（AirframeSpec）

  1. 数据化：AirframeSpec 作为唯一真值（机型 id、后端枚举、引脚/输出通道、参数组掩码、安全策略、构建宏）；先做零行为变化的表 + 宿主一致性测试。
  2. 输出合一：applyAirframeOutputs(spec, cmd) 统一 4 槽写引脚；mapTandemVecOutputs/mapCoaxialVtvOutputs 降为测试适配器。
  3. 后端接口：IControlBackend + 编译期模板特化，单二进制只编一条链；共享只到归一化指令/执行器命令/生命周期。
  4. 参数与遥测 schema：params.def 生成 C++ 注册表与 GCS expected_names；遥测公共头 + 机型扩展块；ID 只许尾部追加并用前缀哈希锁死。
  5. 第三机型试点：四旋翼 VTVL 接表 + tools/airframe_matrix.py 一键矩阵。

边界：控制律/增益/故障阈值/模式状态机不共享；不做运行期热切换（一机型一二进制，可审计）；CTL-003 §4 红线（BTRUE 开方、dMax/dwMax、航向门控）不迁移。

6.1 已知行为与风险

  • 低推力差速不门控：T<0.35 N（含 throttle=0）时 TVC 归中并置 kSatLowThrust，但偏航指令仍驱动差速（实测 m1=1000 µs、m2=1180 µs）。该行为与 legacy mapCoaxialVtvOutputs 完全一致，属有意保留；风险已在 VER-004 登记，是否改为"TVC 不可用即零差速"需实机安全评审，不在本次改动内。
  • 饱和语义：torque_cmd_nm 是钳位后力矩，torque_requested_nm 是未钳位请求，残差按后者算；消费方不得用 cmd-achieved 反推残差。
  • 惯量/推力为 MODEL-DEFAULT：α 权限与逆解精度依赖 coax.inertia_*、coax.lever_m、coax.yaw_nm_per_us，未台架标定前只作设计值。
  • α 跟踪对惯量失配是开环敏感：test_alpha_tracking.cpp 实测实际 α = α_cmd × I_assumed/I_true（×1.5→0.667、×0.67→1.4925），不饱和也不发散；即分配器不会因失配放大指令，但也没有惯量辨识/自适应。惯量辨识或增益调度需实机/台架数据后再做。
  • 遥测 ABI：GncTelemetry 尾部新增 coax_alloc_sat、coax_torque_residual_nm；AnoVars 尚未暴露分配器饱和位。
  • α-native 是唯一路径，增益依赖 T_est 与假设惯量：g ∝ T_est/I_assumed，实机惯量/推力偏差会直接改变内环增益；名义点 A/B 与验收不能外推到实机。0.05/0.08 kg·m²、0.15 m、1e-6 N·m/µs 均为 MODEL-DEFAULT，飞行前需台架辨识惯量与推力并做系留/限高。
  • 制导→动力分配纯函数已接线、结构体契约未接：AUTO_POSITION/GUIDED 已改为调用 PowerAllocation.h，并用网格证明与拆分前逐位一致；GuidanceCommand/AttitudeSetpoint 结构体尚未替换现有函数签名，属于"函数已收口、类型未收口"的中间态。
