3. 关键差异明细（D1–D15）

D1 RATE_MODE 每拍复位速率环（P0，与 D2／D4 合并；2026-10-30 已修复，见 §10）

  • 判定：语义差异／功能降级。
  • 原始（main.cpp:5140-5172）：RATE 分支只 rollAnglePID.reset(); pitchAnglePID.reset();，速率环 PID 状态、rollAngleOutputFilter/rollOutputFilter 状态全部保留；随后 rateTarget=α0.85 filter(...)，内环 computeDerivativeOnMeasurement(...)，输出 α0.25 filter(constrain(±10))。
  • 当前（CoaxialVtvControl.h:321-328 → :417-427）：先 resetRollPitch()（清 angle PID、rate PID、roll/pitch_rate_filter_、roll/pitch_corr_filter_），再取目标速率；两级滤波在分支外无条件执行（:336-348）。
  • 后果：一阶滤波状态每拍归零 ⇒ 单拍输出 = α·输入，两级串联后 稳态增益 0.85×0.25 = 0.2125（相对原固件 1.0）；速率环无积分、无微分历史，纯 P。即同样摇杆量下当前修正角只有原固件的约 21%，且没有消除静差的能力。
  • 影响：RATE_MODE 由 ch9 可切入，未做任何 SIL/台架覆盖。若实飞误切，姿态响应显著变软且带静差——这是可导致失控的差异。
  • 建议：RATE_MODE 恢复"只复位外环"语义（rate PID 与两级滤波不 reset）；在恢复前，共轴配置应显式禁用 RATE_MODE 或上锁告警。同时修正 CoaxialVtvControl.h:20/:23/:323 与 CTL-003:39 的"实飞工程每拍复位速率 PID"错误注释。

D2 RATE_MODE 速率环积分被禁用（P0，并入 D1；2026-10-30 已修复，见 §10）

  • 原始：manage_pid_integrals（main.cpp:4344-4373）令 rate PID 积分使能 = attitude_control_active，RATE_MODE 下同样积分。
  • 当前：CoaxialVtvControl.h:297-301 的积分使能 = attitude_active && !rate_mode。
  • 后果：RATE_MODE 无积分（与 D1 的纯 P 叠加）。

D4 RATE_MODE 目标速率量级（P0，并入 D1；2026-10-30 已修复，见 §10）

  • 原始：线性 map(raw, 988–2012, ±80)；偏航 map(raw-1500, ±512, ±80)（main.cpp:5155、:5201）。
  • 当前：rcRateCurve（RcCurve.h:72-90）＋ MAX_MANUAL_*RATE=600（state_data.cpp:126-128，注释自认"原 80，行为变化 7.5×"）。满杆：横滚/俯仰 333.3°/s、偏航 222.2°/s（rc_rate=0.5、super=0.7/0.7/0.55）。
  • 后果：目标速率量级 4.2×/2.8×，叠加 D1 的 0.21× 增益 ⇒ 大杆量下内环直接饱和（±10°），小杆量下响应又明显偏弱；曲线形状还引入 expo 非线性。

D3 手动 TVC（P2；2026-10-30 输出滤波已修复，见 §10）

  • 原始（main.cpp:4159、:5173-5185）：raw[7] < 1200 为手动 TVC；回中量由 rollTarget/pitchTarget（±30°）map 到 ±10°，再过 α=0.25 输出滤波；RATE_MODE+手动时目标角为 0（回中）。
  • 当前（flight_control.cpp:202、:2191-2196、CoaxialVtvControl.h:304-316）：raw[7] > 1750（2026-08-10 用户要求的反逻辑，已在代码注释记录）；摇杆直接 map(→±10°) 后 clamp，无 α=0.25 滤波；RATE_MODE+手动时给的是杆量而非回中。
  • 影响：稳态一致，瞬态/换挡手感不同；极性反转若未同步到遥控器配置会直接反向。建议：补输出滤波、把极性写入机型配置说明。

D5 姿态误差算法（P2）

  • 原始恒用 2·sign(qw)·q·RAD2DEG（小角近似，main.cpp:5128-5132）；当前在 |q_v|>0.25（≈28.6°）时改用精确 2·atan2(|v|,|w|)/|v|（flight_control.cpp:1518-1537）。小误差逐位一致；大误差时当前输出略大（更"敢修"），属改进但改变了 >28.6° 段的环路增益。

D6 陀螺滤波（P2）

  • 原始单级 α=0.3（main.cpp:452-454）；当前双级 α=0.4→0.99（flight_control.cpp:1495-1514、state_data.cpp:323/328）。等效带宽更低（相位滞后略增），与原始不是同一传递函数；在 22° 超调问题中不可忽略。

D7 姿态环门控 throttle>1050（P1）

  • 原始（main.cpp:5108）：unlocked && !manual_tvc 即进入姿态稳定，与油门无关（只有积分在 >1100 才使能）。
  • 当前（flight_control.cpp:2187-2188）：unlocked && !manual_tvc && throttle_raw>1050；不满足时走"手动回中/杆量"分支。
  • 后果：飞行中把油门收到 1050 µs 以下（下降/收油），姿态稳定整条链路退出，舵机转为开环杆量；原固件此时仍在稳姿态。这是一条未在文档声明的安全语义变化，建议改为"仅积分门控受油门约束，姿态 P 通路常开"。

D8 空中断链策略反转（P1）

  • 原始（main.cpp:702）：断链 → CH5=988 ⇒ 上锁、CH7=988 ⇒ MANUAL、油门 0。即"断链即停桨"。
  • 当前（communication.cpp:230-260）：若断链前在空中（raw[4]>1500 && raw[2]>1100），CH5 保持 1500、CH7=1500 ⇒ 保持解锁并转 AUTO_ALTITUDE 定高，水平位置随风漂移（VER-002:45 已记录无磁漂移 75/113 m）。
  • 后果：这是有意的设计选择（避免空中停桨），但属于安全策略反转，且没有"链路丢失超时后自动降落/上锁"的兜底。需项目 owner 明确裁决并写入安全文档，否则不应声称"失效行为与实飞一致"。

D9 45° 锁电机（P1，新增）

  • 原始 mix（main.cpp:5227-5257）没有任何倾角保护；当前 ActuatorOutputMap.h:198-236 在 !unlocked || |roll|≥45 || |pitch|≥45 时把 base 压到 1000 µs。
  • 问题一：无迟滞/去抖，单帧 AHRS 角越 45° 立即切油门；恢复也立即恢复，边界附近可能抖动。
  • 问题二：门控只压 base，yaw_diff 仍按 ±180 µs 叠加 —— 45° 越界瞬间仍可能单电机 1000+180=1180 µs（约 18%）在转，与"锁电机"语义不符。建议门控内强制 yaw_diff=0。
  • 问题三：SIL 全场景峰值 22°，该分支从未被覆盖（见 §7）。

D10 积分门限 1050 vs 1100（P2）

  • 原始：姿态/速率/偏航积分门 = throttle>1100（main.cpp:4344-4373）；当前统一 1050（flight_control.cpp:2187-2189）。差 50 µs，影响积分起始点。

D11 航向不可观降级（P2，新增且已记录）

  • 原始无此逻辑；当前 HeadingAidingGate + flight_control.cpp:402 在磁失效时把 AUTO_POSITION/GUIDED 降为 AUTO_ALTITUDE，并关闭 heading hold。属合理新增，本文档仅记录"非等价"。

D12 积分 dt 语义（P2）

  • 原始 integral_ += error（不乘 dt），Ki 在实例化时预乘 0.005（速率环 0.0004、高度速度环 0.00625 等）；yaw 例外：Ki=0.15 未预乘。
  • 当前 integral_ += error*dt、Ki 直接取 0.08／30。只在 dt=5 ms 时数值等价；一旦调度或 coax.dt_s 改变，增益错位。另：当前新增 clampIntegralState()（限 ±|limit/Ki|）与 NaN 冻结，属改进。

D13 混控数值等价性与差速预限幅（P2）

  • 等价已核实：roll% = 50 + (corr/15)×16.667 ≡ map(-corr,-15,15,66.67,33.33)；pitch% = 50 - (corr/15)×16.667 ≡ map(corr,-15,15,66.67,33.33)；电机 1000+throttle×10、base±diff clamp 1000–2000 与原始一致。
  • 差异：当前先把 yaw_diff 压进 [min-base, max-base] 余量（ActuatorOutputMap.h:216-219），高油门时偏航权限被对称削减；原始只做逐电机 clamp，允许单侧饱和。功能上更保守，但与原固件不等价。

D14 垂直推力链（P2）

  • 公式、cos 下限 0.5、0–14 N 钳位、F/Fmax×100 全部等价。
  • 差异仅重力常数：原始 G=9.79（main.cpp:296），当前取 ekf_gravity_mps2（约 9.806，差 0.16%）；另气压计频率 50 Hz→129 Hz（提高，但未验证对垂直 KF 的影响）。

D15 F3/F4 只检测（P2，新增）

  • 原始无 F3/F4；当前 updateCoaxialFaultDiagnostics（flight_control.cpp:2282-2318）只置 g_actuator_servo_jam/thrust_loss/controlled_descent_request 与 gnc_tel.coax_fault_flags（0x01/0x02/0x04），全仓库无消费者。VER-002 的描述（"只检测/上报，没有重构或安全降落"）与代码一致；但它不构成安全功能。

11.3 已知行为与待决

  • α-native 是唯一路径（2026-10-31）：速率内环直接输出机体系 α， 增益按旧值乘 g=(l·T_est/I)·π/180 折算（偏航 k_yaw/I_z），由分配器逆解； 旧 δ 路径与适配器已删除。宿主 cvc/cparams(605)/aco(5539)/atrk(26)/lra(24)/pwa(299 882) 全过；SIL 单一路径 3×5=8/9（RK4 22.777°，Euler 基线 22.764°，同失败集）、8×5=39/40（Euler 版归档）。 惯量/推力未辨识前不得当作实机可飞依据。
  • 实飞增益/惯量关系：旧 identity 层已删除；当前 α-native 的增益 g ∝ T_est/I_assumed， 惯量与推力估计直接进入内环增益，因此名义点 A/B 一致不能外推到实机。0.05/0.08 kg·m²、 0.15 m、1e-6 N·m/µs 均为 MODEL-DEFAULT，飞行前需台架辨识并做系留/限高（见 CTL-006 §2.4）。
  • 低推力差速不门控：T<0.35 N（含 throttle=0）时 TVC 归中并置 kSatLowThrust，偏航指令仍驱动差速（m1=1000 µs、m2=1180 µs）。与 legacy mapCoaxialVtvOutputs 一致，属有意保留；是否改为"TVC 不可用即零差速"需实机安全评审，本次不改。
  • 杆量曲线：α-native 与旧路径共用同一条 rc 曲线（满杆 333/222 dps、600 dps 封顶），曲线语义不变；历史 A/B 证据见 sim-data/coax-alpha-native-2026-10-31/。
  • 制导→动力分配已提取纯函数、类型契约未接：AUTO_POSITION/GUIDED 已改用 PowerAllocation.h，test_power_allocation.cpp 用拆分前内联实现做 9×9×5×3 网格对拍（299 882 断言 0 失败）；GuidanceCommand/AttitudeSetpoint 结构体尚未替换函数签名。

  • SIL plant 口径（2026-10-31）：默认仍是 legacy L1（线性推力、线性差速偏航）； --coax-plant-model rigorous 切到 kT·ω²/反扭/陀螺/摆座几何的物理模型（MOD-005）。 rigorous 下 3×5=9/9、8×5=40/40，但闭环被 plant 的推力-油门口径改变 （T∝u² vs T∝u），不得写成控制性能提升；legacy 缺省路径逐行不变， 验收基线仍以 legacy 为准。rigorous 只作研究/灵敏度/标定前检查。
