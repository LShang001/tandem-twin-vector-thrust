VER-003 三机型等效模型反演与巨型 MC

目标：从“曾经能飞”的固件参数/控制配置反演三机型等效系统模型，并在该模型上 做十万级参数-噪声-误差-故障扫描。
证据等级：L1（模型/假设内数值包线）。没有原始飞行日志，反演不唯一； 不能据此宣称实机模型或飞行响应通过。

勘误（2026-10-24 同日）：fast_mc.py 早期把 thrust_loss 乘在油门、 再过二次推力曲线，0.5 被平方成 0.25 推力；TandemVec 的故障桶与 “50% 损失≈1 倍 T/W”表述作废。无故障 case（thrust_loss=1）逐位不变。 修正后权威数据见 §3.5/§3.6，历史目录状态见 sim-data/README.md。

1 反演思路

“能飞”只给出可行性约束（推力/重量、控制权限、闭环时间尺度、限幅）， 不能唯一确定质量、惯量、力臂、阻尼等全部参数。本文采用：

  1. 直接回写：固件/模型 JSON 已有的质量、推力、惯量、力臂、时间常数、增益；
  2. 控制权限约束：用实飞增益 + 限幅 + 质量/推力反推等效惯量/力臂量级；
  3. 可行点假设：在不可辨识方向选一个与 SIL/组件估算一致的可行点；
  4. 明确标注：每个参数的来源、置信度、不可辨识项。

反演实现：simulations/three_vehicle_mc/models.py； 快速 MC：simulations/three_vehicle_mc/fast_mc.py。

2.1 共轴反演的定量关系

实飞速率环 u = Kp_r·(ω_ref−ω)，修正角 u 产生力矩 M=L·T·u，于是

ω̇ = (Kp_r·L·T/I)·(ω_ref−ω)

取实飞 Kp_r=0.25、L=0.15 m、T=14 N，并选 I=0.05 kg·m²，得到 速率环等效极点 10.5 s⁻¹（时间常数约 0.095 s）。这是“能飞 + 手感可接受” 的一个可行点，不是唯一解；L 与 I 同比例变化时结果不可区分。

2.2 液体反演

Tmax/Tmin/Isp/M0 直接来自 CCAEGT/实飞配置；惯量按 16.5 kg、约 1.5 m 细长体 I_trans≈m·L²/12≈3 kg·m²、I_axial≈0.35 构造；力臂 0.45 m、 姿态增益为可行点假设。CCAEGT M_DRY=12.5 kg 与固件 DRY_MASS=13.5 kg 存在已知不一致，本模型用 16.5 kg 总量，不修改外部固件。

3 巨型 MC 设计

3.1 扫描规模

  • 名义自检：2000 例/机型（质量/惯量/推力 ±5–10%、低噪声）；
  • 宽范围：100,000 例/机型，共 300,000 例，20 s/例，dt=5 ms；
  • 状态：高度/垂速、roll/pitch/yaw 与角速率；
  • 控制：姿态外环 P→速率内环 P + 高度 PD；
  • 执行器：电机/舵机一阶、推力曲线、限幅、舵机卡死、推力损失；
  • 扰动：质量/惯量/推力/增益/力臂偏差、角度/角速率噪声与偏置、传感器延迟、 垂直风、力矩噪声；参数分布见 simulations/three_vehicle_mc/README.md。

3.2 判据

  • 失败：非有限、h<−0.5 m、h>30 m、max 角度 >60°；
  • 通过：最终高度 8–12 m、max 角度 ≤35°、无失败。
  • 统计最终高度/最大角度 P50/P95、失效率和参数-失败相关系数（仅诊断）。

参数敏感度（Pearson 相关，仅诊断）：

  • TandemVec：thrust_loss=-0.802、delay=+0.179；无故障时失效率 1.09%， 说明主要风险是推力损失与延迟，不是噪声。
  • 共轴：thrust_loss=-0.530、wind_up=-0.181、thrust_mult=-0.178、 mass_mult=+0.173；低推力/高质量/风是主要边界。
  • 液体：mass_mult=+0.410、thrust_mult=-0.381、wind_up=-0.372； 推力系数 0.7–0.9 组失败 48.2%，1.15–1.31 组失败 5.1%，低 T/W 是主导失效。

结论：在反演可行点附近、无故障名义范围，三机型闭环稳定；宽范围包线 主要由推力/质量/风/延迟和故障主导。共轴/液体的惯量/力臂是反演假设， 这些“通过率”不是实机概率。

3.4 鲁棒化 A/B（20k/机型，同参数同种子）

策略 TandemVec 通过/失败 共轴 通过/失败 液体 通过/失败
固定增益 79.01% / 3.01% 84.88% / 4.15% 60.55% / 23.73%
权限归一化（auth） 78.34% / 2.89% 85.05% / 4.14% 60.55% / 23.75%
振荡自适应（osc） 79.97% / 2.33% 84.89% / 4.15% 60.58% / 23.76%
auth+osc 79.66% / 2.38% 84.91% / 4.15% 60.52% / 23.78%
  • 振荡自适应（速率误差频繁换向→逐步降增益，安静时缓慢恢复）对 TandemVec 有小幅正收益：失败 3.01%→2.33%，max_ang P95 11.49°→10.47°； 共轴基本持平，液体无效（低 T/W 是物理边界，调增益救不了）。
  • 权限归一化会把 TandemVec 的 max_ang P95 推到 25°（部分工况降增益过度）， 不作为候选。
  • 这些是降阶 L1 MC 的算法候选，不修改固件默认飞行参数；要上机必须 SIL/台架 A/B，并保持实飞基线可回退。
  • ⚠ 该 20k 批次在 thrust_loss 修正前；TandemVec 的失败率含被放大的故障， 只作方向参考。共轴/液体线性油门，结果不受修正影响。

候选结论：优先研究“振荡检测降增益”作为可选鲁棒层，默认关闭； 不要用权限归一化替代实飞增益；液体需要推力/质量包线门控而不是调参。

该策略已固化为纯模块 TandemVec_FCS/include/AdaptiveGainDamper.h （7 条宿主断言，默认不接入飞控）。快速 MC 的 osc 变体与之同构； 修正后 300k 与 tuned 参数见 §3.6。

3.6 tuned 阻尼与确定性边界网格

在 §3.5 的默认参数（0.25 s/6/0.90/1.01/0.55）之外，用确定性网格 （延迟 0–210 ms × 姿态增益 0.8–1.4 × 速率增益 0.8–1.4 × 无故障/50% 推力损失/舵机卡死，3 次噪声重复）筛选出更快的阻尼参数：

  • tuned：window=0.15 s, threshold=4, decay=0.85, recovery=1.01, floor=0.45；
  • 不采用 recovery=1.00 的 latch 版本：它在网格上更好，但降增益后不再恢复， 长航时/瞬态后性能不可接受，只作为上限参考。

3.16 速率相位超前（phase lead：L1 接近 AAF，SIL 仍否定）

RatePhaseLead.h：ω_eff=ω+K·(ω−LPF(ω))，一阶低通 τ=0.02 s，DC 增益 1、 高频增益 1+K；不直接对陀螺做差分，理论上比 AAF 更抗噪声。20k （seed 20261024，TandemVec）K=0.1/0.3/0.5/1.0：通过 79.48/79.96/80.23/80.50%、失败 1.65/1.31/1.10/0.89%，K=1.0 接近 AAF K=0.8（80.54/0.84）。

固件 SIL 同样否定（同 6 例、--pos-hold、yaw 关闭）：K=0.5 3/6 （mag_clean 三 seed hold 1.6–2.7 m，全部超 1.5 m 门限）；K=1.0 0/6 （mag_clean seed1 roll 49°/pitch 54°；mag_nominal seed1 hold 77.7 m、 roll 23.7°，其余 roll 20–29°）。与 AAF 结论一致：在现有位置保持外环/ Ki/真实陀螺噪声下，任何抬升速率测量高频分量的方案都会降低相位/噪声 裕度，L1 的相位超前收益无法在 L2 复现。BFS_RATE_PHASE_LEAD 默认关闭， 不进入固件候选。数据：sim-data/aaf-2026-10-24/。

3.17 磁航向跳变限幅（否定）

Ekf15State 新增单次磁矢量更新 yaw 修正上限（mag_yaw_jump_limit_rad， 默认 0 关闭；SIL --mag-yaw-jump）。seed7 mag_nominal：关闭 104.7 m/ 37.0°；15°→146.2 m/176.3°（更差）；30°→77.5 m/37.0°；45°→ 104.7 m/37.0°（同 baseline）。15° 限幅拒掉正常航向收敛所需修正，反而 让航向漂移更远；30/45° 只挪动失败点。正常 seed1–3（15°）仍 6/6，门控 本身不破坏正常路径，但单次跳变限幅不能解决磁扰航向问题——需要 连续一致性/多帧确认或更好的磁干扰模型。该 API 保持默认关闭，不进入 默认导航路径。数据：sim-data/aaf-2026-10-24/sil_acceptance.json。

3.18 陀螺约束的磁航向修正门控（否定）

BFS_MAG_YAW_GYRO_GATE：每次磁更新前把单次 yaw 修正上限设为 2° + 3·|gyro_z|·0.1 s，想用“真实航向不可能比陀螺积分变得更快”挡住 磁扰翻转、同时放行正常转弯。SIL：seed7 mag_nominal hold_end 104.7→ 11.9 m、roll 37→15.7°，仍失败，且 yaw 仍在 t=33/35/38 s 出现 −107°/−94°/−74° 翻转；正常 6 例 3/6（mag_clean seed1/2 hold 2.2/11.6 m、mag_nominal seed2 roll 21.8°），门控把正常磁修正也拒掉。 结论：单次幅值门控（固定或陀螺约束）不能区分正常收敛与磁扰翻转； 需要多帧方向一致性/磁矢量与惯导交叉一致性，或改进磁干扰模型。 BFS_MAG_YAW_GYRO_GATE 默认关闭。数据：sil_acceptance.json。

3.19 多帧磁修正一致性门控（否定）

BFS_MAG_YAW_MULTIFRAME_GATE：EKF 把单次 yaw 修正限到 2° 后继续应用 并返回限幅前期望值；导航层连续 5 帧看到超限就暂停磁融合 3 s。SIL： seed7 hold_end 18.2 m（baseline 104.7、单帧陀螺约束 11.9），仍失败； 正常 6 例 1/6（hold 5.6–71.4 m）——2° 限幅本身破坏正常磁收敛。 限幅/拒绝类方法不能再以“修正幅值”作为磁故障判据。 默认关闭。 数据：sil_acceptance.json。

3.20 航向协方差门控（否定）

BFS_YAW_SIGMA_GATE：HeadingAidingGate 增加 EKF 航向 1σ 输入，P_yaw 1σ >10° 持续 0.5 s 降级位置保持，<6° 持续 3 s 恢复。SIL：seed7 hold_end 104.7→54.0 m、roll 37→23.3°，仍失败；正常 6 例 2/6 （hold 8.8/11.1/14.1 m）——正常爬升/悬停 P_yaw 也会短时 >10°，误降级。 协方差门控同样不能用单一阈值区分正常磁收敛与失效。默认关闭。 数据：sil_acceptance.json。

3.22 MATLAB 频域裕度独立复核

MATLAB R2025b Control System Toolbox 对速率环连续近似 L=C·H/(τa s+1)(τf s+1)s·e^{−τs}（τa=0.05 s、τf=2.17 ms、延迟 20 ms） 做 allmargin：roll/pitch fixed PM 37.8°/附加延迟 49.4 ms；detune70 47.7°/82.8 ms；lead05 66.5°/72.4 ms；aaf08 162.6°/13.3 ms。 yaw：fixed 47.9°/81.8 ms、detune70 55.7°/129.3 ms、lead05 72.3°/110.1 ms、aaf08 −128°/−13.7 ms（线性模型已不稳定）。 速率环 GM 无相位穿越（视为∞）。

这独立解释了 AAF 的 SIL 失败：高相位裕度是假象，高频增益把穿越频率 推到延迟主导区，附加延迟裕度只剩 13 ms；lead05 在速率环模型里尚可但 SIL 仍失败，说明外层位置/航向环与 GNSS 重捕获是后续瓶颈（§3.21）。 L1 连续线性近似，不含位置环/磁融合/振动，不是实机结论。 图/数据：sim-data/matlab-2026-10-25/。

4 解释边界

  • 这是 L1 降阶 MC：无 EKF/导航融合、无气动/桨叶动态、无真实振动谱；
  • 共轴/液体的惯量与力臂是反演可行点，不是唯一实机模型；
  • 高通过率只说明“在该假设模型 + 该参数分布下闭环有界”；
  • 低通过率指出需要台架辨识/增益调度的方向，不等于实机失效概率；
  • tuned 阻尼只在 TandemVec（高 T/W）上得到一致收益；共轴中性、液体净负， 不能无条件套用到所有机型；
  • osc/tuned 不是延迟补偿器：>150 ms 仍可失败；也不是推力损失容错， 不能恢复高度或替代安全降落；
  • 快速 MC 的振荡检测只用滚转速率误差；模块本身是标量、可每轴独立实例， 但俯仰/偏航轴的触发频率与收益未在 MC 中验证；
  • 推力损失/舵机卡死模型是简化效率因子/零控制权限，不是真实电机/舵机故障；
  • ML 代理/风险图/主动学习/聚类/TPE 都是 L1 数据内分析：标签来自 fast MC， 不是实机失效；all 模型的高 AUC 部分来自故障标志特征；风险图高延迟角点稀疏； 聚类不是物理失效机理；TPE 候选未经过 SIL/台架，不能直接当固件默认值； 对抗搜索是红队/最坏情况工具，不是概率估计，也不能证明真实结构/气动极限；
  • 固定降增益消融只是 fast MC 的 L1 结果：它降低了模型失败率，但会牺牲真实 驾驶品质/扰动抑制；不能直接写实机调参，必须 SIL/台架验证。
