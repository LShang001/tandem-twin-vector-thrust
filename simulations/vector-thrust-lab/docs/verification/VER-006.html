VER-006 共轴首飞前检查单（2026-11-04）

对象：共轴双桨电火箭，飞控 WeAct H743，固件 CoaxialVTVL。 本检查单不替代台架/系留；没有共轴实飞数据，首飞按风险递减执行。 配套证据：VER-007 共轴随机与摄动测试、VER-008 共轴执行器故障仿真。

1. 固件与机型

项 要求 检查方法
构建 env [env:CoaxialVTVL]（-DBFS_COAXIAL_VTVL） 构建日志
机型标识 veh=CoaxialVTVL DBG health
PID 架构 只用通用 att_*/rate_*；无 coax.att_kp_* GCS 参数页
共轴硬件参数 coax.max_corr_deg=10、coax.mass_kg=0.84 param get
安全限幅 修正角 10°、差速 180µs；手动模式不因姿态角切电机，AUTO 默认 90° 保护 参数/断桨

当前板已烧统一 PID 的 CoaxialVTVL；health 已确认 veh=CoaxialVTVL。

2. 软件证据

项 结果
共轴 SIL（rigorous plant，8 profile×3 seed） 24/24 PASS
共轴 SIL 全量（8 profile×5 seed） 40/40 PASS（2026-11-04）
共轴控制律 test_coaxial_vtv_control 通过
分配器契约 5539/0
共轴参数回归 197/197
GCS 参数测试 12/12
宿主全量 run_all.sh rc=0

复现：

cd TandemVec_FCS
bash test_host/fw_sil/run_coaxial_acceptance.sh   # 默认 rigorous plant

L1 集总 plant 的俯仰/姿态约定有误，会误报 max_pitch≈23°；不得再用 L1 结果判共轴。严格模型在 10° 原限幅 下 24/24，不需要改 15°。

3. 断桨/地面检查（必须）

  1. 断电机动力，只给飞控/舵机供电；
  2. 遥控/地面站看 ch1/ch2：零修正应为 50%（33.33–66.67% 量程）；
  3. 无 TVC 角度传感器：不做舵机摆角方向/中位数据判读；只确认机械无卡滞、线束不干涉；
  4. 未解锁：电机输出必须 1000µs，TVC 不应有大幅动作；
  5. 解锁但零油门：手动模式不因姿态角切电机；AUTO 模式确认 90° 保护/失控保护路径；
  6. 检查差速偏航方向：电机 1/2 差速方向与 yaw 指令一致；
  7. 记录舵机中位/端点 PWM，确认没有机械卡滞；

4. 首飞建议（风险递减）

  • 先 系留/限高，ATTITUDE 模式，小角度（≤5–8°）测试姿态响应；
  • 再低高度悬停（1–2 m），确认配平/漂移和 ch2 不长期贴限幅；
  • 不要首飞直接切 AUTO_POSITION/GUIDED；先手动姿态稳定，再定高，再定点；
  • 全程准备 Kill/上锁；出现持续单侧修正、姿态不跟随、电机异常立即断动力。

5. 证据边界

  • 目前只有 SIL + 源码/参数回归，没有共轴台架、HIL、实飞数据；
  • 质量/推力/力臂/惯量仍是 MODEL-DEFAULT（0.84 kg / 14 N / 0.15 m / 0.05 kg·m²）；
  • 首飞数据应记录：ch1..ch4、IMU/EKF 姿态、高度、coax_alloc_sat、电流/电压；
  • 飞后把实际配平/增益/振动写入 CTL-007/FlightCtrlParams，不要只留在临时参数。

6. 气压 Drift 参照修正（2026-11-04）

室内 hAcc=12–15 m、fake_origin=1 时，气压健康监测曾用不可信 GNSS 高度做 Drift 参照，出现 suspect=1 flags=1。已收紧为：

  • 只有 非假原点且 hAcc∈(0,5m] 才允许用 GNSS 高度判气压 Drift；
  • 无可信绝对高度时不做 Drift 判定（保留 Spike/Stuck）；
  • 室内复测：baro alt≈0.95m、est=0、suspect=0、flags=0。

室外首飞前仍需确认：hAcc≤5m、fake_origin=0、baro suspect=0，并检查 baro alt 随实际升降变化。

7. 上电后必须等待 EKF 静止收敛

2026-11-04 复测：上电 22 s 时 vel=-20.99/8.20/-16.55 m/s（未解锁、静止）， 60 s 后回到 vel=0；这是 EKF 初始化/静止确认的启动瞬态。首飞前必须：

  • 上电静置 ≥60 s；
  • health 的 vel 三轴都≈0、tilt_sig 正常、imu cal=1；
  • 否则不上锁/不起飞。

同时 baro suspect=0；室内 fake_origin=1 属正常，室外应变为 0。

8. 首次解锁 EKF 门（2026-11-04）

固件已加入首次解锁门：地面锁定状态下请求解锁时，必须满足 nav_system_initialized && |v_ned|<1 m/s && tilt_sigma<5°；否则本次解锁被拒绝。 已解锁后不强制上锁，避免空中因速度瞬态误锁。

  • 共轴 24 例 SIL 加门后仍 24/24；
  • 上电 14 s vel=0、tilt_sig=0.54，板子在线；
  • 仍建议按 §7 静置 ≥60 s，门是兜底，不替代操作纪律。

9. 飞行日志新增共轴执行器列（2026-11-04）

tvc record 的 CSV 已增加：tvc_upper_deg、tvc_lower_deg、 motor_front_pct、motor_rear_pct、sat_df/sat_dt/sat_dw。 飞后可直接看两轴喷管、前后电机百分比和输出饱和位。

10. 参数快照（RAM 调参不丢操作）

在线 PID 只写 RAM，重启恢复默认。调参前后使用：

tvc param dump params_before.json     # 148 项全量快照
tvc param load params_before.json     # 重启后写回（RAM）

2026-11-04 实测 param dump 导出 148 项，att_pitch.kp=4.25、 coax.mass_kg=0.84。load 会逐项写回并读回确认，不写 Flash。

11. 未解锁 TVC 回中修复（2026-11-04）

发现无 RC 链路/未解锁时 raw stick=0 被手动 TVC 映射成 ±10°，虽然电机已锁， 但两轴舵机会顶到限位；0xF1 遥测也误报 tvc_upper=-9.99/tvc_lower=+9.99。

修复：

  • mapCoaxialVtvOutputs：!unlocked || !attitude_safe 时两轴修正角强制 0（50%）；
  • 0xF1 遥测同步写最终值（未使能时 0），不再把原始手动映射当实际 TVC；
  • 断桨复测：tvc_upper/lower=0.000、电机 0%、sat 全 0；
  • test_vehicle_profile 新增“未解锁 TVC 回中 50%”断言，通过。

12. IMU 2kHz/P1 飞前检查（2026-11-04）

  • 默认 CoaxialVTVL 使用 P1：2kHz ISR→SPSC ring→Navigation 200Hz 排空；
  • 用 tvc record（不得用 DBG 测时序）记录 10s，然后：
py -3.12 TandemVec_FCS/tools/verify_imu_p1.py <csv>
  • 通过条件：mean≥1950、std≤100、imu_ring_drop=0；
  • 同时检查 conv=1、vel=0、姿态稳定；
  • 若 FIFO 初始化失败，固件自动回退 UI 轮询（CoaxialVTVL_UI 为整机回退环境）；
  • 当前默认实测 mean≈1998、std≈72、ring_drop=0。

13. 飞前状态自动验收（2026-11-04）

tvc record start -o preflight.csv -d 5

  • --expect-powered 额外要求电池>1V、RC有效脉宽；
  • 当前USB供电实测：软件 PASS；--expect-powered 按预期 FAIL（电池0/RC0）。

13.1 负例自检（2026-11-04）

构造 flight_mode=1、unlocked=1、motor_front_pct=5 的坏 CSV，脚本按预期 返回 exit=1 并列出三项违规，证明飞前检查不是空检查。

14. 参数加载/EKF收敛检查（2026-11-04）

  • 批量 param load 会逐项 apply，实测加载148项后 EKF conv=0（pos_sig27.5）； 重启后恢复 conv=1（pos_sig9.03、vel=0）。
  • 飞前流程：param load → 重启飞控 → 等GNSS/对准 → health 确认 conv=1、pos_sig<10m、vel≈0，才能进入解锁检查。
  • 禁止在空中/解锁状态批量加载参数。

15. 首次解锁必须真实GNSS锚点（2026-11-04）

原首次解锁门只要求 g_ekf_converged + nav_system_initialized + vel<1 + tilt<5°， 室内 fake origin 也可能满足；若带 fake origin 起飞、飞行中才首次 GNSS，会触发 硬重锚（位置/速度重置），造成导航突变。

已改为首次解锁还要求 nav_has_real_gnss_anchor。无GNSS室内飞行必须显式走 单独模式，不能靠默认解锁。SIL 构建 FW_SIL_REAL_NAV 仍旁路该门。

15.1 修正（2026-11-04）：无GNSS可解锁

用户明确：无GNSS应允许解锁，退化到姿态模式，只是没有定点功能。因此撤回 “首次解锁必须真实GNSS锚点”的硬门；改为：

  • 无GNSS/fake origin 可解锁，姿态模式可用；
  • 已解锁且fake origin时，首次GNSS不硬重锚，等上锁后再锚定；
  • 这段飞行没有绝对位置/定点，不能宣称位置保持。

16. 断链/模式 SIL 前置修复（2026-11-04）

build_and_run_failsafe.sh 之前全空中场景失败，根因是测试夹具没有设置 g_ekf_converged/g_nav_tilt_sigma_deg，首次解锁门拒绝解锁；补上后：

  • 断链4场景全PASS（air_low/normal、ground、air_relink）；
  • RATE积分/模式重入全PASS。 这是测试前置缺失，不是断链逻辑回归。
