# 目标达成度评估（2026-11-08，Round 175）

> 目标原文：「反正真实实飞固件已经成功飞行过了，飞行没有问题。你自己想办法通过
> 全面仿真分析确认修复所有问题和矛盾，结合实机烧录测试」
>
> 本文是对这个目标的**诚实评估**——哪些做到了、哪些没做到、哪些做不到。

## 1 按目标的三个子句逐条对账

### 1.1 「全面仿真分析」

| 维度 | 状态 | 证据 |
|---|---|---|
| 守卫项数 | **20 项快档 + 2 项慢档 = 22 项** | `verify-all.py --include-sil --include-host` 22/22，750 s |
| 能失败验证 | **14/22 做过违规实验** | VER-009 §2.16 的逐条表 |
| 三机型 SIL | 纵列 3 项、共轴 40 例矩阵、单涵道 2 项 | `run_all_airframes.sh` 6 项全过 |
| 宿主回归 | 全量 | `run_all.sh` 330 s |
| 仿真域单测 | 92 项 | Node test 全过 |
| 参数/推进/分配对拍 | 三层同构 | 3 个 parity 脚本 |

**做到了**：覆盖是宽的，且有 22 项常设守卫持续守。

**没做到**：8 项守卫没做过「能失败」验证（多数是运行时对拍，造违规成本高）。

### 1.2 「确认修复所有问题和矛盾」

**做到了的**（按轮次，有实测支撑）：

| 类型 | 典型例子 |
|---|---|
| 真 bug | 共轴 SIL 编译回归（两行声明被合并，坏了两周） |
| 结构性缺陷 | F4 检测的「指令饱和」条件在真实卡死场景永不成立 |
| 单位混用 | 原始共轴固件 `|Roll| > 45.0f`（弧度当度用，联锁从未生效） |
| 覆盖缺口 | 纵列 3-seeds 验收不在跑批里 |
| 文档腐坏 | AGENTS.md 写「7 项」实际 19 项；CTL-007 状态过时；`2/6` 数字已不适用 |
| 静默失效 | `check_coax_parity` 的 `len(vals)<3: continue` 让「没抓到」等于「真一致」 |

**明确没做到的**：

1. **F4 判据仍是结构性的缺陷**——知道它不工作，但改它需要重新评估误报率，
   且它不执行任何动作（影响仅限遥测），故本轮只记录不改。
2. **`NavAidLossDetector` 仍未接线**——有实现、有单测、固件不调用。
3. **3 个模块完全未用 + 2 个仅测试引用**——都已在 `check-module-wiring.py` 登记：
   - 完全未用：`AdaptiveGainDamper`、`AdrcController`、`GenericControlAllocation`
   - 仅测试：`IncrementalPID`、`ins_gnss_pps_latency` 等 9 项
   - `MedianFilter` / `IMU_AutoCalibrator` **不是死代码**（经 `state_data.h` 间接在用，
     只看直接 include 会误判）
4. **迟滞未加**（A-8 剩余项）——需权衡，当前实飞未观察到边界抖动。
5. **`alpha_ref` 因果链仍未验证**——「不能外推」有实验支持，「为什么不能」仍是推测。

### 1.3 「结合实机烧录测试」

| 项 | 证据 |

| 持续运行 | **39951 s（11.1 小时）**，跨过 `micros()` 回绕点 9.4 倍 |
| CPU 稳定 | 48.5–49.2%（修复前会在 71.6 分钟跳到 409%） |

**做到了**：长时间稳定性有五次独立观测 + 一次工具化验证。

**没做到**：**没有新的实飞**。所有实机证据都是「地面通电运行」，不是飞行。

## 2 三个做不到 / 不该做的

1. **「所有问题」不可能穷尽**——本文档只能说「已发现的都处理了」，
   不能证明「没有未发现的」。这个区别必须保留。
2. **不给实飞结论**——本轮没有任何新的飞行数据。用户说固件已飞过，
   本轮的实机测试是地面自检，不能用来支持或否定飞行结论。
3. **不改固件默认行为**——所有改动都在工具层、文档层、SIL 判据层。
   `FlightCtrlParams.h` 的默认值一个没动，`BFS_*` 宏默认状态一个没改。

## 3 一句话总结

**仿真侧**：覆盖从 7 项守卫扩到 22 项，其中 14 项验过能失败，全量 22/22。
**实机侧**：板子连续跑 9.3 小时、跨回绕点 7.9 倍，8 项自检反复通过。
**问题侧**：发现并处理了 6 类问题，但**仍有 5 项明确未完成**（见 §1.2），
其中 F4 判据是结构性的。

**没有做到「所有」——做到了「已发现的都有结论，未完成的都写明了」。**
