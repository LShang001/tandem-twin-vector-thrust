# VER-002 三机型兼容性与虚拟验证

> 本文回答一个具体问题：把共轴 VTVL（`VTVL_ElectricDualRotor_FCS`）和液体火箭（`VTVL_LiquidRocket_FC`）接入统一固件后，**原来的纵列双发飞行器是否还能按原行为飞行**，以及三机型各自能证明到什么程度。
> 全部结论均为 L0/L1/L2 虚拟证据；没有 HIL、台架或实飞数据，不能写成“实机通过”。

---

## 1 兼容性判据

| 层级 | 判据 | 本次采用 |
|---|---|---|
| C1 输入/模式/导航 | 相同 RC/传感器输入 → 相同模式判定与导航输出 | TandemVec：逐位一致；共轴：共用同一层，SIL 验证 |
| C2 制导/姿态/速率 | 相同姿态/误差/角速率 → 相同执行器指令 | TandemVec：逐位一致；共轴：按实飞工程 PID/滤波/限幅结构逐项对齐；液体：仅 L1 模型，未接飞行模式 |
| C3 执行器输出 | 相同指令 → 相同 PWM/µs/百分比 | TandemVec：逐位一致；共轴：`mapCoaxialVtvOutputs` 与实飞 mix 等价单测；液体：未接固件 |
| C4 闭环响应 | 相同场景 → 高度/姿态/位置包线一致 | TandemVec SIL 24/24；共轴 SIL 8 profile×5 seeds **39/40**（生产口径；旧口径 3×5=14/15）；液体 SIL 9/9 参数扫描 |

**结论先说**：

- **纵列双发（原飞行器）兼容性成立**：新固件在 `TandemVec_FCS` env 下与改造前基线逐位一致，SIL 24/24。
- **共轴 VTVL**：控制律按实飞工程结构逐项移植，但原始固件对照审计（[VER-004](VER-004-共轴机型原始固件对照-控制与安全.md)）发现 RATE_MODE 复位/积分语义与目标量级不等价，属 P0 待处理项；真实固件 + 近似 plant 生产口径 8 profile×5 seeds **39/40**、旧口径 3×5=**14/15**（不是旧文档写的 15/15）。**没有外部实飞日志回放**，不能证明逐波形一致。
- **液体火箭**：只有 L1 推进/质量/喷管模型 + 自研简单回收 SIL；**实飞 CCAEGT 制导未移植，不能声称飞行响应兼容**。

## 3 大规模虚拟验证结果

### 3.1 TandemVec（原飞行器）

- 逐位回归：`mag_clean seed2` 改前/改后 JSON 完全一致（hold_end 0.712 m、max_roll 10.723°）；SIL 1 Hz 轨迹 diff 为空。
- 验收：`mag_clean/mag_nominal/mag_disturbed/nomag_degraded/imu_stuck/imu_nan/imu_drop/gnss_spoof` ×3 seeds **24/24 PASS**；核心三 profile 追加到 5 seeds **15/15 PASS**。
- 无磁 `nomag_degraded`：3/3，定高 9.99–10.03 m、max_roll=0、`pos_degraded=1`（航向不可观主动降级）。
- **长航时边界**：`mag_clean` 时长扫描 40/45/50/55 s 通过，**60 s 失败**
  （roll 179°、pitch 21°，随后 IMU 饱和/健康 Failed）；120 s 同样失败。
  失效起始在 55–60 s，属于既有位置保持-横滚/航向耦合边界；40 s 基线不能外推。
- 边界：无磁 nominal/degraded 会按设计放弃位置保持，风致漂移 75/113 m；不计入位置保持验收。

### 3.2 共轴 VTVL
> 口径说明（2026-10-30 更新）：本节数字全部来自 HEAD `57be7ef` + 未提交的共轴参数化/ plant 开关工作树，用 `run_coaxial_suite.sh --realistic` 一次跑完，证据见 `TandemVec_FCS/test_host/fw_sil/sim-data/coax-2026-10-30/`。旧文档的 "15/15 / 60/100 / P95 64.93" 已被本轮实测替换。逐项语义差异与 P0/P1 结论见 [VER-004](VER-004-共轴机型原始固件对照-控制与安全.md)（控制与安全域）与 [VER-005](VER-005-共轴机型原始固件对照-导航与系统.md)（导航与系统域）。

- **参数化与遥测（本轮新增）**：共轴增益/限幅/滤波/物理常量共 **25 项**注册为 `coax.*`（ID 133–157，表尾追加、旧 ID 不动），默认值由 `static_assert` + `test_coax_params` 的 422 条断言锁定为与原硬编码逐位相同；`GncTelemetry` 尾部追加修正角/偏航差速/饱和/故障位 5 个字段，`AnoVars` 暴露 `coax_sat`/`coax_flt`。风险：这些安全关键常量可在线写且固件无范围钳制，生产前需写保护与评审；`0xAB` 保存仅改 RAM，重启回默认（VER-005 P1）。
- **SIL plant 保真度**：执行器一阶滞后 τ=0.28 s、舵机 300 °/s、0.1% PWM 量化自 `fd6e692` 起本来就在 2 kHz 内环里；本轮把这三项显式参数化（`--coax-motor-tau/--coax-servo-rate/--coax-ground-mu`，默认哨兵保持原值），新增 `--coax-realistic`、舵机卡死注入与电机持久损失。默认开关下 15 场景输出与改动前逐字节一致。按用户口径（VTVL 低速）**不做气动阻尼**，旧 `wind` 直接力语义保留。
- **验收（生产传感器口径，8 profile×5 seeds）**：**39/40 PASS**；唯一失败 `mag_nominal seed1`：`max_pitch=22.108° > 20°`（roll 8.21°、hold_end 0.96 m），两个纯净构建逐位同值。3 profile×5 seeds 口径为 **14/15**（同一失败）。俯仰超调是当前主要裕度瓶颈：该场景指令上限 15°，实测超 7.1°，距 20° 门仅 2.1°。
- **realistic 对照**：8 profile×5 seeds **40/40**；同 seed 翻绿来自地面摩擦 μ 对起飞前地面段的扰动，余量仅 0.085° ⇒ **近门限敏感，不能解读为 "realistic 更安全"**。
- **随机参数 MC**（100 例）：current **56/100**、realistic **57/100**；hold P50/P95 = 1.27/27.59 m（realistic 0.99/21.23），roll P95 12.25°（11.74），pitch P95 58.13°（57.25）。最差 8 例全部是俯仰超调（case073 69.5°、014 62.7°、046 54.8°），两套几乎同集合 ⇒ **俯仰裕度问题在默认 plant 就存在**。该 MC 说明增益对 plant 参数偏差没有宽裕度，必须台架标定。
- **plant 边界扫描**（18 组）**15/18**：失败 `lever_low`（pitch 45.03°）、`iy_high`（pitch 35.39°）、`combined_low`（roll 34.75°/pitch 35.66° 且 F4 触发）；`mass_low` 本轮 PASS（pitch 27.86°），旧文档 "mass=0.70 必失败" 的笼统边界未复现。双发 60% 损失触发 F3、舵机卡死触发 F4（只检测/上报，**没有重构或安全降落**）。
- **120 s 长航时**：沿用旧口径记录（mag_clean 通过，hold_end 0.857 m、max_pitch 2.53°），本轮 suite 未重跑长航时 ⇒ 该数字仍是旧证据。
- **参考等价测试**：`test_coaxial_reference_equivalence` 声称 "原头文件 600 拍 max_err=0"，但 `reference/coaxial/coax_reference.cpp` 与 `PositionPID.h` 是按当前控制器语义重写的（含 reset_roll_pitch 清速率环、积分使能 `!rate_mode`），**是自指测试**，不能独立证明与实飞工程等价（VER-004 P1 已点名）。
- **未证明**：真实共轴惯量/力臂/差速力矩、TVC 机械方向、45° 锁电机故障行为、实飞航向保持、RATE_MODE 语义差异的实机影响。
### 3.3 液体火箭

- `LiquidRocketModel`：点火/解锁互锁、阀门/推力速率、Tmin、Isp 质量流、耗尽关机、双轴 asin 喷管几何；宿主单测 33 断言。
- `test_liquid_rocket_sil`：30 m、3 kg 代表场景接地 2.22 m/s，max_roll 3.0°、max_pitch 2.0°。
- `run_liquid_sil_sweep.sh`：20/30/40 m × 2.5/3/4 kg 共 9 组，全部着陆，接地 2.15–2.45 m/s。
- `test_liquid_ccaegt_reference`：把外部实飞工程的 CCAEGT 制导库（逐字复制于
  `test_host/reference/ccaegt/`，仅加注释字段）作为参考制导，驱动本机
  `LiquidRocketPropulsion`：30 m 回收进入 BRAKE、触地 1.87 m/s、LANDED，
  质量 16.5→15.96 kg、剩余推进剂 3.46 kg。证明“实飞制导假设 + 本机推进模型”
  可以闭合，**不等于**把 CCAEGT 接入了固件飞行模式。
- `run_liquid_sweep.py` 15 组推进参数扫描：Isp 150–250 s、Tmax 180–220 N、
  Tmin 60–100 N、阀门 5–20/s、推力速率 900–2700 N/s、20–40 m、2.5–4 kg。
  **14/15 通过**；唯一边界 Tmax=180 N 时接地 4.00 m/s（刚好越过 4 m/s 门限），
  说明低推力裕度不足时必须降低回收高度/提高 Tmax 或放宽着陆速度。
- `run_ccaegt_sweep.sh`：CCAEGT 参考制导 20/30/40 m 三组全部着陆，
  接地 1.84–1.87 m/s；说明参考制导在本 L1 模型下对高度不敏感（在 4 kg
  推进剂包线内），不是实机包线。
- **随机参数 MC**（`run_liquid_mc.py`，200 例，宽范围）：**160/200 通过**；
  接地速度 P50/P95=2.30/3.46 m/s，roll/pitch P95≈4.6°。
  Tmax 180–190 N 组仅 30/63，Tmax≥200 N 组 84/84；低推力/高质量组合是
  主要失效边界。参数为 L1 模型假设，不是实机包线。
- 已知参数不一致：外部 CCAEGT `M_DRY=12.5 kg`，外部固件 `DRY_MASS=13.5 kg`；
  参考测试用 12.5+4.0=16.5 kg 对齐 CCAEGT，未擅自改外部飞行固件。
- 未证明：CCAEGT 固件级接入、真实阀门/泵压/室压、RCS、多级、气动、实机。

## 4 模块化与复用边界

当前分层（详见 [CTL-003](../05-控制与分配/CTL-003-多机型与执行器抽象.md)）：

| 层 | 模块 | 复用方式 |
|---|---|---|
| L0 机型数据 | `VehicleProfile.h` | 机型能力位/输出表 |
| L1 正向模型 | `AirframeModel.h`、`TandemVec_Propulsion.h` | 执行器几何/输入映射/数值 B |
| L2b 垂直推力 | `ThrustAllocation.h` | 比力 → 总推力/油门 |
| L2 转动分配 | `TandemVecAllocator.h`、`GenericControlAllocation.h`、`CoaxialVtvControl.h` | 机型逆解/通用 N 输入/DirectTvcRate |
| L3 输出 | `ActuatorOutputMap.h` | 归一化指令 → 舵机/电调/阀门 |
| L4 GNC 胶水 | `runGNCExecutive` | 输入/模式/定高/目标姿态共用；机型分支只替换控制/混控 |
| 安全观测 | `HeadingAidingGate.h`、IMU/GNSS/磁门控 | 跨机型复用 |

**当前机型选择是编译期**（`TandemVec_FCS` / `CoaxialVTVL`）；后续可把 `VehicleProfile` 选择做成运行期参数/配置，但要先完成各机型参数/输出表的实机标定，不能只靠枚举切换。

## 5 结论与下一步

**可以确认**：统一固件在 TandemVec 配置下与改造前行为逐位一致；共轴控制律结构已移植，共轴 SIL 8 profile×5 seeds 39/40（旧口径 14/15）、realistic 40/40、sweep 15/18、MC 56/100；液体推进/质量/喷管模型通过 9 组回收 SIL。共轴原始固件对照审计已完成（VER-004/VER-005），发现 RATE_MODE 语义差异等 P0/P1 项，处置前不得直接飞共轴。

**不能确认**：共轴/液体与各自实飞固件的逐波形响应一致；三机型在真实气动/推进/传感器/执行器/HIL 下的稳定性；液体 CCAEGT 飞行模式兼容；共轴在 RATE_MODE 语义差异未处置前的可控性。

**实飞日志检索结果**：已检查两个外部工程的 git 全历史、`outputs/`、`test/`、
`tools/`、归档与 `.reasonix` 目录，未发现可回放的 `.bin/.csv/.tlog/.ulg` 飞行记录。
因此当前只能做到控制律/结构级等价和 SIL，不能做飞行波形回放；需要用户提供
原始黑匣子/遥测日志后才能完成 C4 级飞行响应对照。

下一步按证据优先级：

1. **先处置 VER-004 的 P0-4（RATE_MODE）**：恢复实飞工程的复位范围/积分语义或显式禁用该模式，二选一需由机主裁决；同时处理 P1（参考测试自指、俯仰裕度、空中断链策略、45° 硬切）后再谈共轴台架；
2. 用两型实飞日志做传感器/指令回放，比较新固件执行器输出与原固件（最强兼容性证据）；
3. 移植/审查 CCAEGT 制导与液体双摆座/阀门/RCS 输出，建立液体固件分支；
4. 共轴台架标定惯量、力臂、差速力矩、TVC 方向与 45° 锁（VER-005 另列 DETA100 直出、航向门控、参数持久化、GNSS 丢失兜底 4 项 P1 需同步评审）；
5. 再做 HIL/系留，最后才谈实飞。
