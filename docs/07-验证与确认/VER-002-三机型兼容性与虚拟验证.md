# VER-002 三机型兼容性与虚拟验证

> 本文回答一个具体问题：把共轴 VTVL（`VTVL_ElectricDualRotor_FCS`）和液体火箭（`VTVL_LiquidRocket_FC`）接入统一固件后，**原来的纵列双发飞行器是否还能按原行为飞行**，以及三机型各自能证明到什么程度。
> 全部结论均为 L0/L1/L2 虚拟证据；没有 HIL、台架或实飞数据，不能写成“实机通过”。

---

## 1 兼容性判据

| 层级 | 判据 | 本次采用 |
|---|---|---|
| C1 输入/模式/导航 | 相同 RC/传感器输入 → 相同模式判定与导航输出 | TandemVec：逐位一致；共轴：共用同一层，SIL 验证 |
| C2 制导/姿态/速率 | 相同姿态/误差/角速率 → 相同执行器指令 | TandemVec：逐位一致；共轴：按实飞工程 PID/滤波/限幅结构逐项对齐；液体：仅 L1 模型，未接飞行模式 |
| C3 执行器输出 | 相同指令 → 相同 PWM/µs/百分比 | TandemVec：逐位一致；共轴：`mapCoaxialVtvOutputs` 与实飞 mix 等价单测；液体：未接固件 |
| C4 闭环响应 | 相同场景 → 高度/姿态/位置包线一致 | TandemVec SIL 24/24；共轴 SIL 15/15；液体 SIL 9/9 参数扫描 |

**结论先说**：

- **纵列双发（原飞行器）兼容性成立**：新固件在 `TandemVec_FCS` env 下与改造前基线逐位一致，SIL 24/24。
- **共轴 VTVL**：控制律按实飞工程结构逐项对齐，真实固件 + 近似 6DOF plant 15/15；但**没有外部实飞日志回放**，不能证明逐波形一致。
- **液体火箭**：只有 L1 推进/质量/喷管模型 + 自研简单回收 SIL；**实飞 CCAEGT 制导未移植，不能声称飞行响应兼容**。

## 3 大规模虚拟验证结果

### 3.1 TandemVec（原飞行器）

- 逐位回归：`mag_clean seed2` 改前/改后 JSON 完全一致（hold_end 0.712 m、max_roll 10.723°）；SIL 1 Hz 轨迹 diff 为空。
- 验收：`mag_clean/mag_nominal/mag_disturbed/nomag_degraded/imu_stuck/imu_nan/imu_drop/gnss_spoof` ×3 seeds **24/24 PASS**；核心三 profile 追加到 5 seeds **15/15 PASS**。
- 无磁 `nomag_degraded`：3/3，定高 9.99–10.03 m、max_roll=0、`pos_degraded=1`（航向不可观主动降级）。
- **长航时边界**：`mag_clean` 120 s 在约 65 s 后姿态发散（max_roll 180°、max_pitch 90°），
  陀螺饱和/IMU 健康 Failed；40 s 基线仍通过。该长航时位置保持不通过，不能把
  40 s 结果外推到 120 s；属于既有位置保持-航向/姿态边界。
- 边界：无磁 nominal/degraded 会按设计放弃位置保持，风致漂移 75/113 m；不计入位置保持验收。

### 3.2 共轴 VTVL

- `CoaxialVtvControl` 与实飞工程逐项对齐：外环/内环 PID 增益、积分限幅（40/5/50）、输出限幅（±80/±10/±180）、微分滤波 0.2、姿态目标 α=0.85、修正角 α=0.25、RATE_MODE 每拍复位速率 PID。
- **输出级参考等价**：`test_coaxial_reference_equivalence` 直接编译实飞工程的
  `PositionPID.h`/`ComplementaryFilter.h` 原头文件做参考，在 600 拍确定性序列
  （ATTITUDE/RATE/手动 TVC/失效回中）上逐拍比较两轴修正角与偏航差速，
  `max_err roll/pitch/yaw = 0.000000`。
- 真实固件（`BFS_COAXIAL_VTVL`）+ 近似 plant：`mag_clean` hold_end 0.29–0.88 m、max_roll 0.71–1.17°；`mag_nominal` hold_end 0.16–0.85 m、max_roll 8.59–14.23°；`nomag_degraded` 定高 9.84–9.92 m、`pos_degraded=1`。合计 **15/15 PASS**。
- `run_coaxial_sweep.py` 17 组 plant 参数/故障扫描：质量 0.70–1.00 kg、推力 12–16 N、力臂 0.08–0.22 m、Iy 0.03–0.08、Iz 0.04–0.12、差速力矩 0.0002–0.001。**13/17 通过**；边界为 mass=0.70 kg、lever=0.08 m、Iy=0.08（位置保持/俯仰先失稳），说明当前实飞增益对低质量/低力臂/高转动惯量没有鲁棒裕度；`servo_jam` 如预期不可恢复（无共轴故障检测/重构），`motor_loss_30` 仍可定高。**这些是参数边界，不是可忽略的噪声。**
- **120 s 长航时**：`mag_clean` 通过（hold_end 0.857 m、max_roll 1.17°、max_pitch 2.53°），未出现 TandemVec 的 65 s 发散。
- `CoaxialVTVL` env 编译 SUCCESS；宿主 6DOF 闭环（初始 5°/3°、10°/s 偏航）收敛。
- 未证明：真实共轴惯量/力臂/差速力矩、TVC 机械方向、45° 锁电机故障、实飞航向保持。

### 3.3 液体火箭

- `LiquidRocketModel`：点火/解锁互锁、阀门/推力速率、Tmin、Isp 质量流、耗尽关机、双轴 asin 喷管几何；宿主单测 33 断言。
- `test_liquid_rocket_sil`：30 m、3 kg 代表场景接地 2.22 m/s，max_roll 3.0°、max_pitch 2.0°。
- `run_liquid_sil_sweep.sh`：20/30/40 m × 2.5/3/4 kg 共 9 组，全部着陆，接地 2.15–2.45 m/s。
- `test_liquid_ccaegt_reference`：把外部实飞工程的 CCAEGT 制导库（逐字复制于
  `test_host/reference/ccaegt/`，仅加注释字段）作为参考制导，驱动本机
  `LiquidRocketPropulsion`：30 m 回收进入 BRAKE、触地 1.87 m/s、LANDED，
  质量 16.5→15.96 kg、剩余推进剂 3.46 kg。证明“实飞制导假设 + 本机推进模型”
  可以闭合，**不等于**把 CCAEGT 接入了固件飞行模式。
- `run_liquid_sweep.py` 15 组推进参数扫描：Isp 150–250 s、Tmax 180–220 N、
  Tmin 60–100 N、阀门 5–20/s、推力速率 900–2700 N/s、20–40 m、2.5–4 kg。
  **14/15 通过**；唯一边界 Tmax=180 N 时接地 4.00 m/s（刚好越过 4 m/s 门限），
  说明低推力裕度不足时必须降低回收高度/提高 Tmax 或放宽着陆速度。
- 已知参数不一致：外部 CCAEGT `M_DRY=12.5 kg`，外部固件 `DRY_MASS=13.5 kg`；
  参考测试用 12.5+4.0=16.5 kg 对齐 CCAEGT，未擅自改外部飞行固件。
- 未证明：CCAEGT 固件级接入、真实阀门/泵压/室压、RCS、多级、气动、实机。

## 4 模块化与复用边界

当前分层（详见 [CTL-003](../05-控制与分配/CTL-003-多机型与执行器抽象.md)）：

| 层 | 模块 | 复用方式 |
|---|---|---|
| L0 机型数据 | `VehicleProfile.h` | 机型能力位/输出表 |
| L1 正向模型 | `AirframeModel.h`、`TandemVec_Propulsion.h` | 执行器几何/输入映射/数值 B |
| L2b 垂直推力 | `ThrustAllocation.h` | 比力 → 总推力/油门 |
| L2 转动分配 | `TandemVecAllocator.h`、`GenericControlAllocation.h`、`CoaxialVtvControl.h` | 机型逆解/通用 N 输入/DirectTvcRate |
| L3 输出 | `ActuatorOutputMap.h` | 归一化指令 → 舵机/电调/阀门 |
| L4 GNC 胶水 | `runGNCExecutive` | 输入/模式/定高/目标姿态共用；机型分支只替换控制/混控 |
| 安全观测 | `HeadingAidingGate.h`、IMU/GNSS/磁门控 | 跨机型复用 |

**当前机型选择是编译期**（`TandemVec_FCS` / `CoaxialVTVL`）；后续可把 `VehicleProfile` 选择做成运行期参数/配置，但要先完成各机型参数/输出表的实机标定，不能只靠枚举切换。

## 5 结论与下一步

**可以确认**：统一固件在 TandemVec 配置下与改造前行为逐位一致；共轴控制律结构已对齐实飞工程并通过 15 个 SIL 场景；液体推进/质量/喷管模型通过 9 组回收 SIL。

**不能确认**：共轴/液体与各自实飞固件的逐波形响应一致；三机型在真实气动/推进/传感器/执行器/HIL 下的稳定性；液体 CCAEGT 飞行模式兼容。

**实飞日志检索结果**：已检查两个外部工程的 git 全历史、`outputs/`、`test/`、
`tools/`、归档与 `.reasonix` 目录，未发现可回放的 `.bin/.csv/.tlog/.ulg` 飞行记录。
因此当前只能做到控制律/结构级等价和 SIL，不能做飞行波形回放；需要用户提供
原始黑匣子/遥测日志后才能完成 C4 级飞行响应对照。

下一步按证据优先级：

1. 用两型实飞日志做传感器/指令回放，比较新固件执行器输出与原固件（最强兼容性证据）；
2. 移植/审查 CCAEGT 制导与液体双摆座/阀门/RCS 输出，建立液体固件分支；
3. 共轴台架标定惯量、力臂、差速力矩、TVC 方向与 45° 锁；
4. 再做 HIL/系留，最后才谈实飞。
