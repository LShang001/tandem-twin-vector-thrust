# VER-008 共轴执行器故障仿真（2026-11-04）

> 目的：验证 TVC 舵机卡死、单电机推力损失时的保护行为。  
> 结论先说：现有固件有 45° 姿态保护切电机，但**没有执行器故障检测/恢复**；
> 故障后仍会坠落，不能把这类故障当作可控。

## 1. TVC 舵机卡死（t=8 s，20 s 仿真）

| 故障 | 结果 |
|---|---|
| roll 舵机卡死 | 45° 保护切电机，max_roll≈180°、pos_rms 10.2 m、t≈12.7 s 落地 |
| pitch 舵机卡死 | 45° 保护切电机，max_roll≈180°、max_pitch≈90°、t≈10.3 s 落地 |

## 2. 单电机推力损失 50%（t=0）

| 故障 | 结果 |
|---|---|
| motor1 损失 50% | max_roll≈60°、max_pitch≈60°、alt→0 |
| motor2 损失 50% | max_roll≈47°、max_pitch≈47°、t≈17.6 s 落地 |

## 3. 结论与首飞要求

- 45° 姿态保护能切电机，但不能救回姿态；没有故障检测、没有冗余执行器。
- 首飞必须保证舵机/电机机械与电气可靠，系留/低高度、场地隔离；
- 不要在人员/设备上方飞，不要依赖“故障后自动恢复”；
- 若后续要做故障容错，需要额外的角位置/转速/电流反馈和检测律；当前无 TVC 角度传感器。

## 4. 手动 RATE 特技不切电机（2026-11-04 用户要求）

45° 姿态切电机改为**仅非手动 RATE 模式**生效：

```cpp
manual_rate_mode = (attitude_mode == RATE_MODE) && (mode == MANUAL);
attitude_safe = manual_rate_mode || (|roll| < limit && |pitch| < limit);
```

- AUTO_ALTITUDE / AUTO_POSITION / GUIDED / ATTITUDE 仍保留 45° 保护；
- 手动 RATE 允许翻跟头/横滚，超过 45° 不切电机；
- 未解锁/大倾角保护的 TVC 回中逻辑不变，仅在非手动 RATE 生效。

复现：

```bash
fw_coax.exe --real-nav --profile mag_clean --seconds 8 --seed 1 --no-wind \
  --coax-plant-model rigorous \
  --rc-profile test_host/fw_sil/rc_rate_flip.csv
```

实测 t=7 s：`roll=-179.4°、motor=(52.4%,52.5%)`，电机未切；此前会在 45° 切到 0。
该表只注入 CH7=MANUAL、CH9=RATE、pitch 满杆，用于保护门回归。
