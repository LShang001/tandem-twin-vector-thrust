## 4 分主题核对结论

### 4.1 姿态、旋转与欧拉角

- `math.mjs` / `QuaternionMath.h` / `Quat4f.h`：四元数乘法、共轭、归一化、三明治积 `q⊗v⊗q*` 与 `t=2(q×v)` 展开一致；数值复算误差 `3.11e-15`（sim）、`1e-15` 量级（fw-nav）。
- `theta = -asin(R13)` 与代码 `sin_pitch = 2(wy−xz)` 是恒等变换（`R13=2(xz+wy)`），且被列为红线；fw-nav 已加“不可改符号”警示。
- `eulerFromQuat` 实际是 **ZYX(Rᵀ)** 分解（三个角都是逆旋转角），MOD-002 只解释了 theta 的负号——sim 已登记 P2，建议文档补全语义。
- 姿态更新右乘 `q_{k+1}=q_k⊗Exp(ωΔt)` + 每步保范，与 REF-120 §9.2 (9.2.14) p.268、MOD-002 §3 一致。

### 4.2 捷联惯导与 15 状态 ESKF（固件，本轮无 P0）

- 比力方程 `V̇ⁿ=Cⁿ_b f^b−(2ω_ie+ω_en)×Vⁿ+gⁿ`（REF-120 §7.4 (7.4.6) p.189）、速度更新 (9.6.9) p.298、旋转效应 (9.6.17)、划摇 (9.6.25) p.301：与 `ekf_15_state.h` 实现逐项一致；P0-0 修复后 T7 残差 `0.000125005`（期望 `0.000124999`）。
- 误差定义：固件为体轴右乘 `q_true=q_est⊗Exp(δβ)`，与秦书导航系失准角 `φ` 的关系 `φ=Cⁿ_b·δβ`；`δ=计算值−真值` vs 固件 `δ=真值−估计` 的方向取反已单列推导（FW-EKF §2.4 E-1…E-6），F 矩阵与 (9.8.3)/(9.8.13) 换算后逐块一致——**属于等价变换，不是符号错误**。
- KF 五方程 (2.2.4a–e) p.33–34、Joseph (2.2.4e) p.42–43、序贯/子集 §3.3 p.84–86、NIS χ² §7.3.1 p.255–259：一致。
- 地球模型：固件级数式 vs Somigliana (7.2.17)(7.2.18) p.178 差 ~`1e-5 m/s²`（远小于 MEMS 加计零偏），已 `@deviation` 登记。
- 航向源：伪磁初值 `(30,0,40)` + `P0(8,8)=0.2` 是**伪磁确定性初始化**，不是秦书意义的罗经/自对准（MEMS 零偏 0.4 dps ≫ `ω_ie·cosL≈13.25°/h`）。无磁馈入时航向无绝对物理源，属已知设计缺口（fw-nav P1）。
- 静止/ZUPT/光流双新鲜度、`throttle≥3%` 跳过 static gyro 等坑位均已按 AGENTS.md 逐项写入注释。

### 4.3 控制、分配与执行器

- **轴映射**（最高风险项）：以 mix 层实码为锚，确认 `alpha_roll→Mz'→上摆 δf`、`alpha_pitch→My'→下摆 δt`、`alpha_yaw→Mx'→差速 Δω`；三处文档（根 AGENTS / TandemVec_FCS/AGENTS / CTL-001 §3）存在“模型系 vs 存档系”混读，已在 GOV-004 §7.2 增加固定置换说明。
- **速率环量纲**：输入 deg/s、输出 deg/s²，仅在 `ControlOutputs_t` 边界 ×π/180；kp `16.042818/16.042818/11.459156`、ki `5.729578/5.729578/4.297184`，与旧混合域 `0.28/0.20/0.10` 逐位等价（fw-control 复算）。
- **差速**：`ωf=ω0√(1+Δω)`、`ωt=ω0√(1−Δω)`；有效增益 `kp·(w0_actual/w0_used)²`、τm 观测器 `w_est += (w_cmd−w_est)·dt/τm`（0.005/0.28）、封顶 1.0 与 AGENTS 三层记录一致。
- **B 矩阵**：解析式九元素与论文 `eq:Btrue_allocation` 逐项一致，数值差分 T11 等价；方阵用 B⁻¹ 而非 B⁺（与 CTL-001 §2 一致）。
- **两个固件 P0（已按 DEC-002 修复）**：
  - C-01 `ActuatorFaultMonitor` 的 `vertical_vel_err` 符号：调用方原传“目标−当前（下沉为正）”，与监测器“下沉为负”相反；现统一走 `thrustLossVerticalVelocityError(measured,target)`，并只在自动垂直模式启用 F3。
  - C-02 惯量前馈：`omega_body` 为存档系（z=推力轴），`Ix,Iy,Iz` 与 `h_rotor` 原按模型系（x'=推力轴）排列；现由 `computeInertiaCompensationFromArchive()` 一次性置换到模型系，机动时前馈回到正确通道。
- RATE_MODE 每拍复位内环 PID → 等效纯 P（P1，与论文“Rate 模式 PI”表述不符）；在线辨识符号链未对齐（P1）。

### 4.4 推进、气动与六自由度动力学

- `propulsion.mjs` / `hifi_core`：`T=k_Tω²`、`Q=k_Qω²+J_pω̇`、转子角动量、六维映射、差速平方和近似不变，与 THY-002 一致；B 矩阵解析 vs 数值差分误差 `2.38e-9`。
- `aerodynamics.mjs`：动压、升力/阻力/侧滑/阻尼、0.5 m/s 空速下限与 MOD-001 一致；悬停开气动时线性模型失效已注明（P2）。
- 刚体动力学：牛顿-欧拉、RK4 保范、子步 `n=ceil(dt/maxStep)`、地面约束一致；端到端收敛阶实测 1.53/1.38/1.74（一阶 RK4 只作用于 [v,ω,q] 的已知限制，P2）。
