# MOD-005 共轴双桨 VTVL 动力学模型（rigorous）

- 状态：研究模型（SIL 可选，默认关闭）
- 日期：2026-10-31
- 关联：THY-002 §3–§6、CTL-006 §2、VER-004 §11、`TandemVec_FCS/test_host/fw_sil/coaxial_dynamics_model.h`
- 证据：`TandemVec_FCS/test_host/fw_sil/sim-data/coax-model-2026-10-31/`

## 1. 目的与边界

旧 SIL 的共轴 plant 是 L1 集总模型：推力取两电机平均转速的线性映射，差速直接给偏航力矩，
没有反扭的转速平方项、没有转子惯量项、没有双转子陀螺耦合。它可以复现历史验收基线，
但不能回答“物理上力矩从哪来、惯量/反扭/陀螺如何影响响应”。

本模型给 SIL 增加一个可选的 L2 物理模型（`--coax-plant-model rigorous`），用于：

1. 反扭、陀螺、摆座几何与 6DOF 积分的定量研究；
2. 参数（kT/kQ/Jp/τ_m/I）灵敏度与标定前的量级检查；
3. 为后续台架辨识提供"参数→响应"的正向模型。

**不在范围内**：桨叶挥舞/入流/诱导速度、平动升力、地效、旋翼干扰、伺服柔度、电池电压跌落、
气动阻尼（按用户口径 VTVL 低速不做气动，默认 `drag=0`）。地面接触仍由 SIL `Plant::step`
负责，本模型不重复施加地面力。参数默认值全部来自存档 L1，**不是实机辨识值**。

## 2. 坐标系与符号

- 机体系 FRD：x 前、y 右、z 下；NED：z 下。
- 推力轴零摆角沿 −z_b（向上）。
- 摆座角与固件通道一致：δt（俯仰通道）绕 y_b、δf（滚转通道）绕 x_b：

```
F_b = T · [ sin δt,  sin δf,  −cos δf · cos δt ]ᵀ
M_b = [ l·T·sin δf ,  l·T·sin δt ,  −Q_net ]ᵀ
```

`l = 0.15 m` 为 CG 到推力作用点沿 z_b 的距离（ARCH 存档值）。δf、δt 的通道方向沿用
SIL/固件已标定的极性（δf→+Mx、δt→+My）；符号回归测试见 §5。

## 3. 旋翼、反扭与电机

单旋翼（准稳态叶素/动量理论的一阶近似）：

```
T_i = kT · ω_i²
Q_i = kQ · ω_i² + Jp · ω̇_i
```

- `kT = T_max / (2·ω_max²)`：由“双旋翼满转 = 14 N”反标定，`ω_max = 1150 rad/s`。
- `kQ/kT = 0.027`：沿用纵列实机经验值；共轴桨的该比值需台架重测。
- `Jp = 2.0e-4 kg·m²`：转子+桨的转动惯量量级估计，直接进入加减速反扭项。
- 电机一阶：`ω̇ = (ω_cmd − ω)/τ_m`，`τ_m = 0.28 s`；SIL 的 2 kHz 内环另外已有同样的
  一阶跟随与 0.1% PWM 量化，本模型在 `step()` 中独立实现以便单测，SIL 接线只替换 wrench。

双旋翼净反扭：

```
Q_net = kQ (ω_f² − ω_t²) + Jp (ω̇_f − ω̇_t)
M_z = −Q_net
```

符号：`ω_f > ω_t` 时净反扭使机体向 −z（右偏航的反向）转，与旧 SIL 的
“wf>wt → −Mz”一致；旧模型用一个线性系数×差速代替本式。

## 4. 陀螺耦合与摆座

双转子的净角动量（沿推力轴）：

```
h = (0, 0, −Jp (ω_f − ω_t))ᵀ
M_gyro = −Ω × h
```

- 等速反转（ω_f = ω_t）时 `h = 0`，陀螺项**严格为零**——这是“反转双桨互相抵消”的
  数学表达，也是单测断言之一。
- 存在转速差时，机体滚转/俯仰角速率会通过 `−Ω × h` 产生附加力矩；模型提供
  `enable_gyro` 开关，便于 A/B 判断该项对响应的影响。

摆座力矩只保留力臂项 `l·T·sin δ`（小角度下即 `l·T·δ`），不含舵机动力学/间隙；
舵机一阶 + 300 °/s 速率限幅在 `step()` 中实现，与 SIL 2 kHz 内环同口径。

## 5. 6DOF 积分与地面

- 平动：NED 下 `m·v̇ = R(q)·F_b + m·g_ned + 气动阻尼(默认 0)`。
- 转动：欧拉方程 `I·ω̇ = M_b − ω × (I·ω)`；`I = (0.05, 0.05, 0.08) kg·m²`。
- 姿态：`q̇ = ½ q ⊗ (0, ω)`，每步归一化。
- 积分：经典四阶 Runge-Kutta（k1–k4，`h/6` 加权；每子步 q 归一），默认 `substeps=10`。
  2026-10-31 起宿主模型、SIL `Plant::step`、宿主 6DOF 测试统一用 RK4，不再用欧拉积分。
  RK4 在模型内部的 `derivative()` 里同时给出旋翼/舵机一阶导数、地面接触力和四元数导数。
- 地面（`enable_ground`，单测使用；SIL 接线关闭）：`z ≥ 0` 时法向弹簧-阻尼
  `N = k·z + c·v_z`（截断为非负），水平库仑摩擦按 `μ·N` 且单步不反向。
- 能量：`E = ½m|v|² + ½ωᵀIω − m·g·z`，用于自由落体守恒断言。

## 7. 验证（2026-10-31）

**宿主单测** `test_host/test_coaxial_dynamics_model.cpp`（`cdyn`）：36 断言通过。覆盖
kT 反标定/悬停转速、ω² 推力、反扭两项、陀螺符号与等速抵消、摆座力矩方向、自由落体
能量守恒、悬停保持、地面吸收/摩擦、舵机速率限幅、NaN、dt=0。

**SIL 验收对比**（积分统一 RK4 后，`T:/sil_rk4/fw_coax.exe`，同一 seed）：

| 口径 | legacy L1 | rigorous | 说明 |
|---|---:|---:|---|
| 3×5（mag_clean/mag_nominal/nomag_degraded） | 8/9 | 9/9 | legacy 唯一 FAIL `mag_nominal seed1` max_pitch **22.777°**>20° |
| 8×5（含 mag_disturbed/imu_*/gnss_spoof，Euler 版） | 39/40 | 40/40 | 同一失败场景；RK4 后仅复跑 3×5 |
| `mag_nominal seed1` max_pitch（Euler 版对照） | 22.764° | 3.427° | 见 §8 解释，**不是控制器改进** |
| 同场景 hold_end / roll_max（RK4） | 0.91 m / 8.34° | 1.19 m / 8.94° | rigorous 保持略差、滚转略大 |

**积分口径变化**：RK4 后 legacy 的 `mag_nominal seed1` 由 22.764°→**22.777°**（+0.013°），
失败集与其它场景结论不变；rigorous 仍全通过。宿主 `T8` 6DOF 闭环改用 RK4 后
`roll=0.001 pitch=0.001 pos=(-1.11,1.98,0.10)`，与 Euler 版（-1.10,1.95,0.10）同级，
断言全过。RK4 不改变“legacy 是验收基线、rigorous 只用于研究”的结论。

## 8. 关键发现：推力-油门关系与固件 T_est 的口径差

旧 L1 与固件 `T_est = 0.01·throttle_pct·maxT` 都假设“推力 ∝ 油门”线性。物理模型是
`T = maxT·(ω/ω_max)²`，而 SIL 的电机目标 `ω_cmd = (throttle/100)·ω_max`，于是

```
T_actual(u) = maxT · u²     (u = throttle/100)
T_est(u)    = maxT · u      (固件/分配器假设)
```

悬停时 `u≈0.767`，`T_actual=8.24 N` 而 `T_est=10.74 N`，即分配器把 α 权限
`l·T_est/I` 高估约 30%，实际力矩约为指令的 `T_actual/T_est≈0.77`。这解释了为什么
rigorous 下 `mag_nominal seed1` 的俯仰峰值从 22.764° 降到 3.427°：**不是控制变好，
而是同一 α 指令在物理 plant 上产生的力矩更小、姿态激励更弱**；同时 hold 略差。

结论与后续：

1. rigorous 模型**不能**用来宣称“控制性能提升”；它只说明 plant 口径改变了闭环历史。
2. 若要让 α 权限在物理 plant 上正确，需要标定 `T(u)` 曲线并把固件 `T_est` 改成同一
   映射（二次或查表），这属于安全关键区改动，需台架数据与明确授权，本轮不做。
3. 在此之前，`legacy` 仍是验收基线；`rigorous` 只用于研究/灵敏度/标定前检查。

## 9. 与 legacy 的差异清单

| 项 | legacy L1 | rigorous L2 |
|---|---|---|
| 推力 | `avg(ω)/ω_max · maxT`（线性） | `kT(ω_f²+ω_t²)`（平方） |
| 偏航力矩 | `k_yaw · (ω_f−ω_t)/ω_max` | `−[kQ(ω_f²−ω_t²)+Jp(ω̇_f−ω̇_t)]` |
| 陀螺 | 无 | `−Ω×h`，等速反转抵消 |
| 摆座力矩 | `l·T·sinδ`（T 为线性推力） | `l·T·sinδ`（T 为平方推力） |
| 积分 | Plant 刚体 **RK4**（四 stage，q 每步归一） | 模型 `step()` **RK4**；SIL 两口径同一积分器 |
| 地面 | `Plant::step` 钳制 + 可选 μ | 模型自带（单测用）；SIL 关闭以免双计 |
| 气动 | 无（可选地面 μ） | 默认 0，可开线性/二次阻尼 |

## 10. 标定计划（建议）

1. 台架：给定 PWM 扫点，测 `T(u)`、`Q(u)`、`ω(u)`，拟合 `kT/kQ` 与 `T(u)` 曲线；
   同时测加减速反扭（`Jp`）与电机时间常数 `τ_m`。
2. 双桨对转、固定摆座：测净反扭与转速差的关系，校验 `kQ/kT`。
3. 单轴角速率脉冲：辨识 `I` 与陀螺项符号；与 §4 的 `−Ω×h` 对照。
4. 标定完成后，再决定是否把 `T_est` 改成 `T(u)` 曲线并切换默认 plant 口径。
