# MOD-003 配平与稳定性分析

> 定位：在 MOD-001 整机动力学推导基础上，定量核对纵列双发矢量推力飞行器的纵向配平条件，分析摆角配平裕度与执行器限幅的关系，并给出小扰动稳定性框架与数值证据。本文档为概念级分析，参数均取自 `models/aircraft-model.json`（v0.2.0，推进/惯量/质量/配平为 ESTIMATED 实机回写值；气动/SAS 为 MODEL-DEFAULT）。

---

## 1. 配平问题定义

> **参数集说明（v0.2.0，2026-08-01）**：本文数值全部基于当前参数集（m=0.7kg、kT=1.04e-5、wMax=1150、a=b=0.315m，气动按 VTOL 机身等效）。配平为 **28 m/s 四方程**（Fx/Fz/My/Mz 联立，含前摆 dfTrim 配平尾摆反扭 z 分量），求解器 `scripts/trim_solve.py`（坐标下降）。

考察**纵向定直平飞参考状态**（steady level flight reference）：

```
V  = 28 m/s        （配平速度）
γ  = 0             （航迹倾斜角为零，水平飞行）
β  = 0             （无侧滑）
φ  = 0, p = q = r = 0   （无滚转、无角速度）
```

联立纵向力、俯仰力矩与偏航力矩（含前摆反扭投影的 Mz 分量）：

```
L ≈ m·g            （升力平衡重力，隐含于 Fz 方程）
T ≈ D              （推力平衡阻力，隐含于 Fx 方程）
M_y = 0            （俯仰力矩为零）
M_z = 0            （偏航力矩为零，前摆 dfTrim 配平）
```

代码中配平初始条件由 `state.mjs:resetFlightState` 设置：

```javascript
F.vel.x = P.vTrim * cos(P.aTrim);
F.vel.z = P.vTrim * sin(P.aTrim);
S.quat  = (0, sin(P.aTrim/2), 0, cos(P.aTrim/2));
```

其中 `P.vTrim = 28 m/s`、`P.aTrim = 0.071939478 rad`（4.122°）、`P.thrTrim = 0.19227159`、尾摆配平偏置 `P.dtTrim = -0.32642196 rad`（-18.702°）、前摆配平偏置 `P.dfTrim = -0.03034756 rad`（-1.739°）。按照项目锁定的欧拉角提取约定，物理俯仰为 `+aTrim` 时 HUD 显示 `theta = -aTrim`；二者不能混用。

## 2. 纵向配平求解

### 2.1 联立平衡方程

在 `V = 28 m/s`、`beta = p = q = r = 0` 且航迹角为零时，物理俯仰角等于迎角 `alpha`。令双发稳态推力相等为 `T = k_T(thr*w_max)^2`、反扭 `Q = k_Q·(thr·wMax)²`（稳态 ω̇=0），未知量取 `[alpha, thr, delta_t, delta_f]`。将推进力、线性气动力和重力全部写入机体系，四方程平衡条件为（与 `scripts/trim_solve.py::residuals` 逐项一致）：

```
Fx = T·cos(df) + T·cos(dt) + aX = 0         aX = L·sin(alpha) − D·cos(alpha)
Fz = −T·sin(dt) + aZ + m·g·cos(a0) = 0      aZ = −L·cos(alpha) − D·sin(alpha)
My = −b·T·sin(dt) − Q·sin(df) + q̄·S·c̄·(Cm0 + Cma·alpha) = 0
Mz =  a·T·sin(df) − Q·sin(dt) = 0
```

其中 `qbar = rho·V^2/2`、`L = qbar·S·CLa·alpha`、`D = qbar·S·(CD0 + CDk·(CLa·alpha)^2)`。四方程同时约束纵向力、法向力、俯仰矩与偏航矩：尾摆 δt 承担俯仰力矩配平，前摆 δf 配平尾摆反扭在 z 轴的分量 `−Q·sin(dt)`。侧向 `Fy = T·sin(df)` 为小量（配平后 ≈0.03 N），未计入方程组。

### 2.2 数值解与代码参数

使用 `models/aircraft-model.json` 的当前参数求解得到：

| 量 | 数值 | 代码参数 |
|---|---:|---|
| 配平迎角 `alpha_0` | 0.071939478 rad = 4.122° | `aTrim` |
| 配平油门 | 0.19227159 | `thrTrim` |
| 尾摆配平偏置 `delta_t0` | -0.32642196 rad = -18.702° | `dtTrim` |
| 前摆配平偏置 `delta_f0` | -0.03034756 rad = -1.739° | `dfTrim` |
| 单发转速 | 221.11 rad/s | `thrTrim*wMax` |
| 单发推力 | 0.5084 N | `kT*(thrTrim*wMax)^2` |

代回上述四式后，`F_x`、`F_z`、`M_y`、`M_z` 四个残差均小于 `1e-12`（SI 单位，坐标下降收敛）。这不是六自由度全配平：非零 `dfTrim` 使前电机反扭矩在 y 轴留下 `M_y` 一阶小残差，且未闭合 `F_y`、`M_x`。

在 60 Hz 帧率、4 ms 子步和全 SAS 模式下连续运行 10 s，回归基线（2026-08-05 重采）末点：空速 `24.5955 m/s`（油门开环 phugoid 衰减，自 28 m/s 下降约 12%）、`z=1.7475 m`、显示俯仰角 `-4.569°`，同时出现 `phi=0.690°`、`psi=4.113°` 和侧移 `y=-7.838 m`。因此该初值应称为"纵向配平参考点"；它适合验证纵向平衡与控制符号，但不能直接作为完整九状态 Jacobian 的平衡点。

### 2.3 指令零位与显示角

UI 中尾摆滑块表示相对配平增量，实际执行角为 `delta_t,act = dtTrim + delta_t,UI + delta_t,SAS`。因此滑块为零不代表物理尾摆角为零，而代表处于 `dtTrim` 配平偏置。全 SAS 的俯仰姿态误差定义为：

```
theta_error = theta_display - theta_ref = theta_display + aTrim
theta_ref = -aTrim
```

保持这一显式定义可以避免将物理俯仰 `+aTrim`、HUD 显示 `-aTrim` 和控制器误差混为一谈。

## 3. 配平摆角裕度：dtTrim 与执行器限幅的关系

### 3.1 当前参数下无 C_m0 补偿需求

v0.2.0 气动已换为 VTOL 机身等效参数：`C_m0 = 0.0`（无翼机身无配平弯度）、`C_mα = −0.1`（细长体弱静稳定）。因此**不再存在**旧参数集（C_m0=0.011、C_mα=−0.4）下的"零迎角俯仰力矩配平补偿"问题——那段 C_m0 案例分析（旧参数下配平摆角占限幅 81%、裕度仅 19%）随参数集变更而失效，其机理教训（控制权限 vs 静稳定度）保留在 MOD-001 §7.2。

### 3.2 尾摆配平偏置占限幅比例（新参数）

配平尾摆偏置 `dtTrim = −18.702°` 与限幅的关系：

```
仿真限幅  P.dMax = 25°  →  18.702° / 25° ≈ 74.8%，剩余增量裕度约 6.3°
固件限幅  dMax  = 15°  →  18.702° / 15° ≈ 124.7%，超出限幅！
```

**⚠️ 实机对照结论**：固件实机 2026-08-07 已将 TVC 摆角限幅收紧至 ±15°（`TandemVec_Config.h` dMax=0.2618 rad、`state_data.cpp` MAX_CORRECTION=15），而当前巡航配平尾摆偏置 −18.702° 已超出该限幅——**28 m/s 巡航配平点在固件 15° 限幅下不可达**（悬停构型不使用 dtTrim 配平偏置，摆角基准为 0，不受此影响；但任何固定翼巡航/过渡飞行需求必须在实机重新评估配平或放宽限幅）。仿真侧参数（25°）未随固件回写，摆角裕度结论外推实机前必须按 15° 重算（见 [假设与局限日志](../registers/假设与局限日志.md) ASM-017）。

### 3.3 SAS 增量裕度

配平偏置之上的 SAS 增量权限：仿真 ±6.3°（25°−18.702°），若 SAS 积分/比例输出触限则姿态修正饱和。SAS 输出本身被限幅至 ±dMax（仿真 25°），但实际可用增量小于名义限幅——调参时须以"限幅 − |dtTrim|"为有效权限。

## 4. 小扰动线性化框架

### 4.1 状态与输入定义

若先求得六自由度全配平，可选取机体坐标系小扰动状态：

```
x = [ Δu, Δw, Δq, Δθ, Δv, Δp, Δr, Δφ, Δψ ]^T
```

输入为执行机构修正量：

```
u = [ Δδ_t, Δδ_f, ΔΔω ]^T
```

其中：

- 纵向通道：`Δu, Δw, Δq, Δθ`；输入 `Δδ_t`。
- 横侧向通道：`Δv, Δp, Δr, Δφ, Δψ`；输入 `Δδ_f`（偏航）、`ΔΔω`（滚转）。

### 4.2 纵向模态定性分析

纵向力与力矩在配平点附近线性化：

```
X = X_u Δu + X_w Δw + X_δt Δδ_t
Z = Z_u Δu + Z_w Δw + Z_δt Δδ_t
M = M_u Δu + M_w Δw + M_q Δq + M_δt Δδ_t
```

典型固定翼纵向模态：

| 模态 | 主导状态 | 稳定条件 | 本项目依据 |
|---|---|---|---|
| 短周期 | `Δα`（或 `Δw`）、`Δq` | `M_α < 0`（静稳定）、`M_q < 0`（阻尼） | `C_mα = −0.1 < 0`、`C_mq = −2.0 < 0`，弱静稳定且阻尼为负 |
| 长周期 / 沉浮 | `Δu`、`Δθ` | 推力 − 阻力曲线在配平点附近斜率为负 | 当前工作点已同时闭合纵向力、法向力、俯仰矩与偏航矩；油门开环下实测 10 s 弱 phugoid 慢发散（回归基线锁定） |

结论：导数符号支持短周期静稳定与角速率阻尼，10 s 纵向参考量保持有界；横航向仍存在可测残差。这既不能替代特征值、参与因子和更长时域验证，也不能把当前纵向工作点直接称为完整线性化平衡点。

### 4.3 横侧向模态定性分析

横侧向力与力矩线性化：

```
Y = Y_v Δv + Y_δf Δδ_f
L = L_v Δv + L_p Δp + L_δω ΔΔω
N = N_v Δv + N_r Δr + N_δf Δδ_f
```

典型固定翼横侧向模态：

| 模态 | 主导状态 | 稳定条件 | 本项目依据 |
|---|---|---|---|
| 荷兰滚 | `Δβ`、`Δr`、`Δφ` 耦合振荡 | `C_nβ > 0`（航向静稳定）、`C_nr < 0`（偏航阻尼） | `C_nβ = 0.03 > 0`、`C_nr = −0.1 < 0`，航向弱稳定且有阻尼 |
| 滚转收敛 | `Δp` | `C_lp < 0`（滚转阻尼） | `C_lp = −0.3 < 0`，滚转运动收敛 |
| 螺旋 | `Δφ` 缓慢收敛/发散 | `C_lβ < 0`（横滚静稳定）抑制发散 | `C_lβ = −0.05 < 0`，有利于螺旋模态稳定 |

滚转控制特殊性：本布局滚转由双发反扭矩差驱动，控制效率 `∂M_x/∂Δω ≈ −2·k_Q·ω₀²` 为负，SAS 符号已按此整定；低油门时反扭矩差基数减小，滚转权限衰减。

### 4.4 适用边界

上述线性化仅在以下条件有效：

- 小迎角、小侧滑角、小摆角；
- 气动模型为线性，未计入失速、压缩性、螺旋桨滑流干扰；
- 推力/阻力平衡近似，长周期分析需配合精确油门；
- 无风、理想执行器（无舵机速率饱和、无安装误差）。

## 5. 数值证据

回归基线定义于 `tests/scenarios.mjs`（`regression.test.mjs:28` 遍历四个场景），采用固定 60 Hz 帧步长驱动 `stepPhysics`，数据取自 `tests/fixtures/regression-baseline.json`（2026-08-05 重采）：

| 工况 | 描述 | 观察指标（8 s / 10 s 末点） | 结论 |
|---|---|---|---|
| A：纵向配平参考 10 s | 无额外输入，从四方程平衡状态出发 | `V=24.5955 m/s`、`z=1.7475 m`、`theta=-4.569°`；`phi=0.690°`、`psi=4.113°`、`y=-7.838 m` | 四方程残差闭合；横航向残差有界但非零；油门开环 phugoid 慢衰减为固有行为 |
| B：俯仰增量阶跃 8° / 4 s | 从 NED `z=-100 m` 开始，`delta_t,UI = 8°` 持续 240 帧后撤除 | 8 s 时 `V=29.0659 m/s`、`theta=-4.747°`、`q=0.03720 rad/s`，全程未触地 | 验证自由飞行响应与撤除事件；8 s 内尚未完全回到参考点 |
| C：滚转阶跃 0.25·dwUiMax / 4 s | `Delta omega = 0.1375` 持续 240 帧后撤除 | 8 s 时 `V=25.6709 m/s`、`phi=-0.797°`、`psi=8.676°`、`p=0.00254 rad/s` | 姿态误差显著衰减；偏航漂移来自差速-滚转-侧滑耦合 |
| D：偏航阶跃 8° / 4 s | `delta_f,UI = 8°`（绝对前摆指令，配平偏置 dfTrim 之上）持续 240 帧后撤除 | 8 s 时 `V=25.5144 m/s`、`psi=-38.3°`、`theta=-11.9°`、`p=-0.106 rad/s` | 偏航机动响应显著；机动中下降触地（`z=6.2 m` 地面钳位生效），验证地面约束事件 |

上述结果属于**演示性数值检查**，仅在所列工况、当前参数、线性气动模型与理想执行器假设下观察到响应有界。不能外推为大机动、失速、悬停或全包线稳定结论。详细验证流程与通过准则见 VER-001。

## 6. 已知限制与未覆盖项

1. **线性气动**：未含大迎角失速、非定常气动力、螺旋桨滑流与机身干扰。
2. **欧拉角奇异**：`eulerFromQuat` 在 `theta = ±90°` 附近出现万向锁；代码未做特殊处理，大俯仰机动可能数值不稳定（悬停模式已改用四元数级联控制绕开，见 CTL-001 §8）。
3. **低速 / 悬停**：真实空速为零时动压与气动力严格为零，姿态稳定完全依赖推进控制；`lockXY` 只是外部运动学约束，不构成悬停能力证明。
4. **理想执行器**：电机为一阶滞后、摆角瞬时到达指令、无舵机带宽与饱和特性。
5. **无风环境**：未引入大气扰动、阵风或风切变。
6. **四方程配平**：当前参数闭合 `F_x`、`F_z`、`M_y`、`M_z`；完整稳定性矩阵前必须继续求解 `F_y`、`M_x` 与滚转姿态的横航向平衡。
7. **配平偏置与限幅**：`dtTrim=-18.702°` 超出固件实机 15° 摆角限幅（见 §3.2），巡航配平结论不能直接外推实机。
