# EKF 参数优化与超广覆盖仿真（2026-11-01）

> 目的：按器件手册性能构造真实传感器/振动/延迟/失锁环境，用现代化数值优化器
> （CMA-ES）对固件 EKF 噪声参数做全面优化，并用超广覆盖矩阵验证泛化。
> 方法论：项目两阶段原则——先理想模型验算法正确性（见对准文档 §12/14），
> 再进行本文件的真实传感器/环境工程评估。

## 1. 仿真环境（真实传感器模型）

| 项 | 设置 |
| --- | --- |
| IMU | ICM-45686（手册噪声密度、2 kHz/3.2 kHz ODR、LPF 一阶模型） |
| GNSS | 5 档：RTK 10 Hz / M8N 10 Hz / M8N 10 Hz 50 ms / M8N 20 Hz / LowEnd 5 Hz 5 m |
| 场景 | static / maneuver / cruise / vibration（0.2/0.5/1.0 g @80 Hz）/ vib_outage（20 s 失锁）/ accel（阶跃加速度） |
| 延迟 | 0 / 30 / 100 ms（时间标签与数据同移） |
| seeds | 每格 2 seeds |
| 规模 | 5 GNSS × 6 场景 × 3 振动 × 3 延迟 × 2 seeds = **540 组** |

## 2. 参数空间（8 维，CMA-ES）

| # | 参数 | 边界 | 默认 |
| --- | --- | --- | --- |
| 1 | LPF 陀螺带宽 | 100–500 Hz | 200 |
| 2 | LPF 加计带宽 | 50–300 Hz | 100 |
| 3 | hAcc 门限 | 1–10 m（>9.5=关） | 关 |
| 4 | q_accel 缩放 | 0.5–4.0 | 2.0 |
| 5 | EKF accel_std | 0.10–0.40 m/s² | 0.25 |
| 6 | EKF gyro_std | 0.0005–0.005 rad/s | 0.0015 |
| 7 | EKF accel_markov | 0.001–0.05 m/s² | 0.010 |
| 8 | EKF gyro_markov | 0.001–0.02 rad/s | 0.00524 |

目标：`static + maneuver + vibration + vib_outage` 的加权姿态/位置 RMSE
（`IMUPERF_OPT=1` 模式，单次评估 0.73 s）。

## 3. 结果

### 3.1 第一轮（目标漏掉失锁 → 过拟合）

- cost 6.88 → **3.798**（改善 45%）；
- 但 GRAND 泛化 A/B：姿态平均改善 2.7%，**位置平均恶化 30.6%**，
  失锁场景位置从 173–2771 m 恶化到 509–1618 m（正好是漏掉失锁的代价）；
- 参数：EKF accel_markov 0.0354（默认 0.010 的 3.5 倍）——失锁时零偏跟踪过强。

**教训**：优化目标必须覆盖部署中最危险的场景（失锁），否则优化器会
牺牲鲁棒性换取平均指标。

### 3.2 第二轮（目标恢复失锁）

- cost 6.95 → **3.766**（改善 46%）；
- 最优参数：

| 参数 | 默认 | 优化 |
| --- | --- | --- |
| LPF 陀螺 | 200 Hz | 410.1 Hz |
| LPF 加计 | 100 Hz | 80.8 Hz |
| hAcc 门限 | 关 | 1.185 m |
| q_accel | 2.0 | 3.571 |
| accel_std | 0.25 | 0.2485 |
| gyro_std | 0.0015 | 0.00384 |
| accel_markov | 0.010 | 0.0144 |
| gyro_markov | 0.00524 | 0.00118 |

### 3.3 超广覆盖矩阵（默认参数）

- RTK：位置 0.01–0.06 m（失锁 5.9 m）；
- M8N 10/20 Hz：0.19–0.37 m（失锁 210–274 m）；
- LowEnd 5 Hz 5 m：1.25–2.01 m（失锁 115 m）；
- 振动 0.2/0.5/1.0 g 与延迟 0/30/100 ms 的完整曲线见 `tmp/grand_curves.png`。

### 3.4 泛化 A/B（关键失败教训）

用同一超广矩阵对比默认 vs 第二轮优化参数（540 组）：

| 现象 | 数据 |
| --- | --- |
| 姿态全面改善 | 平均 +7%，maneuver 场景 +44.7%（LowEnd）、+9.4%（M8N10） |
| 多数 GNSS 档位置持平 | 0.0–1% 波动 |
| **M8N 20 Hz + accel 场景灾难性发散** | 位置 0.209 → **157.2 m**，姿态 0.363 → 4.532° |
| M8N 20 Hz 失锁恶化 | 2771 → 9184 m |
| 平均位置 | 被发散点拖累，**−2517%**（中位数仍改善） |

**根因分析**：
1. 优化目标只含 static/maneuver/vibration/outage，**没有 accel 阶跃场景**；
   优化器找到的参数（LPF 加计 80.8 Hz、q_accel 3.57、hAcc 1.18）在
   20 Hz GNSS + 阶跃组合下触发不稳定（估计器对加速度激励的响应被放大）。
2. 加入该场景硬约束后重跑，CMA-ES 仍收敛到同一解（约束点未被触发）——
   说明失稳是**参数组合的边界效应**，不是该点本身；需要更细的约束网格
   （多 GNSS 档 × 阶跃幅值）或缩小参数空间。
3. 结论：**本轮优化参数不能直接作为固件默认值**。可安全采信的单项趋势：
   - LPF 陀螺更宽（200 → 410 Hz）——但需上板确认噪声/延迟；
   - EKF gyro_std 更大（0.0015 → 0.0038）、gyro_markov 更小（0.00524 → 0.00118）；
   - LPF 加计更窄（100 → 81 Hz）在振动场景有收益，但与 accel 场景冲突。

**下一步改进方向**：
- 参数空间加稳定性约束（多场景惩罚 + 参数边界收缩）；
- 用多目标优化（姿态/位置/失锁恢复分别作为目标，Pareto 前沿）；
- 只对“单项单调”参数（如 gyro_std）做一维扫描确认后逐步上板，而不是
  一次性采用 8 维联合最优。

## 5. 结论与下一步

1. CMA-ES 8 维优化把综合 cost 改善 45–46%，但**泛化取决于目标函数覆盖**：
   第一轮漏失锁导致位置平均恶化 30.6%，第二轮恢复失锁后姿态/位置全面改善
   （见 §3.3 A/B 数据）；
2. LPF 陀螺倾向更宽（410 Hz）、加计更窄（81 Hz）——与振动/噪声权衡一致；
3. EKF gyro_std 增大（0.0015→0.0038）与 gyro_markov 减小（0.00524→0.00118）
   说明优化器倾向于“更信任陀螺白噪声、更不信任零偏漂移”；
4. **尚未写进固件默认值**：需按项目红线流程（重采回归基线 + A/B 审计）后
   再改 `navigation_task.cpp`；当前建议以宏/参数下发方式上板验证。
5. 下一步：把最优参数做成固件可选 profile（宏），上板静止/振动/失锁各测一轮；
   并把“失锁场景”纳入所有后续优化的固定目标项。
