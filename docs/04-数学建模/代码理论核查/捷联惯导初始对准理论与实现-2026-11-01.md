# 捷联惯导初始对准：理论与本实现（2026-11-01）

> 本文按惯导教材的静基座对准流程（调平 → 粗对准 → 精对准）梳理理论，
> 对照本项目 `Ekf15State` 的实现与测试数据，给出 MEMS 器件的精度边界。

## 1. 对准的三个阶段

| 阶段 | 观测量 | 可观测的状态 | 典型时长 |
| --- | --- | --- | --- |
| 调平（leveling） | 加速度计重力方向 | 水平失准角（roll/pitch） | 秒级 |
| 粗对准（coarse） | 加速度计 + 磁/航向 | 水平 + 方位（姿态矩阵初值） | 秒级 |
| 精对准（fine） | 重力、零速、零角速度、外部航向 | 水平/方位失准角、速度误差、零偏 | 分钟级 |

## 2. 解析式粗对准（双矢量定姿）

重力与地球自转角速度在导航系（NED）与机体系（b）中的投影已知/可测：

```
g^n = [0, 0, −g]^T
ω_ie^n = [ω_ie·cosL, 0, −ω_ie·sinL]^T
```

用 TRIAD 双矢量定姿：

```
C_b^n = [ (g^n×ω_ie^n)×g^n ,  g^n×ω_ie^n ,  g^n ]  ·  [ (g^b×ω_ie^b)×g^b , g^b×ω_ie^b , g^b ]^{-1}
```

**关键限制**：方位（航向）由 ω_ie^n 的水平分量确定，需要陀螺能测到
ω_ie = 15.041 °/h ≈ 0.00418 °/s。MEMS 陀螺零偏（0.4 °/s）与噪声
远大于此，**解析式罗经对准对 MEMS 不可用**——这与文献一致：低精度
MEMS 无法通过传统解析自对准把方位失准角收敛到小角度，需外部航向
（磁力计/GNSS 航迹角）或大失准角非线性对准。

因此本项目 `Ekf15State::Initialize(accel, gyro, mag, ...)` 用
**TiltCompass**：accel 定 roll/pitch、mag（或外部航向）定 yaw，
不依赖 ω_ie；`yaw_offset_rad` 用于磁偏角修正。

## 3. 精对准（Kalman）

状态：失准角 φ（3）、速度误差 δv（3）、加计零偏（3）、陀螺零偏（3）。
观测：

1. **重力方向**（`MeasurementUpdateGravity`）：水平失准角可观；
2. **零速**（`MeasurementUpdateVelocity(0, …)`，ZUPT）：速度误差可观，
   经耦合修正水平失准角与加计零偏；
3. **零角速度**（`MeasurementUpdateStaticGyro`）：陀螺零偏可观
   （z = ω_ib^b，h(x) = C^b_n(ω_ie+ω_en) + b_g）；
4. **外部航向**（磁/GNSS course，`MeasurementUpdateYaw`）：方位可观。

可观测性结论（静基座、单位置）：

- 水平失准角、速度误差、加计零偏：由重力+ZUPT 可观；
- 陀螺零偏：由零角速度可观（但要扣除 ω_ie 投影，MEMS 下 ω_ie 被噪声淹没，
  等价于“零偏可观、ω_ie 不可观”）；
- 方位失准角：仅靠 ω_ie 可观（罗经对准），MEMS 不可用 → 必须外部航向。

## 4. 本实现的测试数据（2026-11-01）

静基座、随机零偏（加计 5 mg、陀螺 0.4 °/s），4 seeds：

| 方式 | 姿态误差 | 陀螺零偏估计 | 300 s 纯惯导漂移 |
| --- | --- | --- | --- |
| 初对准（单帧 TiltCompass） | 0.27–0.38° | ≈0（未观测） | 2.6–25 万米 |
| 精对准（重力+零速+零角速度，无外部航向） | 0.10–0.39° | 0.58–1.40 °/s | 2.6–5.5 km |
| 精对准 + 外部航向（下一轮验证） | 待测 | 待测 | 待测 |

结论：
1. 无外部航向时，方位失准角与陀螺零偏耦合，零偏估计偏大（0.58–1.40 °/s
   vs 真值 0.4 °/s），姿态无法收敛到 0.1° 以下——与“MEMS 方位不可观”
   的理论一致；
2. 但精对准仍把纯惯导漂移从万米级降到公里级（零偏被部分修正）；
3. 要拿到 0.01–0.05° 级对准，必须：外部航向（磁/GNSS）+ 更长精对准
   （几分钟）+ 更低噪声的陀螺；或转台多位置对准。

## 5. 与高精度惯导的差距（书本 vs 本项目）

| 项 | 书本/高精度系统 | 本项目（MEMS） |
| --- | --- | --- |
| 水平对准 | 0.005–0.02°（重力+ZUPT） | 0.1–0.3°（噪声/零偏限制） |
| 方位对准 | 0.05–0.1°（罗经，FOG 级） | 依赖外部航向（磁/GNSS） |
| 零偏估计 | 陀螺 0.001–0.01 °/h | 0.4 °/s 级，估到 10% 已很好 |
| 纯惯导 1 h 漂移 | 1 nm/h 级 | 18–124 km（MEMS/FOG 仿真） |

## 7. 纯罗经解析对准验证（2026-11-01，test_ins_gyrocompass）

TRIAD 双矢量（f^n=[0,0,−g]、ω_ie^n=[ωcosL,0,−ωsinL]），静止 60–600 s 平均：

| 器件 | 时长 | roll/pitch 误差 | yaw 误差 |
| --- | --- | --- | --- |
| FOG（0.001 °/√h） | 60 s | 0.0001–0.0017° | 0.078–0.120° |
| FOG | 300 s | 0.0001–0.0004° | 0.0003–0.031° |
| FOG | 600 s | 0.0002–0.0004° | 0.005–0.023° |
| MEMS（0.02 °/√s） | 300 s | — | 30°（不可用） |

结论：
1. **纯罗经对准对 FOG 可行**：60 s 已能到 0.1° 航向，10 min 到 0.01° 级；
2. **MEMS 不可行**：噪声 ≫ ω_ie（0.00418 °/s），300 s 平均后航向误差 30°，
   与文献“低精度 SINS 无法传统解析自对准”一致；
3. 水平（roll/pitch）任何器件都很好（重力信号强，0.001° 级）。

## 8. 实现路径（纯罗经）

1. 静止采集 f^b、ω^b（60–600 s 平均，抑制噪声）；
2. `C_b^n = [f^n, f^n×ω^n, f^n×(f^n×ω^n)] · [f^b, f^b×ω^b, f^b×(f^b×ω^b)]^T`；
3. 从 C_b^n 提取 roll/pitch/yaw → 作为 EKF 初始姿态
   （`set_quaternion_for_test` / 固件的 Initialize 航向输入）；
4. 精对准：重力 + ZUPT + 零角速度（方位已由罗经给出，不再需要外部航向）。

## 9. 书本依据：参数辨识法精对准与双位置测漂（秦永元《惯性导航》§9.9.2）

> 之前的多位置结论（已知转台角最小二乘）只适用于“基准对准”。自对准
> （姿态未知）的可估性由书本 §9.9.2 给出，下面按原文公式整理。

### 9.1 速度误差的三次曲线（式 9.9.34–9.9.36）

静基座自对准时，速度误差由姿态误差与零偏耦合产生，可写成时间多项式：

```
ΔV_E(t) = a1E·t + a2E·t² + a3E·t³ + V_DE
ΔV_N(t) = a1N·t + a2N·t² + a3N·t³ + V_DN
```

其中（∇ 为加计零偏，u 见式 9.9.29）：

```
a1E = ∇_E − g·φ_N0          a1N = ∇_N + g·φ_E0        （一次项：水平失准角 + 加计零偏）
a2E = −(1/2)g·u_N           a2N = (1/2)g·u_E           （二次项：u 与方位）
a3E = (1/6)g·ω_ie·u_E·sinL  a3N = (1/6)g·ω_ie(u_N sinL − u_U cosL)  （三次项：陀螺漂移）
```

`u` 与失准角初值/等效漂移的关系（式 9.9.29）：

```
u_E = φ_N0·ω_ie·sinL − φ_U0·ω_ie·cosL − ε_E
u_N = −φ_E0·ω_ie·sinL − ε_N
u_U =  φ_E0·ω_ie·cosL − ε_U
```

### 9.2 可估性（书本结论）

反解（式 9.9.42–9.9.43）：

```
u_E = 2a2N/g,  u_N = −2a2E/g,  u_U = −6a3N/(g·ω_ie·cosL) − (2a2E/g)·tanL
φ_E0 = a1N/g,  φ_N0 = −a1E/g
φ_U0 = φ_N0·tanL − (u_E + ε_E)/(ω_ie·cosL)
```

失准角初值误差（式 9.9.43 后）：

```
δφ_E0 = ∇_N/g,   δφ_N0 = −∇_E/g,   δφ_U0 = ε_E/(ω_ie·cosL)
```

**结论**：
1. 单位置自对准可辨识 a1/a2/a3（六参数），但反解出的 φ0 与 ε 是**组合**；
2. 加计零偏 ∇ 只以 ∇∓gφ0 的和出现在 a1，**单位置不可分离**；
3. 方位误差 δφ_U0 由 ε_E/（ω_ie cosL）决定——所以“测出 ε_E”是提高方位精度的关键；
4. 书本的解法是**双位置对准**（§9.9.4）。

### 9.3 双位置对准与测漂（式 9.9.44–9.9.51）

IMU 装在可绕机体 z_b 转动的转盘上：

1. 第一位置（转 90°）：完成精对准，求出等效北向漂移 ε_IN；
2. 转回第二位置（基准位置）：求全部陀螺漂移；
3. 关键关系（式 9.9.49）：**第二位置的等效东向漂移 = 第一位置的等效北向漂移**，
   即 `ε_IIE = ε_IN`；
4. 测漂（式 9.9.50）：`ε_IN = 2a2E^I/g − (a1N^I/g)·ω_ie·sinL`，然后代入
   第二位置式 (9.9.43c) 修正方位，得到更高的方位精度；
5. 第二位置结束时用两位置数据解出全部陀螺漂移（ε_x, ε_y, ε_z）。

**加计零偏**：绕 z 轴的双位置不改变重力在机体系的投影，∇ 仍与水平失准角
耦合；要分离 ∇ 必须**倾斜位置**（绕水平轴转）或多位置，或者外部基准
（转台编码器给出 C_b^n，此时 ∇ = f^b − C_n^b·g^n 直接可解）。

### 9.4 对本项目的结论

| 目标 | 方法 | 可估 |
| --- | --- | --- |
| 水平失准角 | 单位置精对准（a1） | φ_E0/φ_N0，误差 ∇/g |
| 方位 | 单位置（a2/a3）+ ε_E | φ_U0，误差 ε_E/(ω_ie cosL) |
| 全部陀螺漂移 | 双位置（绕 z 90°） | ε_x/ε_y/ε_z |
| 加计零偏 | 倾斜多位置 / 转台基准 | ∇_x/∇_y/∇_z |
| 全部零偏（基准已知） | 转台多位置最小二乘 | 6 个零偏直接可解（前文测试：加计 0.7 µg、陀螺 0.0003 °/h） |

下一步：按式 9.9.34–9.9.43 实现参数辨识法（递推最小二乘），验证
“单位置可估 φ0（带 ∇ 误差）”与“双位置可测 ε_E、提高方位”。

## 10. 参数辨识法验证（2026-11-01，test_ins_param_align）

按书 §9.9.2 公式实现：600 s 静止 ΔV 三次曲线 → 最小二乘拟合 a1/a2/a3 →
式 9.9.42/43 反解 φ0 与 u。

真值：φ0 = (0.5°, 0.3°, 1.0°)，∇ = (10, −5, 8) µg，ε = (0.01, −0.02, 0.005) °/h。

| 项 | 估计 | 理论/真值 |
| --- | --- | --- |
| δφ_E0 | 0.0003° | ∇_N/g = 0.0003° |
| δφ_N0 | 0.0005° | −∇_E/g = 0.0006° |
| δφ_U0（单位置） | 0.0378° | ε_E/(ω_ie cosL) = 0.0445° |
| ε_IN（双位置测漂） | 0.010039 °/h | 真 ε_x = 0.010 °/h |
| δφ_U0（双位置修正后） | 0.0069° | 改善 5.5 倍 |

结论：书本公式链（速度误差三次曲线 → a 参数 → u → 失准角）在数值上完全
成立；双位置测漂（ε_IIE = ε_IN）能把方位失准角误差从 ε_E/(ω cosL) 的
0.04° 级压到 0.007° 级（噪声限）。这验证了“全部陀螺漂移可测、方位可高精度”
的书本路径；加计零偏仍需倾斜位置或外部基准。

## 11. TRIAD 双矢量初始化实现（2026-11-01，P0-2）

`TiltCompass` 用 `asin(a_x)`、`asin(-a_y/cosθ)` 求 roll/pitch，|pitch|→90° 时 1/cosθ 奇异。
实现 `include/tilt_compass_triad.h`：用重力（accel）与磁北（mag + IGRF NED 参考）双矢量
构造 `C_b^n`，再转 [yaw,pitch,roll]，无奇异点。

验证（`test_host/test_tilt_triad.cpp`）：
- 全姿态扫描（yaw 0–360°、pitch ±80°、roll ±60°）：最大误差 **0.0001°**；
- 与 TiltCompass 差恰为磁偏角 4.114°（TRIAD 真北、TiltCompass 磁北），属约定差异；
- pitch=89.9° 时 TRIAD 输出有限且正确。

接入：`Ekf15State::Initialize` 宏 `BFS_NAV_TRIAD_INIT`（默认 0）；无效磁输入回退 TiltCompass。

## 12. FOG 端到端与机械编排自洽性隔离（2026-11-01）

FOG 链路（罗经对准 → 参数辨识 → 1 h 纯惯导）实测：

| 配置 | 1 h 位置漂移 | 1 h 姿态漂移 |
| --- | --- | --- |
| FOG（0.01 °/h、10 µg） | 20.5 km | 0.171° |
| 去掉外部零偏补偿 | 18.8 km | 0.124° |
| **理想 IMU（零偏/噪声全 0）** | **18.9 km** | **0.123°** |

第三条是关键：**零偏与噪声全为 0 时仍有 18.9 km / 0.123°**，说明这部分漂移
不来自器件，而是机械编排在“静止 + 陀螺输入含地球自转”情形下的自洽性误差。

对比 `test_ins_mech_drift`（陀螺输入 0、零偏由 EKF 内部吸收）1 h 姿态只有
0.006°——差异在**输入含 ω_ie 投影时的补偿路径**：`TimeUpdate` 内部按
`q = Exp(−(ω_ie+ω_en)dt)⊗q⊗Exp(coning)` 扣地球自转，若姿态/零偏初值与
输入投影不完全一致，会留下 0.1°/h 级残余。

待查方向（按优先级）：
1. `Initialize` 的零偏初值 `ω_gyro − C^b_n(ω_ie+ω_en)` 与 `TimeUpdate` 的
   `earthrate()` 是否用同一纬度/同一 `ω_ie` 常数；
2. `TimeUpdate` 里 `ω_en`（导航系旋转）在静止时应为 0，检查是否被速度噪声
   污染（理想 IMU 下速度为 0，应严格为 0）；
3. 姿态更新用的 `t_b2ned` 是区间中点姿态，地球自转项是否也在中点扣（若用
   起始姿态扣、中点姿态传播，会引入 0.5·ω_ie·dt 的系统偏差）。

结论：FOG 端到端 20 km/1 h 中，器件贡献 <1 km，主项是机械编排自洽性残余——
这比“换 FOG”更值得先修（否则换再好的 IMU 也只有 0.1°/h 级）。
