# EKF 静止 ZUPT 与位置可观测性（2026-11-04）

> 触发：室内长静止 `conv=0`、`pos_sig` 增大，怀疑 ZUPT/采样故障。
> 结论：ZUPT 只给速度观测，不给绝对位置；当前无外部参考 30 s 后停用 ZUPT，
> 室内长时间静置掉 conv 是设计边界，不是 IMU/P1 故障。

## 1. ZUPT 到底观测什么

- 静止时真实速度=0，量测 `z = 0 − v̂`，观测矩阵 `H = [0₃ I₃ 0₃…]`。
- 它约束 **NED 三轴速度**与速度零偏，不直接给位置。
- 没有 GNSS/光流/已知锚点时，位置仍不可观；位置协方差会随加速度零偏/噪声
  随机游走，`pos_sig` 可缓慢增大。ZUPT 只能通过速度-位置交叉协方差间接
  抑制，不能把位置“钉死”。

## 2. 当前固件的门控

`include/ins_static_aid_profile.h`：

- 无外部参照 >0.75 m/s 残差：拒绝 ZUPT；
- 无外部参照 ≥3 s：ZUPT 噪声封底 0.30 m/s；
- 无外部参照 ≥30 s：**完全停用 ZUPT**，只保留 Gravity/StaticGyro。

这是防止“无参照时把零速当位置真值”的保守设计。停用后速度/位置协方差
会重新增长，`conv` 掉0；重启/重新对准后 `pos_sig` 回到初值，`conv`恢复1
（2026-11-04 实测：重启后 pos_sig9.03、conv=1；长静置后 pos_sig27.5、conv=0）。

## 3. 为什么不能简单“一直 ZUPT”

- ZUPT 持续开也不会产生绝对位置；只是把速度钉0。
- 若要室内位置保持，需要**零位置/锚点伪量测**（相对定位），必须显式标注
  不是绝对导航，并设计退出/重锚逻辑。
- 把室内 conv=1 当飞行级收敛会掩盖无GNSS时的位置不可观测性，风险更高。

## 4. 正确使用

- 室内静态只用于检查 IMU 采样、姿态、速度零偏，不作为位置/飞行级 EKF 证据。
- 飞前：加载参数后**重启**，室外 GNSS/对准，`health` 确认
  `conv=1、pos_sig<10m、vel≈0`。
- 若未来要做室内定点，单独实现 `BFS_NAV_STATIC_POS_HOLD`（锚点伪量测、
  明确相对定位、失锁/移动退出），不要偷改 ZUPT 门限。

## 5. 相关证据

- 长静置：`conv=0、pos_sig=27.5、fake_origin=1`；
- 重启20s：`conv=1、pos_sig=9.03、vel=0、tilt_sig=0.52`；
- P1 IMU：2000Hz、ring_drop0；宿主/SIL 全绿；
- 参数 load 148项后会扰动 EKF，飞前需重启（见 VER-006 §14）。

## 6. 反证实验：ZUPT 持续开启仍不收敛（2026-11-04）

临时把“无外部参考30s后停用ZUPT”改为1e9s（ZUPT一直开），室内静止：
- 70s：vel=0、pos_sig=9.98、conv=0、conv_s=1.2；
- 130s：vel=0、pos_sig=11.68、conv=0、tilt_sig=0.46；
- 全程 ring_drop=0、IMU rate约2.0–2.06kHz、陀螺零偏约-0.023dps。

结论：即使 ZUPT 持续提供速度=0，位置σ仍从9.98涨到11.68。ZUPT 不能替代
位置量测；实验已撤销，默认30s门控恢复。

## 7. 正确的改进：ZUPT + 零位移伪量测（设计）

静止模型不是只有 `v=0`，还满足：

```
p(t) = p(t0) + ∫ v dt = p0   （静止段相对位置不变）
z_v = 0 − v̂          H_v = [0  I  0]
z_p = p0 − p̂         H_p = [I  0  0]
```

- ZUPT 只用了 `H_v`；要让位置σ收敛，必须增加 `H_p` 的**零位移伪量测**。
- `p0` 是进入静止确认时的锚点；该量测是**相对定位**，不是绝对位置，不能替代 GNSS。
- 门控：仅 `is_static_confirmed && throttle<3% && fake_origin/无外部位置`；
  一旦退出静止/检测到运动立即停用；锚点随重新静止更新。
- 噪声：`R_p` 取米级（按静止检测可信度），NIS/残差门控，避免把地面滑行/推机当静止。
- 实现位置：EKF 误差状态位置块是 LLA/位置误差，需新增
  `MeasurementUpdatePositionDetailed`（H 位置块=I，Joseph/NIS 同速度更新），
  不能复用速度更新，也不能直接改 `p_` 对角线。
- 验证：静止300s `pos_sig` 有界且 conv=1；推机/滑行立即退出；GNSS恢复后重锚；
  SIL 理想静止+运动段不得被伪位置拉死。

当前只做到：ZUPT 持续开130s 仍 pos_sig 增长 → 证明必须加 `H_p`，但本轮不改 EKF
核心；下一步单独实现/验证。

## 8. 已实现：静止零位移伪量测（2026-11-04）

- EKF 新增 `MeasurementUpdatePositionDetailed(anchor_lla, ne_std, d_std)`：
  H=[I₃ 0]，残差 `lla2ned(anchor, current)`，NIS=16.3，Joseph 更新。
- Navigation 仅在 `is_static_confirmed && throttle<3% && fake_origin` 时，
  进入静止时保存锚点并持续做零位移更新；运动/恢复绝对参考立即退出。
- 上板80s：`conv=1、conv_s=77.3、pos_sig=0.44、vel=0、rate=2000`；
  全量宿主 rc=0、共轴 SIL 40/40。
- 性质：相对定位保持，不是绝对导航；不能替代 GNSS。

## 9. EKF位置与origin语义（2026-11-04）

- EKF 内部状态位置 = **绝对 LLA**（纬度/经度/椭球高），不是相对坐标。
- `rel_ned` 是输出：`lla2ned(EKF_LLA, origin_LLA)`，用于控制/遥测。
- 上电无GNSS：用 fake LLA 初始化，`nav_initialized_with_fake_origin=true`，
  origin=fake点，`rel_ned=0`。
- 上电有GNSS：用GNSS绝对LLA初始化，origin=GNSS点，`rel_ned=0`。
- 无GNSS后首次有效GNSS、且**未解锁**：`reanchorNavigationToGnss()` 把EKF
  Reset到当前GNSS绝对LLA，并把origin设为当前GNSS，`relative_*=0`。
- 已解锁后：保留真实起飞 origin；GNSS更新绝对LLA，`rel_ned`=当前位置−起飞点。
- 静止零位移量测锚点也是**绝对LLA**，但只做相对位置保持，不改变绝对导航语义。

结论：EKF输入绝对位置，相对位置只是输出；首次GNSS归零/解锁后保留起飞点的
行为已由代码实现，不要再把 `rel_ned` 当EKF状态输入。

## 10. 误差状态与对外输出（2026-11-04）

- `x_` 是15维误差状态：前3维位置误差（m）、3维速度误差、3维姿态误差、
  加速度/陀螺零偏误差；`P_` 是其协方差，不是位置误差本身。
- 每次量测 `x_ = K·y` 后 `InjectErrorState()` 把误差注入名义状态并清零。
- 对外：
  - `ins_lla_rad_m()`：名义绝对位置（LLA）；
  - `ned_vel_mps()`：名义NED速度；
  - `rel_ned`：`lla2ned(绝对位置, origin)` 的相对位置输出。
- 所以 ZUPT/零位移/GNSS 量测更新的是误差状态，EKF对外给的是名义绝对状态；
  `rel_ned` 也不是“位置误差”。
