# EKF 收敛判据与首次解锁门（2026-11-04）

> 目的：回答“怎么保证/判断 EKF 收敛”。结论：收敛不是单一 initialized 标志，
> 而是协方差健康 + 状态不确定度 + 速度 + 连续时间的组合判据；首次解锁门
> 只用其中可观测、可验证的量，不把“静止检测器”当硬条件。

## 1. 判据（`updateEkfConvergence()`）

每个导航周期（200 Hz）计算，以下全部满足才累计保持时间：

| 条件 | 阈值 | 含义 |
|---|---|---|
| `nav_system_initialized` | true | EKF 已初始化 |
| `covariance_is_healthy()` | true | P 对称、对角有限、无负方差/NaN |
| 位置 σ（P00/11/22 最大） | < 10 m | 位置不确定度有界 |
| 速度 σ（P33/44/55 最大） | < 1 m/s | 速度不确定度有界 |
| 倾斜 σ | < 3° | 姿态可观测/无发散 |
| `|v_ned|` | < 0.5 m/s | 当前静止/低速 |
| 连续保持 | ≥ 3 s | 防单帧偶然满足 |

满足后：
- `g_ekf_converged = true`；
- `conv_s` 是连续满足时间；
- 任一条件失效立即清零 `conv_s` 并置 false，不锁存。

## 2. 首次解锁门

地面锁定→请求解锁时，要求 `g_ekf_converged`、速度<1 m/s、tilt_sigma<5°；
否则本次解锁被拒绝。已解锁后不强制上锁，避免空中因速度瞬态误锁。
SIL 构建（`FW_SIL_REAL_NAV`）旁路该门，因为 SIL 直接构造飞行状态、不等启动收敛；
飞行构建保留。

## 3. 板上实测

2026-11-04，CoaxialVTVL，静止：

```
conv=1 conv_s=9.9  pos_sig=5.09 vel_sig=0.05 tilt_sig=0.50
30 s 后: conv_s=45.0 pos_sig=2.75 vel_sig=0.04 tilt_sig=0.49
```

`health` 字段：
```
ekf ... conv=0/1 conv_s=... pos_sig=... vel_sig=... tilt_sig=...
```

## 4. “保证”收敛的操作

1. 上电静置，不碰板/桨；等 `conv=1` 且 `conv_s>=3`（建议 ≥10 s，保守 60 s）。
2. 看 `imu cal=1`、gyro bias 稳定；`vel≈0`；`tilt_sig<3`。
3. 室外确认 `hAcc≤5m`、`fake_origin=0`、`baro suspect=0`。
4. `conv` 一直 0：查 P 是否健康、pos_sig 是否 >10（无 GNSS/位置漂移）、
   vel_sig 是否 >1、tilt_sig 是否 >3；不要强行解锁。
5. 首次解锁门是兜底，操作纪律仍是“静置到收敛再解锁”。

## 5. 不能保证的部分

- 无 GNSS/光流时位置不可观测，`pos_sig` 会随时间增长；超过 10 m 时 conv 不会置位，
  这是正确的“不可收敛”信号，不是 bug。
- 静止检测器 `is_static_confirmed` 在未解锁地面可能一直 false，因此没有作为
  收敛硬条件；速度/σ 已覆盖“静止”的可观测部分。
