# AHRS 姿态辅助门控与无 GNSS 重力方向融合（2026-11-01）

> 对象：`TandemVec_FCS` 导航任务【B2】姿态量测分支（`src/navigation_task.cpp`）
> 与新增 `include/ins_gravity_aid_noise.h`。
> 证据等级：**L2**（真实固件源码 + 宿主 SIL real-nav，VTOL `mag_clean` profile；
> fresh gate 5 seeds、量测源 1110 次 MC + 门限扫描；未做上板验证）。
> 结论一句话：**AHRS 姿态量测“常开”才是主要误差源**——关掉不适用的帧
> （fresh gate）使 clean 段姿态 RMSE 5.41°→1.23°。无 GNSS 失联段的量测源：
> **重力方向直连 + 5° 方向门在大多数条线优于 AHRS**（失联 10 s 姿态
> 2.27°→2.08°、失败率 6%→3%；风条线 2.72°→2.98° 但失败率 22%→6%、
> 位置 6.54→4.93 m；无位置环 3.12°→1.66°）；只有 1 g 振动条线 AHRS 更稳
> （p95 3.68° vs 5.68°）。默认取 mode 1。

---

## 1. 问题

旧的【B2】分支在“本帧没有 GNSS 出队”时就允许 AHRS 姿态量测
（`!gnss_instant_valid_for_nav`）。GNSS 10 Hz / 导航 200 Hz 下这等于
**约 96% 的帧都可融合**（本次 SIL 实测 clean 40 s 融合 3833 次），而：

1. Madgwick 的 roll/pitch 本身已含同一陀螺积分，再作为独立量测喂 EKF
   属于信息重复计数（新息不白、NIS 统计不成立）；
2. 匀速/悬停段的比力方向与重力方向可由推力/升力显著偏离，Madgwick 会
   把机体“拉平”（导弹 SIL 2026-10-27 已量化：无方向门 9.80–11.68°）；
3. 振动下 Madgwick 的重力参考被污染（2026-10-27：1 g 振动 6.94°）。

## 2. 改动（三项，均带运行期开关或编译期宏）

### 2.1 GNSS 新鲜度门默认启用

`BFS_AHRS_GNSS_FRESH_GATE` 由 opt-in 改为**默认 1**（用 `#if` 语义，
`-DBFS_AHRS_GNSS_FRESH_GATE=0` 可复现旧行为）。条件从
“本帧 GNSS 是否出队”改为“GNSS 数据是否在 `GNSS_NAV_DATA_TIMEOUT_MS` 内新鲜”。

### 2.2 无 GNSS 运动段：重力方向直连（mode 1，默认）

新增运行期全局 `g_att_aid_mode`（`state_data.h/.cpp`，ANO 变量 `att_mode`）：

| 值 | 语义 |
| --- | --- |
| 0 | 仅 AHRS 姿态量测（2026-10 旧行为，A/B 基线） |
| 1 | 仅重力方向直连（**默认**）：`MeasurementUpdateGravityDetailed()` |
| 2 | 重力优先，被门控/NIS 拒绝时回退 AHRS 姿态量测 |

默认值由 `BFS_ATT_AID_MODE_DEFAULT`（`include/ins_gravity_aid_noise.h`）给出。
SIL 可用 `--att-aid-mode 0|1|2` 同二进制 A/B。

### 2.3 自适应观测噪声 + 恒定方向门

`include/ins_gravity_aid_noise.h::InsGravityAidNoiseRad()`：

```
a_lin   = sqrt(max(0, |f|² − g²))            # 模长反解线加速度
σ_a_eff = σ_a + 2·vib_rms·g                   # 振动 RMS 并入传感器噪声
σ_dir   = clamp( sqrt(σ_a_eff² + a_lin²)/|f|, 0.02, 0.50 ) rad
```

运动段方向门**恒定启用**（15°，`BFS_MOTION_GRAVITY_GATE_RAD`），复用
`InsAhrsGravityDirectionAllowed()`；AHRS 兜底路径仍用原有的
“VTOL 包线外才启用”门，保持 mode 0 逐项兼容。

## 3. 证据（SIL real-nav，VTOL `mag_clean`，40 s）

### 3.1 fresh gate 隔离 A/B（同一 `--att-aid-mode 0`，5 seeds，中位数）

| 条件 | 旧门控 fresh=0 姿态 / 位置 | 新门控 fresh=1 姿态 / 位置 | AHRS 融合次数 旧→新 |
| --- | --- | --- | --- |
| clean（无风） | **5.406° / 0.724 m** | **1.231° / 0.657 m** | 3833 → 0 |
| 1 g 振动 | **5.453° / 0.741 m** | **1.983° / 0.696 m** | 3276 → 0 |
| GNSS 失联 20–30 s | **6.210° / 11.187 m** | **2.931° / 4.454 m** | 3824 → 292 |

姿态最大误差同步下降：clean 10.11°→3.64°、振动 11.79°→4.24°、失联 10.50°→7.42°。
机制：旧配置在 clean 段也有 3833 次 AHRS 融合（≈96 Hz），把 Madgwick 的
固定增益与推力污染直接注入 EKF。

### 3.2 失联段量测源 A/B（`--gnss-outage 20:30`，10 seeds，中位数）

| mode | 姿态 RMSE | roll | pitch | yaw | 姿态 max | 位置 RMS | 位置 max | 最大俯仰 | AHRS 融合 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 0（AHRS） | 3.000° | 1.788° | 2.285° | 0.770° | 7.345° | 4.714 m | 21.13 m | 6.868° | 288.5 |
| 1（重力直连） | **1.927°** | 1.537° | **0.720°** | 0.850° | 5.731° | 2.917 m | 13.48 m | 2.837° | 0 |
| 2（重力+回退） | **1.831°** | **1.377°** | **0.694°** | 0.850° | 5.075° | **2.226 m** | **9.46 m** | **2.743°** | 0.5 |

- 重力直连相对 AHRS：姿态 −36%、俯仰 −69%、位置 RMS −38%、位置 max −36%；
- yaw 略有变差（0.77°→0.85°），量级小且在失联段航向依赖磁/运动可观性，
  不作为选型依据；
- mode 2 比 mode 1 略好（10 seeds 里仅 2 次回退），说明“重力为主 + 极少
  回退”是稳健组合，但默认仍取 1（代码路径最简、无相关性回流）。

`run_real_acceptance.py --profiles mag_clean,mag_nominal --seeds 1,2,3

条线（均 `--real-nav --profile mag_clean`）：

| out5 | `--gnss-outage 20:25` + 定点保持 | 50 |
| out10 | `--gnss-outage 20:30` + 定点保持 | 100 |

| out10 | 0/1/2 | 2.27 / 2.26 / 2.53 | 1.23 / **0.56** / 0.66 | 1.03 / 1.33 / 1.37 | **2.90** / 3.60 / 3.88 | 6% / 6% / 8% |
| out10_noph | 0/1/2 | 3.12 / **1.59** / 1.60 | 2.37 / 0.68 / **0.68** | 0.67 / 0.54 / **0.53** | 5.02 / 2.18 / **2.14** | 0 / 0 / 0 |
| out10_wind | 0/1/2 | **2.72** / 4.91 / 3.51 | 0.89 / 0.87 / 0.79 | **1.36** / 3.43 / 2.19 | 6.54 / 9.01 / **5.23** | **22%** / 48% / **22%** |
| out10_vib1g | 0/1/2 | **2.40** / 3.02 / 3.08 | 0.96 / 0.82 / 0.92 | **1.09** / 1.98 / 1.79 | **3.35** / 4.55 / 4.70 | **0%** / 18% / 14% |
| out20 | 0/1/2 | 3.34 / **3.13** / 4.54 | 1.75 / **0.77** / 1.64 | **1.82** / 1.96 / 2.35 | **19.5** / 22.6 / 19.8 | **6%** / 22% / 46% |

**读法**

1. **俯仰（倾角）重力直连全面更好**：0.56° vs 1.23°（out10）、0.77° vs 1.75°
   （out20）、0.68° vs 2.37°（无位置环）。这是直接重力观测的预期收益。
2. **无位置环（纯姿态/自由飘）重力直连完胜**：姿态 1.59° vs 3.12°、
   位置 2.18 vs 5.02 m，且两者失败率都是 0。
3. **有位置环 + 风/振动时 AHRS 更稳**：风条线 att>5° 失败率 48%→22%、
   航向 3.43°→1.36°；振动条线 18%→0%。机制推断：失联期控制律为保持
   位置而主动倾斜，产生的水平加速度正是控制器动作本身，方向门无法把它
   与重力“错误”区分；Madgwick 的低增益天然把它滤慢，EKF 直连则当真值吸收。
4. **长失联（20 s）**：重力直连姿态中位更好（3.13 vs 3.34）、最大更低
   （11.7 vs 17.1），但 att>5° 失败率更高（22% vs 6%）、位置 p95 更差
   （8.22 vs 5.65）；位置本身在 20 s 失联下三种模式都大面积超 10 m
   （78–80%），量测源救不了位置。
5. **mode 2（重力+AHRS 回退）** 在短失联/风条线接近 AHRS 的尾部、在无位置环
   接近重力的精度；但 20 s 失联回退频繁（约 36 次/seed），中位反而最差（4.54°）。

**调参变体（噪声地板 0.06 rad、门限 10°，`mc_tuned.json`，mode 1）**：

| 条线 | 默认 mode 1 | 调参 mode 1 | mode 0（AHRS） |
| --- | --- | --- | --- |
| out10 | 2.26 / 5.08 p95 | **1.99** / 5.68 | 2.27 / 5.36 |
| out10_wind | 4.91 / 8.76 | **3.21** / 8.44 | 2.72 / 7.92 |
| out10_vib1g | 3.02 / 6.54 | 3.10 / 6.03 | **2.40** / 3.68 |
| out10_noph | **1.59** / 2.54 | 2.19 / 6.64 | 3.12 / 4.43 |

调参把风条线从 4.91° 压到 3.21°，但把无位置环从 1.59° 拉到 2.19°（p95
2.54→6.64）——**不是免费午餐**，说明单一噪声地板无法同时覆盖“闭环扰动”
与“开环自由飘”两种比力污染水平。

### 3.4.1 方向门限扫描（关键结论，2026-11-02）

并发会话曾依据 ABI 实测把 `BFS_MOTION_GRAVITY_GATE_RAD` 从 15° 临时收紧到 5°
（工作区改动，后来已回退；当前默认仍是 15°）。为量化该方向的影响，用
`-DBFS_MOTION_GRAVITY_GATE_RAD=0.0872665f` 重建二进制（`tmp/sil5/fw_real.exe`）
跑同批条线（mode 1）；结论可用于决定是否把 5° 写成默认。

| 条线 | 门限 15°：姿态中位 / p95 / att>5° / pos>10° | 门限 5°：姿态中位 / p95 / att>5° / pos>10° |
| --- | --- | --- |
| out10 | 2.26 / 5.08 / 6% / 3% | **2.08 / 4.47 / 3% / 1%** |
| out10_wind | 4.91 / 8.76 / 48% / 44% | **2.98 / 5.61 / 6% / 4%** |
| out10_vib1g | 3.02 / 6.54 / 18% / 6% | **2.89 / 5.68 / 14% / 2%** |
| out10_noph | **1.59 / 2.54 / 0% / 0%** | 1.66 / 4.66 / 4% / 2% |

对照 AHRS（mode 0）：out10 6%/3%、风 22%/22%、振动 0%/0%、无位置环 0%/0%。

**5° 门限下重力直连反超 AHRS**：out10 与风条线的失败率都低于 AHRS
（风 6% vs 22%），位置也更好；只有 1 g 振动条线 AHRS 仍更稳
（p95 3.68° vs 5.68°、att>5° 0% vs 14%），说明振动污染应靠振动噪声项/
滤波处理，而不是继续放宽或收紧方向门。

### 3.5 选型建议

- **推荐 mode 1（重力方向直连）+ 把方向门从 15° 收到 5°**：在 out10/风/无位置环
  三条线上姿态与位置均优于 AHRS，振动条线略逊但可接受。当前默认仍是 15°，
  5° 只是本报告的实验变体（1 行宏改动），建议按红线流程 A/B 后落默认。
- **长时间振动主导的飞行段**：`mode 0` 或 `mode 2`；或把振动 RMS 项系数调大，
  让重力观测在振动下自动降权（下次 A/B 的候选）。
- **长失联（>20 s）**：三种模式都保不住位置，应回到“速度保持 + 降级/降落”
  保护逻辑（CTL-005），量测源选择不再是决定因素。
- 若后续要“全都要”：把 `g_att_aid_mode` 与飞行模式/振动水平绑定
  （振动高或定点保持用 AHRS，其余用重力直连），而不是继续调单一噪声地板。

## 4. 边界与风险

1. **L2 证据**：VTOL `mag_clean` 合成 profile，不是实机；振动/磁扰动包线未扫。
2. **mode 1 无 AHRS 兜底**：若方向门/NIS 连续拒绝，倾角只有陀螺——
   长失联（>20 s）时这是已知退化路径（见 §26 失联报告），与 AHRS 无关。
3. **yaw 不受益**：三种模式航向都靠磁/运动可观性，本次改动不解决失联航向。
4. **导弹/高动态构型**：本报告中 AHRS 的害处已被 2026-10-27 导弹 SIL
   独立复现（无方向门 9.80–11.68°）；fresh gate 默认开对导弹构型等价于
   报告 §4.9 的推荐配置，应向该构型回归一次。
5. **实机风险**：`ekf_gravity_mps2` 在 EKF 未初始化时 = `G_ACCEL_CONST`，
   噪声公式不受影响；但实机振动谱与 LPF 群延迟未验证，上板需先地面静止
   与系留测试。
6. **DETA100 直出模式**：该模式下 `isGnssDataFreshForNav()` 恒 false
   （UBX 停泵），运动段辅助会常开——但此模式 EKF 输出本就不进控制，
   影响限于 EKF 内部状态与切回 INTERNAL 时的初值，与旧行为等价。
