## 3 纪律

1. **注释与行为分离**：本轮只加注释/文档；发现代码与理论不一致时，登记 P0/P1 并上报，不擅自改行为。
2. **不写行号引用**：代码位置一律用符号名，避免重构后失效。
3. **引用必须可追溯**：`@ref REF-120 §章节 (式号) p.印刷页`；禁止“见书/见教材”。
4. **数值证据优先**：测试断言、复算命令、回归夹具；没有证据写“未验证”，不要写“应该一致”。
5. **不做机械翻译**：行内注释只写“为什么/单位/边界/出处”，不复述代码。
