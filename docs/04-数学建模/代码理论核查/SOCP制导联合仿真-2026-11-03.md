# SOCP 制导联合仿真（2026-11-03）

> 目的：验证飞控 GUIDED 通道 + 外部 SOCP 轨迹规划器能否完成从 10 m 到地面的
> 完整着陆。对象是 `TandemVec_FCS/test_host/fw_sil/fw_sil_guidance_main.cpp`
> （高精度 6DOF plant、线性推力映射）+ `guidance_bridge.py` + 外部
> `vtvl-gnc/latte-panda/tests/vtvl_sim.py`（SOCP）。

## 1. 方法

```powershell
# 1) SIL（200 Hz，无噪声/无延迟，autonomous 模式）
T:/fw_sil_guidance/fw_sil_guidance.exe 7001 7002 1.0 1.0 0 0 0 0 auto

# 2) SOCP bridge（目标 = 地面 0,0,0）
py -3.12 TandemVec_FCS/test_host/fw_sil/guidance_bridge.py `
  --gnc-dir "D:/电火箭制导控制/vtvl-gnc/latte-panda/tests" `
  --target 0 0 0 --duration 35 --out tmp/socp_joint2.csv

# 3) 自动判定（退出码 0=PASS）
py -3.12 TandemVec_FCS/test_host/fw_sil/check_socp_joint.py tmp/socp_joint2.csv
```

判定阈值：最终 `|up|<=0.05 m`、横向 `<=0.10 m`、过程最低 `>=-0.60 m`、
最大垂直速度 `<=6.0 m/s`；阈值可在脚本参数覆盖。

- bridge 收到 SIL 状态后求解一次 SOCP（自由终端时间候选搜索），之后按计划
  时间索引给前馈 + 位置/速度 PD。
- 初始约 10 m，目标 0；`r=[up,east,north]`。

## 2. 发现并修复：规划结束后的“假平衡”

**现象（修复前）**：规划 tf=5.73 s 成功，但最终稳定在 **1.21 m**，不是 0；
CSV 显示末端 `rref_up=0`、`a_up≈-0.003`，指令几乎为 0。

**根因**：SOCP 只约束终端 jerk（`a_N=a_{N-1}`），不约束终端推力加速度等于
重力。实测该规划末端 `app_acc=11.24 m/s²`，而悬停应为 `g0=9.79`；bridge 在
`t_rel>tf` 仍把 `app_acc-g0=+1.45` 当前馈，位置误差 -1.21 经 `kp=1.2` 产生
-1.45，正好抵消 → 形成 `kp·Δr = a_ff` 的假平衡。

**修复**（`guidance_bridge.py`）：`t_rel >= tf` 后前馈归零，只保留 PD 把终端
误差拉回 0。

## 3. 修复后结果（35 s，SIL 无地面约束）

| 指标 | 值 |
| --- | --- |
| 规划 | tf=5.51 s，f_opt=52.37，成功 |
| 最终位置 | **up=0.002 m**，east=0.000，north=0.000 |
| 过程中最低/回弹 | -0.375 m / +0.596 m |
| 最大垂直速度 | 3.95 m/s |
| 横向误差 | 0（本场景无横向指令） |

自动判定 `check_socp_joint.py`：4/4 PASS。结论：**终端假平衡已消除，能落到 0**。残余 -0.375 m 超调来自“规划一次 +
PD 跟踪”的跟踪滞后（SIL 无地面，负高度不代表撞地），不是固件发散。

## 4. 局限与下一步

1. 本测试是 GUIDED 外环 + 固件内环的联合验证，**不是飞行验收**；SIL 无地面
   碰撞、无噪声/延迟/风。
2. 规划器未在 tf 后重规划，PD 增益固定；若要压超调，候选：
   - 规划加终端 `a_N=g` 约束；
   - tf 附近重规划/终端速度闭环；
   - 降低下降末速（制导侧限速）。
3. 复现时 `--gnc-dir` 必须指到 `latte-panda/tests`（`vtvl_sim.py` 所在目录），
   指到仓库根会 `ModuleNotFoundError`。
4. 结果 CSV 在 `tmp/`，不提交；本文只保留结论与命令。
