# IMU 2 kHz 采样架构设计（ICM-42688-P，2026-11-04）

> 目标：把 IMU 采样从协作式主循环中解耦，达到稳定 2 kHz；不再靠改 ODR、
> 定时器 tick 或继续加 FIFO 包数。当前默认轮询实测 1429.6 Hz（std263），
> FIFO2 实测 2107 Hz（std571）；两者都不满足“稳定 2k”。

## 1. 事实基线

- `getAGT()`：1 次 INT_STATUS(0x2D) + 1 次 TEMP_DATA(0x1D) 14B burst；
  SPI1 10 MHz。
- `imufifohist`（DBG 内阻塞主循环）2.12 包/ms≈2120 Hz，时间戳持续前进；
  传感器/FIFO/SPI 正常。
- 主路径 FIFO2：`calls=13434 packets=19007 n0/1/2=426/7009/5999`，
  平均1.415包/次；无 DBG 记录 mean2107/std571，静态 vel=0。
- TIM8 6.4→12.8 kHz：mean1409/std267，无改善。
- 结论：瓶颈是主循环里的 IMU 消费/处理与任务调度，不是采样源。

## 2. 推荐架构：2 kHz 采样 ISR + SPSC ring + 主循环处理

```
TIM8/2kHz ISR
  ├─ 读 FIFO（1~2 包，SPI 短事务）
  ├─ 填入 SPSC ring（ImuFifoSample，深度 64）
  └─ 仅置 flag/计数，不做滤波/Madgwick
主循环 handleICM42688
  ├─ 弹 ring 样本
  ├─ 校准/低通/轴变换/增量累加（每样本）
  ├─ Madgwick/AHRS 降频到 200 Hz（可选）
  └─ imu_delta 双样本缓冲供 Navigation 200 Hz
```

要点：
1. **ISR 只搬运**，不跑浮点滤波/Madgwick；SPI FIFO 读 ≤2 包。
2. ring 为单生产者（ISR）/单消费者（主循环），head/tail 用 `volatile` +
   内存屏障；溢出计数进健康遥测。
3. 主循环处理不过来时，ring 积压由 Navigation 的 delta 时间跨度吸收；
   不能丢弃而不计数。
4. 每个样本用 **FIFO Packet3 时间戳**换算 dt，不用“强制1/ODR”；
   timestamp 每样本约4计数，需用实测标定比例。
5. Madgwick/AHRS 可 200 Hz 更新（只影响备份姿态/遥测），
   增量/EKF 仍按每样本；先做 A/B 证明不影响 EKF。
6. DMA 作为第二阶段：SPI1 RX DMA 读 FIFO burst，ISR 只处理完成事件；
   第一版先中断+短 SPI，确认时序。

## 3. CPU/时序预算

- 当前 FIFO2 主路径 `ICM42688` 任务 avg≈178µs/次、n≈1.4；
  2k 样本/秒的处理预算必须实测。
- ISR SPI 2 包约 32B @10MHz ≈26µs + 开销，2k 下 <6% CPU；
- 主循环处理目标：每样本 <250µs，2k 总 <50% CPU；
- Navigation 200Hz max <15ms；`imu_delta` overflow=0。

## 4. 分阶段实施

### P0 观测（已完成）
- 0xF4 普通遥测 `imu_rate_hz`；禁止 DBG 测时序。
- 基线：默认1429.6/263.2；FIFO2 2107.1/571.3；12.8k 1409.4/266.9。

### P1 单包 ISR ring（实验宏）
- 2k ISR 读1包入 ring；主循环只处理；测 imu_rate/Navigation/EKF。
- 验收：非 DBG mean≥1950、std<100、Navigation max<15ms、conv=1。

### P2 双包/时间戳
- ISR 读≤2包，主循环按 timestamp 算 dt；处理 Madgwick 降频 A/B。
- 若仍抖动，查 SPI 事务/中断延迟，不要加包数。

### P3 DMA/watermark
- SPI1 RX DMA + FIFO watermark；DMA 完成中断置 flag；
- ring 不变；验证同上。

### P4 默认切换
- 实验宏默认关；A/B 通过后改 `[env:CoaxialVTVL]`；
- 保留 `[env:CoaxialVTVL_UI]` 纯轮询回退；上板静态/系留再飞。

## 5. 判定与回退

- 只用 `tvc record` + 0xF4/普通遥测；DBG 不参与时序。
- 任何阶段 `Navigation max>15ms`、`conv=0`、`imu_delta_overflow>0` 即回退。
- 不允许用提高 ODR/放宽验收掩盖采样架构问题。
- 当前默认轮询版是可飞基线；架构实验代码必须默认关闭。


## 6. P1 验证结果（2026-11-04）

- 2kHz ISR 单包→SPSC ring，Navigation 200Hz 排空；
- SPI 缓冲传输 + 24MHz、备份姿态200Hz，单样本约16µs；
- 非 DBG 0xF4：mean=1999.5 Hz、std=71.4、min1735.5/max2352.9；
- health：rate2000.4、conv=1、vel=0、CPU41.5%；
- 全量宿主 rc=0；共轴 SIL 40/40。
- 默认 CoaxialVTVL 已切换；CoaxialVTVL_UI 为纯轮询回退。

## 7. P1 默认版复测（2026-11-04）

- 0xF4 新增 `imu_ring_drop`：SPSC ring 溢出计数。
- 默认 P1 版复测：`imu_rate mean=1996.7/std=70.4、ring_drop=0、vel=0`。
- 说明静态2kHz下 Navigation 排空跟得上，没有 ring 溢出；后续动态/高负载继续观察该计数。

## 8. 60 秒静态耐久（2026-11-04）

`ring_drop=0`、`vel=0`、roll 稳定；无长时漂移/溢出。
