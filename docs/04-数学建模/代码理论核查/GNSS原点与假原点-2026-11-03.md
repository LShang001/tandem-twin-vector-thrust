# GNSS 原点、假原点与室内位置显示（2026-11-03）

> 现象：室内 `gnss fix=3 sv=8 hAcc=23–36 m` 时，`health` 显示
> `rel_ned=3.5/9.1 km`，容易被误判为 EKF 发散。本文固定判据。

## 1. 实现

- `GNSS_INIT_MAX_H_ACC_M = 5.0 m`（`navigation_task.cpp`）。
- 初始化时只有 `gnss_instant_valid_for_nav && hAcc∈(0,5m] && vAcc/sAcc 合格`
  才用真实 GNSS 原点（`fake_origin=0`）。
- 否则用硬编码假原点（28.2°N / 112.9°E / 50m），`fake_origin=1`；
  等首次高质量 fix 再 `reanchorNavigationToGnss()` 把原点改到当前点。
- `health` 的 `rel_ned` 是 `relative_north/east/down = lla2ned(当前GNSS, 原点)`，
  **不是 EKF 内部位置**；假原点下它当然可以是几 km。

## 2. 判据

| 条件 | fake_origin | rel_ned | 结论 |
|---|---|---|---|
| 室内 hAcc=23–36m | 1 | 3.5/9.1 km | 正常：假原点到真实位置的偏移 |
| 室外 hAcc≤5m | 0 | ≈0（重锚后） | 正常：原点已切到当前 GNSS |
| 室外 hAcc≤5m | 1 | 几 km 且不收敛 | 异常：重锚未触发，查 `gnss_quality_for_reanchor` |
| 任意 | 1 | 0 | 假原点恰在当前点/未更新，查初始化 |

## 3. 已做改动

- `health` 的 `pos_ned` 标签改为 `rel_ned`，并新增 `fake_origin=0/1`；
- 保留原有 `GNSS_INIT_MAX_H_ACC_M=5m` 与重锚逻辑，不改默认行为；
- 室内不把 `fix=3` 当可信定位；定位精度/重锚必须室外复核。

## 4. 待验证

- 室外高质量 fix：确认 `fake_origin` 从 1→0、`rel_ned` 回到 0 附近；
- 若室外仍不重锚，检查 `gnssEpochPassesFullQuality()` 的
  fix/sv/spd_acc/pdop 与 `hAcc` 门限。
