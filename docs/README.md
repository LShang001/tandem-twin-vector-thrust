## 4. 维护规则

1. **新增文档**：按 `域前缀-三位序号-标题.md` 命名，落进对应域目录，并**同时**：
   ①在本文 §2 对应小节加一行（表格式：链接 + 一句话内容）；
   ②若属 `memory/`，首行加 `> **触发条件**：…` 并登记 [`../AGENTS.md`](../AGENTS.md) 索引表；
   ③跑 `py -3.12 tools/verify-all.py` 确认文档守卫全绿。
2. **结论过时或错误**：**直接删掉或就地改对**，只保留当前唯一正确口径。不写「曾经错、现在改」的对照说明
   （2026-11-07 用户指令）。担心误用就改写正确表述本身使其可判定。
3. **不要建"报告"而不改系统**：文档只在它能让下一个人少走弯路时才有价值。冗余报告合并精简。
4. **入口唯一性**：新会话的入口链是
   `../README.md` / `../AGENTS.md` → 本文 → 各域。**不要另建平行的总索引文件**，否则必然漂移。
