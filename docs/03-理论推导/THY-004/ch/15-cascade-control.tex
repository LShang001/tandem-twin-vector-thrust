\section{级联姿态-角速度控制架构：解耦设计与交叉项补偿}
\label{sec:cascade_chapter}

前文分别发展了三种姿态控制架构：第\ref{sec:control}节的级联SAS（对角分配）、
第\ref{sec:INDI}节的INDI（在线效能矩阵+角加速度反馈）、
第\ref{sec:lqr}节的LQR（工作点最优全状态反馈）。
第\ref{sec:coupling_rejection}节与第\ref{sec:lqr_coupling_limit}节的耦合抑制对比表明，
三者在处理本构型固有的反扭矩投影交叉耦合时各有局限：
SAS的对角分配结构性放弃交叉项，INDI受角加速度估计噪声与增量饱和制约，
LQR的冻结效能矩阵随工作点漂移而退化。
本章提出一种级联姿态-角速度控制架构，通过时间尺度分离将姿态控制与交叉项补偿解耦，
并给出完整的设计思想、数学理论、参数整定方法与仿真验证。

\subsection{设计思想：时间尺度分离与功能解耦}
\label{sec:cascade_philosophy}

单级控制架构的根本困难在于：姿态误差动力学、角速度动力学与执行器交叉耦合
被压缩在同一个反馈回路中，控制律必须同时兼顾跟踪品质、稳定性与耦合补偿，
三者相互掣肘。第\ref{sec:lqr_coupling_limit}节的仿真表明，即使将LQR的效能矩阵
在线化（增益调度、SDRE或在线分配），只要保留单级全状态反馈结构，
交叉项补偿就难以突破$1^\circ$量级——补偿力矩被姿态-角速度耦合动态"淹没"。

级联架构的设计思想是\textbf{用时间尺度分离换取功能解耦}：
将控制问题分解为两个带宽分离的回路，每个回路只承担单一职能。

\begin{itemize}
    \item \textbf{外环（姿态环，慢环）}：仅负责姿态误差的调节，输出角速度指令。
          由于不直接操作执行器，外环无需考虑效能矩阵、执行器饱和与交叉耦合，
          可采用极简的纯比例（P）或比例-积分（PI）结构；
    \item \textbf{内环（角速度环，快环）}：仅负责跟踪角速度指令，输出执行器指令。
          由于角速度环带宽显著高于姿态环（时间尺度分离假设），
          内环可在姿态还未来得及响应前快速抑制交叉耦合扰动，
          使其无法经角速度-姿态积分传播到姿态环。
\end{itemize}

这一思想的物理本质是：\textbf{交叉耦合的抑制速度必须快于它影响姿态的速度}。
在单级架构中，补偿力矩与耦合扰动同时作用于同一动力学，无法形成时间尺度上的先后；
级联架构则通过内环的高带宽，使耦合扰动在姿态环"察觉"之前即被消除。
这与第\ref{sec:control}节SAS的级联思想一脉相承，但内环用在线效能矩阵
替代了对角近似，从而把几何解耦升级为精确解耦。

\subsection{控制律设计}
\label{sec:cascade_design}

\subsubsection{外环：误差四元数比例-积分控制}

姿态反馈采用第\ref{sec:quat_control}节的误差四元数，
以规避欧拉角在$\theta=\pm90^\circ$处的万向锁奇异性。
设当前姿态四元数$\mathbf{q}$、期望姿态$\mathbf{q}_{\mathrm{des}}$，
误差四元数$\mathbf{q}_{\mathrm{err}}=\mathbf{q}_{\mathrm{des}}^{*}\otimes\mathbf{q}$
的矢量部分$\boldsymbol{\varepsilon}_{\mathrm{err}}\in\mathbb{R}^3$编码姿态误差。
外环将其映射为角速度指令：

\begin{equation}
    \boxed{
    \boldsymbol{\omega}_{\mathrm{ref}}
    = -\mathbf{K}_p\,\boldsymbol{\varepsilon}_{\mathrm{err}}
      - \mathbf{K}_i\int\boldsymbol{\varepsilon}_{\mathrm{err}}\,\mathrm{d}t
      + \boldsymbol{\omega}_{\mathrm{ref}}^{\mathrm{ff}}
    }
    \label{eq:cascade_outer_ch}
\end{equation}

其中$\mathbf{K}_p=\operatorname{diag}(k_{p,1},k_{p,2},k_{p,3})$、
$\mathbf{K}_i=\operatorname{diag}(k_{i,1},k_{i,2},k_{i,3})$为正定对角增益矩阵，
$\boldsymbol{\omega}_{\mathrm{ref}}^{\mathrm{ff}}$为期望轨迹角速度前馈。
在小姿态误差下$\boldsymbol{\varepsilon}_{\mathrm{err}}\approx\frac{1}{2}\Delta$姿态角，
故$K_p$的物理意义是姿态回正的特征角速率。

\subsubsection{内环：角速度环与在线效能矩阵分配}

内环将角速度误差映射为虚拟角加速度，再经在线效能矩阵分配为执行器增量：

\begin{align}
    \boldsymbol{\nu} &= \mathbf{K}_\omega\left(\boldsymbol{\omega}_{\mathrm{ref}}
                        - \boldsymbol{\omega}\right)
    \label{eq:cascade_nu_ch}\\
    \mathbf{u}_{k+1} &= \mathbf{u}_k
        + \mathbf{B}_{\mathrm{true}}^{-1}(\mathbf{u}_k)\,
          \mathbf{I}\,\boldsymbol{\nu}\,\Delta t
    \label{eq:cascade_alloc_ch}
\end{align}

其中$\mathbf{u}=[\Delta\omega,\delta_t,\delta_f]^T$，
$\mathbf{B}_{\mathrm{true}}(\mathbf{u}_k)$为式(\ref{eq:B_true})的在线Jacobian，
$\mathbf{I}=\operatorname{diag}(I_x,I_y,I_z)$为惯量矩阵（$\boldsymbol{\nu}$是角加速度指令，
必须乘惯量转换为目标力矩增量再经$\mathbf{B}^{-1}$分配——缺$\mathbf{I}$时
各向异性惯量会使快轴通道被放大、慢轴通道衰减，v0.2.0 参数下表现为滚转通道发散），
$\mathbf{K}_\omega=\operatorname{diag}(k_{\omega,1},k_{\omega,2},k_{\omega,3})$，
$\Delta t$为控制周期。内环的两个关键设计：

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{交叉项精确补偿}：$\mathbf{B}_{\mathrm{true}}^{-1}$的非对角元
          将前摆对俯仰的反扭矩耦合$-\tau_f\cos\delta_f$、
          尾摆对偏航的耦合$-\tau_t\cos\delta_t$显式计入分配，
          实现任意工作点下的精确解耦；
    \item \textbf{无角加速度估计}：$\boldsymbol{\nu}$由角速度误差经比例生成，
          $\mathbf{B}_{\mathrm{true}}^{-1}$仅作静态分配而非动态逆，
          从而规避第\ref{sec:estimator_study}节分析的角加速度估计噪声放大问题。
\end{enumerate}

\begin{remark}[固件实现：串级PID + 在线Jacobian静态非线性控制分配]
\label{rem:firmware_alloc}
式(\ref{eq:cascade_alloc_ch})为增量形式（$\mathbf{u}_{k+1}=\mathbf{u}_k+\Delta\mathbf{u}$），
概念仿真中按此实现。
固件（\texttt{flight\_control.cpp} \texttt{mix\_and\_output\_commands}）的实际控制链为：
\begin{equation}
    \boldsymbol{\alpha}_{\mathrm{cmd}} \xrightarrow{\;\times\,\mathbf{I}\;}
    \mathbf{M}_{\mathrm{cmd}} \xrightarrow{\;\mathbf{B}_{\mathrm{true}}^{-1}(\mathbf{u}_{k-1})\;}
    \mathbf{u}_k = [\Delta\omega,\;\delta_t,\;\delta_f]^T
    \label{eq:cascade_alloc_firmware}
\end{equation}
其中$\boldsymbol{\alpha}_{\mathrm{cmd}}$为速率内环（PI）直接输出的角加速度指令，
$\mathbf{I}=\operatorname{diag}(I_x,I_y,I_z)$为惯量矩阵，
$\mathbf{B}_{\mathrm{true}}(\mathbf{u}_{k-1})$为在\textbf{上一拍执行器工作点}
处求值的在线Jacobian。

\textbf{架构定性}：串级PID + 静态非线性控制分配（Static Nonlinear Control
Allocation）+ 在线Jacobian更新（gain-scheduling）。具体地：
\begin{itemize}
    \item \textbf{不是NDI}：没有任何一层显式计算并对消非线性动力学
          $f(\mathbf{x})$（陀螺力矩$\boldsymbol{\omega}\times\mathbf{I}\boldsymbol{\omega}$、
          气动力矩、重力梯度矩）。
          NDI的核心操作$\mathbf{u}=\mathbf{B}^{-1}(\boldsymbol{\nu}-f(\mathbf{x}))$
          中的$f(\mathbf{x})$项不存在。
          $\mathbf{I}\cdot\boldsymbol{\alpha}$仅是量纲缩放
          （角加速度$\to$力矩），不构成动力学逆。
    \item \textbf{不是INDI}：没有使用IMU实测角加速度$\dot{\boldsymbol{\omega}}$，
          没有增量累加$\mathbf{u}_k=\mathbf{u}_{k-1}+\Delta\mathbf{u}$。
    \item \textbf{BTRUE的"上一拍工作点"}：仅指Jacobian在上一拍真实摆角/转速处求值
          （而非零摆角名义点），这是gain-scheduling的思想——
          使分配矩阵跟踪工作点变化，但不涉及动态逆或增量修正。
\end{itemize}

选择此架构的工程理由：
\begin{enumerate}[label=(\arabic*)]
    \item 速率PI直接输出$\boldsymbol{\alpha}$，经$\mathbf{I}$缩放后即为力矩量纲，
          无需维护执行器状态$\mathbf{u}_k$的增量累积历史；
    \item 规避INDI对$\dot{\boldsymbol{\omega}}_{\mathrm{IMU}}$数值微分的需求，
          消除高频噪声经$\mathbf{B}^{-1}$放大的路径；
    \item 未建模非线性（陀螺耦合、气动交叉）由内环PI的积分项
          作为"慢扰动"逐步补偿，而非显式对消——
          概念阶段参数不确定度大（$I$约$\pm20\%$，气动系数未标定），
          显式对消反而可能引入更大误差；
    \item 在线辨识模块（\texttt{TandemVec\_OnlineID.h}，遗忘因子RLS）
          监测惯量比$b$与总扰动$d$，
          自适应增益建议$K_p/\sqrt{b}$已实现但当前为\textbf{纯观测模式}——
          仅写入遥测量供地面站显示与离线复算，未写回PID增益。
          待多架次数据确认估计稳定后，再闭环接入。
\end{enumerate}

生产固件的姿态外环与速率内环均采用\texttt{PositionPID}（位置式PID，v3），
具备2-DOF设定点加权、反算抗饱和（back-calculation）、微分先行、
输出变化率限制与NaN防护。当前姿态通道增益配置：
外环纯P（$K_p=5.0$，$K_i=K_d=0$），内环PI（$K_p=0.30$，$K_i=3\times10^{-4}$，$K_d=0$）。
\texttt{TandemVec\_AttitudeCtrl.h}中的纯比例几何控制器
用于宿主机回归测试与算法验证，两者在小角度下行为等价。
\end{remark}

\subsection{闭环动力学与传递函数分析}
\label{sec:cascade_tf}

为定量理解级联架构的解耦机理，对内外环分别建立线性化闭环模型。
在小姿态误差与单通道近似下，误差四元数运动学为
$\dot{\boldsymbol{\varepsilon}}\approx\frac{1}{2}(\boldsymbol{\omega}-\boldsymbol{\omega}_{\mathrm{ref}})$，
角速度动力学（忽略交叉项与未建模动态）为
$\dot{\boldsymbol{\omega}}=\mathbf{I}^{-1}\mathbf{B}_{\mathrm{true}}\mathbf{u}$。

\subsubsection{内环闭环}

将内环分配（式\ref{eq:cascade_alloc_ch}）连续化，
$\dot{\mathbf{u}}\approx\mathbf{B}_{\mathrm{true}}^{-1}\mathbf{K}_\omega
(\boldsymbol{\omega}_{\mathrm{ref}}-\boldsymbol{\omega})$，
代入角速度动力学：
\begin{equation}
    \dot{\boldsymbol{\omega}}
    = \mathbf{I}^{-1}\mathbf{B}_{\mathrm{true}}\mathbf{B}_{\mathrm{true}}^{-1}
      \mathbf{K}_\omega(\boldsymbol{\omega}_{\mathrm{ref}}-\boldsymbol{\omega})
    = \mathbf{I}^{-1}\mathbf{K}_\omega(\boldsymbol{\omega}_{\mathrm{ref}}-\boldsymbol{\omega})
    \label{eq:cascade_inner_dot}
\end{equation}
这里体现了在线$\mathbf{B}_{\mathrm{true}}$的关键作用：
$\mathbf{B}_{\mathrm{true}}\mathbf{B}_{\mathrm{true}}^{-1}=\mathbf{I}$使角速度动力学
\textbf{精确对角化}——这正是交叉项补偿的数学本质。
每个角速度通道成为独立一阶系统，闭环传递函数为
\begin{equation}
    G_i(s) = \frac{\omega_i(s)}{\omega_{\mathrm{ref},i}(s)}
    = \frac{k_{\omega,i}/I_i}{s + k_{\omega,i}/I_i}
    = \frac{1}{\tau_i s + 1},\qquad
    \tau_i = \frac{I_i}{k_{\omega,i}}
    \label{eq:cascade_inner_tf}
\end{equation}
内环带宽$\omega_{\mathrm{BW},i}=k_{\omega,i}/I_i$。
值得注意的是：若用冻结$\mathbf{B}|_{\delta=0}$替代在线$\mathbf{B}_{\mathrm{true}}$，
则$\mathbf{B}\mathbf{B}_0^{-1}\neq\mathbf{I}$，交叉项残余
$(\mathbf{I}-\mathbf{B}\mathbf{B}_0^{-1})$随摆角增大，
这正是LQR工作点退化的传递函数解释。

\subsubsection{外环闭环}

在时间尺度分离假设下（$\tau_i$远小于外环时间常数），内环近似单位增益
$\boldsymbol{\omega}\approx\boldsymbol{\omega}_{\mathrm{ref}}$，
代入外环（式\ref{eq:cascade_outer_ch}，取纯比例$\mathbf{K}_i=0$）：
\begin{equation}
    \dot{\boldsymbol{\varepsilon}}
    \approx \frac{1}{2}\boldsymbol{\omega}_{\mathrm{ref}}
    = -\frac{1}{2}\mathbf{K}_p\boldsymbol{\varepsilon}
    \label{eq:cascade_outer_dot}
\end{equation}
外环同样对角化，各通道为一阶系统，闭环传递函数
\begin{equation}
    G_o(s) = \frac{\varepsilon_i(s)}{\varepsilon_{\mathrm{cmd},i}(s)}
    = \frac{1}{\tau_o s + 1},\qquad
    \tau_o = \frac{2}{k_{p,i}}
    \label{eq:cascade_outer_tf}
\end{equation}
外环带宽$\omega_{\mathrm{BW},o}=k_{p,i}/2$。
加入积分项后外环成为二阶系统，可消除常值扰动的稳态误差。

\subsubsection{时间尺度分离条件}

级联架构成立的前提是内环远快于外环。由式(\ref{eq:cascade_inner_tf})
与式(\ref{eq:cascade_outer_tf})，要求
\begin{equation}
    \boxed{
    \frac{\omega_{\mathrm{BW},i}}{\omega_{\mathrm{BW},o}}
    = \frac{k_{\omega,i}/I_i}{k_{p,i}/2}
    = \frac{2k_{\omega,i}}{I_i k_{p,i}} \gtrsim 3\text{--}5
    }
    \label{eq:tss_condition_ch}
\end{equation}
仿真采用$K_p=2.0$、$K_\omega=8.0$、$I_y=0.085$\,kg$\cdot$m$^2$，
得$\omega_{\mathrm{BW},o}\approx1$\,rad/s、$\omega_{\mathrm{BW},i}\approx94$\,rad/s，
分离比约94倍——远超下限，这解释了为何级联架构的耦合抑制如此彻底：
内环几乎是"瞬时"地完成角速度跟踪，外环根本"看不到"交叉耦合的瞬态。

\subsection{灵敏度函数与鲁棒性分析}
\label{sec:cascade_sensitivity}

\subsubsection{扰动灵敏度}

设内环存在交叉耦合扰动$\mathbf{d}$（如反扭矩投影），
角速度动力学为$\dot{\boldsymbol{\omega}}=\mathbf{I}^{-1}\mathbf{B}\mathbf{u}+\mathbf{d}$。
以内环参考$\boldsymbol{\omega}_{\mathrm{ref}}$为输入、扰动$\mathbf{d}$为扰动源，
角速度输出的扰动灵敏度函数为
\begin{equation}
    S_d(s) = \frac{\omega(s)}{d(s)} = \frac{1}{s + k_{\omega}/I}
    = \frac{\tau_i}{\tau_i s + 1}\cdot\frac{1}{\tau_i}\cdot\frac{1}{1}
    \label{eq:cascade_sens}
\end{equation}
其幅值$|S_d(j\omega)|$在低频段约为$1/(k_\omega/I)$——
内环增益$k_\omega$越大，对耦合扰动的抑制越强。
这从频域解释了为何提高内环带宽是耦合抑制的关键。

\subsubsection{对模型误差的鲁棒性}

在线$\mathbf{B}_{\mathrm{true}}$依赖模型参数（$k_T,k_Q,a,b$）。
设真实效能矩阵$\tilde{\mathbf{B}}=(\mathbf{I}+\boldsymbol{\Delta})\mathbf{B}_{\mathrm{true}}$，
$\boldsymbol{\Delta}$为乘性模型误差。则式(\ref{eq:cascade_inner_dot})变为
\begin{equation}
    \dot{\boldsymbol{\omega}}
    = \mathbf{I}^{-1}(\mathbf{I}+\boldsymbol{\Delta})
      \mathbf{K}_\omega(\boldsymbol{\omega}_{\mathrm{ref}}-\boldsymbol{\omega})
    \label{eq:cascade_model_err}
\end{equation}
交叉项残余为$\mathbf{I}^{-1}\boldsymbol{\Delta}\mathbf{K}_\omega
(\boldsymbol{\omega}_{\mathrm{ref}}-\boldsymbol{\omega})$。
由于$\mathbf{B}_{\mathrm{true}}$的元素由当前推力/摆角\textbf{在线测量}计算
（而非依赖标定常数），$\boldsymbol{\Delta}$主要来自参数摄动，
其量级由第\ref{sec:verification}节的台架标定精度决定。
在MODEL-DEFAULT参数下，若$k_T,k_Q$标定误差$\pm10\%$，
则$\|\boldsymbol{\Delta}\|\sim0.1$，交叉项残余约为标称耦合的$10\%$——
仍远优于对角SAS的$100\%$不补偿。

\subsection{奇异摄动与稳定性}
\label{sec:cascade_sp}

时间尺度分离的严格理论基础是奇异摄动（singular perturbation）理论。
引入小参数$\epsilon=\tau_i/\tau_o$，将内外环写成奇异摄动标准形：
\begin{align}
    \dot{\boldsymbol{\varepsilon}} &= \frac{1}{2}\boldsymbol{\omega}
    \label{eq:sp_slow}\\
    \epsilon\dot{\boldsymbol{\omega}} &= \frac{\tau_o}{I}\mathbf{K}_\omega
    \left(-\mathbf{K}_p\boldsymbol{\varepsilon}-\boldsymbol{\omega}\right)
    \label{eq:sp_fast}
\end{align}
其中$\boldsymbol{\varepsilon}$为慢变量、$\boldsymbol{\omega}$为快变量。
当$\epsilon\to0$时，快子系统在边界层内指数稳定于拟稳态
$\boldsymbol{\omega}=-\mathbf{K}_p\boldsymbol{\varepsilon}$，
慢子系统退化为$\dot{\boldsymbol{\varepsilon}}=-\frac{1}{2}\mathbf{K}_p\boldsymbol{\varepsilon}$。
由Tikhonov定理，当快子系统在边界层内指数稳定时，
原系统的解在$O(\epsilon)$误差内逼近退化系统——
这为时间尺度分离的近似提供了严格的误差界：
\textbf{内外环分离比越大（$\epsilon$越小），解耦近似越精确}。

需要强调：本架构的工程稳定性已由大量时域仿真间接确认，
但严格的Lyapunov稳定性证明与增益裕度评估仍是后续工作。
上述奇异摄动分析给出了近似的理论基础，但不构成完备证明。

\subsection{控制参数优化与离线整定}
\label{sec:cascade_tuning}

级联架构有三个待整定增益（$K_p,K_i,K_\omega$）。
本节给出离线最优参数搜索方法。

\subsubsection{多目标代价函数}

参数整定的目标是在耦合抑制、跟踪速度与执行器代价间取得平衡。
定义复合代价函数
\begin{equation}
    J(\mathbf{g}) = w_1\,\theta_{\mathrm{peak}} + w_2\,t_{\mathrm{settle}}
    + w_3\,\bar{u}
    \label{eq:cascade_cost}
\end{equation}
其中$\mathbf{g}=[K_p,K_i,K_\omega]^T$，
$\theta_{\mathrm{peak}}$为耦合扰动下的俯仰峰值，
$t_{\mathrm{settle}}$为调节时间（回到峰值$10\%$内），
$\bar{u}$为控制能量（执行器指令幅值均值），
$w_1,w_2,w_3$为权重。

\subsubsection{网格搜索与精化}

采用两阶段离线搜索：
\begin{enumerate}[label=(\arabic*)]
    \item \textbf{粗网格}：在$K_p\in[1,3]$、$K_i\in[0,1]$、$K_\omega\in[4,12]$
          上逐点仿真评估$J$；
    \item \textbf{精化}：在最优点附近细分网格，重复搜索至收敛。
\end{enumerate}
仿真发现$J$曲面在低增益区平缓（图\ref{fig:cascade_param_opt}），
最优解为$K_p\approx1.0$、$K_i\approx0$、$K_\omega\approx4.0$。

\subsubsection{整定原则的物理理解}

离线优化揭示了一个反直觉但有物理依据的结论：
\textbf{在本架构下，较低增益即可实现优良耦合抑制}。
这与直觉（高增益抑制扰动）看似矛盾，根源在于级联架构的解耦本质——
交叉项补偿由在线$\mathbf{B}_{\mathrm{true}}$的\textbf{结构}保证，
而非由增益大小保证。$K_\omega$只需满足时间尺度分离（式\ref{eq:tss_condition_ch}），
过高的$K_\omega$反而放大角速度噪声并增加执行器代价。
然而，过低的$K_\omega$会牺牲噪声鲁棒性（见第\ref{sec:cascade_sim}节），
故整定应在"结构解耦"与"噪声鲁棒"间折中。
$K_i$的引入主要用于消除常值扰动的稳态误差，但会略微增大耦合峰值
（积分项的慢放电与耦合瞬态叠加），故在耦合抑制优先的场景可取$K_i=0$。

\subsection{分析讨论}
\label{sec:cascade_analysis}

\subsubsection{三种"LQR在线B"路径的失败教训}

曾系统评估三种LQR交叉项补偿在线化的直接路径
（增益调度LQR、SDRE在线Riccati、LQR外环+在线B分配）。
仿真表明三者的耦合抑制均未能显著改善（峰值$1.3$--$2.6^\circ$）。
根本原因是它们都保留\textbf{单级全状态反馈}结构——
无论效能矩阵如何更新，交叉项补偿仍与姿态-角速度耦合动态竞争。
这一失败从反面印证了级联架构的核心论点：
\textbf{交叉项补偿的有效性更多取决于控制架构的解耦程度，
而非效能矩阵的在线化程度}。

\subsubsection{架构的适用边界}

\begin{enumerate}[label=(\arabic*)]
    \item \textbf{时间尺度分离}：内环带宽须足够高。执行器响应迟缓时解耦退化；
    \item \textbf{低油门退化}：$\omega_0\to0$时$\mathbf{B}_{\mathrm{true}}$奇异，
          需回退对角分配或舵面控制；
    \item \textbf{执行器饱和}：大幅扰动下摆角/差速限幅仍会使补偿失能，
          尽管级联的完整力矩分配比INDI的增量限幅更耐饱和。
\end{enumerate}

\subsubsection{与其他架构的定位关系}

\begin{itemize}
    \item 定点跟踪品质为主、工作点变化小：LQR的最优增益平衡有优势；
    \item 需强未建模动态对消且能提供高质量角加速度：INDI更合适；
    \item 需工作点鲁棒的交叉项补偿、规避角加速度估计噪声、宽噪声区间稳定：
          \textbf{级联架构是首选}。
\end{itemize}

\subsection{结论}
\label{sec:cascade_conclusion}

本章提出的级联姿态-角速度控制架构，通过时间尺度分离将姿态调节
（外环，误差四元数P/PI）与交叉项补偿（内环，在线$\mathbf{B}_{\mathrm{true}}$分配）解耦。
传递函数分析表明在线效能矩阵使角速度动力学精确对角化；
灵敏度与奇异摄动分析给出了时间尺度分离的频域与理论基础；
离线参数优化揭示了"结构解耦优于增益提高"的整定原则。
仿真验证覆盖巡航耦合抑制（$0.06$--$0.08^\circ$，约两个数量级改善）、
宽噪声区间鲁棒性（$0.05$--$0.42^\circ$全程最优）、
执行器饱和鲁棒性与tail-sitter万向锁有效性。
该架构规避了INDI的角加速度估计噪声、LQR的工作点漂移、SAS的对角近似三大缺陷，
是概念阶段向工程实现过渡的推荐控制结构。
严格Lyapunov稳定性证明、参数摄动下的解析鲁棒界与硬件在环验证，
是后续工作需要补强的方向。
