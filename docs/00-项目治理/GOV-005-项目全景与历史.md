### 3.4 工作流铁律（2026-11-10 用户指令）

**改代码、改项目一律在 revo 本机做，再经 Git 同步到其他机器。**
理由不是洁癖：实测同一份源码、同一个 env，revo 编译的共轴+45686 固件烧录后 IMU 3200 Hz 正常启动；

**"编译在哪台机器"会实际改变固件行为。** 详见 [AGENTS.md](../../AGENTS.md) §多会话并发与变更联动规范。

## 4. 已解决、但最容易重犯的问题

> 完整清单在 [`../registers/踩坑记录-AGENTS.md`](../registers/踩坑记录-AGENTS.md)（130+ 条）与 [`../memory/`](../memory/)（15 篇）。

| 现象 | 真相 | 别再做什么 |
|---|---|---|
| 高频时序测量读数乱跳 | **DBG 命令本身阻塞调度**，污染读数。曾把正常 FIFO 测成 3198 Hz / 21 m/s | 测 IMU 时序一律走 0xF4 遥测，不用 `health`/`tasks`/`vars watch` → [memory/2026-11-04](../memory/2026-11-04-IMU-2kHz攻关.md) |
| 45686 换型后 EKF 发散 | 两个真因：`injectFifo` 从未实现（排空第 2 次永久降级）＋ 批量帧用 `micros()` 差分致 dt 小 39 倍 | 不要"FIFO 批量读"，那是已写明的无效路线 → [memory/2026-11-09](../memory/2026-11-09-ICM45686换型适配.md) |

## 5. 已知未决 / 口径上要小心的地方

> 这一节是「不要拿旧结论当定论」的清单。逐条给出当前可信边界。

1. **参数全是设计值**：`models/aircraft-model.json` 的惯量、推力系数、舵效、质量都是 `MODEL-DEFAULT`/`ESTIMATED`，
   没有一项经过台架标定。任何"仿真显示性能如何"的结论都不能外推到实机。
2. **α-native 增益 `g ∝ T_est/I_assumed`**：惯量与推力估计直接进内环增益。名义点 A/B 一致**不能**外推到实机；
   飞行前必须先台架辨识惯量/推力并做系留/限高（[CTL-006](../05-控制与分配/CTL-006-控制机型解耦契约与分配器.md) §2.4）。
3. **共轴 SIL 有一项真实超调**：新传感器口径下俯仰峰值 22.1°，比 15° 指令上限高 47%，只比 20° 验收门低 2.1°。
   这是**真实姿态裕度不足**，不是门设得紧（[VER-004](../07-验证与确认/VER-004-共轴机型原始固件对照-控制与安全.md) C-6）。
4. **`tools/verify_board.py` 读数全 `-1`**：但原始字节里确实有合法 AnoCom 帧。属工具与固件的口径不一致，**尚未修**。
   在此之前判 IMU 速率用 0xF4 遥测或 DBG `health` 的 `isr_c/isr_f`，不要用这个脚本的结论。
5. **遥控 CH5–CH8 当前未配置**（读到 999）：所以"解锁/点火/模式/手动 TVC 现在测不了"不是固件问题。
   CRSF 未配置通道返回 **999**（不是 988），合法窗口是 0–998 与 1011–2047，990–1010 视为无效。
6. **magicbook 等对端机器可能残留旧 env 与 stash**：同步前先 `ssh <host> "git rev-parse --short HEAD"` 核对，
   不要假设两边一致。
7. **液体火箭机型不在三机型 SIL 跑批里**：它走宿主单测覆盖，这是覆盖设计，不是缺口（2026-11-08 澄清）。
