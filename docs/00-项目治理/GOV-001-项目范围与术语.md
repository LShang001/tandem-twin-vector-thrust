# GOV-001 项目范围与术语

> 本篇界定「纵列双发矢量推力飞行器」整机工程项目的治理边界：说明项目定位、目标、包含与不包含的工作范围，罗列当前资产与文档体系，并给出术语与缩略语统一表。本篇不展开技术推导，具体物理与数学内容见 THY/MOD/CTL 系列文档。

---

## 1. 项目定位与目标

本项目是一个**纵列双发矢量推力飞行器整机工程**，研究对象为纵列双发布局、正交单轴矢量推力 + 差速反扭驱动的固定翼/VTOL 混合构型，当前由四个相互耦合的子系统组成：Web 六自由度仿真（`simulations/vector-thrust-lab`）、Python 高保真分析（`simulations/high-fidelity-analysis`、`py-web-lab`）、**实机飞控固件**（`TandemVec_FCS`，2026-08 实机首飞验证通过，进入调参优化阶段）、**上位机地面站**（`TandemVec_FCS/GCS`）与 **LaTeX 论文工程**（`TandemVec-Paper`）。

**执行器轴映射**（2026-08-07 轴置换后锚定，悬停构型语义）：

- **上摆 δ_f（前电机，机头朝天时位于最高点）**：绕机体系 z_b 单轴摆动 → **滚转主控**；
- **下摆 δ_t（尾电机，位于最低点）**：绕机体系 y_b 单轴摆动 → **俯仰主控**；
- **差速 Δω（前后转速差）**：绕推力轴 x_b 反扭 → **偏航主控**。

同一执行器的机体系力矩映射（δ_f→M_z、δ_t→M_y、Δω→M_x）不随姿态变化；"前摆=偏航、差速反扭滚转"是**巡航构型读法**，悬停（机头朝天）下重读为上摆=滚转 / 下摆=俯仰 / 差速=偏航。锚点 = 手动模式摇杆直通实机验证（roll_raw→上摆、pitch_raw→下摆）。

零摆角时前后推力线均通过质心，物理力臂 `a = b = 0.315 m`（注意：渲染几何中电机位置为前 +1.78 m / 尾 −1.82 m，仅用于可视化，不进入动力学计算）。

项目目标：

1. 建立可复现、可追踪的 6-DOF 数学模型与控制律研究平台（仿真 ↔ 固件三端同构）；
2. 提供基于 Web 的交互式仿真演示载体，用于教学、方案迭代与概念验证；
3. 交付可飞行的 STM32H743 飞控固件（统一四元数姿态控制 + 惯量逆解 + 在线 BTRUE 分配）与上位机（AnoCom/MAVLink 遥测、128 参数在线读写）；
4. 实践「参数单一事实源 + 生成代码 + 自动化回归测试」的轻量级研发治理流程。

项目成熟度声明：仿真域为**概念级**（推进/惯量/质量/配平 ESTIMATED 实机回写、气动/SAS MODEL-DEFAULT）；固件域**实机首飞验证通过（2026-08），进入调参优化阶段**，仿真结果不直接构成飞行性能承诺。

### 2.2 不包含范围（Out-of-Scope）

| 领域 | 说明 |
|------|------|
| 仿真域硬件建模 | 仿真不含传感器 / 电调 / 电池模型（实机物理层由固件工程承载，不归仿真需求管辖） |
| 适航与认证 | 不涉及民航/军品适航审定、安全关键软件开发流程（如 DO-178C） |
| 机体结构设计 | 不含机加、复材、总装等制造域；实机为现成飞控板 + 电机电调框架组装（见 TandemVec_FCS/README） |
| 高保真气动 | 仿真当前采用线性导数模型，不含 CFD、风洞或涡格法气动数据库 |
| 批量生产与商业化 | 无生产、销售、运营计划 |

## 5. 术语与缩略语表

| 术语/缩略语 | 说明 |
|-------------|------|
| 6-DOF | 六自由度（Three-Degrees-of-Freedom Translation + Three-Degrees-of-Freedom Rotation） |
| NED | 北东地坐标系（North-East-Down），惯性/世界参考系，x 指北、y 指东、z 指地 |
| 机体系 {b} | 机体固连坐标系，原点在质心 CG，具体轴向约定见 MOD-002 |
| CG / 质心 | Center of Gravity，飞行器质量中心，机体系原点 |
| DCM | Direction Cosine Matrix，方向余弦矩阵，即 SO(3) 旋转矩阵 R |
| 四元数 | 单位四元数 q = (q0, q1, q2, q3)，用于无奇点姿态积分；本项目采用右乘机体系角速度形式 |
| 欧拉角 | 航空 3-2-1 顺序（偏航 ψ / 俯仰 θ / 滚转 φ），仅用于显示与控制反馈提取 |
| α（迎角） | Angle of Attack，机体系 x 轴与空速矢量投影夹角 |
| β（侧滑角） | Sideslip Angle，空速矢量相对机体对称面的侧向偏角 |
| q̄（动压） | 动压 `q̄ = 0.5·ρ·V²`，气动升/阻/力矩计算的基础 |
| 矢量推力 | 通过电机整体摆动改变推力方向，产生直接力与控制力矩 |
| 上摆 δ_f | 悬停构型（机头朝天）下前电机（最高点）摆角 → 滚转主控；机体系映射绕 z_b → M_z |
| 下摆 δ_t | 悬停构型下尾电机（最低点）摆角 → 俯仰主控；机体系映射绕 y_b → M_y |
| δf / δt | 前/尾电机摆角（前 = front，尾 = tail）；巡航读法：δ_f→偏航、δ_t→俯仰（已废止作语义锚点，保留作机体系映射） |
| Δω / 差速 | 前后电机转速相对配平的归一化差值；悬停语义 = 偏航主控（绕推力轴 x_b 反扭）；机体系映射 M_x |
| FCS | Flight Control System，飞控系统（`TandemVec_FCS` 工程，STM32H743） |
| GCS | Ground Control Station，地面站上位机（`TandemVec_FCS/GCS`，AnoCom 协议） |
| AnoCom | 固件↔上位机私有遥测协议（帧 0x01/0x03/0x0A/0x21/0xF1 等 + 0xE0-0xE3 参数链路） |
| MAVLink | 开源飞行器通信协议；固件 DBG `proto mavlink` 运行时切换（与 AnoCom 互斥） |
| ELRS / CRSF | ExpressLRS 遥控链路及其遥测协议（Crossfire） |
| GNSS | 全球导航卫星系统；固件 UBX/NMEA 双协议（lib/ublox-main，minmea 解析） |
| BTRUE | 在线 Jacobian 控制分配：内环目标力矩经 B⁻¹ 转换到执行器（TandemVec_ControlAllocation.h；仿真 control-allocation.mjs） |
| τm 观测器 | 电机转速一阶观测器 `w_est += (w_cmd−w_est)·dt/τm`；B 矩阵工作点/调度/当前状态全用观测值（2026-08-09 抖油门震荡修复） |
| 差速增益调度 | `(w0_eff/w_hover)²` 封顶 1.0 的差速通道有效增益调度（固件 flight_control.cpp 层2） |
| RATE_MODE | 角速度模式（固件姿态子模式）：摇杆经 Betaflight 三参数曲线（rc_rate/expo/super）映射目标角速率 |
| 航向锁 | yaw ratchet hold：解锁上升沿锁航向，摇杆偏离死区恒角速度，回中锁定（att_yaw.kp×短弧误差） |
| 配平（Trim） | 使机体在稳态飞行中合外力与合外力矩为零的状态/参数组合 |
| 反扭矩 | 螺旋桨旋转产生的绕机体纵轴反作用力矩，双发反向旋转以部分抵消 |
| 拉力式 | 螺旋桨位于机翼/机头前方，拉力驱动气流过翼面 |
| 推进式 | 螺旋桨位于机身后方，推动机体前进 |
| SAS | Stability Augmentation System，增稳系统；本项目为速率+姿态比例+积分反馈 |
| MODEL-DEFAULT | 参数状态 6 级之一：模型默认值，无标定/验证证据 |
| ASSUMED | 参数状态 6 级之一：基于工程假设的估计值 |
| ESTIMATED | 参数状态 6 级之一：基于分析/类比计算得到的估计值 |
| DATASHEET | 参数状态 6 级之一：来自公开或厂商数据手册 |
| BENCH-TESTED | 参数状态 6 级之一：经过地面台架测试标定 |
| FLIGHT-IDENTIFIED | 参数状态 6 级之一：经过飞行试验辨识 |
| 回归基线 | `tests/fixtures/regression-baseline.json` 记录的标准工况时序输出，容差 1e-9 |
| 行为保持红线 | 仿真实现中不可随意改动的数值/算法契约，修改需重采基线并记录原因 |
