# 参数数据手册

> 本手册为 `models/aircraft-model.json` 的人工维护镜像，用于快速查阅、交叉引用与文档化。参数真值源始终以 JSON 文件为准；若二者冲突，以 JSON 与 `tools/sync-params.py` 生成的 `src/core/parameters.mjs` 为准。参数状态升级流程见 [GOV-002](../00-项目治理/GOV-002-信息与配置管理.md)。

---

## 1 说明

- **版本**：`0.2.0`
- **模型 ID**：`PAR-C0-001`
- **总体状态**：`MODEL-DEFAULT`（推进/惯量/质量/配平为 ESTIMATED 组件估算并回写固件实机构型值，待台架标定；气动与 SAS 为概念值）
- **参数总数**：59
- **生成文件**：`simulations/vector-thrust-lab/src/core/parameters.mjs`
- **同步命令**：`py -3.12 tools/sync-params.py`（仓库根目录）
- **固件对照**：机型参数（kT/kQ/wMax/a/b/Ix/Iy/Iz/m/dMax/dwMax/tauM）以 `TandemVec_FCS/include/TandemVec_Config.h` 为固件侧镜像；控制参数（姿态/角速率 PID、滤波、惯量前馈掩码、FPV 摇杆曲线）以 `TandemVec_FCS/include/FlightCtrlParams.h` 为固件唯一事实源（GCS 在线读写 128 参数全链路）。**仿真参数 ≠ 固件参数**：仿真侧为概念级模型，固件侧为实机调参产物，两者共享机型参数但控制参数各自独立。

所有角度的内部单位均为弧度（rad）；界面显示时可视需要转换为度。

## 10 使用说明

1. 如需修改参数，请编辑 `models/aircraft-model.json` 后运行同步脚本；禁止直接修改 `src/core/parameters.mjs`。
2. 参数从 `MODEL-DEFAULT` 升级至 `ASSUMED` / `ESTIMATED` / `DATASHEET` / `BENCH-TESTED` / `FLIGHT-IDENTIFIED` 时，须同步更新本手册的「来源」与「置信度」字段，并按 [GOV-002](../00-项目治理/GOV-002-信息与配置管理.md) 记录决策依据。
3. 本手册未包含参数之间的耦合关系；设计研究时应结合 [`模型-代码追溯矩阵`](../registers/模型-代码追溯矩阵.md) 与 [`假设与局限日志`](../registers/假设与局限日志.md) 使用。
