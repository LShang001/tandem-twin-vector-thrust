# CTL-003 多机型与执行器抽象

> 目标：让飞控固件从“纵列双发专用”演进为“机型数据表 + 通用控制/分配/输出内核”，在不破坏现有实机行为的前提下，可逐步接入多旋翼 VTVL、液体火箭等构型。
> 本文给出分层边界、现有资产、接入步骤和分阶段边界；不在本文重复控制律/分配公式，见 [CTL-001](CTL-001-控制架构与SAS.md)、[CTL-002](CTL-002-可控性与失效模式.md) 与 [THY-003](../03-理论推导/THY-003-刚体动力学控制分配与模态分析.md)。

---

## 1 设计原则

1. **数据驱动优先**：机型差异尽量写成表（执行器几何、输入映射、输出量程、能力位），算法层不出现“前电机/尾电机”之类名字。
2. **行为保持优先**：现有纵列双发路径是实机基线；任何通用化先以“加表 + 旧路径等价适配器”落地，旧回归零漂移后再切换。
3. **编译期确定、无动态内存**：执行器数量用固定上限 + count，禁止运行期堆分配/虚函数表；200 Hz 路径保持确定性。
4. **边界分层**：控制律、分配、输出、遥测、协议各自可替换；不把机型差异塞进 PID 或 EKF。
5. **能力位不是实现声明**：`capability_mask` 只说明表结构具备该能力，未接入控制链/实验验证前不得声称支持对应飞行器。

## 2 分层

| 层 | 职责 | 现有/新增 | 机型无关性 |
|---|---|---|---|
| L0 数据 | 机型 ID、能力位、执行器物理表、输出表、限幅/标定 | `TandemVec_Config.h`、`FlightCtrlParams.h`；新增 `VehicleProfile.h` | 数据可替换 |
| L1 正向模型 | 输入 → 推力/力矩/六维 wrench、B 矩阵 | `AirframeModel.h`、`TandemVec_Propulsion.h` | 已支持 N 电机，kT/kQ 仍共用 |
| L2 转动分配 | α_cmd/力矩 → N 个控制输入，限幅/冗余/秩亏 | `TandemVec_ControlAllocation.h`（3×3 legacy）、`TandemVecAllocator.h`（纵列机型逆解）、`GenericControlAllocation.h` | 纵列专用逆解 / N 输入加权最小范数 |
| L2b 垂直推力 | 期望天向比力 → 总推力/油门/阀门/推力曲线 | 新增 `ThrustAllocation.h`（当前线性油门口径） | 曲线与质量/推力上限按机型替换 |
| L3 输出 | 归一化执行器指令 → 舵机/电调/阀门/点火/RCS | 旧 `mix_and_output_commands`；新增 `ActuatorOutputMap.h` | 按 `OutputChannelSpec` 遍历 |
| L4 制导/模式 | 模式状态机、高度/位置/姿态外环、过渡段 | `flight_control.cpp` | 当前仍为纵列双发语义 |
| L5 遥测/参数 | 0xE1/0xF1/0xF2/0xF3、GCS、黑匣子 | `ano_params.cpp`、`ano_vars.cpp`、`GCS` | 旧帧保兼容，新增按表扩展 |

> **垂直推力映射**同样属于机型相关，边界已于 2026-10-24 抽出：`compute_thrust_control()` 只输出 `specific_force_up_mps2`（含 1g 重力）与 `thrust_cos_tilt`，`mix_and_output_commands()` 再调用 `ThrustAllocation.h`，按质量/最大推力映射为油门。`throttle_percent` 仍只是 TandemVec 的线性油门口径，不是跨机型物理推力；共轴/火箭必须替换为各自推力曲线/阀门映射，不能直接复用该数值。

### 2.1 已完成的第一刀（2026-10-24）

- `include/VehicleProfile.h`：`VehicleKind`、`CapabilityFlag`、`OutputChannelSpec`、`VehicleProfile`、表校验；内置 `kTandemVecProfile`、共轴 `kCoaxialVtvProfile`，并提供 `kQuadVtvProfile`/`kLiquidRocketProfile` 作为表结构示例（后两者**未接入控制链**）。
- `include/ActuatorOutputMap.h`：归一化指令 → 输出命令表；`mapTandemVecOutputs()` 与 `mapCoaxialVtvOutputs()` 分别是两套旧 mix 公式的等价适配器（共轴适配器含 1000–2000 µs 差速与 45° 锁电机保护）。
- `include/TandemVecAllocator.h`：把 **α_cmd + 油门 → 惯量逆解/轴置换/BTRUE/差速/电机百分比** 从 `flight_control` 自动路径抽出；控制层到此只输出角加速度，机型层负责逆解，输出层只做 GPIO/量纲。该抽取已由 SIL 基线逐值回归。
- `include/ThrustAllocation.h`（2026-10-24 第二刀）：把 **期望天向比力 + cos_tilt + 质量/最大推力 → 总推力/油门** 从 `compute_thrust_control()` 抽出；`ControlOutputs_t` 新增 `specific_force_up_mps2`/`thrust_cos_tilt`/`throttle_direct`，自动模式的 `throttle_percent` 由 mix 层回填。TandemVec 仍采用既有线性油门口径（刻意不改成 kT·ω² 物理逆，避免实机行为漂移），`test_thrust_allocation.cpp` 锁定旧 `mapFloat` 逐值口径。
- `include/HeadingAidingGate.h`（2026-10-24 安全门控）：以磁矢量最近成功融合时间为唯一绝对航向源；失效立即降级、恢复需连续 3 s 磁新鲜。`determine_control_mode()` 据此把 AUTO_POSITION/GUIDED 强制降为 AUTO_ALTITUDE，`execute_yaw_controller()` 同时关闭 heading hold（回中只给 ω_ref=0）。无磁 `nomag_degraded` SIL profile 3 seeds 通过（定高 9.17–9.29 m、max_roll 0、`pos_degraded=1`）；无磁位置保持不再被当作验收项。
- `include/CoaxialVtvControl.h`（2026-10-24）：DirectTvcRate 控制律已按实飞工程结构逐项对齐——`PositionPID` 外环 4.25/0（±80°/s、积分限 40）、速率内环 0.25/0.08（±10°、积分限 5、微分滤波 0.2）、偏航 3.8/30（±180 µs、积分限 50、阈值 40），外加姿态目标 α=0.85、修正角 α=0.25 两级滤波；`RATE_MODE` 与实飞工程一样每拍复位速率 PID。已通过 `BFS_COAXIAL_VTVL` / `CoaxialVTVL` env 接入 `runGNCExecutive`，共用输入/模式/定高/目标姿态层；`test_coaxial_reference_equivalence` 用实飞工程 `PositionPID/ComplementaryFilter` 原头文件做参考，600 拍（ATTITUDE/RATE/手动/失效）逐拍误差 0；`run_coaxial_acceptance.sh` 用真实固件 + 近似共轴 plant 跑出 mag_clean/mag_nominal/nomag_degraded ×5 seeds **15/15 PASS**。**仍无共轴台架/HIL/实机；plant 惯量/力臂/差速力矩是 L1 假设，没有外部实飞日志做逐波形回放。**
- `include/LiquidRocketModel.h`（2026-10-24）：L1 液体火箭推进模型（点火/解锁互锁、阀门/推力速率、Tmin、比冲质量流、推进剂耗尽、变质量）与双轴喷管 asin 几何；参数取自外部 `VTVL_LiquidRocket_FC` 的 CCAEGT 示例，**不是本机标定值**。`test_liquid_rocket_sil.cpp` + `run_liquid_sil_sweep.sh` 对 20/30/40 m × 2.5/3/4 kg 共 9 组做垂直回收闭环，接地速度 2.15–2.45 m/s、姿态有界；`test_liquid_ccaegt_reference` 又把外部实飞 CCAEGT 制导库作为参考，驱动本机推进模型完成 30 m 回收（接地 1.87 m/s）。**CCAEGT 仍未移植进固件飞行模式；无气动/RCS/多级/泵压动态；参数不是本机标定值。**
- `src/flight_control.cpp` 层 3 已改为走 `ActuatorOutputMap`；GPIO/PWM 写入仍留在固件层，通用层不依赖 Arduino。自动分配路径走 `TandemVecAllocator`，manual/locked 路径保留旧安全分支。
- `include/GenericControlAllocation.h`：3×N 加权最小范数分配，含限幅、秩亏标记和残差；与 legacy BTRUE 的 3×3 等价由宿主测试锁定。
- 宿主测试：`test_vehicle_profile.cpp`、`test_generic_allocation.cpp`；SIL 基线保持。

### 2.2 共轴双桨 VTVL 对照（外部工程 `VTVL_ElectricDualRotor_FCS`）

外部共轴工程与当前纵列双发的**执行器数量相同**（2 电机 + 2 舵机），但拓扑、混控和控制架构不同，不能只换参数：

| 维度 | 纵列双发（当前实机） | 共轴双桨 VTVL（外部工程） |
|---|---|---|
| 推力布局 | 前/后两电机，力臂 a/b | 两对转电机共轴，力臂≈0；差速只产生偏航反扭 |
| TVC | 上摆=滚转、下摆=俯仰；齿轮 40/30、半行程 45°、dMax 15° | 喷管两轴 TVC；舵机 33.33–66.67% 对应 ±15°，`MAX_CORRECTION=10°` |
| 偏航 | Δω → `w0√(1±Δω)`，BTRUE 力矩分配 | 偏航速率 PID → 电机 PWM 微秒差（1000–2000 µs） |
| 控制架构 | 姿态/速率环 → 三轴力矩 → 3×3 BTRUE → 执行器 | 姿态/速率环 → roll/pitch 摆角 + yaw µs，**直接 TVC 混控** |
| 主要限幅 | dMax 15°、dwMax 0.7、零油门 5% 归中 | `MAX_CORRECTION=10°`、电机 1000–2000 µs、大倾角 45° 锁电机 |
| 增益 | `FlightCtrlParams.h`（2.8/16.04/11.46 等） | `VtvLParams.h`（4.25/0.25/3.8 等） |

**通用点**（可直接复用）：IMU/GNSS/气压/光流/磁传感器与导航、EKF、模式判定/解锁/点火/燃料联锁、RC 输入与 FPV 曲线、任务调度、日志/GCS/AnoCom/AnoVars、四元数姿态误差、PID/滤波/限幅工具、地面/飞行安全门控、FRD/NED 坐标系约定。

**不同点**（必须由机型层吸收）：推力几何与力臂、TVC 机械映射、偏航执行方式、控制架构（力矩分配 vs 直接 TVC）、增益/限幅/保护门限、参数表/遥测字段。

本轮的 `kCoaxialVtvProfile` 与 `mapCoaxialVtvOutputs()` 已能表达共轴输出表并复现外部 mix 的舵机方向、PWM 差速和大倾角锁电机；但 **DirectTvcRate 控制律尚未接入当前 `runGNCExecutive`**，因此仍不能把当前固件直接飞共轴机型。外部工程中的几何/三阶多项式 TVC 映射目前未被其实际 mix 调用，暂作为可选运动学表保留，不冒充当前实现。燃料阀门/点火是独立安全输出，未纳入 4 路姿态 mix；接入共轴整机时需把阀门/点火增加到 profile 或复用现有 fuel 安全链。

## 3 新机型接入步骤

### 3.1 共轴双桨 VTVL

1. 选 `kCoaxialVtvProfile`：2 舵机 + 2 电调，`DirectTvcRate` / `DifferentialPwmUs`；
2. 控制律使用 `CoaxialVtvControl.h`，已通过 `BFS_COAXIAL_VTVL` 接入 `runGNCExecutive` 并建立共轴近似 6DOF SIL（9/9 PASS）；下一步是共轴台架/HIL 标定惯量、力臂、差速力矩与 TVC 机械方向；
3. 输出层调用 `mapCoaxialVtvOutputs()`：复现 ±15°→33.33–66.67%、1000–2000 µs 联合限幅、未解锁/45° 大倾角锁电机；
4. 复用现有模式/解锁/点火/燃料联锁、导航、传感器、日志和 GCS；**不要复用 TandemVec 的 BTRUE 差速开方路径**；
5. 增加共轴 6DOF SIL/台架场景（推力同轴、反扭差速、TVC 机械映射）；旧纵列路径回归不变；
6. 外部工程的几何/三阶多项式 TVC 表可选接入，但当前实际 mix 是线性 ±15° 映射，先不要混用。

### 3.2 多旋翼 VTVL

1. 填 `VehicleProfile` 输出表（N 路 ESC）与能力位；
2. 用 `AirframeModel::ActuatorDef` 填 N 个旋翼几何/旋向/输入索引；
3. 用 `GenericControlAllocation` 生成力矩指令（3×N）；
4. 新增 VTVL 的 mix 策略：油门分配 + 差速/反扭（若共轴）→ 每电机归一化指令；
5. 在 L4 增加/复用姿态、高度、位置模式；过渡段另立；
6. 以 SIL + 台架验证，旧 `TandemVec` profile 回归不变。

### 3.3 液体火箭

1. 输出表增加阀门、点火、双摆座、RCS；能力位 `ThrustValve/Ignition/Rcs/VariableMass`；
2. 推进模型已抽 `LiquidRocketModel.h`（推力曲线/阀门/点火/比冲流量/变质量/双轴喷管），但参数是外部 CCAEGT 示例，需本机标定；RCS 脉冲/多级尚未实现；
3. 分配内核使用 N 输入（摆座 2 + RCS 脉冲），处理秩亏/最小脉冲；
4. 模式状态机需要 `IGNITION/ASCENT/STAGE_SEP/DESCENT/LANDED` 等新状态；现有解锁/燃料联锁可复用，但不能直接复用 VTOL 模式；外部 `VTVL_LiquidRocket_FC` 的 CCAEGT 制导库只作参考，未复制进本仓库；
5. 级间分离、变质量、RCS 最小脉冲和上升段制导必须单独安全论证；**本轮只做 L1 模型，不接入飞行模式**。

## 4 兼容与红线

- 旧 `TandemVec` 路径的差速开方 `ω=w0√(1±Δω)`、τm 观测、零油门 5% 归中、轴置换、dMax/dwMax、锁定 0% 不得被通用分配器替换；通用层只能以等价适配器接入。
- 航向不可观时不得继续 AUTO_POSITION/GUIDED 水平位置闭环，也不得做绝对航向 heading hold；这是 `HeadingAidingGate` 的安全红线，不是可调增益。
- 液体火箭模型的点火/解锁互锁、推进剂耗尽推力归零、质量不得为负是硬边界；模型参数未标定，不得用于实机推力/着陆预测。
- 参数 ID=注册表下标是协议，只允许尾部追加；0xF1 旧帧保持，新增执行器遥测优先走 AnoVars/新帧。
- 任何新机型 profile 在没有 SIL/台架/实飞证据前，状态只能是“表结构可表达”，不是“已支持”。
- 变质量/多级/点火/RCS 属于新安全论证范围，不塞进现有 6DOF 控制链。

## 5 分阶段

| 阶段 | 内容 | 闸门 |
|---|---|---|
| P1（本轮） | `VehicleProfile`、`ActuatorOutputMap`、`GenericControlAllocation`；legacy 输出等价接入 | 宿主测试 + SIL 基线零漂移 |
| P2 | 通用输出驱动接管 GPIO/PWM；VTVL 输出表 + 四旋翼 SIL | 旧 profile 零 diff；新 profile 可装表 |
| P3 | 通用 N 输入分配接入 VTVL/共轴；饱和再分配策略 | 旧 BTRUE 保留；新机型闭环 |
| P4 | 液体火箭地面点火/阀门/摆座/RCS；推力/质量时变模型 | 台架/系留，不涉及级间 |
| P5 | 上升/下降制导、级间分离、着陆 | 独立安全论证/HIL |

> 当前完成 P1 的代码骨架；P2 之后才可能谈“支持某新机型”。现有实机仍应按原纵列双发基线调参/飞行。
