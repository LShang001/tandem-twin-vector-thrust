# CTL-004 无磁航向与运动 EKF

> 2026-10-25。适用范围：短期不加磁力计、仅磁初始对准、或起飞前手动对准
> 航向的飞行配置。证据等级 L2（真实固件源码 + SIL），未做实机验证。

## 1. 三种航向源模式

`g_heading_aid_mode`（编译期默认 `BFS_HEADING_AID_MODE`，SIL 可
`--heading-aid-mode` 覆盖）：

| 模式 | 含义 | 磁融合 | 初始航向 |
|---|---|---|---|
| 0 | MAG_ONLY（默认，保持原行为） | 连续 | 真实磁（含磁偏角）或伪磁 |
| 1 | MAG_INIT_ONLY | 仅初始化，之后停止 | 真实磁（含磁偏角）；无磁时手动 |
| 2 | NO_MAG_MANUAL | 不融合 | 手动 `heading_align_deg` |

手动对准角 `g_heading_align_deg`（默认 0°，机头真北顺时针）。模式 1/2
在无真实磁时，EKF 初始航向不确定度取 0.05 rad（约 3°）；模式 1 有真实
磁时取 0.1 rad。

## 2. 航向可观性

- **纯悬停**：无绝对航向源；陀螺积分只能短时维持，航向 1σ 随时间增长。
- **纯平移（风推、无倾斜）**：GNSS 速度方向不等于机头方向，航向仍不可观。
  SIL seed1 在 4 m/s² 侧风、定高模式下，真实 yaw 保持 0°，EKF yaw 漂到
  −147°（40 s）。**不能把 GNSS 速度方向直接当航向。**
- **速度 + 倾斜运动**：前飞时推力方向随姿态倾斜，GNSS 速度/加速度与
  机体系比力联合可观测航向；EKF 才会收敛。

## 3. 位置保持门控

`HeadingAidingGate` 在模式 1/2 下：

- 仅当 **水平速度 >2 m/s 且 |roll| 或 |pitch| >5°**（运动激励）且
  **EKF yaw 1σ ≤10°** 时，允许 `AUTO_POSITION` / heading hold；
- 运动激励消失后最多 coast **3 s**，随后降级为 `AUTO_ALTITUDE`；
- 航向 1σ >10° 时即使有速度也不允许位置保持；
- heading hold 与位置保持共用该门控：降级后回中只做零角速率阻尼，
  不追漂移的航向估计。

**纯悬停/侧风漂移时不提供位置保持**，这是物理可观性边界，不是调参问题。
短期使用方式：手动/定高起飞与悬停；需要位置保持时先做一段有倾斜的前飞，
让 EKF 收敛航向，再进入定点。

## 4. SIL 证据（2026-10-25）

- 模式 0（磁连续）mag_clean 3 seeds 保持原验收：hold_end 1.15/0.71/1.10 m。
- 模式 1（磁仅初始）与模式 2（无磁手动）mag_clean 3 seeds：高度
  9.96–10.07 m、max_roll 0、`pos_degraded=1`（按设计不定点）、
  `mag_fused=0`（初始化后不再融合）。
- 模式 2 clean 3 seeds：高度 9.99–10.03 m、max_roll 0、`pos_degraded=1`。
- 门控单元测试 T9–T11：无运动激励降级；运动激励恢复；停止后 3 s coast
  再降级；yaw 1σ 12° 时运动激励也不解除。
- 模式 0 默认行为未改变；`test_heading_aiding_gate` 全绿。
