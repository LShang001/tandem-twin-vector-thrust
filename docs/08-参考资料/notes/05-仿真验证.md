## 0. 结论摘要（先给判断）

1. **仿真框架本身有重大保真度缺陷（必须先修再引用旧结论）**：`opt_ekf.py` 的
   `measurement_update_yaw_h2()` 把航向雅可比写成 `H[0, 7:10]`，而固件是
   `h_yaw(0, 6..8)`（`ekf_15_state.h:3162-3226`）。水平姿态下该索引把航向新息
   **注入加计零偏 x**，航向完全不被修正（单点注入实证：+10° 航向观测 → 航向不变、
   `ba_x += 0.173 m/s²`）。**报告中" H2 修复 SC4 47.7°→0.14°"的对比方向需要重读**：
   那是"把航向观测误接到 ba_x"与"H=e8"的对比，不是倾斜补偿的收益。`sim/hifi/run_scenes_opt.py`
   同样调用该函数，故高保真闭环结论也受影响。
2. **磁航向（候选 A）：仿真证据支持"加门控+自适应 R+正确雅可比"后有明显增益，但只在
   有独立航迹/GNSS 可用的机动段**。SC3 转弯位置 56.6 m→1.16 m（ideal）、航向 0.47°→0.28°、
   GNSS 接受率 0.842→0.956；SC5 失联航向 0.86°→0.25°。**裸用受扰磁会灾难性发散**
   （SC3 647 m）；门控能挡住 92% 受扰历元、但剩下 8% 仍使 SC3 退化到 96 m。**推荐形态
   是"理想/标定良好的磁 + 门控 + 自适应 R"，不是"任意磁都能救 F2/F3"**（HW 必须做磁标定）。
3. **GNSS 故障隔离（候选 B）：只做子集隔离（B_fdi）无明显收益甚至变差；收益全部来自
   "速度连续被拒后重锚"**（B_fdi_reset）：SC3 位置 56.6 m→2.52 m、SC6 0.738 m→0.451 m、
   速度失锁时长 10.8 s→1.0 s、位置误隔离率 SC6 0.739→0.30。**代价：航向/姿态略退化**
   （SC3 航向 0.47°→3.12°、姿态 13.7°→15.2°；SC8 航向 1.58°→2.12°；SC5 位置 3.03→3.19 m）。
   属"用航向换速度/位置"的权衡，**需实机验证是否可接受**。
4. **振动自适应 Q（候选 C）：巡航有增益（SC2 航向 3.9°→1.8°、速度 0.112→0.065 m/s），
   但悬停低震动时严重有害（SC7 航向 0.26°→17.2°；固定 Q=0.05 同样 23.6°）**。
   与报告"Q 0.25→0.05 有明确增益"的结论在悬停场景**冲突**，不能无条件上机。
5. **ZUPT 误静止（Lead 指定 P0 场景）**：5 m/s 平滑巡航 + GNSS 失联时，静止检测在
   0.095 s 内误确认（失联期 99.8% 时间），但固件 `Icm45686AdaptZuptNoiseForResidual`
   的 **1.5 m/s 残差跳过门**挡住了全部 1363 次 ZUPT → 速度不坍塌（位置 11.5 m）。
   关掉该跳过门后复现 Lead 预测：失联后 **6.05 s** P_vv 膨胀到 NIS 可过，ZUPT 把 5 m/s
   拉零，位置误差 180 m（NIS=1000 时 212 m）。**新发现：速度 <1.5 m/s 的慢速巡航落在
   盲区**——1 m/s 巡航时跳过门不触发，速度被 ZUPT 拉零，失联 40 s 位置误差 51.6 m。

## 2. 前置发现：仿真双矢量航向 H 索引错位（影响所有 yaw_aid 场景）

### 2.1 证据

| 实验 | 结果 |
|---|---|
| 静态单点注入（+10° 航向观测，基线 `measurement_update_yaw_h2`） | 航向 **+0.000°**，`Δba_x=+0.173 m/s²` |
| 同一注入，修正版 `yaw_update_h2_fixed`（H=6..8，固件口径） | 航向 **+9.975°**，`Δba_x=0.000` |
| 固件 `ApplyYawUpdateDetailed` | `h_yaw(0,6)=t_b2ned(2,0)` … 即索引 6..8 |

原因：`opt_ekf.py:429` 写 `H[0, 7:10] = h_axis`，比固件整体右移一格；水平时
`h_axis=[0,0,1]` 落在索引 9（加计零偏 x）。**这是仿真代码缺陷，不是固件缺陷**；
`sim/hifi/run_scenes_opt.py:125` 复用同一函数，高保真闭环变体结果同受影响。

### 2.2 影响与处理

- **2026-10-21 已修**：`opt_ekf.py:429` 改 `H[0,6:9]`；`--selftest` 4/4；
  A/B/P0 全部重跑。以下 19.8°/18.7° 是历史基线；当前 JSON 中 `A_nomag_legacy`
  与 `A_nomag` 已等价，不再作为“错位对照”。
- 所有 `yaw_aid.enable=True` 的场景（SC2/SC3/SC4/SC7）在 baseline 仿真里双矢量航向
  实际是"航向新息→加计零偏 x"的错误接线，**F2 航向弱可观的仿真定量结论不能直接引用**。
- 本文候选 A/B 一律在修正基线（`yaw_h2_fix`）上评估；修正后 SC3 航向 0.47°、
  SC4 姿态 2.43°（旧 19.8°/18.7° 只作历史参照）。
- **仍需固件侧核对**：数值微分表明，若把该量测当作"欧拉 yaw"，其严格雅可比是
  `(0, sinφ/cosθ, cosφ/cosθ)`，而固件用的 `C_b^n` 第 2 行在水平时成立、大俯仰时
  与数值雅可比不一致（俯仰 90° 与物理下轴差一个符号）。修 H 索引是最小改动，
  但倾斜段是否应改用严格雅可比/四元数误差，建议另立任务核对。**（SIM+解析证据，需 HW/固件复核）**

## 3. 候选 A：磁航向辅助

### 3.1 实现要点

- 磁模型（μT，NED）：与固件 `include/mag_reference.h` 一致，IGRF-14 2026.0 @28.2N/112.9E：
  N/E/D=35.075/−2.523/+34.079，水平 35.166、|B|=48.969、倾角 44.10°、磁偏角 −4.114°
  （D 向下为正；2026-10 由旧水平 27/垂直 39 的错误量级统一）。**本文件以下候选
  结果若引用旧 JSON，均使用旧磁模型；本轮只做常量修正/自检，完整 hifi 套件未重跑。**
  - `ideal`：真值场 + 0.3 μT 白噪声；
  - `disturbed`：机体系硬磁 `[4.5,−3.0,3.5] μT` + 软磁 `diag(1.06,0.95,1.04)` +
    NED 慢变干扰 2.5 μT（周期 70–110 s）+ 0.6 μT 噪声。
- 观测：`m_n = C^n_b(est)·m_b`，`y = dec − atan2(m_n[E],m_n[N])`（NED 航向误差）。
- **雅可比用解析式**（与数值微分逐位一致，自检 5）：
  `∂az/∂ε_i = [−m_E, m_N, 0]/(m_N²+m_E²) · (c_i × m_n)`，`c_i`=C^n_b 第 i 列。
  **不用**固件式 `C_b^n` 第 2 行（大俯仰下符号/转置不一致，悬停实测会把航向推反）。
- 门控（任一触发即跳过）：|B| 偏差 >5 μT；倾角偏差 >6°；与 GNSS 航迹隐含航向误差
  不一致 >20°（`r_track = |y + (ψ_est − track)|`，航向误差自动抵消）；|y|>45°；
  姿态 1σ（P66/P77）>8°。
- 自适应 R：`σ = σ0 + k_norm·|‖B‖−47.4| + k_dip·Δdip + k_track·r_track
  + k_att·√(P66²+P77²)`，限幅 0.3–25°，再按 NIS≤12 硬门；`robust` 形态把 σ 抬到
  `max(σ, |y|/2.5)` 做有界影响软更新。

### 3.3 磁 A 套件负面/边界结果（**不得只挑 SC3 位置改善**）

1. **裸用受扰磁是灾难**：SC3 位置 647 m、GNSS 接受率 0.533、速度失锁 39.9 s。
   磁航向对硬磁/软磁极其敏感，**没有标定与门控绝不能接入**（HW 必做椭球标定 + 轴映射）。
2. **门控能"防死"但不能"治好"**：受扰磁+门控 SC3 仍 96.5±180 m（受扰历元跳过 92%），
   远差于理想磁 1.16 m——**门控只是止损，磁质量才是收益来源**。
3. **鲁棒软更新无额外收益**：`dist_gate` 与 `dist_robust` 结果逐位相同（门控太严，
   通过的历元残差都小，Huber 缩放未触发）。不建议为鲁棒项增加复杂度。
4. **悬停（SC7）无增益、且姿态略退化**：理想磁 yaw 0.256°→0.438°、att 0.774°→1.00°；
   受扰磁门控 att 2.39°。原因是悬停时航向误差落在**机体系 roll 误差态**，而 P0 把
   航向不确定度记在 yaw 态（P88），单点注入实测 6 次更新后航向仅移动 0.3°（真值误差 10°），
   磁的纠偏权威被协方差记账限制；这不是磁算法本身的问题，**是 ZYX 误差态在
   gimbal lock 的已知缺陷**（需四元数/无奇点误差参数化才能根治，SIM）。
5. **过渡段（SC4）无位置增益**：63.5–66.3 m 与无磁持平（位置误差来自无水平位置
   控制的开环漂移，不是导航层）；磁只改善航向/姿态（2.34°→1.12°）。

## 7. 失败案例与外推边界

### 7.1 仿真保真度限制（外推边界，必须随结论一起引用）

1. **无控制闭环**：SC3/SC4 的位置误差主要是开环漂移（无水平位置控制），不能把
   "位置 RMSE"当导航精度；导航层结论只看航向/姿态/速度/接受率/失锁。
2. **转弯无坡度**：`TrajGen.add_turn` 只转偏航、roll=0；真实协调转弯有 11–20° 坡度，
   磁/重力/航向耦合会不同（磁门控的"倾斜"分支在 SC3 未被真实检验）。
3. **磁模型简化**：只建了常值硬磁 + 对角软磁 + 正弦慢变干扰；无机体电流/电机谐波、
   无安装角误差、无温度漂移、无椭球标定残差。实机磁误差结构会更复杂（HW）。
4. **GNSS 误差模型**：白噪声位置/速度 + 阶跃野值 + 多径缩放；无多路径相关、
   无周跳/欺骗、无卫星几何变化；**没有卫星级 RAIM**，本文的"隔离"是位置/速度子集级。
5. **IMU 震动**：仅 80 Hz 单频正弦（0.03/0.15 m/s²），无宽带谱/桨叶通过频率；
   候选 C 的调度器在实机谱下的行为需重新标定。
6. **静止检测器**：仿真用固件四条件 + 迟滞，但 IMU 噪声是白噪声；实机低频晃动/
   温度漂移可能改变误确认概率。
7. **统计规模**：每格 5 种子（A/B/C/P0），SC3 无磁的种子方差（±49 m）说明 5 种子
   不足以定论发散概率；**关键结论需 ≥20 种子 + 实机数据**。
8. **单点/解析证据**：H 索引、雅可比、磁符号均为"数值+解析"证据（可复现），
   但固件倾斜段是否应改严格雅可比仍需固件/理论组复核。

### 7.2 明确的失败/无增益项

- 受扰磁裸用（SC3 647 m）、受扰磁门控在 SC3 仍 96 m ——**磁不标定不上机**。
- 磁在悬停（SC7）与过渡段位置（SC4）**无增益**，姿态略退化。
- 仅子集隔离（不重锚）**无收益甚至变差**（SC6 位置 0.738→1.23 m）。
- 自适应 Q/固定 Q=0.05 在悬停**严重有害**（yaw 17–24°）。
- 鲁棒软更新在严格门控下无差异；重锚的膨胀与重置在多数场景等效。
