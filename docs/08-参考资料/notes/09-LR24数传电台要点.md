# LR24 数传电台要点（微空 MicoAir）

> 来源：[LR24数传电台用户手册](https://micoair.cn/zh/docs/telemetry/lr24/lr24-telemetry)（官方，最近修改 2025-07-10；抓取 2026-11-06）
> 用途：单涵道机 `[env:SingleEdf4Vane_Flight]` 的地面链路；本机接在**飞控侧**，电脑侧接 USB。

## 一、型号

| 型号 | 发射功率 | 板载 USB 转 TTL | 备注 |
|---|---|---|---|
| LR24-F-Mini | 27 dBm | **无** | 无外壳，只有 SH1.0-4P TTL |
| LR24-F | 27 dBm | CP2102 | 常规款 |
| LR24-P | 30 dBm | CP2102 | 高功率 |

不同型号可互配，**通联距离取功率较小的一端**。

## 二、核心参数

- 频段：2400–2482 MHz（2.4 GHz ISM）
- 调制：LoRa 扩频 + FHSS 跳频；**20K 档改用 FLRC**
- 透传速率：**2.4K / 4K / 8K / 20K Byte/s**（默认 2.4K）
- 最大串口单包：20K Byte
- 串口（GH1.25 TTL）波特率：9600 / 19200 / 38400 / 57600（默认）/ 115200 / 230400 / 460800 / 921600
- USB 波特率：57600 / 115200 / 921600（默认 57600）
- 供电：4.5–5 V；功耗 3 W（P）/ 2 W（F/F-Mini）
- 天线：SMA 内孔

## 三、三条硬规则（配错必踩坑）

1. **20K 档 = 20K Byte/s = 160 kbps**，不是 20 kbps。按 20K 算，6.9 KB/s 的遥测流只占 34%。
2. **速率与波特率必须匹配**：用 8K 档要求 ≥115200；用 **20K 档要求 921600**。本机已配 921600。
3. **飞控端频点模式应配 FHSS-AIR**，电脑端配 FHSS-GROUND。默认是「自动」——速率不受影响，但抗干扰差一截。

## 四、其他配置项

- **工作模式**：双工 / 广播-发射 / 广播接收，默认双工。**作为飞控数传只能用双工**。
- **频点模式**：手动 / 自动（默认）/ FHSS-GROUND / FHSS-AIR。手动模式下频点 0–82 对应 2400–2482 MHz。
- **模块地址**：默认 1000，范围 1–30000，**两端必须一致**；多对数传同场时改为不同地址。
- **LED 指示**：1 Hz 闪 = 未连接；常亮 = 已对频连接。
- **双工带宽共享**：上下行共用同一透传速率，参数读写/命令回传也占这部分带宽。

## 五、对本项目的影响（2026-11-06 实测）

现象：单涵道接 LR24（用户称配 20K、921600）后，**所有遥测帧统一掉到 21.24 Hz**
（0x01 应 100Hz、0x0A 应 50Hz 同比例下降）。

固件侧已排除：`ano_skip=0`、`proto_drop=0`、200Hz 任务实测 199–200Hz、UART 占用仅 7.7%。

**推断**：若模块真在 20K 档，6.9 KB/s 只占 34%，不该丢到 21%；
更可能是模块仍在**默认 2.4K Byte/s**（6.9 KB/s 超 2.9 倍，理论只能过 34%，实测 21% 与其吻合）。

处置：固件分频已下调（commit e8ff64b），总带宽 6.9 → **1.8 KB/s**，对 2.4K 档安全、
对 20K 档留 91% 余量。上板后若帧率达到设计值即可反证模块工作在 2.4K 档。

**若确认模块是 20K 档**，可把分频恢复（或折中到 40Hz 姿态），需重测。
