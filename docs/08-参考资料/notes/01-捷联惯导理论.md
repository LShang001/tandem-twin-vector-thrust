## 0. 结论摘要（5 条，先给判断）

1. **圆锥/划摇补偿系数没有正确性错误。** 固件双子样圆锥 `2/3·Δθ₁×Δθ₂`（`ekf_15_state.h:2275-2280`）与秦书 (9.3.30)（p.274）一致；双子样划摇 `(2/3)(Δθ₁×Δv₂+Δv₁×Δθ₂)`（`:2281-2287`）与秦书 (9.6.25)（p.301，注意 Δv×Δθ = −Δθ×Δv，两式恒等）一致；两者同时是锥/划桨运动下的**最优系数**（表 9.4.1 p.284；9.6.3 节 p.303）。数值复核：10 Hz 划桨运动、5 ms 周期下系数残差 0.12%。
2. **但速度积分有一处“旋转效应重复计入”的正确性缺陷（P0-1）。** 固件把 `0.5Δθ×Δv` 放进划摇补偿项，随后又用**中点姿态** `t_b2ned_mid` 旋转该增量（`:2297-2300`、`:2358`）。秦书 (9.6.17)(9.6.19)（p.298–299）的旋转补偿是配合**区间起始姿态** `C^n_b(m−1)` 使用的；中点姿态已包含半程旋转，故该项被计了两次。数值复算：ω=2 rad/s、|f|≈10 m/s²、dt=5 ms 时误差恰为 `0.5Δθ×Δv` = 2.5×10⁻² m/s²；典型机动 1.2×10⁻² m/s²【项目证据，附录 A】。修复为 1 行改动。
3. **全 F 矩阵与秦书误差模型在结构上一致，但状态定义不同：秦书是导航系失准角 φⁿ（ENU，`Ĉⁿ_b=(I−φ×)Cⁿ_b`），固件是体系误差 δβᵇ（NED/FRD，右乘，`q_true=q_est⊗Exp(δβ)`）。** 一阶等价关系 `φ = Cⁿ_b δβ`；固件的 `F(v,β)=−C[f]×`、`F(β,v)=−Cᵇ_n M`、`F(β,β)=−[ω_ib]×` 与该换算逐项吻合（推导见 §1.6、§2.2；注意秦书 δ 为“计算值−真值”，固件 δv 为“真值−估计”，相差一次取反）。缺失项只有 `F(β,P)`、`F(v,P)` 的纬度/高度高阶耦合（量级 ≤10⁻⁹ m/s² 每米，可忽略）与刻度系数/安装误差（不在 15 状态内）。**15 状态内没有发现“模型级”不一致。**
4. **初始对准不是秦书意义的“对准”，而是“伪磁确定性赋值 + GNSS/光流双矢量动态校正”。** 初始化航向来自体固常量伪磁 `(30,0,40)`（`navigation_task.cpp:810-819`）经 TiltCompass（`tilt_compass.h:34-63`），该矢量不随姿态/磁北变化，因此航向初值只保证数值确定、不保证物理正确；`P0(8,8)=0.2 rad` 是人为语义（`navigation_task.cpp:1010-1011`）。无空速 + 磁未接入时，唯一绝对航向源是“GNSS 航迹角 − 光流侧滑角”（`navigation_task.cpp:394-519`，要求 v≥1 m/s、|ω_z|≤0.35 rad/s、光流有效）。MEMS 陀螺（配置的初始零偏不确定度 0.4°/s，实际零偏稳定性需 Allan 实测）不具备静基座罗经对准能力：秦书 (9.9.43c)(9.9.44)（p.334）给出 `δφ_U0 = ε_E/(ω_ie cosL)`，ε_E=1°/h 即约 4.4°，5°/h 即约 22°【文献+推断】。
5. **精度缺口主要是“双子样块级补偿在高频圆锥下的残差”和“单子样回退路径”，不是系数。** 按秦书表 9.4.2（h=10 ms、a=1°）折算到本机 h=5 ms：50 Hz 圆锥下双子样残余约 125°/h、三子样约 1.5°/h（∝(ωh)⁴ vs (ωh)⁶，【推断】）；单子样在 h=2.5 ms、50 Hz 下达 4059°/h（表 9.4.3 p.284）。是否值得上三子样，取决于实机 5–100 Hz 角振动谱——**这是目前唯一缺失的定量依据**。

## 1. 理论要点（公式 + 页码）

### 1.1 坐标系与符号：先做“翻译”，再逐字对照

**秦书约定（Ch7–Ch9 全文）【文献】**
- 导航系 n = 地理系 g：`x_n 东、y_n 北、z_n 天`（ENU），见 §9.9.1（p.323）明写“n_x 东、n_y 北、n_z 天”。
- 机体系 b：`x_b 右、y_b 前、z_b 上`（RFU），见 §9.9.1（p.323）。
- 姿态阵记法 `C^n_b`（b→n），误差角 φ 的分量次序为 (φ_E, φ_N, φ_U)。

**本项目约定**：n = NED（北东地）、b = FRD（前右下），姿态阵 `t_b2ned = C^n_b`。
**结论【推断】**：秦书与本项目是同一物理方程的两种坐标表述，二者相差一个正常正交变换（(N,E,D) ↔ (E,N,−U)）。因此：
- **矢量方程可以整体搬用**（叉乘在正常正交变换下协变）：如 (9.8.3)、(9.8.13)、(9.6.9)；
- **分量方程不能逐字搬用**（φ_E/φ_N/φ_U 与 f_E/f_N/f_U 的排布、±号会变），必须先换轴再对照；
- 页面上“符号看起来不一致”不等于实现错误——本笔记的对照一律先做该变换。

### 1.2 比力方程（惯导基本方程）【文献】

秦书 §7.4，`(7.4.6)`（p.189）：

```
dV_eT/dt|_T = f − (2ω_ie + ω_eT) × V_eT + g
```

分量形式 `(7.4.7)`（p.189）。三条要点（p.189）：
1. 加速度计测的是**比力 f**，不是加速度；只有扣掉“有害加速度”（哥氏 2ω_ie×V、向心 ω_eT×V、重力 g）后才能积分得地速；
2. 静基座 `V=0` 时 `f = −g`，这是加速度计调平（水平对准）的物理基础；
3. 重力 g 与引力 G 的关系 `G = g + a_c`（(7.2.13) p.178），g 随纬度/高度变化见 (7.2.14)(7.2.17)(7.2.18)（p.178）。

固件对应：`PropagateStateFromIncrements` 中 `coriolis_accel_mid = −(2ω_ie+ω_en)×v_prev`（`ekf_15_state.h:2324-2329`）、`gravity_ned_mid = (0,0,γ)`（`:2322-2323`）、速度积分 `:2357-2360`——与 (7.4.6) 一致（差分见 §2.1）。

### 1.3 NED 力学编排（速度/位置/地球模型）【文献】

**速度更新**：秦书 §9.6，`(9.6.9)`（p.298）

```
V^n_m = V^n_{m−1} + C^n_b(m−1)·ΔV_sf,m + ΔV_g/cor,m
ΔV_sf,m = ΔV_m + ΔV_rot,m + ΔV_scull,m            (9.6.19, p.299)
ΔV_rot,m = ½ Δθ_m × ΔV_m                          (9.6.17, p.298)
```

注意 **姿态阵取区间起始时刻 `C^n_b(m−1)`**，旋转效应 `½Δθ×ΔV` 正是把它“补”到区间平均姿态的一阶项。这是 P0-1 的判据。

**位置更新**：秦书 §9.7 走“位置矩阵 C_e^n + 旋转/涡卷补偿”路线（§9.7.1–9.7.3，p.304–311）。工程上等价且更常用的是直接积分 LLA 速率（本项目采用，见 `ComputeLlaRateFromTerms`，`ekf_15_state.h:2162-2173`）：

```
L̇ = V_N/(Rm+h),  λ̇ = V_E/((Rn+h)cosL),  ḣ = −V_D
```

与秦书 §7.2.3 主曲率半径、§8.1.1 速度/经纬度方程同源。位置用**速度中点**推进（`:2363-2367`）＝梯形积分，二阶精度。

**地球模型**：秦书 §7.2.4（p.178）
- 正常重力（WGS-84 Somigliana）`(7.2.17)`：`g(L) = 9.7803267714·(1+0.00193185138639 sin²L)/√(1−0.00669437999013 sin²L)`；
- 高度修正 `(7.2.18)`：`g(h) = g0·(Re/(Re+h))²`。

固件 `ComputeEarthModelTerms`（`:2120-2160`）用 `g0=9.780318` 的级数式 `g=g0(1+5.3024e-3 sin²L−5.898e-6 sin²2L)/(1+h/R̄)²`。与 (7.2.17) 的差：常数项差 8.7×10⁻⁶ m/s²（相对 ~9×10⁻⁷）、sin²2L 系数差 ≈1×10⁻⁶ m/s²【项目证据】。**结论：量级 ~10⁻⁵ m/s²，远小于加计零偏（~10⁻² m/s²），不是缺口。**

**高度通道**：秦书 §7.5（p.190–191），纯惯导高度通道特征方程 `s² − 2g0/R = 0`（(7.5.2) p.191）——**不稳定**。1×10⁻⁴ g 的加计零偏在 100 s/1000 s/3600 s 分别引起 5 m/630 m/87 381 m 高度误差（p.191 原文数值）。只有引入气压/无线电高度（回路反馈法或卡尔曼法）才能阻尼（p.191）。
**对本项目的意义【项目证据】**：`BFS_EKF_BARO_ALTITUDE_UPDATE` + 气压量测不是“可选优化”，而是垂直通道的**硬约束**；与 TEAM-BRIEF P4 判断一致。

### 1.6 捷联误差模型（ψ/φ 角）【文献】

**速度/位置误差**（§9.8.1，p.317–319）：
```
δV̇ⁿ = −φⁿ×fⁿ + Cⁿ_b([δK_A]+[δA])fᵇ + δVⁿ×(2ω_ie+ω_en) + Vⁿ×(2δω_ie+δω_en) + ∇ⁿ   (9.8.3, p.318)
δL̇ = δV_N/(Rm+h) − δh·V_N/(Rm+h)²                                                  (9.8.5a, p.319)
δλ̇ = δV_E secL/(Rn+h) + δL·V_E tanL secL/(Rn+h) − δh·V_E secL/(Rn+h)²              (9.8.5b, p.319)
δḣ = δV_U                                                                          (9.8.5c, p.319)
```
其中 φ 的定义：`C^{n'}_b = C^{n'}_n C^n_b = (I − φ×)C^n_b`（p.318），即**计算导航系相对真实导航系的失准角**（另见 p.320 的 `δQ = Q ⊗ Q̂*`）。

**姿态误差**（§9.8.2，p.320–322）：
```
φ̇ = φ×ω_in + δω_in − Cⁿ_b([δK_G]+[δG])ω_ibᵇ − εⁿ     (9.8.13, p.321)
```
分量式 (9.8.14a–c)（p.322）给出 `φ̇_E = φ_N(ω_ie sinL+…) − φ_U(ω_ie cosL+…) − δV_N/(Rm+h) + …`。
**关键判读**：φ 是**导航系**误差角；陀螺漂移 `εⁿ` 以负号进入（“捷联陀螺漂移使数学平台向漂移反方向偏”，p.317 原文）。

**与固件 δβᵇ 的换算【推断+项目证据】**：固件约定 `q_true = q_est ⊗ Exp(δβᵇ)`（右乘、体系；见 `ekf_15_state.h:2881` 注释与 `InjectErrorState` 的 `q←q⊗Exp(x₆)` `:2704-2705`，与 REF-170 `ch/05-ekf-15state.tex` 的 `eq:att-err-def` 同一定义），秦书约定 `Ĉ = (I−[φ]×)C_true`。于是
`(I−[φ]×) = C_est C_trueᵀ = Exp(−δβ) ⇒ φ = Cⁿ_b δβ`。
把 (9.8.3)(9.8.13) 换到体系，并对“本固件 δv = 真值−估计、秦书 δV = 计算值−真值”做一次符号取反，得
```
δβ̇ = −[ω_ibᵇ]× δβ − Cᵇ_n M δv − Cᵇ_n δω_ie(P) − x_bg (+ 刻度系数/安装误差项)
```
即 `F(β,β) = −[ω_ibᵇ]×`、`F(β,v) = −Cᵇ_n M`（`δω_en = M δv`，M=∂ω_en/∂v）、`F(β,b_g) = −I`。固件三块分别是 `:2385`、`:2457-2461`、`:2213`，逐项吻合。

### 1.7 初始对准（静基座/动基座）【文献】

**静基座解析粗对准**（§9.9.1，p.323–324）：由 `gᵇ=Cᵇ_n gⁿ`、`ω_ieᵇ=Cᵇ_n ω_ieⁿ`，静止时 `f̃ᵇ≈−gᵇ`、`ω̃_ibᵇ≈ω_ieᵇ`，得
```
T31=f̃x/g, T32=f̃y/g, T33=f̃z/g                                (9.9.3a–c, p.324)
T21=(ω̃ibx−T31 ω_ie sinL)/(ω_ie cosL), …                       (9.9.3d–f, p.324)
T11=T22T33−T23T32, …（正交性补全）                            (9.9.4a–c, p.324)
```
增量形式 (9.9.5a–f)（p.324）。原文明确：粗对准精度“数角分至数十角分”（p.324）。
**必要条件**：已知纬度 L、能测到 `ω_ie`（15.041°/h）、基座基本静止。

**参数辨识法精对准**（§9.9.2，p.328–336）：以速度误差为观测，把 `u = Aφ₀ − εⁿ` 当常参数辨识（(9.9.28)–(9.9.29)，p.328）；极限精度（p.334）：
```
δφ_E0 = ∇_N/g,  δφ_N0 = −∇_E/g,  δφ_U0 = ε_E/(ω_ie cosL)      (9.9.43c/9.9.44, p.334)
```
**这就是“无外部航向时方位精度由东向陀螺漂移决定”的定量边界**。原文还给出双位置测漂以提高方位精度（p.334–336，需转台）。

**卡尔曼滤波精对准**（§9.9.3，p.336–337）：状态 `[δV_E δV_N δV_U φ_E φ_N φ_U ε_Bx ε_By ε_Bz ∇x ∇y ∇z]`（p.336），以速度输出为量测（`Z=δV+V`，p.337）；静基座下 `f=(0,0,g)` 使 `δV̇_E=−gφ_N+…`、`δV̇_N=gφ_E+…`（(9.9.53a–c)，p.336）。

**动基座传递对准**（§9.10，p.338–345）：匹配量包括速度匹配、角速度匹配、姿态角/姿态阵/四元数匹配（§9.10.2，p.340 起），并建模机翼挠曲变形（§9.10.1）。**前提是有主惯导**——本项目没有，故不能照搬；但其“速度/姿态匹配”的思想正是双矢量航向的简化形态。

### 2.2 F 矩阵一致性核对（“全 F 矩阵与秦书是否一致”）

**结论：结构一致，差异仅来自状态定义与可忽略的高阶项。** 核对过程：

1. **约定换算**：秦 `φ = Cⁿ_b δβ`（§1.6 推导），且秦书 δ=计算值−真值、固件 δv=真值−估计（差一次取反）。因此 (9.8.3) 的 `−φ×f` 先展开为 `+C[f]×δβ`，再随 δ 的符号取反得到固件的 `−C[f]×δβ`（`:2383`）；`δω_in` 项同理得到 `−Cᵇ_nMδv`（`:2457-2461`）。逐块：
   - `F(v,β) = −Cⁿ_b[fᵇ]×` ↔ 固件 `:2383` `−t_b2ned_mid*Skew(ins_accel)` ✅
   - `F(β,v) = −Cᵇ_nM` ↔ 固件 `:2457-2461` `−t_b2ned_midᵀ·M` ✅（代码注释已写明 nav-frame 版本为 `+M`，与 (9.8.14) 的 φ̇_E 项 `−δV_N/(Rm+h)` 一致）
   - `F(β,β) = −[ω_ibᵇ]×` ↔ 固件 `:2385` ✅
   - `F(v,v)`：把 (9.8.3) 右端 `δV×(2ω_ie+ω_en)+V×(2δω_ie+δω_en)` 在 NED 下展开为 `−[a]× + [V]×M`（a=2ω_ie+ω_en），与固件 `:2412-2426` 的 9 项逐个相等（附录 B）。
   - `F(P,V)=I`、`F(β,b_g)=−I`、`F(v,b_a)=−C`、零偏 Markov 块：`:2212-2215` ✅
2. **缺失项及量级**：
   - `F(β,P)`（(9.8.14a) 的 `−δL ω_ie sinL`、`+δL(ω_ie cosL+…)`）：换到米制后 ≈ `ω_ie/R`≈1.1×10⁻¹¹ s⁻¹·m⁻¹、`V/(R²)`≈10⁻¹⁰ → **可忽略**；
   - `F(v,P)` 除重力梯度外的纬度/高度耦合：`2ω_ie·V` 项 ≈1.5×10⁻³ m/s² per rad ≈2.3×10⁻¹⁰ per m → **可忽略**；
   - 刻度系数/安装误差 `δK_A/δA/δK_G/δG`（(9.8.4)(9.8.14)）：**不在 15 状态**，属模型截断而非错误（见 §3 P2-3）。
3. **未核项**：`F(P,P)` 的米制形式与 (9.8.5) 的换算未逐项追溯（状态定义不同）；量级 ≤10⁻⁵ s⁻¹，列为待核实低优先。
4. **线性化点**：`t_b2ned_mid`、`vel_prev`、`mid_terms` 均为区间中点/起始点的混合；对一阶 EKF 可接受；唯一问题是它与 P0-1 的“双计”耦合（名义积分用了 mid，旋转项又补了一次 mid）。

### 2.3 三个特别问题的直接回答

#### Q1 现有双子样/圆锥/划摇是否还有正确性或精度缺口？

**正确性：有 1 处（P0-1，旋转效应重复计入），系数本身无错。**
- 圆锥：`2/3` 与 (9.3.30) p.274 完全一致，且是优化系数（表 9.4.1 p.284）——**不需要改**。
- 划摇：与 (9.6.25) p.301 恒等，`2/3` 也是划桨运动最优系数（p.303）——**不需要改**。
- 旋转效应：**错在“既用中点姿态又补半程旋转”**，误差 = `0.5Δθ×Δv`，量级 10⁻² m/s²（0.012–0.05，随 |ω×f|），见附录 A 数值证明。修复后残差降到 10⁻⁵ m/s² 量级。

**精度：有两个可量化缺口，但都被“是否真实存在高频角振动”卡住。**
- 缺口 A（块级双子样）：本机 h=5 ms、2 kHz 原始样被聚成两个 2.5 ms 块。按表 9.4.2（h=10 ms, a=1°）的 `(ωh)⁴` 标度折到 h=5 ms：15 Hz→0.30°/h、30 Hz→9.7°/h、50 Hz→125°/h【推断】。若实机 20–60 Hz 角振动幅值只有 0.1°，上述数字÷100（∝a²），即 0.003–1.3°/h，与陀螺零偏稳定性同量级——**可能不值得改**。三子样把标度变 `(ωh)⁶`，同条件下 50 Hz 从 125°/h 降到 ~1.5°/h【推断】。
- 缺口 B（单子样回退）：`use_two_sample_imu` 不成立时（缓冲溢出/样本<2，`navigation_task.cpp:794-807`）退回 `TimeUpdate`，只有 1/12 流式圆锥修正；表 9.4.3（p.284）显示单子样在 h=2.5 ms、50 Hz 下达 4059°/h。**建议先加退化计数监控（P2-2），而不是直接改算法。**
- 涡卷/位置旋转补偿：量级 ≲10⁻⁶ m/step（§3 P2-1 估算），**不是缺口**。

#### Q2 全 F 矩阵与秦永元误差模型是否一致？

**一致（在状态定义换算后），差异可枚举且可忽略。** 详见 §2.2。三条要点：
1. 秦书 φ 是**导航系**失准角（ENU），固件 δβ 是**体系**误差（NED/FRD）；`φ=Cⁿ_bδβ`，不是“符号错了”。
2. 15 状态内所有非零块（P-V、V-V、V-β、V-b_a、β-β、β-V、β-b_g、bias Markov、重力梯度）都能在 (9.8.3)/(9.8.13) 中找到对应项；**没有发现多余项或反向项**。
3. 缺的只有 `F(β,P)`、`F(v,P)` 的纬度高阶项（≤10⁻¹⁰ 量级）和刻度系数/安装误差状态（模型截断）。`F(P,P)` 因固件用米制位置状态、秦书用 LLA，不能逐项对，但量级 ≤10⁻⁵ s⁻¹，**不构成 P0/P1**。
4. 附带审计：量测 Jacobian 与 δβᵇ 自洽——姿态更新 `H=I`（残差是体轴对数映射 `:3104-3124`）、重力 `H=[d̂]×`（`:2891`，符合 `δd=[d̂]×δβ`）、航向 `H=Cᵇ_n e_z = t_b2ned(2,:)`（`:3197-3209`，H2 修复正确）。**没有“H 用 φ、状态用 δβ”的混用。**

#### Q3 无空速、有 IST8310 条件下初始对准的边界？

**结论：静基座自主方位对准不可行；必须外部航向（磁或 GNSS 双矢量）；水平对准可行且应做均值化；磁在完成标定/轴映射/干扰门控前不得启用。**

1. **静基座自对准边界【文献+推断】**：秦书 (9.9.43c)/(9.9.44)（p.334）`δφ_U0=ε_E/(ω_ie cosL)`。长沙 L≈28.2°，`ω_ie cosL≈13.25°/h`；要 δφ_U<1° 需 `ε_E<0.23°/h`。MEMS 级陀螺零偏稳定性典型 1–20°/h（ICM45686 数据手册未给 Allan 方差，需实测）→ 方位误差 4–90°。**故 (9.9.1)–(9.9.5) 的罗经粗对准在本机不可用**，只能借其“g 定水平”的部分。
2. **水平对准边界【文献】**：`δφ_E0=∇_N/g`（p.334）。∇=0.01 m/s² → 0.06°；∇=0.05 m/s² → 0.29°。单帧 accel 噪声 0.25 m/s²（`navigation_task.cpp` 噪声配置）对应 1.5°，**必须用静止窗口均值**（P1-2）。
3. **磁航向边界【推断】**：IST8310 可提供绝对航向，但 (a) 上板轴映射与椭球标定未验证（AGENTS/ TEAM-BRIEF 明示）；(b) 双电机大电流、机身软铁会使航向偏差随油门变化；(c) 需要倾角补偿（本项目巡航/过渡 x_b 接近竖直，Euler 倾角补偿会退化，应用四元数投影）。**在完成“地面 8 方位标定→系留→低功率悬停→自由飞”门控前不得馈入 EKF**（与 heading-mag 结论一致）。
4. **无空速的边界【项目证据】**：当前双矢量 = `atan2(v_E,v_N) − atan2(v_y_flow,v_x_flow)`（`navigation_task.cpp:486-497`），即“GNSS 航迹角 − 光流侧滑角”。无空速时侧滑/风无法解耦：光流失效（室外高空、无纹理）时，航向只剩 AHRS 相对积分（磁关闭），**纯悬停/低速航向不可观**（F2/F3 的根）。秦书 §9.10 的传递对准不能替代（无主惯导）。
5. **可执行边界表**：

| 阶段 | 可用航向源 | 精度/条件 | 依据 |
|---|---|---|---|
| 地面静置 | 无绝对源（伪磁/人工装订） | 任意；只能保证数值确定 | `navigation_task.cpp:810-819` |
| 地面滑行/转动机头 | GNSS 航迹角（无侧滑假设） | ~2–5°（风/侧滑未建模） | 【推断】 |
| 悬停 | 磁（若启用）或 AHRS 保持 | 磁 ±3–5°（标定后）；AHRS 随时间漂 | 【推断】 |

| 平飞（无光流） | 仅 AHRS/GNSS 航迹角 | 航向弱可观，遇风/侧滑有偏 | F2/F3 |

  2. `test_host/test_ekf_15state.cpp` + `run_all.sh` 全绿；

  4. 实机系留/低速滑行数据回放，比较纯惯导 10 s 速度漂移。
- **预期收益**：消除 10⁻² m/s² 级模型偏差；改善大机动下 NIS 一致性；为后续三子样升级提供干净基线。

### P0-2 把“初始航向”从伪磁语义改为可解释来源（含协方差）

- **动机**：当前航向初值来自体固常量伪磁 `(30,0,40)`（`navigation_task.cpp:819`），经 TiltCompass（`tilt_compass.h:34-63`）得到的 yaw 只保证数值确定，**不保证是真航向**；`P0(8,8)=0.2 rad` 是人为语义（`navigation_task.cpp:1010-1011`）。这使 EKF 的“初始航向误差 11.5°”与真实误差无关，且无 GNSS 速度/光流时航向不可观。
- **文献依据**：REF-120 §9.9.1 (9.9.1)–(9.9.5)（p.323–324，g+ω_ie 粗对准）；§9.9.2 (9.9.43c)/(9.9.44)（p.334，方位精度边界）；§9.10.2（p.340 起，速度/姿态匹配思想）。
- **实现方案**（分三档，均不动固件安全逻辑）：
  1. **短期（文档+参数语义）**：把 `init_heading_err_std_rad` 与实际来源绑定：伪磁→保持较大 σ（≥0.35 rad）且首帧双矢量前禁止航向辅助；磁可用→`σ=磁标定残差`；人工装订→`σ=装订精度`。在 `DBG`/AnoVars 增加 `nav_yaw_src` 枚举与 `nav_yaw_sigma`。
  2. **中期（对齐算法）**：用“TRIAD/四元数双矢量构造”替代 TiltCompass 的欧拉角公式（避免 (9.5.1) 的 1/cosθ 奇点）：由 `f` 定水平、由磁（或人工航向）定方位，直接构造 `Cᵇ_n` 再转四元数；静止窗口内对 f/ω 取均值（与 P1-2 合并）。
  3. **长期（磁接入）**：IST8310 磁航向作为 10 Hz 航向量测，带 |B|/倾角/与 GNSS 航迹一致性门控与自适应 R（设计归 heading-mag，本笔记只给理论边界）。
- **风险**：中。磁轴映射/标定错误时“有绝对航向”比“任意初值”更危险（会被滤波器当成真值）；必须上板门控（地面 8 方位→系留→低功率悬停→自由飞）。
- **验证**：地面转台/手持 8 方位磁航向误差（目标 <3°）；静止 10 min 的水平对准重复性；系留悬停 60 s 航向漂移；SC4 过渡航向 RMSE 与 GNSS 双矢量接受率；与 `heading-mag`/`sim-analyst` 的 A/B 结果对齐。
- **预期收益**：把“航向初值”从不可审计的常量变成可追溯量；为 F2/F3 的根治提供正确的初始条件与协方差。

### P1-1 三子样圆锥/划摇补偿（利用 2 kHz 原始子样）

- **动机**：块级双子样在高频圆锥下残差按 `(ωh)⁴` 增长（表 9.4.2 p.284）；本机 2 kHz IMU 数据已足够做 3 子样（每帧 10 样，3/3/4 分块），无需提高 ODR。
- **文献依据**：REF-120 (9.3.28)（p.273）、(9.4.15)（p.283）、表 9.4.1/9.4.2（p.284）、(9.6.26)/(9.6.27)（p.301）、9.6.3 节最优系数（p.303）；Ignagni 1990/1998（题录）。
- **实现方案**：在 `navigation_task.cpp:755-793` 的组装处把 10 个原始子样按累积时间三分（或按样本数 3/3/4），得到 `Δθ1..3, Δv1..3`；新增 `TimeUpdateThreeSample` 或扩展现有接口（保持 `PropagateStateFromIncrements` 为唯一内核）；姿态用 (9.4.15)，速度划摇用 (9.6.26) 的 9/20、27/40 形式；保留双子样路径作 fallback。IMU 样本数不足/抖动时退回双子样（带计数）。
- **风险**：中。分块不等长会破坏系数假设（需按时间比例验证）；CPU 增加 ~2 次叉积（可忽略）；姿态积分变化属行为红线，需重采回归基线。
- **验证**：合成圆锥/划桨信号（按 (9.4.1)–(9.4.2)、9.6.29 生成）对比理论漂移表；宿主回归；实机 2 kHz 静置/系留数据的角振动 PSD（先回答“有没有 20–100 Hz 角振动”）；若是，再上三子样；若否，**不做**。
- **预期收益**：50 Hz、a=1° 圆锥下从 ~125°/h 降到 ~1.5°/h（h=5 ms，【推断】）；实际收益取决于振动谱，可能接近零。

### P1-2 静基座预对准窗口（均值化 + 初始协方差标定）

- **动机**：`Initialize` 用**单帧** accel/gyro（`ekf_15_state.h:468-470`）做调平与零偏初值（`:603`、`:615-622`）。单帧 accel 噪声 0.25 m/s² → 水平误差 ~1.5°（1σ），虽与配置的 0.08 rad（4.6°）同量级，但重复性差；陀螺单帧零偏初值误差 ~0.086°/s（按配置噪声 0.0015 rad/s）。
- **文献依据**：REF-120 §9.9.1/§9.9.3（p.323–324、p.336–337，静基座对准以速度误差为量测、需要时间积累）；(9.9.43c)/(9.9.44)（p.334）。
- **实现方案**：利用现有静止检测器（`navigation_task.cpp:834-839`）在解锁前累积 5–10 s 的 accel/gyro 均值与方差；用均值做 TiltCompass/TRIAD 与零偏初值；用均值方差设置 `init_att_err_std_rad`、`init_gyro_bias_std_radps`；记录“预对准时长/样本数”到 AnoVars。
- **风险**：低。只改初始化数据来源与 P0，不改滤波结构；需防止“未静止就完成预对准”（用静止置信度门控，超时则退回单帧并放大 P0）。
- **验证**：地面重复上电 20 次，记录初始 roll/pitch/yaw 与 60 s 静止姿态漂移；对照单帧初始化；确认不触发 F1（误静止）。
- **预期收益**：水平初值误差从 ~1.5° 降到 ~0.03°（√N 平均）；陀螺零偏初值误差降一个量级；为静基座 ZUPT/StaticGyro 提供更好的起点。

### P1-3 误差约定回归锁（δβᵇ ↔ φⁿ 的文档 + 断言）

- **动机**：F2 的修复（P0 航向 π→0.2）说明“误差角定义/线性化点”在本项目历史上被混用；当前代码自洽，但没有测试锁防止未来改动引入混合约定。
- **文献依据**：Markley 2003（题录，姿态误差参数化：乘性/加性、体系/导航系）；REF-120 §9.8.2（p.320–322）。
- **实现方案**：在 `test_host` 增加断言：① `F(3,6)` 与 `−C[f]×` 的关系；② 小角度注入 `δβ=εe_i` 后，姿态阵变化与 `C·Exp(εe_i)` 一致；③ 重力/航向 H 与数值差分 Jacobian 一致（±1%）；④ 文档（`TandemVec-EKF-Report/ch/05-ekf-15state.tex` 或本笔记）明确“δβᵇ 右乘（true=est⊗Exp(δβ)）、φ=Cⁿ_bδβ、H 与 δv 的符号约定”。
- **风险**：极低（只加测试/文档）。
- **验证**：断言在 CI/`run_all.sh` 中运行；人为改一处符号应导致失败。
- **预期收益**：把“符号/坐标系一致性”变成可回归的属性，降低后续升级引入隐蔽偏差的概率。

### P2-1 位置旋转/涡卷补偿（结论：暂不做，给触发门槛）

- **文献依据**：REF-120 §9.7.3 (9.7.35)(9.7.39)(9.7.40)（p.309–311），§9.7.4（p.313）；§9.1（p.251）“涡卷最轻”。
- **量级估算【推断】**：涡卷项 ∝ `T⁴·(a×B)`（(9.7.40)）或按 `T·|Δθ×Δv|` 粗估；本机 T=5 ms、|Δθ|≤10⁻³ rad、|Δv|≤0.05 m/s → 每步 ≲10⁻⁶ m；随机符号、不构成常值漂移，分钟级可忽略。**触发条件**：若未来把导航周期放大到 ≥20 ms，或实测角振动 |Δθ|>10⁻² rad/周期，再评估。
- **实现方案（触发后）**：按 (9.7.40) 双子样形式加 `ΔR_scrl`，位置用 `Δp = v·T + ΔR` 更新；风险低但收益更低。
- **验证（若实现）**：合成 T=20 ms、|Δθ|=10⁻² rad 的圆锥/划桨运动，对比有无补偿的位置差；当前不实现，只在触发条件下做。

### P2-2 单子样回退路径监控（先度量，后决定）

- **动机**：`use_two_sample_imu=false` 时退回单子样（`navigation_task.cpp:794-807`、`ekf_15_state.h:2244-2259`），在高振动下精度差（表 9.4.3 p.284，50 Hz 单子样 4059°/h）。
- **方案**：在 AnoVars/DBG 增加 `nav_two_sample_ratio`、`nav_sample_count`、`nav_dt_fallback_count`；若回退率 >1%，再考虑“加长缓冲/降级三子样”。
- **验证**：1 h 静止 + 1 次飞行日志中统计回退率，与调度抖动（`imu_delta_overflow`）对齐；只观测，不改算法。
- **风险**：无（只加统计）。**收益**：把“算法退化”从隐性变成可观测。

### P2-3 刻度系数/安装误差：先标定，不扩维

- **文献依据**：REF-120 (9.8.4)(9.8.14)（p.318–322）含 `δK_A/δA/δK_G/δG`。
- **判断【推断】**：15 状态扩到 21 状态会引入可观性/一致性风险（弱可观状态与航向耦合），而 MEMS 的刻度系数误差可通过出厂/现场标定压到 0.1–1%；**建议用标定而非状态估计**。若未来要做，优先“参数辨识/离线 Allan+转台标定”，而不是 EKF 扩维。
- **验证**：转台/Allan 标定后的刻度系数残差 <0.1%；若标定后仍有随比力/角速率变化的系统偏差，再评估扩维。

## 4. 不建议 / 已足够的方案

| 方案 | 结论 | 理由 |
|---|---|---|
| 静基座自主方位对准（罗经法） | **不可行** | MEMS 陀螺零偏稳定性 1–20°/h ≫ ω_ie cosL≈13.25°/h；`δφ_U=ε_E/(ω_ie cosL)`（p.334）给出 4–90° 误差 |
| 动基座传递对准（§9.10） | **不可行** | 无主惯导；无挠曲模型；GNSS+光流双矢量已是可用替代 |
| 15→21 状态（刻度系数/安装误差） | **不建议（现阶段）** | 可观性/一致性风险 > 收益；先标定（P2-3） |
| 位置矩阵法/涡卷补偿 | **已足够** | 量级 <10⁻³ m/min（P2-1）；现有 LLA 直接积分 + 速度中点已二阶 |
| 四子样/更高阶圆锥 | **暂不建议** | 本机 2 kHz/5 ms 下每块仅 2–3 个原始样，四等分块困难；表 9.4.2（h=10 ms）50 Hz 下四子样 2.27°/h vs 三子样 92.97°/h，但需实测振动谱支撑；三子样已能覆盖 2 kHz 数据 |
| 用欧拉角做姿态更新/量测 | **不建议** | (9.5.1) 的 1/cosθ 奇点（p.284–285）；本项目过渡段 x_b 接近竖直 |
| 用伪磁向量做磁航向观测（给它小 R） | **禁止** | 体固常量不随姿态/磁北变化，不是观测；会系统性污染航向 |
| 收紧 GNSS R / 改 Q 加计 0.25 | **维持现状** | 与本笔记无关，但 TEAM-BRIEF 已证 R 地板不可收紧、Q 缺实机振动数据 |
| 地球重力模型再精细化 | **已足够** | 与 WGS-84 差 ~10⁻⁵ m/s²（§1.3） |
| 比力方程再加“中点哥氏” | **已足够** | 左端点 vs 中点差 ~10⁻⁶ m/s² |

## 5. 开放问题与需要实机数据验证的点

1. **角振动/线振动谱（最高优先）**：2 kHz 静置（电机不同转速）+ 系留 + 自由飞，输出 5–200 Hz 的角速度/比力 PSD。决定 P1-1（三子样）是否值得做、以及划摇残差的实际量级。
2. **ICM45686 零偏稳定性（Allan 方差）与温度特性**：决定静基座对准的可行边界、ZUPT/StaticGyro 门限、`gyro_markov_bias_std` 的物理依据。
3. **IST8310 上板轴映射与椭球标定残差**；电机电流/油门对 |B| 与航向的影响曲线（地面台架可测）。
4. **初始航向真值获取**：转台、GNSS 双天线、或全站仪；没有真值就无法验证 P0-2/P1-2 的收益。
5. **F2/F3 残余的实机证据**：现有仿真（SC4 18.7°）是闭环模型结果；需要用实机过渡段日志验证“航向踢动”是否仍存在、量级多少。
6. **`F(P,P)` 的米制形式**：若未来有人重写位置误差状态，需要重新对照 (9.8.5)；当前量级可忽略。
7. **气压高度的时间延迟/漂移建模**：秦书 §7.5 只给回路阻尼/KF 两种思路，未给气压计误差模型；与本项目 baro bias 状态设计相关（归 kf-theory/gnss-robust）。
8. **延迟回放与两子样/三子样的耦合**：快照保存的是原始增量（`ekf_15_state.h:748-753`），若升级三子样，回放结构需同步扩展。

## 附录 B：F(V,V) 与 (9.8.3) 的逐项对应

```
F(V,V) = [ V_D/Rm                 −2(ω_e sinL + V_E tanL/Rn)     V_N/Rm                ]
         [ 2ω_e sinL + V_E tanL/Rn   (V_D + V_N tanL)/Rn           2ω_e cosL + V_E/Rn    ]
         [ −2V_N/Rm                 −2(ω_e cosL + V_E/Rn)         0                     ]
```
