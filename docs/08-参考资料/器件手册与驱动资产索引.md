## 4. 查找顺序（强制）

1. **本索引** + `docs/08-参考资料/参考资料注册表.md`；
2. 器件驱动目录 `TandemVec_FCS/lib/<器件>/doc/` 下的官方 PDF/MinerU `.md`；
3. 已有核对/审计文档（§3）；
4. 仍缺才上网检索；下载的 PDF 必须走 MinerU（`mineru parse --tier standard`），
   产物入对应 `doc/` 或 `docs/08-参考资料/papers/REF-xxx/`，并更新本索引/注册表。
