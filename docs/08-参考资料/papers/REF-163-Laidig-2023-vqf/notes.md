## 1. 摘要（3-5 句）

1. 针对 MEMS IMU 的姿态估计，作者提出并系统评估了一种四元数姿态估计算法：核心思想是**在"近似惯性系"中对加速度测量做低通滤波**，从而把重力方向估计与线加速度干扰解耦（Abstract、§2）。
2. 算法包含三个扩展：陀螺零偏在线估计（§2.4）、磁干扰抑制（§2.5）、以及面向离线数据的非因果滤波变体（§2.6）。
3. 评估规模在该领域少见：使用多个公开数据集 + 8 种文献方法对比，**VQF 平均 RMSE 2.9°，对比方法 5.3°–16.7°**，且对每种运动特征、以及对陀螺零偏估计均占优（Abstract、§3）。
4. 全文使用**同一组固定参数**跨全部数据集，作者据此主张"开箱即用"的泛化性能（Abstract）。
5. 提供开源实现（§2.7），并给出可直接在生产中使用的算法流程（附录中各步伪代码）。

## 2. 与本项目的关系（5 条）

1. **磁干扰拒绝的现成范式**：§2.5 把磁辅助拆成三件事——**扰动检测**（磁感应强度模值与磁倾角相对参考量、需连续 0.5 s 才判"未受扰"）、**扰动拒绝**（≤60 s 的扰动直接关闭磁更新；更长时间则降低磁更新速度）、**新磁场接受**（扰动但均匀时，把当前模值/倾角设为新参考）。本项目 IST8310 已接驱动/椭球标定但**尚未馈入 EKF/Madgwick**（`kMagFeedMadgwick=false`），这段逻辑正是"上板启用前"应有的门控设计参考。
2. **与"伪磁场 `(30,0,40)`"的对照**：本项目 `mag_ut` 目前仍是固定伪磁场；VQF 的"参考量自适应更新 + 新磁场接受"机制说明：**磁参考不能写死**，否则室内外切换会造成持续航向偏差。这可作为磁辅助升级的验收判据之一。
3. **陀螺零偏在线估计**（§2.4）：本项目用 ESKF 的零偏状态 + 静止检测（`ins_static_detector.h`）估计零偏；VQF 是另一条路线（AHRS 内置偏置估计，与位置/速度解耦）。可作为"AHRS 降级路径（H1）"的独立校验工具，也便于离线对 IMU 数据做零偏标定对照（REF-166 Allan 方差）。
4. **相对 ESKF 的定位**：VQF 是 6D/9D 姿态估计器，**不含位置/速度/零偏组合导航状态**，不能替代 15 状态 ESKF；它的价值在于（a）作为姿态真值/参考用于评估 ESKF 姿态精度，（b）作为失锁/降级分支的备用 AHRS。
5. **计算量友好**：VQF 只涉及四元数运算与一阶滤波，无矩阵求逆，适合 H743 在 200 Hz 主循环外另起低频分支（如 100 Hz AHRS）并行运行。

## 3. 可借鉴点

- **磁扰动三段式门控**（检测/拒绝/接受）可直接移植为 `mag_health` 状态机；注意文中阈值（0.5 s 判定、60 s 全关断）是经验值，需按本项目 IST8310 噪声与飞行环境重标。
- **"在近似惯性系滤波加速度"**（§2.2–§2.3）：比直接对机体系加速度滤波更抗线加速度干扰；可作为 AHRS 分支的实现方式。
- **统一参数跨数据集评估**（§3.2）：提供了一种"不要按场景调参"的评估范式，与本项目"仿真参数 MODEL-DEFAULT，需实机标定"的现状互补——提醒：VQF 的固定参数是在多数据集上选出的，不能直接当成本机最优。
- **开源实现**（§2.7）：便于在 PC 上对固件记录的 IMU 数据复算姿态，做交叉验证。

## 4. 不适用 / 需谨慎外推

- **不是组合导航**：VQF 不含位置、速度、GNSS 更新、地球模型；不能用来回答 TEAM-BRIEF 的导航升级问题（F2/F3）。
- **磁融合前提是标定**：文中默认磁力计已完成硬铁/软铁标定；本项目 IST8310 的椭球标定与**上板轴映射尚未验证**（TEAM-BRIEF §2.2），在标定验证前直接照搬磁融合会引入系统航向偏差。
- **平台差异**：数据集多为人体运动/手持设备（低速、小角速率）；本项目悬停→过渡有机动角速率与持续振动，加速度"近似惯性系"假设会被削弱。
- **9D 模式的航向绝对性**：磁辅助给出的是磁航向，存在磁偏角与局部磁异常问题；本项目为室外长航时，需另做磁偏角修正（不在本文范围）。
- **性能数字不可直接引用为本项目指标**：2.9° RMSE 是跨数据集姿态 RMSE，不是本机指标。
