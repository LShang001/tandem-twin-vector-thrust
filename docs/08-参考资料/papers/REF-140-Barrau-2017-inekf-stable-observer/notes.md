## 1. 摘要（3-5 句）

1. 本文分析不变扩展卡尔曼滤波（IEKF）作为**李群上确定性非线性观测器**时的收敛性，对象是"连续时间动力学 + 离散观测"的系统（Abstract）。
2. 不变观测器的一个核心性质是：对左不变系统，**估计误差的演化是自治的（不依赖真实状态轨迹）**；本文首先把这个性质推广，刻画出满足该性质的更广系统类（§2，Theorem 1）。
3. 基于此，作者证明了该类系统上 IEKF 在**任意轨迹附近的局部稳定性**，条件与线性卡尔曼滤波的经典条件（Deyst–Price，Theorem 3）平行（§3.4，Theorem 4）。
4. 文中用一个简化车辆模型（§4）与一个惯导算例（§5，平地导航）演示；仿真显示在某些挑战性情形下 **EKF 会发散而同等调参的 IEKF 仍收敛**。
5. 关键机制是 §2.3 的"误差对数线性性质"（Theorem 2 / Proposition 2）：即使初始误差任意大，误差在李代数坐标下仍按线性方程演化。

## 2. 与本项目的关系（5 条）

1. **解释了 F2/F3 的"结构性"根源**：本项目标准 EKF 的 `F(v,β) = −C^n_b[f_b]×` 线性化建立在估计轨迹上，误差传播随轨迹变化；IEKF 因误差自治，增益/稳定性不随轨迹抖动。这为 TEAM-BRIEF 中"航向弱可观踢动→速度通道失锁"提供了"不是调参能解决，而是结构问题"的理论依据——但**该文是确定性观测器结论，不是随机一致性结论**，不能直接推出 NIS 门控行为。
2. **给出可检验的入组条件**：Theorem 1 列出三条等价条件，可用于判断"本项目的 INS 误差模型是否属于该文覆盖的系统类"。注意：固件含加计/陀螺零偏（12 维以上）、WGS-84 地球模型（`ComputeEarthModelTerms()`）、ZUPT/气压等非线性辅助，**严格说超出该文假设**，只能作为方向性依据。
3. **左不变 / 右不变观测的选择**：§3.1.1（left-invariant observations）与 §3.1.2（right-invariant observations）分别给出观测更新结构。GNSS 的位置/速度观测在标准 INS 群上有明确的"右不变"性质；这是评估 InEKF 改造路线时必须先做的建模选择（参见 REF-145 用左/右不变误差组合做联邦滤波）。
4. **稳定性 vs 一致性的分层**：本文证明的是"观测器能从初始误差恢复"（渐近稳定），本项目关心的 NIS 拒绝、协方差膨胀、重锚属于随机一致性/容错层。二者不能互相替代：即使用 InEKF，F3 的"6 维联合更新整体拒绝"仍需 FDI/序贯更新（见 REF-154 / REF-161）解决。
5. **升级路径代价评估**：InEKF 需要把状态重新定义到群（如 SE₂(3)）并改写误差/雅可比/注入，属于"结构性重写"；相比之下 OC-EKF/FEJ（REF-138）在现有 15 状态框架内即可获得近似的不变性效果。本文因此更适合作为**路线取舍的判据**，而不是第一优先落地项。

## 3. 可借鉴点

- **§3.2 增益整定（associated "noisy" system）**：给出把 Q/N（噪声协方差）与稳定性条件联系起来的系统性方法，比经验调 Q/R 更有依据；可作为本项目 `Q` 参数标定（REF-166 Allan 方差）之后的"结构侧"补充。
- **§3.3 的 IEKF 方程汇总**：一页内给出预测/更新/增益的完整式子，便于与现有 `TimeUpdateTwoSample()` / `MeasurementUpdateDetailed()` 做形式对照。
- **Theorem 4 的条件清单**（可控性/可观性型不等式，`α₁,α₂,β₁,β₂,δ₁,δ₂,δ₃,M`）：可作为"当前系统是否满足稳定观测器前提"的检查表，尤其第 (v) 条对应可观性累积——与 F2 航向弱可观直接相关。
- **误差自治性的工程用法**：在仿真里固定同一组 Q/R，扫描初始航向误差（如 P0 航向 π vs 0.2 rad），观察 EKF/IEKF 的收敛差异，可复现论文 §5 的对比实验思路（本项目已有 `TandemVec-EKF-Report/sim/opt/` 仿真框架）。

## 4. 不适用 / 需谨慎外推

- **平地导航假设**：§5 的惯导算例使用平地模型，无地球自转/运输率/WGS-84；本项目为长航时固定翼 VTOL，地球模型项不可忽略。
- **确定性观测器结论**：定理给出的是误差收敛（稳定性），**不给**协方差正确性、NIS 分布、野值鲁棒性；不能据此断言"换 InEKF 后 NIS 门控就不会误拒"。
- **局部稳定性**：Theorem 4 是局部结论（存在 ε>0），初始误差过大（例如本项目 P0 航向 π 的历史配置）不保证收敛；论文 §5 的仿真也显示需要合理初始协方差。
- **零偏处理**：论文主体系统不含零偏状态（或需扩展群维数），本项目 6 个零偏状态使群维数上升，雅可比复杂度显著增加，需评估 H743 上 200 Hz 的算力余量。
- **平台差异**：算例为车辆/简化惯导，不是 VTOL；过渡飞行的大俯仰（0–90°）与差速偏航带来的角速率量级需另行评估。
