## 1. 摘要（3-5 句）

1. 本文是对四元数与三维旋转相关概念/公式的"详尽复习"，目标是把它们正确用于误差状态卡尔曼滤波（ESKF）这类估计器（Abstract）。
2. 文中系统整理了旋转群及其李结构，四元数与旋转矩阵两种表述并行给出，并**特别关注旋转扰动的定义、导数与积分**（Abstract）。
3. 全文最终落到可工程实现的 ESKF 公式：连续/离散时间系统运动学、误差状态运动学、观测雅可比、误差注入与重置（§5–§6）。
4. 另给出"全局角度误差"版本的 ESKF（§7）作为对照，并用一张表逐项对比局部/全局误差在复合、积分、观测、注入、重置上的差异。
5. 附录覆盖 RK4 等数值积分（App A）、闭式积分（App B）、级数截断（App C）、转移矩阵（App D）与噪声/扰动积分（App E）。

## 2. 与本项目的关系（5 条）

1. **误差状态定义口径**：本项目 15 状态 ESKF 使用体系姿态误差 `δβ^b`（体轴、局部），对应本文 §5 的 *local angular error*（误差复合 `q_t = q ⊗ δq`）。§7 的 *global angular error*（`q_t = δq ⊗ q`）与固件口径不同，**引用时必须指明是 §5**，不能把 §7 的雅可比/重置式直接搬进固件。
2. **F 矩阵中"比力×姿态误差"项的符号与坐标系来源**：式 (238b) `δv̇ = −R[a_m−a_b]× δθ − Rδa_b + δg − R a_n` 正是本项目 `F(v,β) = −C^n_b[f_b]×` 这一项的通用原型。TEAM-BRIEF F2/F3 的"航向弱可观踢动"机理（大比力水平分量把 GNSS 速度噪声放大到航向）就建立在这一项上；可用 (238b) 逐项核对固件的 `FULL_F_MATRIX=1` 实现是否漏项/错号。
3. **误差注入与协方差重置**：§6.2 注入后必须做重置 `P ← G P Gᵀ`，局部误差的 `G = I − [½δθ̂]×`（§6.3.1）。本项目 `InjectErrorState()` 与 `StabilizeCovariance()` 是否执行同一阶重置，是"注入后一致性"的可核查点——若只归一化四元数而不重置 P，姿态块会引入一阶偏差。
4. **四元数 RK4 与保范投影**：本文 §4.6 讨论角速率的时间积分、App A.3 给 RK4 权系数、App A.4 给一般 RK 形式。项目采用"四元数 RK4 + 每阶段保范投影"，与本文思路一致；本文可用于核对 RK 各阶段是否都在流形上（先积分再投影 vs 用指数映射），这对 200 Hz、子步 ≤4 ms 的稳定性有直接影响。
5. **误差观测雅可比 `Q_δθ` 的显式形式**（局部/全局两版，对比表见 §7 末）可直接对照固件中"姿态量测更新"的 H 矩阵写法（`ApplyAttitudeUpdateDetailed()` / `ApplyGravityUpdateDetailed()` 等），是排查 H 矩阵符号错误的低成本参考。

## 3. 可借鉴点

- **局部/全局误差对照表**（§7 末表）：一张表列出 5 类操作（复合、欧拉积分、误差观测、注入、重置）在两种口径下的公式。用它给 `ekf_15_state.h` 做一次"口径自洽性检查"最省力。
- **误差注入后的重置雅可比**：`I − [½δθ̂]×`（局部）、`I + [½δθ̂]×`（全局）——实现只有几行，但能消除注入后的一阶协方差偏差。
- **噪声与扰动积分**（App E）：把连续噪声映射到离散 Q 的推导方式，可用于核对固件 `TimeUpdateTwoSample()` 里 Q 的离散化系数（是否含 `Δt²/2` 项）。
- **RK4 一般形式**（App A.4）：便于把"四元数专用 RK4"改写为通用 RK 框架，逐阶段做归一化。

## 4. 不适用 / 需谨慎外推

- **非同行评审教程**：引用时应写"技术报告/预印本"，不要当作经同行评议的结论；与 Markley 2003（REF-135）、秦永元 2020 Ch9 交叉核对后再落到固件。
- **无地球模型**：本文运动学是"平地 + 常重力"的简化模型（状态可含 `δg`），**不含地球自转角速度、运输率、WGS-84 曲率**。本项目 `ComputeEarthModelTerms()` 与 FULL_F_MATRIX 的完整 F 不能靠本文验证，必须回到 REF-120 Ch9 / REF-123。
- **IMU 噪声模型**：本文用连续白噪声 + 随机游走偏置；实机 MEMS 的量化、标度因数、振动引起的相关噪声不在此列（见 REF-166 Allan 方差）。
- **数值积分建议有前提**：App B 的闭式积分假设角速率在采样间隔内按多项式变化；高动态（本项目悬停→过渡机动）下需评估假设是否成立。
- **不要把 §7（全局误差）与本项目混用**：两套公式互换会得到"看起来能跑但协方差不对"的滤波器。
