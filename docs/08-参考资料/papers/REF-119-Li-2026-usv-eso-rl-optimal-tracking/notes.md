- **编号**：REF-119
- **作者**：Yinkun Li, Yawen Zhou, Yufeng Zhou（通讯，武汉科技大学）, Li Chai（通讯，浙江大学）

- **DOI**：https://doi.org/10.1016/j.jai.2025.09.002
- **关联项目模块**：FCS 速率环扰动补偿（τm 观测器扩展）/ 在线 B 矩阵分配 / TandemVec-Paper 鲁棒性对照引文

## 核心内容

1. **问题**：3-DOF 欠驱动 USV（只有 surge 力 τu 与 yaw 力矩 τr，sway 无执行器），假设 2 规定位置 (x,y) 与航向 ψ 可测而速度 (u,v,r) 不可测，要求跟踪期望轨迹。
2. **ESO**：把动力学改写为 ä = Θ + Bτ（式 5），Θ 为集总不确定项（C/D/g 全部吸收），B = J(ψ)M⁻¹。基础线性 ESO（式 6）增益条件 l₁l₂ > l₃（Routh–Hurwitz，定理 1 指数收敛到残差集）；改进版（式 11）用 sfal(·) 双模态非线性校正——小误差线性模式（增益 1/q^(1−h) 抑噪）、大误差高增益模式，切换点连续（韩京清 ADRC fal 函数变体）。
3. **控制结构**：两通道四级反步 + DSC。偏航：z₁ = ψ − ψd → 一阶滤波 → ẑ₂ → τrm；纵荡：z₃ = √(xe²+ye²) → cosψe 因子虚拟控制 → 一阶滤波 → ẑ₄ → τum。每级独立定义二次型代价 Jᵢ = ∫(zᵢ² + αᵢ²)，∂H/∂α = 0 得 α* = −½∂J*/∂z，再分解 ∂J*/∂z = 2βᵢzᵢ + Jᵢᵒ（已知线性部分 + NN 逼近部分）。ESO 估计 r̂/û 与集总项 x̂₃ᵢ 直接嵌入反步方程并前馈抵消（式 46/78 的 −x̂₃₃、−x̂₃₁cosψ − x̂₃₂sinψ 项）。
4. **Actor–Critic 更新**（每子系统一对 30 神经元 RBF 网络）：critic 律 ω̇̂c = −γc·B·ω̂c（B = ϑϑᵀ + dI）；actor 律 ω̇̂a = −B[γa(ω̂a − ω̂c) + γcω̂c]，证明 ω̂a → ω̂c 使 HJB 残差梯度（式 29）→ 0。定理 2：参数条件 (84)–(87) 下全部误差信号 SGUUB。
5. **仿真**：1:67 缩比船模（m=27kg，M=diag(25,24,3.7)，模型承袭 Wen et al. 2019 [40]），圆轨迹与 Lissajous 轨迹两场景，与全状态可测基准 RLOTC [34]（Chen/Dai/Dong, TNNLS 2024）对比：ESO 从起始即贴合状态；跟踪精度场景 1 略优、场景 2 距离误差略差但在可控范围；初期 surge 力与成本两场景互有高低；权值范数有界收敛。

### 可借鉴的方法
- **ESO 集总估计 + 前馈抵消模式**：把"电机滞后 + 气动未建模 + 电机不对称 + 差速反扭"全部集总为 Θ 在线估计并前馈抵消，是现有 τm 观测器（仅覆盖电机一阶滞后）的自然升级路径；每轴 3 个积分器 + 1 个非线性函数，200Hz 嵌入式算力完全可行。前提"输入增益 B 已知"本项目恰好满足（在线 B 矩阵）。
- **sfal 双模态增益调度**：小误差低增益（保护噪声裕度）/ 大误差高增益（快收敛），且切换点连续无抖振——与本项目"物理减震底座 + 数字滤波近全关 + 滞后硬预算 4.2°/6.9°"的约束场景互补，可作为观测器校正项的参考设计。
- **代价函数惩罚虚拟控制**（式 17，Remark 5）：在反步虚拟控制上加二次惩罚抑制执行器过度动作，与 SAS 限幅目标一致，可作为论文中"能量最优性"讨论的对照引文。

### 关键差异（不适用之处）
- **AC-RL 部分不可移植**：critic 是纯衰减律（无误差驱动项，见问题①），NN 项稳态自动归零，闭环等效于"线性 DSC 反步 + ESO 前馈"——本项目已有确定性架构 + 实机验证 + LMI 裕度，引入 4×30 神经元权值只增加复杂度与适航验证负担，无对应收益。
- **无执行器动态模型**：本文 τ 即时生效；本项目的 τm 瞬态失配（w0_actual/w0_cmd≈1.33，有效增益瞬态越震荡点）恰恰是本文 Θ 有界假设（‖Θ̇‖≤S）所回避的快瞬态问题。
- **SISO 解耦链不适用**：本文靠欠驱动 USV 的弱耦合假设逐通道设计；本项目执行器轴映射耦合（上摆=滚转/下摆=俯仰/差速=偏航 + 非对角耦合）必须走 B 矩阵分配路线。

## 精读发现（逐式核对后的问题清单）

以下问题基于 MinerU 转换稿（paper.md）与 pdfplumber 双通道交叉核对得出，公式编号以原文为准：

1. **critic 更新律是纯衰减，无数据驱动项**（式 26/48/62/79）：ω̇̂c = −γc(ϑϑᵀ+dI)ω̂c ⪯ −γc·d·ω̂c，与跟踪误差和 HJB 残差无关，ω̂c 单调衰减到零；actor 又收敛到 critic（式 31），故 NN 项 −½ω̂aᵀϑ 稳态归零。闭环稳态等效于线性项 −βᵢzᵢ + ESO 前馈。式 (29) 显示 HJB 残差梯度 = ½ϑϑᵀ(ω̂a − ω̂c)，即"解 HJB"是**按构造**满足（控制律代入自身值函数估计），不是从数据学习真值；全文无持续激励（PE）条件、无收敛到真值 ω* 的论证（Lyapunov 只给有界性，φ 中的 ω*ᵀBω* 为常数余项）。**"强化学习/最优控制"的实质是 ADRC 式 DSC 反步 + 瞬态正则化网络**。
2. **仿真参数系统性违反定理 2 条件**：(84)–(87) 要求 2γc > γa，而仿真四通道全部反向（γc1=1 vs γa1=8；2.7 vs 10；3 vs 12；2.7 vs 10）；要求 β2 > 3/4+1/(2c₁)=5.75（c₁=0.1），仿真 β2=1.2；要求 β4 > 1+1/(2c₂)=6，仿真 β4=1.2。仿真仍稳定说明充分条件过于保守——**定理对实际设计无指导力，作者自己也不用它**。
3. **定理陈述与证明步骤自相矛盾**：(51)–(52) 推导要求 β₂ > 5/4 + 1/(2c₁)（ℓ₂₁ > 0），定理 2 的 (85) 却写 β₂ > 3/4 + 1/(2c₁)。
4. **制导几何语义存疑**：ψd = atan2(yₑ, xₑ) 且 xₑ = x − x_d（式 14 后定义）——该方位向量从**参考点指向船**，yaw 环驱动 ψ → ψd 意味着船首对准"背离参考点"方向，稳态需负 surge（倒车）逼近目标；若 xₑ 实为 x_d − x（符号笔误）则退化为标准 LOS 前向追踪。文中未澄清，仿真图无法判别。
5. **式 (16) 隐式丢弃 ė₁₃**：由 ESO 第一式 ψ̇ = r̂ + k₁₃e₁₃ + ė₁₃，原文直接写 ż₁ = r̂ − ψ̇d + k₁₃e₁₃，ė₁₃（有界趋零项）未说明即丢弃。
6. **印刷/编辑错误若干**：式 (12) 参数约束印作 "0 < γ < (1−h)/γ"（自指，疑为 0 < γ < 1−h）；Remark 1 的指数表达式 h+γ(|e|−q) 与式 (12) 的 h−1+γ(|e|−q) 不一致；定理 1 残差集用 λmin(P₁) 而证明用 P_o；式 (89)–(90) 丢负号（应为 V̇ ≤ −ℓV + φ、e^{−ℓt}）；仿真 D 矩阵系数 "41|bv|" 疑为 4.1。
7. **ESO 增益不符合自家极点配置公式**：式 (13) k₁=3ℏ、k₂=3ℏ²/F、k₃=ℏ³/F，而仿真 (k₁,k₂,k₃)=(5,8,10) 无 (∏,F) 同时满足（由 k₁ 得 ℏ≈1.67，由 k₃ 得 ℏ≈2.18）。
8. **抗扰卖点未验证**：仿真无海流/波浪/风/参数摄动注入，集总项 Θ 仅含标称模型项；"robust disturbance rejection"停留在 ESO 结构层面。亦无与 LESO/ADRC 基准的对比（仅对比全状态 RLOTC）。
9. **逐级最优 ≠ 全局最优**：四子系统各自 HJB 是 optimized backstepping 一族（Wen et al. [40] 谱系）的结构性局限，"最优"主张弱于本项目的 LMI 全局裕度口径。

## 关键摘录

> 式 (26)：$\dot{\hat{\omega}}_{c1} = -\gamma_{c1} \mathcal{B}_1 \hat{\omega}_{c1}$，其中 $\mathcal{B}_1 = \vartheta_1(z_1)\vartheta_1^T(z_1) + d_1 I_w$ —— critic 无误差驱动项，纯衰减（问题①的根源）。

> 式 (29)：$\frac{\partial H_1(\cdot)}{\partial \hat{\omega}_{a1}} = \frac{1}{2}\vartheta_1\vartheta_1^T(\hat{\omega}_{a1} - \hat{\omega}_{c1})$ —— HJB 残差梯度仅由 actor-critic 差构成，"解 HJB"是构造性的，与真值函数无关。

> 式 (46)：$\hat{\tau}_{rm} = -\beta_2\hat{z}_2 - \hat{x}_{33} - \frac{1}{2}\hat{\omega}_{a2}^T\vartheta_2(\hat{z}_2)$ —— 真正的抗扰主力是 ESO 集总项前馈 −x̂₃₃（ADRC 精髓），NN 项是瞬态装饰。

> Remark 12：β₃ > 9/(4cos²ψe) 在 |ψe|=90° 奇异，作者以"物理系统惯性不会持续正交"辩护——回避而非解决，且该条件含状态量使参数整定与运行状态耦合。

## 复现验证（2026-08-16，详见 reproduction.md）

独立仿真复现（`sim/reproduce.py`，论文参数忠实实现）实证了精读发现：

- **发现 ① 实证**：critic/actor 范数单调衰减且末态完全重合（≤0.05），稳态 NN 项 ≈ 0，闭环稳态 = 线性 DSC 反步 + ESO 前馈 ✓
- **发现 ④ 实证**：u 稳态 ≈ −1.0 m/s（船尾朝前倒退追踪），论文 Fig.3 同为负——印刷符号即其实际实现，非笔误 ✓
- **发现 ⑨ 加重**：z₃ 在任何忠实配置下都不收敛到 0（稳态为绕参考点的有界轨道，半径≈1.4 m）；平衡分析表明 z₁≈0 且 z₃≈1.5 的滑行不是该控制律的平衡点（αu=−β₃z₃≈−8.25 m/s ≫ 匹配参考所需 −0.94）。论文自己的 Fig.5 平台也在 1–2 m——"最优跟踪"实为有界轨道误差 ≤2 m
- **新增**：稳态轨道模态对 D 矩阵印刷损坏敏感（D22=4.1 vs 41 各吻合论文一部分），精确模态欠定；全状态精确 Θ 抵消版瞬态反而剧烈得多（τu 峰值大 81 倍），ESO 估计滞后起平滑作用
