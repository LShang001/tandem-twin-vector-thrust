## REF-120 秦永元《惯性导航（第三版）》

- 版本：科学出版社，2020.11，第 3 版，ISBN 978-7-03-066408-2。
- 原始 PDF：`book.pdf`（388 页；本地，不跟踪）。
- 已转换范围：**全文 PDF 1–388 页**（part0=1–169，part1=170–280，part2=281–388）；
  导航算法重点为第三篇 Ch7–Ch10（PDF 170–388）。
- 页码映射：**印刷页 + 8 = PDF 页**（例：Ch7 p.170 → PDF 178）。
- 文件：
  - `book.md`：合并全文（Ch1–Ch10 + 前置页，约 100 万字符）
  - `chapters/ch1-绪论.md`、`ch2-陀螺仪.md`、`ch3-摆式加速度计.md`、
    `ch4-陀螺稳定平台工作原理.md`、`ch5-三轴陀螺稳定平台.md`、`ch6-双轴陀螺稳定平台.md`
  - `chapters/ch7-惯导基本关系.md`（§7.1–7.5）
  - `chapters/ch8-平台式惯导系统.md`（§8.1–8.5）
  - `chapters/ch9-捷联式惯导系统.md`（§9.1–9.11；**本项目最重要**）
  - `chapters/ch10-极区惯性导航.md`（§10.1–10.3，本机不涉及）
  - `notes.md`：书籍级笔记（版本、章节导览、精读范围、关键结论）
  - `ocr-errata.md`：OCR 校订记录（对照 PDF 原页；覆盖范围/残余风险）
  - `part0/`、`part1/`、`part2/`：MinerU 原始分卷输出
- 质量：MinerU v4 VLM；全文约 1800+ 公式块；表格为 HTML 形式，需要时用
  `mineru_postprocess.py` 展平。
- 阅读重点：Ch7.4 比力方程、Ch7.5 高度通道；Ch8.3 初始对准（平台式对照）；
  Ch9.2–9.4 四元数/旋转矢量/圆锥；Ch9.6–9.7 划摇/涡卷；Ch9.8 误差模型；
  Ch9.9–9.10 自对准/传递对准；Ch9.11 余度/故障检测。Ch2–Ch6 为惯性仪表/稳定平台，
  本项目只作背景，不进入导航算法推导。

## 引用约定

- 书籍引用到**章节 + 印刷页**，例如 `[REF-120 §9.6 (9.6.19) p.298]`、
  `[REF-121 §7.3.1 p.259]`。
- 代码引用到 `文件:行号 函数名`，例如
  `ekf_15_state.h:2284 PropagateStateFromIncrements()`。
- 转换文本的 OCR 可能有个别错字/公式上下标错误；**引用前以 PDF 原页复核**（尤其是
  符号、下标、正负号）。`notes/01`/`02`/`03` 作者已用目录锚点交叉校验页码；仍建议
  关键公式回看 PDF。
