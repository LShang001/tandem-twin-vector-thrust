## 精读范围与结论

- 深读：Ch2、Ch3.3/3.5/3.6/3.7/3.8/3.10、Ch4、Ch6.2–6.4、Ch7.2–7.5、Ch8.2–8.5。
  笔记见 `../../notes/02-卡尔曼滤波理论.md`（535 行）、`03-组合导航与鲁棒性.md`（521 行）、
  `04-航向与磁辅助.md`（648 行）。
- 关键结论：
  1. 现有 ESKF 五方程/Joseph/序贯结构正确；缺的是**故障可分离性**——6 维联合 NIS
     把速度故障判成整帧坏，位置陪葬。最小改动=联合门常开、拒绝后 3+3 子集 χ² +
     速度软重锚（Ch3.3、Ch7.3）。
  2. F2/F3 不是数值问题：Ch4 定理 4.5 的“完全随机可检测”在航向子空间不成立；
     P 稳定化对 F2/F3 无责，但掩盖“P 是否统计正确”（无 NEES/SNIS 监控）。
  3. UD/平方根是“构造保证 PSD”，当前 Joseph+投影是“事后修”；无数值失效前不重写。
  4. 联邦滤波/协方差交叉不适合单 IMU+PVT 架构；PVT-only 不能落地经典 RAIM，
     只能做 PVT 域 FDI；CUSUM/GLR 与单历元 NIS 互补（Ch7.3/7.5）。
  5. Ch8.2.3 明确“阻尼必须外来信息”；这支持 ZUPT 外部参照门控（P0-3）。
