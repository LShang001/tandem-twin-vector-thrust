## 结论

单涵道 + X 型四燃气舵机型（`[env:SingleEdf4Vane]`）首次自由飞成功，飞行稳定，
**出厂默认控制参数无需调整**。质量/推力/舵效/惯量仍是 MODEL-DEFAULT（未称重未实测）。

## 前序工作（当天闭环）

1. 从外部工程 `Universal-EDF` 移植机型：四舵 PA0–PA3、推进器 PC8、使能 PE6；3×4 分配矩阵。
2. 舵面映射反复三轮定案：手动直通与自动修正**共用同一张源机型矩阵**；
   `yaw` 正方向与通道约定相反（机型知识，收在 allocator 里）。
3. 速率环最终定**角加速度域**（输出目标 α [deg/s²]，kp=57.3 = 源机型舵角域 0.25 的等价换算；
   用户只设机械摆角 `sedf.ctrl_vane_deg`，`applyFlightCtrlParams()` 内部换算成输出限幅）——
   参数表上的限幅因此就是"舵面最多偏多少度"，与源机型口径一致。
4. 在线调参：匿名助手 2.0.11 对齐（0xE3 DEV_NAME 变长、0xE2 NAME 定长 20、0xE0 个数 u16 3 字节）；
   USB 调试口同时承载 AnoCom 上行（`BFS_ANOCOM_ON_USB`）。
5. 解锁门按用户要求放宽：去掉加速度/倾角限制，仅保留"EKF 已收敛 + 导航已初始化"；
   一旦本次上电解锁过，空中误上锁可无条件重新解锁。
