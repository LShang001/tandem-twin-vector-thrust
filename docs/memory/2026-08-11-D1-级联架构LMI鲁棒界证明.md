## 要点

### 1. 单通道 LMI 框架已建立（cvxpy + CLARABEL + Petersen 引理）
- 状态 [ε, ω]，标称闭环 A₀ = [[0,½],[-KωKp,-Kω]]（论文符号 K_p=2·vtolAttKp、K_ω/I=btrueK）。
- 标称 Lyapunov LMI（P≻0, A₀ᵀP+PA₀≺0）feasible：P={0.238,0.016;0.016,0.004}，补上 ch/15:510 开放问题(i)。
- 范数有界不确定 A(δ)=A₀+BΔ·δ·CΔ（δ 集总 B 矩阵误差 - 惯量误差，一阶展开）。
- Petersen 引理块 LMI（eq:cascade_petersen），二分 γ 求 γ̄。补上开放问题(ii)。
- 工具栈：cvxpy 1.8.2 + CLARABEL（Rust 后端，开源，无需 MOSEK）；sympy 符号推导自检。

### 2. 核心结论：γ̄=0.968，级联架构对内环增益缩放极其鲁棒
- 仿真增益（vtolAttKp=2.5, btrueK=60）下 γ̄=0.968 ⟹ 内环有效增益可偏差 ~97% 仍二次稳定。
- 真实失稳边界 δ*=-1.000（内环增益归零，系统开环临界），LMI 保守度 0.968（近紧，仅 3.2%）。
- γ̄ 内 5000 样本蒙特卡洛 0% 失稳（LMI 充分性验证通过）；特征值 ⟺ 时域（matrix exponential）全一致。
- 实机对照：att_roll/pitch(2.8)→γ̄=0.965；att_yaw(5.0, τm 修复后)→γ̄=0.943，都在鲁棒域。

### 3. ★ 指导后续：静态增益鲁棒性已解决，真正风险源是瞬态失配 + 交叉耦合
- γ̄≈0.97 证明**静态、对角的增益缩放不是该架构的瓶颈**——这解释实机 kQ 两轮迭代（0.030→0.025→0.027）都稳定。
- 单通道模型**不覆盖**实机 yaw 的 τm 瞬态失配（差速分配器用指令油门、力矩用实际转速导致的**时变**工作点失配）。
- 也不覆盖多通道交叉耦合（B_true 非对角 Δ）——需复合 Lyapunov + Arcak 交叉项界（论文 §10.6 remark 已标注为扩展方向）。
- **后续优先级**：A2（ADRC-ESO 前馈对消瞬态失配）直接针对 D1 暴露的风险；C1（闭环辨识）提供更准标称 I 给 LMI 重解。

### 4. D1 的诚实边界（写进论文 remark，勿超范围宣称）
- 单通道（B_true 对角化假设）、小角度线性化（覆盖悬停小误差邻域，大角度转换需 ch/12 非线性 Lyapunov）。
