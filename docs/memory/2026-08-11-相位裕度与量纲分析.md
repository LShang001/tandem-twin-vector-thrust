## 要点

### 1. 迁移前：固件 kp 曾是混单位增益（历史问题）
- 固件 `flight_control.cpp:992`：`current_omega_dps = current_omega_rps × RAD_TO_DEG`（PID 输入 deg/s）
- `PositionPID.h:253`：`pOut = kp·error`，**无任何单位转换**
- `flight_control.cpp:1310-1312`：`M = I·alpha`，无转换（alpha 注释 rad/s²）
- ⟹ **rate.kp=0.28 是 (rad/s²)/(deg/s)，等效 rad 域带宽 = 0.28×180/π ≈ 16.04 rad/s**（不是 0.28！）
- 同理外环 att.kp=2.8（度→度）带宽就是 2.8 rad/s；分离比 16/2.8=5.7
- **历史教训：迁移前的固件 kp 数字不等于物理带宽，必须乘 180/pi。迁移后
  `kp` 已直接采用 `s^-1`，不得再次换算。**

### 2. 三方带宽统一 + 差速通道 PM 临界
- 固件 16.04 / 仿真 btrueK=60 / 旧论文 K_ω/I=364（Hermes 已废止）
- 差速通道 PM（含 τm=0.28s 执行器 + 陀螺滤波 τf=9.8ms）：
  K=16→PM=22.5°（偏紧）；**K=60→PM=6.0°（落实机经验 [4.2°,6.9°] 带内，吻合最佳）**；K=364→PM=-13.1°（必失稳）
- **旧论文 364 假设下差速通道必然失稳 → 支持 Hermes 量纲修正方向**
- 摆角通道（舵机快，无 τm）：PM=62.5° 充足 → 抖振只在 yaw 的结构性解释

### 3. τm 观测器补偿量化（抖油门震荡的频域解释）
- 无观测器：油门释放 → w0 失配（w_used=指令、力矩=实际）→ 有效增益 ×(w_ratio)² 瞬态到 ~166
  → 差速 PM 从 6° 崩塌到 **-4.7°**，失稳窗口 **~200ms**（memory 实测 ~160ms，同量级 ✓）
- 观测器修复：w_est≈w_act → 增益恒定 60 → PM 恒 6° → **补偿 +10.7°**
- 这坐实 memory 三层定位的"瞬态失配才是根因"——静态 K=60 PM=6° 尚稳（D1 γ̄≈0.97），瞬态 K→106 必失稳

### 4. α×τm 二维边界（实机 4.2°/6.9° 的完整参数图）
- 174 个 (α,τm) 组合落 PM∈[4.2°,6.9°] 边界带（CSV: scripts/figs/pm_2d_boundary.csv）
- **α=0.4 时 τm 容忍范围 [0.23, 0.50]s**（实际 0.28 在带内 ✓）
- 标称点灵敏度：ΔPM/Δα(+0.2)=+3.5° vs ΔPM/Δτm(+0.1s)=-0.9° → **滤波 α 灵敏度更高，但 τm 决定 PM 绝对水平**

### 5. D1 结论稳健性（γ̄ 对带宽不敏感）
- 固件等效 γ̄=0.897 / 仿真 0.968 / 旧论文 0.866 → 全部 ≈0.9
- "静态增益缩放非瓶颈"在任意量纲下成立 → D1 不会因 Hermes 量纲修正翻车
