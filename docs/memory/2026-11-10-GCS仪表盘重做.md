# GCS 仪表盘重做：为什么"丑"，以及怎么验

2026-11-10。用户原话：「仪表盘太丑了，而且还是之前的纵列机型的，继续优化改进重做」。
一句话里两个抱怨，查下来同一个根因。

## 1. 「丑」多半不是配色问题，是**大面积空数据**

面板里堆的全是 AnoCom 纵列机型专有帧（0xF1 摆角、DETA100 电调、0xF2 变量）：
换成 MAVLink 链路后 `tvc_*`/`deta100_online`/`vars_*` 全没有，于是满屏 `--`、
8 行空 RC 条、空仪表。**先数一屏有几个 `--`，再谈配色。** 换协议/换机型后
一定要重扫一遍面板里哪些字段是本机型才有的。

判据：字段不存在就**整行隐藏 + 一句人话**（"当前链路不上报执行器状态"），
不要留"永远 --"的假行。真实链路（ArduPilot/PX4）持续上报 HEARTBEAT、
SYS_STATUS、VFR_HUD；演示数据缺这几帧，对应 UI 就等于从未被验证过。

## 2. 同一物理量在两协议下**字段名和单位都不同**，共用一张表必错

| 逻辑量 | AnoCom | MAVLink | 坑 |
|---|---|---|---|
| 飞行模式 | 0–3 自定义 | ArduPilot custom_mode 0–25 | 共表会把 GUIDED 显示成 AUTO_ALT |
| 油门 | `ctrl_thr_pct` | `throttle_pct`（VFR_HUD） | 共表 → 油门永远 `--` |
| 精度 | `gps_pdop`（无量纲） | `gps_eph`（m） | 共表 → 把 0.9 m 说成 PDOP 0.9 |
| 解锁 | `unlocked` | `armed` | |
| 位置 | `gps_lat/gps_lon` | `lat_deg/lon_deg` | |

做法：取值统一走 `pick(s, ['ctrl_thr_pct','throttle_pct'])` 别名表；
模式名与精度项**按协议分表/分标签**，不合并。

## 3. ★ 几何是否正确，**只认像素测量，不认缩略图**

本轮两次把正确渲染判成 bug：先看 1920 缩放图以为地平线倾斜、又看 1024 图
以为 `.att-axis` 与 track 读数打架。实测后全部自洽：

```
roll=+8.0° → 天地分界左右高度差 -17px（理论 tan(8°)*120 = 17）
roll=-0.7° → +2px ；roll=0.0° → 0px
att 三轴读数 与 track「实际」值逐次相同
```

量法（Playwright `evaluate` 里读 `getImageData`，沿两列自上而下找天地分界）：

```js
const col = (x) => { for (let y = cy-80; y < cy+80; y++) {
  const p = ctx.getImageData(x*dpr, y*dpr, 1, 1).data;
  if (p[0] > 45 && p[0] > p[2]) return y; } return null; };
const tiltPx = col(cx+60) - col(cx-60);   // 与 tan(roll)·60 对比
```

同理，**面板内大片空白也要量**：`面板底边 − 最后一个可见子元素底边`。
本轮 hud 面板空 200px 就是这样抓出来的（缩略图只看得出"有点空"）。
该判据已进 `tools/tablet_check.py`（> 40px 判失败），当前 7 块面板全部 1px。

## 4. `drawAttitude` 横滚指针：数学角 ≠ 屏幕角

```js
// 错：canvas 的 cos/sin 以 3 点钟为 0，roll=0 时顶点落在正右方、
//     底边朝左张开 166° → 画出半径 0.95R 的巨型三角盖住半个地平线
const rp = -(rollDeg) * Math.PI / 180;
// 对：基准在 12 点钟，且指针应是小三角
const rp = -Math.PI / 2 - (rollDeg) * Math.PI / 180;
```

画任何"指向某方向的指针"前先确认：数学角 0° 在 3 点钟，屏幕"正上方"是 −90°。

## 5. 内联 `style.display = ''` 会回落 CSS，不是"恢复显示"

```js
$('rcNoData').style.display = hasRc ? 'none' : '';      // ✗ CSS 里 .rc-nodata{display:none} → 永远不显示
$('rcNoData').style.display = hasRc ? 'none' : 'block'; // ✓ 显式给值
```

`''` 的语义是"清除内联样式"，随后由 CSS 规则决定；若 CSS 写着 `display:none`，
就永远出不来。用类切换（`.no-data` 前缀选择器）比内联更稳。
