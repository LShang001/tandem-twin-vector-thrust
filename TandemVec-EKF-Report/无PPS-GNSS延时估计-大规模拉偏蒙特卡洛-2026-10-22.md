# 无 PPS GNSS 延时估计：大规模拉偏与蒙特卡洛

> 日期：2026-10-22
> 对象：`test_host/test_gnss_delay_batch.cpp` 联合位置+速度批处理估计
> 默认固件参数未修改。

## 1. 结论

两独立 seed、各 2000 例；**加入 5 ms 网格抛物线亚网格插值后**：

| 指标 | 结果 |
|---|---|
| 总案例 | 4000 |
| ≤20 ms 通过 | **3999 / 4000 = 99.975%** |
| 平均绝对误差 | **2.59 ms** |
| P50 | 1.67–1.71 ms |
| P90 | 6.0–6.2 ms |
| P95 | 8.2–8.4 ms |
| P99 | 13.0–13.3 ms |
| 最大绝对误差 | **21.2 ms** |
| 唯一失败案例 | 68 ms 延时 / 0.60 m GNSS / 0.15 m/s / 0.61 m/s² 零偏 / 34 m/s / 3D 机动 |

结论：

- 3D 机动 + 宽范围速度/噪声/零偏/失锁下，误差主体在 10 ms 内；
- 20 ms 门限通过率 99.95%；
- 边界失败集中在**高延时 + 高噪声 + 高速度 + 大零偏 + 3D 机动**；
- 不能用单次估计直接长期替换 15 ms，仍需门控/滞回/回退。

- 野值剔除门限：位置 >50 m 或速度 >20 m/s；
- 10% 野值下仍全部有效；
- 该结果是模块级（IMU 参考），不是固件导航输出参考。

## 4.2 抛物线亚网格插值

原实现候选 `tau` 为 5 ms 网格，存在量化/偏置。对最优点及左右邻点做抛物线插值：

```text
delta = 0.5*(c_minus - c_plus) / (c_minus - 2*c0 + c_plus)
tau* = tau_best + clamp(delta*5ms, ±5ms)
```

对比：

| 指标 | 5 ms 网格 | 抛物线插值 |
|---|---|---|
| 通过率 | 3998/4000 | **3999/4000** |
| 平均绝对误差 | 2.92 ms | **2.59 ms** |
| P50 | 2.1 ms | **1.67–1.71 ms** |
| P95 | 8.5 ms | **8.2–8.4 ms** |
| 最大 | 23.0 ms | **21.2 ms** |

结论：亚网格插值降低量化偏置约 11%，且不增加候选网格数量；已同步到 `InsGnssDelayAutoEstimator`。

## 4.4 闭环估计→补偿验证（修正延迟模型后）

修正 `test_ekf_highspeed_realistic`：

- GNSS 值取 `truth(t-tau)`；
- 批处理时间戳用投递时刻；
- EKF 用估计 tau 作为 `measurement_age`。

结果（30/50 m/s，50/100 ms，maneuver 1/2）：

| 速度 | 延时 | 估计 tau | 位置改善 |
|---|---|---|---|
| 30 | 50 ms | 49.6 ms | 86.1% |
| 50 | 50 ms | 49.4 ms | 93.5% |
| 30 | 100 ms | 99.7 ms | 93.5% |
| 50 | 100 ms | 99.6 ms | 96.8% |
| 30 | 50 ms 3D | 52.2 ms | 90.2% |
| 50 | 50 ms 3D | 51.6 ms | 93.6% |
| 30 | 100 ms 3D | 102.1 ms | 95.3% |
| 50 | 100 ms 3D | 101.9 ms | 96.9% |

结论：

- 修正数据模型后，闭环估计误差约 0–2 ms；
- 估计 age 用于 EKF 后位置改善 86–97%；
- 这是“估计→补偿”闭环有效的直接证据；
- 固件已默认打开 **估计 + 补偿**（`ESTIMATE=1`、`APPLY=1`）；
- 仅在估计有效、sharpness≥0.003、估计新鲜≤5 s、与 15 ms 先验差≤100 ms、且振动不处于高振动状态时替换 age；
- 否则回退 15 ms。

## 5. 对固件的意义

1. 20 ms 门限不是绝对保证，必须保留 15 ms 回退；
2. 估计值应低通/滞回，不能单次直接替换；
3. 高延时/高噪声/大零偏/3D 机动组合应降低置信度；
4. 失锁窗口不提供新量测，估计必须停止；
5. 建议有效门限：
   - `sharpness > 0.005`
   - 连续 N 次估计与当前值差 <20 ms
   - `tau` 限幅 0–150 ms
   - 失锁 >0.5 s 回退
6. 真实振动/多径/杆臂未纳入本数据集，不能外推。
