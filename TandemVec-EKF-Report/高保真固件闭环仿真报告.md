## 二、暴露的问题清单（高保真仿真价值所在）

### 2.1 [真实架构注意点] EKF 重力方向量测假设水平构型，VTOL 悬停下方向错误
- **现象**：悬停构型（机头朝天）比力沿机体 **+x**（≈[g,0,0]），而 EKF 重力方向量测（ekf_15_state.h:2806 `gravity_specific_force_ned=(0,0,-1)`）预测方向 = C^n_b·(0,0,-1)。悬停时该预测 = **(-1,0,0)** 与测量 **(1,0,0)** 符号相反 → 若触发该量测，姿态被强拉 180°。
- **固件对照**：navigation_task.cpp 静止辅助分支**无悬停构型特判**；静止检测的 `|a|≈g` 检查（ins_static_detector.h）无法区分悬停（比力沿 +x）与水平（沿 -z）——两种构型下 |a|=g 都成立。
- **当前为何未实机触发**：悬停时陀螺角速度通常 >0.01 rad/s（气流/桨流扰动）→ 静止检测不确认 → Gravity 不触发。但**完全静止的悬停**（无扰动）满足静止条件时会误触发。
- **建议**：① 静止辅助调度加构型判断（悬停 vs 水平，可用 EKF 姿态的俯仰 |θ|>45° 区分）；② 或重力方向量测改为按当前姿态投影（预测方向始终 = C^n_b·(0,0,-1)，测量方向 = 实际比力，二者在**同一构型**下才一致）；③ 文档显式声明 Gravity 辅助仅适用于水平构型。

### 2.2 [框架适配限制] EKF 垂直通道在悬停构型下高度估计错误
- **现象**：S2 定高发散（位置漂移 9km）、ekf_alt 卡负值而动力学高度正常增长。
- **根因**：ekf_core 的 EKF 为水平构型实现（TiltCompass 水平对准、重力方向量测 g_sf_ned=(0,0,-1)），与悬停动力学构型不匹配——EKF 把悬停比力（沿 x）误判为水平加速度，垂直通道失效。
- **性质**：这是**仿真器适配层**问题（固件用轴置换统一语义），但暴露了"EKF 导航与 VTOL 悬停构型的集成需要显式轴置换"这一真实工程约束。
- **建议**：高保真仿真应统一构型（全部悬停 + 轴置换，或全部水平）；固件侧确认导航输出（AHRS_Packet 欧拉角）在悬停构型下的语义与控制器一致（AGENTS.md 已记录 2026-08-07 轴置换）。

### 2.3 [真实物理] 阵风推离后姿态持续偏（无水平位置控制）
- **现象**：S1 阵风 5s 把飞行器推到 14 m/s 侧移速度，此后 qdist 持续增长（0.3→0.45 rad），|ω| 不恢复。
- **机理**：无水平速度控制时，保持侧向加速度需要持续倾斜——控制律使姿态倾斜与侧向速度自洽，非 bug。若需阵风后回中，需水平速度环（vel_n/vel_e PID，固件已实现但本仿真未接）。
- **建议**：固件定高/悬停模式确认水平位置环接入条件（GPS 有效时）。

### 2.4 [框架确认] GPS 丢失与传感器故障鲁棒性
- **S3**：GPS 丢失 30s 姿态保持（|ω|RMS 0.29），位置漂移 684m（无水平速度约束的预期漂移）——静止辅助+AHRS 回退链路有效。
- **S4a**：加计零偏跳变 1 m/s² 被 EKF 零偏估计吸收（|ω|RMS 0.26，姿态保持）——EKF 零偏可观性设计有效。
- **S4b**：陀螺零偏跳变 0.05 rad/s 引起姿态明显扰动（|ω|RMS 1.86）——陀螺零偏直接影响姿态积分，EKF 收敛前扰动持续，符合预期。

### 3.1 仿真暴露的真实设计注意点（非已触发 bug）

**EKF 重力方向量测的构型假设**是本仿真最有价值的发现：
- 固件 ekf_15_state.h:2806 无条件假设比力沿 NED 上（水平构型）
- 悬停构型（机头朝天）比力沿机体 +x，与该假设差 90°

- 实机未触发是因为悬停总有角速度扰动 → 静止检测挡住；但这是**隐式依赖**，无显式防护

## 五、第二轮严格复查与结论纠正（2026-08-13）

### 5.1 上轮 §2.1 结论**被推翻**：悬停构型下 Gravity 量测方向一致，非 bug

严格数值验证（固件 ekf_15_state.h:2806-2809 逻辑）：
```
预测方向 predicted_dir = C^b_n · (0,0,-1)  （NED 上 → 机体）
悬停构型（机头朝天, q=Rx(90°)）：predicted_dir = [1,0,0]
测量方向 measured_dir = 比力方向 = [1,0,0]
→ 夹角 0°，新息≈0，不会误触发/强拉姿态
```
上轮只看了 `(0,0,-1)` 没算 `C^b_n` 旋转，误判"预测 (-1,0,0) 与测量 (1,0,0) 相反"。**实机无此问题，固件无需改动**。

### 5.2 上轮 §2.2 结论**修正**：发散根因在仿真适配层，非 EKF 垂直通道

严格单步验证（悬停爬升 1.2 m/s²）：
```
比力_ned=(0,0,-11) → 机体=[11,0,0] → EKF 单步 dv_ned=[0,0,-0.006] ✓ 垂直通道正确
```
实际发散根因（全部在仿真适配层，已修）：
1. **init 姿态错**：ekf_core 最小旋转法把悬停 +x 比力解读为"机体倾倒 90°"，需传入悬停姿态并重算零偏
2. **静止检测缺帧间条件**：恒定加速度运动时 |a|≈g 且 |gyro| 小 → 误判静止 → Gravity 把运动比力当重力修正（已补四条件 + 低动态速度门控）
3. **alt_hold 油门映射**：误把 alt_vel 输出当"加速度"而非"油门百分比"（固件语义 ±12.5% 限幅），已修正
4. **高度映射符号**：`alt_up` 双重取反（已修正）
5. **rng 消费时序**：每帧调 gps_measure 改变 GPS 噪声序列使场景不可复现（已改为仅融合帧调用）

### 5.4 仿真暴露的真实边界（记录，非固件 bug）

**长时 EKF 过度自信（40s+）**：简化静止辅助 + 固定 GPS R 下，EKF P 长期收缩至过度自信，GPS 无法纠正，垂直状态冻结 → 定高 40s 后段发散。25s 内稳定（0.5-0.6m）。
- **性质**：仿真简化所致（真实固件有 GNSS 动态权重、重捕获膨胀、协方差稳定化分频、完整静止调度兜底）
- **验证边界**：本仿真用于 25s 内场景的机制验证；长时（>40s）行为需完整固件或实机数据回放确认
- **启示**：固件 GNSS 动态权重（R 随 pDOP/精度变化）与失联膨胀正是对抗此问题的设计——仿真间接验证了其必要性
