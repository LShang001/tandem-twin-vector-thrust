## 一、研究框架

### 1.1 仿真层（`sim/opt/`，新建）

在既有 `ekf_core.py`（15 态 EKF，修复后语义）之上扩展：

- `opt_ekf.py`：变体 EKF（自适应 R/重捕获衰减/气压辅助/H2 航向投影/分离序贯更新/
  航向 P 地板/再锚定）+ 固件语义静止检测器（四条件+迟滞 20/5 帧+置信度 dwell）+
  三档静止辅助分级 + 运动学一致轨迹发生器（yaw/pitch 状态、机体角速度反算、
  悬停平滑减速）+ 场景运行器（指标：分轴 RMSE/NIS/3σ 覆盖/零偏收敛/接受率）。
- 关键保真度修正（相对既有 ekf_core 场景）：
  1. 传感器真值噪声（加计 0.05 m/s²）与 EKF 假设 Q（0.25）分离——Q 标定研究对象；
  2. 静止时 GNSS 速度量测强制=0（固件 navigation_task.cpp:1148-1153 语义）；
  3. ZUPT 残差自适应噪声（固件 ins_static_aid_profile.h 语义）；
  4. 气压辅助 25Hz（固件 `BFS_EKF_BARO_ALTITUDE_UPDATE` 已启用，旧仿真缺失）；
  5. 重捕获窗口计时递减（固件语义）。
- `ekf_core.py` 最小手术：全部门限/系数改为 cfg 可配置（默认=固件现值，行为保持），
  经 `verify.py`/`verify_integration.py`/原 hifi 场景回归确认无行为变化。

### 1.2 场景电池（8 类）

| 场景 | 内容 |
|---|---|
| SC1 静基座对准 120s | 零偏收敛（无 GNSS） |
| SC2 水平巡航 120s | 2s 静止 + 5.1m/s 匀速 + GNSS 10Hz + 双矢量航向 |
| SC3 巡航转弯 90s | 匀速→定常偏航率 0.2 rad/s 协调转弯→匀速 |
| SC4 VTOL 过渡 60s | 静止→俯仰 0→90° 过渡（1 m/s² 加速 12s）→悬停减速→悬停 |
| SC5 失联重捕获 120s | 巡航，30-80s 失联，恢复后 15s 多径（噪声×2.5） |
| SC6 野值 90s | 巡航 + 3 次 25-40m 位置野值 |
| SC7 悬停+震动 60s | 机头朝天悬停（初始化为悬停姿态），80Hz 震动 |
| SC8 传感器故障 60s | 巡航，t=30s 加计零偏跳变 0.8 m/s² |

### 1.3 关键机制（研究过程中建立）

**误静止判定**：匀速水平飞行时 |a|≈g、|ω|≈0、Δa≈0，与真静止在 IMU 上不可区分；
固件静止检测有意不用 GNSS 速度（防噪声漏触发，navigation_task.cpp:732），
因此巡航期静止会"确认"。此时固件行为链：ZUPT（残差 5m/s > 1.5 被残差自适应拒绝 ✓）
→ GNSS 速度强制 0（1148-1153）→ 6 维联合更新新息 5 m/s → NIS≈1100 > 30 →
**位置更新一并被拒** → 位置纯惯导漂移（≈速度×时间）。

**航向弱可观踢动**：F(v,β)=−C^n_b·[f_b]× 中，比力水平分量 f_xy 使 δv 对航向误差
δβ_z 敏感；P(8,v) 按 f_xy·P(8,8) 速率增长，K(8,v)=P(8,v)/S_v ∝ f_x·P(8,8)/Q_a。
P0 航向=π 时，VTOL 过渡（f_xy 峰值 7.8 m/s²）或协调转弯（f_xy≈1 m/s²）期间，
GNSS 速度噪声（σ≈0.15）被增益 ≈1-2 放大为 ±10-25°/epoch 的航向随机踢动；
航向误差 >~9° 后双矢量量测因 NIS 超敏（P(8,8) 已坍缩）全部拒绝 → 航向失锁，
速度积分因比力误投影发散 → GNSS 联合更新失锁 → 位置发散。

## 三、F1 误静止巡航 —— 修复与验证

**修复**（已实施）：GNSS epoch 速度模长 > 1.5 m/s 时强制退出静止
（`Icm45686StaticDetectorReset`）。非对称设计：仅退出不进入，GNSS 噪声不会妨碍
真静止确认；门限 1.5 m/s 与固件 ZUPT 残差自适应拒绝门（>1.5 m/s 不融合）同口径。

|---|---|---|---|

## 四、F2 航向弱可观踢动 —— 根因与缓解

### 4.1 机制定位（插桩证据）

- 过渡起始（t=3.8-4.5s，俯仰 1.5-13°，f_xy 1.3-3.3 m/s²）：GNSS 更新每次注入
  纯体轴 z 旋转 **+12.9/+9.4/−11.9/+19.9/−25.5/−14.5/−9.7°**（滚转/俯仰分量 <0.2°）；
- 此时 P(8, 0:6) 已长到 [0.13, 0.01, 0, 2.56, 0.11, …]（0.24s 内），K(8,v)≈1-2；
- 航向误差超 ~9° 后双矢量量测 NIS 40-380 全部拒绝（P(8,8) 坍缩至量测噪声 0.03²，
  S 过小 → 超敏）→ 失锁。

### 4.2 根因

P0 航向 = π 与确定性伪磁初始化（TiltCompass 伪磁场 (30,0,40)，navigation_task.cpp:694）
语义矛盾（原 LOW-7）：初始航向实际是"伪磁系下的确定航向"，π 的协方差把弱可观
耦合（信息率 ∝ f_xy²/R_v，本身很弱）放大成巨大卡尔曼增益的随机踢动。

### 4.3 修复（已实施）与验证

P0 航向 π → **0.2 rad**（≈11.5°，与确定性初始化语义一致）。

**高保真闭环（单种子，固件控制律+6DOF 动力学）**：

| 场景 | 固件 P0=π | P0=0.2 |
|---|---|---|
| H1 悬停+阵风 | 位置 2499m / 姿态 55.9° | **212.6m / 14.1°** |
| H2 定高 10m | 2882m / 169.5° | **395.6m / 11.6°** |
| H3 GPS 丢失 30s | 6732m / 55.1° | **111.5m / 15.3°** |
| H4 加计零偏跳变 | 4807m / 55.3° | **0.17m / 5.8°** |
| H5 倾斜 20° | 2933m / 56.0° | **388.9m / 12.7°** |

**开环**：SC4 航向 43.8°→18.7°；SC3 5 种子中 4 种子 1.1-1.2m（原 0/5）。

### 4.4 开放问题（记录，不擅自改）

1. **过渡期航向可观测性**的根治方案（显式航向可观测性门控 / 独立的航向子滤波 /
   磁航向接入）需要更深入的工作；当前 P0 修复是"语义修正+损伤抑制"，已把闭环
   姿态误差压到 5-17°，但过渡机动中航向仍会漂移（18.7°@SC4）。
2. 试过的候选（多种子验证为**不稳定**，不推荐）：航向 P 地板 0.05 rad、
   NIS 拒绝后膨胀 R 再锚定、双矢量速度门 1.0→0.5、切断 F(v,β) 航向列（方向错误，
   滤波器会忽视真实耦合导致更差）。

## 五、转弯段速度失控锁死（F2 残余）——回放定性修正

### 5.1 现象与修正后的归因

初版报告曾把转弯场景的偶发发散（2/5 种子 258-333m）归因于"15ms 回放有害"。
追加决定性实验（8 种子，控制变量）后修正归因：

| SC3 转弯（8 种子，age=15ms） | pos_ne RMSE | 分布 |
|---|---|---|
| P0=π + 回放 | 99.2±2.5m | 全种子 97-105（误静止漂移，无失控） |
| P0=0.2 + 回放 | 99.4±2.4m | 同上 |
| **P0=0.2 + 回放 + 静态门控** | **15.7±38.5m** | **7/8 种子 1.0-1.2m，1/8 种子失控 117m** |
| P0=0.2 + 无回放 | 95.3±2.3m | 全种子（误静止漂移，无失控） |

- 失控只出现在"门控 + 回放"组合下，且 P0 修复后概率 2/5 → 1/8；
- 种子追踪（失控种子）：t=0-50 完美（含转弯段），t≈52 速度被踢 ~3 m/s 后**恢复**，
  t≈72 再次被踢 ~9 m/s → GNSS 6 维联合更新 NIS 爆炸 → 速度态永久失锁 → 位置以
  ~30 m/s 发散——**根因是 F2 航向弱可观踢动的残余**（P0=0.2 压幅 ~50 倍但未消除），
  回放只是改变踢动落点/恢复时序的共因，不是独立有害机制。

### 5.2 决策：回放保持，不修改固件

- 固件侧 `DISABLE_GNSS_DELAY_REPLAY=1` 会经 `require_delayed_snapshot=true`
  路径**拒绝全部 GNSS**（宏为纯惯导测试设计），"禁用回放但保留 GNSS"需额外的
  调用点修改，收益不成立；
- 回放无独立危害证据（无门控时 8 种子全部无失控），MED-4"无收益"维持；
- 真正的修复方向是**速度通道鲁棒恢复**（失锁后重锚）与**航向可观测性门控**，
  见 §十开放问题。

## 八、高保真闭环验证小结

- 固件口径（P0=π）5 场景全崩 → P0=0.2 全部恢复（§4.3 表）。
- 闭环剩余误差主要来自无水平位置控制的物理漂移（阵风推离）与过渡瞬态，非导航层。
- 验证了 P0 修复在"EKF 输出驱动控制律"的闭环中的价值：姿态误差 55-170°→5-17°。

- #1：仅影响"静止确认状态下收到大速度 GNSS epoch"的路径——静止被解除、GNSS 速度
  正常融合；不影响解锁/故障保护/输出限幅。最坏情况（GNSS 速度野值 1.5+ m/s 而
  真静止）导致静止辅助暂停 100ms（重新确认需 20 帧），ZUPT 短暂失效，量级可控。
- #2：改变初始航向协方差，影响首分钟航向收敛路径（更信任伪磁初始化）；滚转/俯仰/
  位置/速度通道无影响。双矢量航向与 GNSS 融合正常纠偏。
- #3：ZUPT 增加统计门控一层；固件残差自适应（>1.5 m/s 拒绝）为第一道防线，行为
  不变；静止漂移>4σ 时 ZUPT 拒绝率上升（保护性）。

**仍需上板验证的风险点**：三项均属导航状态估计层，建议实机按"地面静止→系留低功率
→自由飞"分阶段验证；重点观察起飞后航向收敛速度（#2）与静止判定行为（#1）。

## 十、建议与开放问题（研究已收敛，按工程判断处置）

1. **速度通道鲁棒恢复**（F2 残余的根治方向，最高优先级开放项）：转弯/过渡机动中
   航向踢动残余（P0 修复后概率 1/8）使速度估计失锁后，GNSS 6 维联合更新整体拒绝、
   无法重锚。候选：①速度失锁检测（连续 N 次速度新息超限）后对速度通道做保守重锚
   （膨胀 R 或位置/速度分离序贯更新让位置继续融合）；②过渡期航向可观测性显式门控
   （比力水平分量大且航向不确定度高时压低 K(8,v)）。**回放机制维持现状不修改**
   （§五 决策：共因非根因，禁用宏会拒绝全部 GNSS）。
2. **Q 加计噪声标定**（P3）：实测悬停/巡航震动谱后把 `accel_std_mps2` 0.25 收敛到
   0.05-0.15；仿真已给出收益量级（位置 −40%、航向 −60%）。**无实机震动数据前
   维持 0.25 不动**（保守侧安全）。
3. 次要：GNSS NIS 30→45（可选，收益小）；MED-9 静止辅助分频相位（前轮遗留）。
