# 高保真全方位仿真现状（2026-10-21）

## 1. 模型链

`run_scenes_opt.py` / `run_full_envelope.py`：
6DOF 动力学 + 固件控制律（`hifi_core`） → IMU/GNSS/气压/光流传感器
→ 固件语义 EKF（`OptEkf` + 静止辅助 + 双矢量 + 延迟回放/重捕获）
→ 执行器动态 → 6DOF 闭环。

`run_nav_envelope.py`：
同一 6DOF/传感器模型，但**控制器用真值状态**稳定飞行器（导航在环），
EKF 只吃传感器；用于把“导航误差”与“控制振荡”解耦。

## 2. 本轮修复的 hifi 根因

1. **控制轴序错位**：`Dynamics` 的 `omega` 是机体系 `[x,y,z]`
   （x=推力轴/偏航、y=俯仰、z=滚转），旧控制把它当 `[roll,pitch,yaw]`，
   速率环正反馈 → 起飞后滚转/偏航发散。已改为 `[ωz,ωy,ωx]`；
   `q_err` 也按 `[qerr.z,qerr.y,qerr.x]` 映射到 `[roll,pitch,yaw]`。
2. **悬停配平油门**：旧默认 50% 对应 `w0=575`，比 `w_hover=573.996` 高 0.17%，
   60 s 爬升约 60 m；已改 `100*w_hover/wMax≈49.912%`。
3. **`gps_jump` 数组真值判断**：`if fault.get("gps_jump")` 对 numpy 数组抛
   `ValueError`；已改 `if "gps_jump" in fault`。

| A6 GNSS 跳变 | 4.21 m | 0.55° | 0.05 m | PASS |

| A9 长时悬停 | 0.08 m | 0.64° | 0.06 m | PASS |

**根因修正**：此前 A0/A9 的 3–4 m“静止漂移”不是 EKF，而是**真值控制器把
`gyro_bias_true` 又减了一次**：`omega_body` 已是真值角速率，控制器再减真实零偏，
等于给速率环注入 -bias，导致真值姿态/位置慢漂。把真值控制器的 `gyro_bias`
置零后，A0/A9 降到 **0.08 m**，A3 0.04 m。这是**测试框架 bug**，不是导航改进。
另一个 bug 是 `opt_ekf.measurement_update_baro` 把 `alt_est` 写成 `-(lla-home)`
且 H 符号反，导致 F1 高度发散；修正后 F1 alt_err **0.07±0.01 m**。

**仍然不能写成全阶段通过**：
- A8_yaw90 仍移除（`yaw_lock`/`q_target` 目标不成立）；
- A5 姿态误差 9.35° 仍偏大；
- 未覆盖 90° 偏航、巡航、过渡；
- 闭环（EKF 进控制）仍是 10/10 FAIL。

**可用结论**：A0–A7/A9 的导航链在 6DOF 真值闭环下表现正常；A5 姿态、
A8 目标定义仍需修。**不能把 9/9 诊断写成“全方位通过”。**

  AnoVars 增加 `afm_sjam/afm_tloss/afm_desc` 三个只读遥测量。
